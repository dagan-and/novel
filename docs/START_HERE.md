## 새 HTML 세계관·게임형 소설

《완전한 두 번째 삶》(가제)의 [프로젝트 안내](../second-life/README.md)에서 이어갑니다. 각 편의 김용식은 2005년 1월 1일에 회귀합니다. 편별 사건과 진행은 월 단위로 쌓습니다. 첫 작업은 [투자 편의 2005년 1월](../second-life/series/investing/months/2005-01.md)입니다. 해당 월의 후보 장면과 조사 목록을 읽고 이어갑니다.

HTML로 월별 진행 상황을 보려는 방향은 유지합니다. 화면에서 이야기를 직접 진행할지, 채팅 진행 결과를 기록한 현황판으로 쓸지는 미정입니다.

`immortal-game/`에는 상태·사건·기술 트리 JSON을 HTML 현황판으로 만드는 코드가 있고, `baekje-world-conquest/`에는 턴 기록을 HTML 연대기로 만드는 코드가 있습니다. 참고 자료이며 새 프로젝트의 세계관이나 규칙을 결정하지는 않습니다.

### GitHub Pages와 접근

GitHub Pages는 정적 HTML 게시 후보입니다. 웹페이지 자체에서 AI 진행이나 기기 간 상태 저장까지 원하면 별도 설계가 필요합니다. 채팅에서 진행하고 HTML을 갱신하는 방식과 구분해 설명하세요.

GitHub에 파일이 있다는 것만으로 Pages 게시가 확인되지는 않습니다. 실제 설정·배포·응답을 확인하고, 확인된 접속 주소를 제공합니다. 배포 후에는 같은 주소로 갱신 내용을 볼 수 있으나 반영에 시간이 걸릴 수 있습니다.

## 이번 정리에서 한 일

2026-11-18 기준:

- 루트 `README.md`: 전체 프로젝트와 시작 위치 정리.
- 루트 `AGENTS.md`: 새 세션이 작업 대상을 찾고 프로젝트별 지침을 읽도록 안내.
- `docs/START_HERE.md`: 시작 문장, 새 프로젝트 구상, 미정 사항과 다음 행동 기록.
- 기존 작품·폴더·경로·HTML·실행 코드는 유지.

위 목록은 최초 정리 작업의 내역입니다. 새 작품의 최신 작업 상태는 프로젝트 안내에서 확인하세요.

## 환경 관련 참고

앞선 환경 설정 과정에서 Python 3.12 기반의 백제 HTML 생성기 테스트 4개, 실제 데이터 10턴 생성, 로컬 HTTP 콘텐츠 확인이 통과했습니다. 이는 당시 인스턴스의 검증 결과이며 새 세션의 상태를 보장하지 않습니다.

당시 재사용 시작 지침의 환경 설정 저장은 ASB에서 거부되었습니다. 이 저장소 문서는 환경 설정 저장·게시의 완료를 의미하지 않습니다. 새 세션에서는 체크아웃과 도구, 필요한 프로세스의 상태를 확인하세요.
