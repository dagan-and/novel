# 핵심 컨셉

## 한 줄 컨셉

김시안이 자주 드나드는 생활권마다 그를 짝사랑하는 여자가 있고, 한 편 안에서 그 마음이 핑계와 소품을 통해 드러나는 독립 단편 로맨스.

## 기본 약속

- 각 편은 독립 단편이다.
- 파일 번호는 정렬용이며, 관계 진도는 이어지지 않는다.
- 히로인은 시작 시점부터 시안을 좋아하고 있다.
- 시안은 그 마음을 바로 확신하지 못하고, 장면 안에서 뒤늦게 알아차린다.
- 외형 설정은 캐릭터 파일의 `### 외형`을 그대로 따른다.
- 장면은 생활권의 소품과 행동으로 움직인다.

## 히로인별 기본 축

- 박미현: 자주 가는 카페 알바 / 컵 메모 / 창가 자리 / 마감 후 시간
- 유하린: 학교 후배 / 길 안내 / 포스트잇 / 비 오는 귀가길
- 서나윤: 자주 가는 편의점 알바 / 영수증 / 폐기 간식 / 야간 교대
- 정다은: 직장 동료 / 수정 요청 / 회의록 / 탕비실 / 야근
- 이재인: 인턴 동기 또는 프로젝트 동료 / 물, 간식, 자리 잡기 / 회사 로비
- 최윤서: 사진관 알바 / 증명사진 / 재촬영 / 사진 봉투 / 빠진 컷

## 단편 엔진

```text
시안의 회피 또는 생활 곤란
↓
히로인의 사소한 핑계와 접근
↓
시안이 호감을 장난으로 넘기려 함
↓
생활 소품 때문에 마음이 들킴
↓
시안의 작은 선택
↓
사건은 닫히고 관계는 여운으로 남음
```

## 성인씬 운영

- 성인씬은 작품의 결말 후보 중 하나다.
- 직접 묘사보다 성인씬 컨텍스트 구역으로 기록한다.
- 성인씬이 없어도 스킨십 직전, 질투, 다음 약속, 남겨진 물건으로 관계 진도 체감을 남긴다.
