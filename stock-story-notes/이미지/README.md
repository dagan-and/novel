# 이미지 폴더

이 폴더에는 인물별 이미지가 하위 폴더로 나뉘어 저장되어 있다.

## 인물별 폴더

- `김가영(20)`
  - 2008년 1-2월 수지/수지고 졸업생 이미지.
  - 귀엽고 발랄한 강아지상, 니트와 악세사리 중심.

- `장윤정(20)`
  - 2008년 1-2월 풍덕고 졸업생 이미지.
  - 빨간 코트, 세련된 고양이/뱀상, 새침한 분위기.

- `이재인(20)`
  - 2008년 1-2월 서원고 졸업생 이미지.
  - 작은 키, 귀엽고 블링블링한 첫사랑 느낌.

- `사쿠라이 미사키(25)`
  - 2024년 결혼 시점의 미사키 이미지.
  - 가나자와 출신 일본 여성, 단정하고 여성스러운 분위기.

## 참고

GitHub에서 `이미지` 폴더가 비어 보이면, 위 하위 폴더를 클릭해서 확인하면 된다. macOS의 한글 파일명 표시 방식 때문에 터미널이나 일부 UI에서 경로가 어색하게 보일 수 있지만, PNG 파일들은 Git에 포함되어 있다.
