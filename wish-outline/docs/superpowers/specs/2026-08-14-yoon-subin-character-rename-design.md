# 윤수빈 캐릭터 리네임 설계

## 목표

기존 캐릭터를 윤수빈으로 변경하고, 사용자가 제공한 외형 설정과 용식과의 관계 설정을 캐릭터 원본, 프로필 JSON, 생성된 outline 참조에 일관되게 반영한다.

## 범위

- `characters/<기존이름>.txt`를 `characters/윤수빈.txt`로 변경한다.
- `profiles/김민정.json`을 `profiles/윤수빈.json`로 변경한다.
- `prompts/outline.txt`의 예시 캐릭터명을 윤수빈으로 바꾼다.
- 기존 이름으로 등장하는 기존 outline 파일의 이름, 호칭, 캐릭터 프로필 블록, 생성용 id를 윤수빈 기준으로 동기화한다.

## 캐릭터 캐논

윤수빈은 2004년생, 2026년 기준 연나이 22세, 157cm/45kg의 작은 체구를 가진 e스포츠 아나운서/게임 행사 진행자다. 얼굴은 작고 또렷한 둥근 계란형이며, 큰 눈과 얇은 속쌍, 살짝 올라간 눈꼬리, 원래부터 조금 올라간 입꼬리가 핵심 인상이다. 헤어는 차분한 애쉬브라운 롱헤어이며 무대에서는 높은 포니테일을 주로 쓴다.

용식은 방송국 PD이자 수빈의 직장 선배다. 접점은 e스포츠 중계, 방송국 스튜디오, 대기실, 리허설, 경기 후 인터뷰, 게임 행사 뒤풀이로 잡는다.

## 검증

수정 후 `rg "<old-name>|<old-short-name>|<old-id>"`로 구이름 잔여를 확인하고, `python3 -m json.tool profiles/윤수빈.json`로 JSON 형식을 검증한다.
