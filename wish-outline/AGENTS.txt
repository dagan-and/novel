# Repository Instructions

이 저장소는 소설 본문이 아니라 성인 장면 개요 생성을 위한 설정과 참고 자료를 관리한다.

## 기본 작업 원칙

- 개요를 만들거나 수정할 때는 먼저 `00_core/성인씬_개요_작성_기준.txt`를 읽고 그 우선순위를 따른다.
- 기본 작업 단위는 앞뒤 화와 이어지지 않는 독립 성인 장면 개요다.
- 기존 화별 개요 본문(`05_outline/`)은 기본 입력으로 읽지 않는다.
- `03_story_state/`, `04_tracking/`, `02_characters/관계_요약표.txt` 갱신은 사용자가 연속성 반영을 명시적으로 요청한 경우에만 한다.
- 이름, 호칭, 말투는 인물 설정을 참고하되, 성관계 횟수, 의심도, 열린 거짓말, 단서 누적은 독립 장면에서는 맞추지 않아도 된다.
- 모든 장면은 성인 간 명확한 상호 동의를 전제로 한다.

## 수정 범위

- 고정 규칙은 `00_core/`
- 세계관과 생활 동선은 `01_world/`
- 인물별 설정은 `02_characters/`
- 현재 시점, 열린 사건, 정보 공개 상태는 `03_story_state/` (연속성 요청 시 참고)
- 거짓말과 단서는 `04_tracking/` (연속성 요청 시 참고)
- 화별 개요는 `05_outline/` (연속성 요청 시 참고)

## 검증

개요나 설정을 수정한 뒤에는 `rg`로 오래된 기준 파일명, 어색한 조사, 독립 장면 원칙과 충돌하는 상태 갱신 의무가 남았는지 확인한다.
