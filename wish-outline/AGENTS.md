# Repository Instructions

이 저장소는 소설 본문이 아니라 집필용 설정, 상태, 화별 개요를 관리한다.

## 기본 작업 원칙

- 개요를 만들거나 수정할 때는 먼저 `00_core/개요_작성_기본파일.txt`를 읽고 그 우선순위를 따른다.
- 기존 화별 개요 본문(`05_outline/`)을 기본 입력으로 많이 읽지 않는다. 개요는 작성 후 `03_story_state/`, `04_tracking/`, `02_characters/관계_요약표.txt`에 반영된다는 전제로 작업한다.
- 화별 개요 본문은 직전 장면의 장소, 대사, 소품, 감정 연결이 꼭 필요하거나 상태 문서와 충돌이 의심될 때만 제한적으로 확인한다.
- 새 개요를 확정하거나 기존 개요를 바꾼 뒤에는 관련 상태 파일도 함께 갱신한다.
- 이름, 호칭, 말투, 성관계 횟수, 의심도, 열린 거짓말과 단서는 설정 파일과 상태 파일을 기준으로 맞춘다.

## 수정 범위

- 고정 규칙은 `00_core/`
- 세계관과 생활 동선은 `01_world/`
- 인물별 설정은 `02_characters/`
- 현재 시점, 열린 사건, 정보 공개 상태는 `03_story_state/`
- 거짓말과 단서는 `04_tracking/`
- 화별 개요는 `05_outline/`

## 검증

개요나 설정을 수정한 뒤에는 `rg`로 오래된 이름, 어색한 조사, 모순되는 선물/호칭/의심도 표기가 남았는지 확인한다.
