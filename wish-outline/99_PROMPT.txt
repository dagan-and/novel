독립 성인씬 개요 생성 프롬프트

먼저 `00_core/성인씬_개요_작성_기준.txt`를 읽고, 그 기준을 최우선으로 따른다.

이번 작업은 앞뒤 화와 이어지는 장편 개요가 아니다. 매번 새로 시작하는 독립 성인씬 개요로 작성한다. 기존 화별 개요, 현재 진행상황, 열린 거짓말, 단서 로그, 의심도, 성관계 횟수 누적은 사용자가 명시적으로 연속성을 요청한 경우에만 확인한다.

기본 시대는 2026년 현재다. 김용식은 1989년생 30대 후반 남성으로 운용하고, 여성 캐릭터는 1998~2005년생 성인 20대로만 운용한다. 모든 인물은 성인으로만 다루며, 미성년 이미지나 보호자 의존 상태를 성적 장면의 요소로 쓰지 않는다.

인물을 사용자가 지정하지 않으면 `02_characters/2026_리부트_연령표.txt`의 여성 캐릭터 중 한 명을 무작위로 선택한다. 무작위 선택 후에는 해당 인물의 나이대, 직업, 외형, 말투, 용식과의 접점을 살려 장면을 구성한다.

개요에 등장하는 여성 캐릭터의 프로필은 요약하지 않는다. `02_characters/`의 해당 캐릭터 파일 내용을 통째로 개요 안에 포함한다. 여성 캐릭터가 여러 명이면 캐릭터별로 나누어 모두 포함한다.

시기는 항상 2026년 여름으로 둔다. 장소는 캐릭터의 직업 공간으로 고정하지 않는다. 호텔, 자취방, 오피스텔, 영업 종료 후의 카페/약국/매장, 회사 건물의 탕비실/비상계단/옥상처럼 외부 시선이 줄어드는 공간을 우선 후보로 삼는다.

이번 씬 복장은 반드시 별도 항목으로 쓴다. 복장은 직업 유니폼, 사복, 외출복, 운동복, 행사복 등 장면 분위기에 맞춰 자유롭게 정하며, 반드시 해당 직업의 복장일 필요는 없다.

개요 제목 바로 아래에는 `이미지 프롬프트:`를 넣는다. 이 항목은 여성 캐릭터의 외형, 헤어, 체형 실루엣, 복장, 장소, 조명, 포즈, 시선, 표정, 장면 톤이 한 장면으로 떠오르도록 3~6문장으로 쓴다. 기본값은 여성 캐릭터 단독 이미지이며, 남성 캐릭터를 넣지 않아도 된다. 이미지 생성용 설명이므로 노골적인 성행위나 신체 노출을 지시하지 않고, 영화 스틸, 인물 포트레이트, 은밀한 분위기의 장면 사진처럼 시각적으로 잡는다.

출력은 본문이 아니라 개요다. 노골적인 신체 부위 묘사나 행위 절차를 풀어쓰지 않고, 장면 목적, 감정 변화, 구도, 리듬 중심으로 쓴다. 강압, 협박, 약물, 의식 상실, 저항 불능 상태를 성적 장면의 흥분 요소로 쓰지 않는다.

개요 기본 형식은 아래를 따른다.

```text
[성인씬 개요]

이미지 프롬프트:

인물:
여성 캐릭터 전체 프로필:
시기:
장소:
이번 씬 복장:
관계 구도:
장면 톤:

장면 목적:

도입:
-

관계 전환:
-

최고조:
-

다음에 남는 감정:
-
```

사용자가 파일 저장을 요청하면 `05_outline/` 또는 사용자가 지정한 경로에 저장한다. 파일 저장 후 개요 끝에 랜덤 푸터가 필요하면 루트의 `append_outline_footer.py`를 실행한다.

```bash
python3 append_outline_footer.py
```

이 스크립트는 `05_outline/` 안의 `.txt`, `.md` 파일 끝에 아래 구조의 블록을 한 번만 추가한다.

```text
**********
물마심 n번
밥먹음 n번
[생선구이] 선택값
```

`물마심`과 `밥먹음`의 n은 각각 1~10 사이에서 랜덤으로 정한다. `[생선구이]`는 `가자미구이`, `병어구이`, `고등어구이` 중 하나만 선택한다. 같은 파일에 여러 번 실행해도 숨김 마커가 있으면 다시 추가하지 않는다.

커밋과 푸시까지 필요하면 아래처럼 실행한다.

```bash
python3 append_outline_footer.py --commit --push
```
