개요 생성 운영 프롬프트

이 프로젝트의 생성 규칙은 `generate_outlines.py`와 `profiles/*.json`을 기준으로 한다.
등장인물의 원본 설정은 `characters/<이름>.txt`에서 읽으며, 생성 결과는 `outlines/`에 저장한다.

구성 원칙:

1. 모든 등장인물은 성인이며 장면은 명확한 상호 동의를 전제로 한다.
2. 기본 시기는 2026년 여름이다.
3. 캐릭터의 직업, 성격, 외형, 말투를 해당 캐릭터 파일에서 가져온다.
4. 캐릭터 전용 JSON이 있으면 그 JSON의 `events`를 우선 사용한다.
5. 하나의 이벤트 안에서 `place`, `weather`, `pressure`는 고정한다.
6. `start`, `turn`, `after`는 같은 `arcs` 항목 안에서 함께 선택한다.
7. `outfit_pool`과 `hair_pool`만 같은 이벤트 범위에서 변주한다.
8. 다른 장소의 소품, 인력, 동선을 섞지 않는다.
9. 결과 파일명은 `001화.txt`, `002화.txt`, `100화.txt`처럼 세 자리 숫자를 사용한다.

실행 명령:

```bash
python3 generate_outlines.py 10
python3 generate_outlines.py 10 --character 윤수빈
python3 tools/append_footer.py
python3 tools/remove_footer.py
python3 tools/push_outlines.py
```

첫 번째 숫자는 생성할 개요 수다. JSON 프로필이 있는 캐릭터만 기본 생성 대상이 되며,
현재처럼 `profiles/윤수빈.json` 하나만 있으면 요청한 모든 화가 윤수빈으로 생성된다.
요청 범위 뒤에 이미 존재하는 개요 파일은 자동으로 삭제하지 않는다.

캐릭터 전용 장면을 추가할 때는 캐릭터 파일과 같은 이름으로 JSON을 만든다.
예: `characters/윤수빈.txt`와 `profiles/윤수빈.json`.
별도의 파일명 등록은 필요하지 않다.
