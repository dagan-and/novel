# 열린 스레드

이 파일은 113화 종료 시점(2009년 1월 23일 금요일 밤) 기준이다.

## 즉시 이어갈 사건 (114화 이후)

- 세연은 반지 물증을 잃었지만 수진 개입을 상당히 의심한다. 113화에서 은지의 알바 카페를 다시 찾아 직접 폭로 없이 "요즘 용식이 많이 바쁘죠?"라는 애매한 말로 은지를 흔들었다.
- 은지와 용식은 조건부 화해 상태다. 은지는 110화에서 한나영 연락을 "학과 친구 정산"으로 둘러댄 용식의 휴대폰 반응을 기억하고, 113화에서 세연 카페 재방문과 용식의 선제 전화를 연결해 더 조용히 의심하게 됐다.
- 유진은 111화에서 반지 한쪽 이야기를 다시 꺼냈다. 용식은 여전히 모르는 척했고, 유진은 관계 정의 요구에 대한 답도 아직 못 들었다.
- 민정은 111화에서 유진의 반지 분실 이야기를 처음 들었다. 용식-유진 관계를 알고도 침묵하는 공범 위치는 유지되지만, 질투와 확인 욕구가 커졌다.
- 수진은 109화에서 세연이 자신을 의심한다는 것을 알았다. 용식이 다시 자신에게 바로 전화했다는 사실 때문에 이용당하는 걸 알면서도 더 묶였다.
- 한나영은 112화에서 두 번째 만남을 가졌고, 반말/호칭이 확정됐다. 돈과 고급 호텔에 끌리지만 자기 속도를 지키며 선을 그었다.

## 다음 개요를 짤 때 먼저 정해야 할 것

- 은지가 세연 카페 재방문과 용식의 선제 전화를 가지고 용식을 어떻게 시험할지.
- 용식이 세연을 막기 위해 직접 만나러 갈지, 수진을 다시 끌어들일지.
- 한나영의 다음 연락/선물이 은지에게 보일지, 혹은 아무도 모른 채 관계 가능성만 커질지.
- 민정이 유진의 반지 이야기를 어떻게 기억하고, 용식에게 다시 꺼낼지.
- 유진이 관계 정의 요구를 다시 할지, 반지 문제를 더 구체적으로 캐물을지.
- 수진이 세연과 직접 연락해 진정시키거나 오히려 오해를 키울지.

## 해결된 사건 (61-103화에서 처리 완료)

- 세연과의 단독 만남, 첫 성관계, 반지 발견, 정기적 패턴 형성, 반지 카드의 격상(말로 언급 -> 직접 캐묻기 -> 구체적 요구/기한 -> 기한 만료 후 예고 없는 행동 -> 은지와의 직접 대면 -> 물리적 증거 요구 -> 명시적 위협) -> 62, 69, 70, 72, 74, 78, 82, 84, 87, 96, 103화.
- 수진과의 마지막 만남과 관계 종료 -> 66화. 완전 퇴장으로 확정하지 않음 -- 나중에 우연히 재회할 여지는 열어둔다(구체적 계기·시점 미정).
- 유진과의 세 번째 관계와 반지 분실 -> 65화. 본인 인지 -> 73화. 관계 정의 요구 -> 81화. 네 번째 관계와 감정적 진심 노출 -> 85화. 민정에게 상담, 신년 모임 근접 -> 95, 98화. 반지 분실 본인 자각 -> 101화.
- 은지의 의심 진행: 0단계 -> 8단계(물증, 67화) -> 심증 대상 구체화(세연, 75화) -> 직접 목격(77화) -> 물증 질적 강화(79, 80, 83화) -> 세연의 카페 방문(84화) -> 세연과 직접 대면(87화) -> 스스로 데드라인 결심(89화) -> 크리스마스에 하루 유보(93화) -> 사진 확보(94화) -> 흔적 발견 및 물증 완성(97화) -> 실제 대면 준비(98화) -> 사진 대면과 거리두기 선언(99화) -> 조건부 화해(102화).
- 은지의 정면 추궁과 냉전, 표면적 화해와 재균열, 용식이 먼저 다가가 관계 회복 시도, 시험하는 밤, 갈등 없는 크리스마스, 능동적 함정, 정면 대면, 화해 거래 -> 67, 68, 72, 75, 80, 88, 93, 94, 99, 102화.
- 민정과의 스타크래프트 친선전 실제 진행, 유진과 첫 직접 대화, 싸이월드 모순 발견, 어색한 반응 확인, 유진의 무심코 실토, 직접 목격, 이름 확정, 폭로 대신 접근 결심, 직접 고지, 첫 관계, 유진의 상담 대응, 신년 모임 근접 위험, 내적 회의 자각 -> 71, 73, 76, 81, 83, 86, 89, 90, 91, 92, 95, 98, 101화. 의심도 0단계 -> 8단계, 관계는 실제로 시작됨(성관계 1회).
- 냉전 중 세연과의 여섯 번째 관계(용식의 자기합리화, 세연의 계산된 위로) -> 100화.
- 수진 재등장, 7번째 관계, 반지 회수 성공, 세연의 반지 실종 인지 -> 104, 105, 106, 107화.
- 새 얼굴 한나영 등장과 연락처 교환 -> 108화.
- 세연의 반지 상실 후 첫 추궁, 수진 경고 전화 -> 109화.
- 은지와 조건부 화해 일상, 한나영 연락을 학과 친구 정산으로 둘러댐 -> 110화.
- 학원 축에서 유진의 반지 이야기 재등장, 민정이 이를 기억함 -> 111화.
- 한나영 두 번째 만남, 반말/호칭 확정, 고급 호텔 라운지 앞에서 멈춤 -> 112화.
- 세연의 은지 카페 재방문과 용식의 선제 전화 -> 113화.
