# 의심도 현황판

`00_core/에피소드_개요_양식.md` 3번 항목의 공통 척도(0~8단계)를 기준으로, 인물별 현재 의심 단계를 여기서 관리한다.

새 화를 쓰기 전에 반드시 이 파일에서 시작 단계를 확인하고, 화 완성 후 여기를 갱신한다. AI가 화 하나 안에서 임의로 여러 단계를 건너뛰지 못하게 하는 것이 목적이다.

## 공통 척도 (참고용)

```text
0단계: 전혀 의심하지 않음
1단계: 설명할 수 없는 이물감만 느낌
2단계: 사소한 단서를 기억하기 시작함
3단계: 확인 질문을 함
4단계: 특정 인물을 의심하기 시작함
5단계: 거짓말 가능성을 의식함
6단계: 직접 확인 행동에 들어감
7단계: 상당한 확신
8단계: 물증 또는 직접 목격
```

| 김은지 | 용식이 다른 여자와 얽혀 있을 가능성 | 8단계 (물증) 유지, "거리두기 선언" -> "조건부 화해"로 전환 | 99화에서 사진을 직접 꺼내 정면 대면했고, 용식의 절반의 시인/부인이 뒤섞인 해명 끝에 "당분간 만나지 말자"고 선언했다. 102화에서 용식의 화해 시도를 받아들이되 "이번이 마지막"이라는 명시적 조건을 걸며 관계를 재개했다 | 102화 |
| 최유진 | 단풍 여행 때 용식이 거짓말했을 가능성 + 반지 분실 자각(신규) | 2단계 -> 3단계 | 101화에서 반지 한쪽이 없어진 것을 처음 자각하고 "그날 이후로 못 본 것 같다"는 구체적 기억의 실마리를 갖게 됐다. 다만 반지의 실제 행방(세연 보관)은 여전히 모른다 | 101화 |
| 이수진 | (관계 종료, 서울 취업) | 4단계에서 고정 | 66화로 공식 관계는 종료됐지만 완전 퇴장 아님. 용식과 무관한 독립적인 이유(세연 등 기존 친분 방문, 개인 용무)로도 재등장 가능하며, 그 과정에서 육체적 재회나 갈등 개입으로 이어질 수 있다. 재등장 시 기능(단서 노출/제거, 오해 형성/해소, 갈등 심화/중재)은 고정하지 않는다(`02_characters/이수진.md` "서울행 이후" 참고). 구체적 시점·계기는 미확정 | 66화 |
| 김민정 | 용식과 유진이 실제로 은밀한 관계일 가능성 | 8단계 (물증/직접 목격, 이름까지 확정) 유지 | 101화에서 학원 축 내부 근접 위험을 겪은 이후 처음으로 "이 관계를 계속 이어가는 게 맞나" 하는 내적 회의를 느끼기 시작했다(승부욕·흥미에서 다른 무게가 실리는 감정으로) | 101화 |
| 박세연 | (정보 우위자/공범, "카드"가 "명시적 위협"으로 격상) | 해당 없음 (독자적 의심 단계 대신 "카드 상태"로 관리) | 100화에서 은지와 냉전 중인 용식과 여섯 번째 관계를 가지며 권력 우위를 확신했으나, 103화에서 용식의 달라진 태도(은지와의 화해)를 감지하고 반지 존재와 은지 접촉 가능성을 처음으로 명시적 위협으로 꺼냈다 | 103화 |

## 세연의 "카드" 보유 현황 (별도 관리)

- 보유 물건: 유진의 반지 한쪽.
- 세연이 아는 것: 은지 외에 최소 한 명(정체 불명)이 더 있다는 것. 은지의 얼굴을 84화에서 직접 확인했다. 103화에서 용식과 은지가 다시 가까워졌다는 것을 심증으로 확신했다(직접 목격은 아님).
- 세연이 모르는 것: 그 여자가 누구인지(유진이라는 이름, 학원 스터디 관계 등). 은지가 12월 27일 저녁 자리를 사진으로 확보했다는 것. 12월 31일 자신이 남긴 흔적이 이미 발견되고 해명까지 오갔다는 것. 1월 3일 은지·용식 사이의 정면 대면과 거리두기 선언, 1월 10일 조건부 화해의 구체적 내용.
- 진행 상태: 69화(확보, 침묵) -> 74화(말로 언급) -> 78화(직접 캐묻기) -> 82화(구체적 요구, 명시적 기한 확정) -> 84화(기한 만료, 카페 방문) -> 87화(은지와 직접 대면) -> 96화(물리적 증거 요구, 흔적 실제로 남김) -> 103화(반지 존재 재언급 + 은지 접촉 가능성을 처음으로 명시적 위협으로 꺼냄).
- 아직 결정되지 않은 것: 세연이 실제로 은지에게 연락할지, 반지를 실제로 꺼내 쓸지. 104화 이후 개요에서 먼저 결정하고 시작한다.

## 민정의 "선택" 상태 (별도 관리)

- 아는 것: 용식과 유진이 실제로 얽혀 있다는 것(8단계 확정). 관계의 정확한 성격(섹파 여부)까지는 모른다.
- 선택: 89화에서 확정된 확신을 폭로가 아니라 접근의 계기로 쓰기로 결심(90화). 91화에서 용식에게 직접 안다고 밝히되 침묵을 약속했고, 92화에서 실제 관계로 진전됐다. 95화, 98화에서 유진의 상담과 근접 위험에 대응했다. 101화에서 처음으로 "이 관계를 계속 이어가는 게 맞나" 하는 내적 회의를 느끼기 시작했다 -- 단순한 흥미·승부욕을 넘어서는 감정으로 번지고 있다는 것을 스스로 자각했다.
- 아직 결정되지 않은 것: 학원 축 내부(유진과의 물리적 근접)에서 발생하는 위험을 계속 어떻게 관리할지, 그리고 스스로 자각한 감정 변화를 어떻게 할지. 104화 이후 개요에서 필요 시 정한다.

## 다음 화(104화)에서 허용되는 범위

- 김은지: 8단계(숫자) 유지. "조건부 화해" 상태 -- 세연 문제가 재발하면 "이번이 마지막"이라는 조건이 실제로 시험대에 오를 수 있다.
- 김민정: 8단계(물증+이름 확정) 유지, 내적 회의가 생긴 상태. 이 감정을 어떻게 다룰지 다음 개요에서 정한다.
- 박세연: 103화에서 반지 존재와 은지 접촉 가능성을 명시적 위협으로 꺼냈다. 실제로 실행할지(반지를 쓰거나 은지에게 연락하는 것)를 다음 개요에서 먼저 정한다.
- 최유진: 101화에서 반지 분실을 자각했지만 행방은 모른다. 반지의 실제 행방(세연이 가지고 있다는 것)을 알게 되는 시점은 아직 미정. 81화의 관계 정의 요구에 대한 답도 아직 미해결. 민정-용식 관계의 존재도 여전히 모른다.
- 이수진: 관계 종료. 회상/언급으로만 등장 가능. 우연한 재회 자체는 배제하지 않지만, 뚜렷한 계기 없이 임의로 등장시키지 않는다.
