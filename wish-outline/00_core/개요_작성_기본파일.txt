# 개요 작성 기본파일

다음 5개 화의 큰 흐름이나 개별 화 개요를 만들 때는 화별 개요 본문보다 설정 파일, 캐릭터 파일, 세계관 파일, 현재 상태 파일을 우선한다. 이 파일은 토큰을 아끼면서도 세계관과 인물 설정을 놓치지 않기 위한 기본 읽기 순서다.

## 기본 전제

- `05_outline/`의 개요 본문은 매 화 확정 후 상태 문서에 반영된다.
- 따라서 다음 개요를 만들 때는 지나간 개요 본문을 반복해서 많이 읽지 않고, 최신 상태 문서와 설정 파일을 기준으로 판단한다.
- 단, 상태 문서가 모든 장면의 말맛과 직전 장소까지 보장하지는 않는다. 직전 장면에서 바로 이어지는 대사, 장소, 소품, 감정의 연속성이 중요할 때만 필요한 최근 화수 개요를 제한적으로 확인한다.
- 큰 흐름을 먼저 제안하고 사용자 확인을 받은 뒤 세부 개요로 들어간다.

## 1차 필수 입력

다음 파일은 개요 판단 전에 먼저 확인한다.

1. `00_core/작품_핵심.txt`
2. `00_core/집필_절대규칙.txt`
3. `00_core/에피소드_개요_양식.txt`
4. `03_story_state/현재_진행상황_2009-01-23.txt`
5. `03_story_state/열린_스레드.txt`
6. `03_story_state/정보_공개_현황.txt`
7. `03_story_state/의심도_현황.txt`
8. `02_characters/관계_요약표.txt`
9. `04_tracking/거짓말_로그.txt`
10. `04_tracking/단서_흔적_로그.txt`

## 2차 선택 입력

이번 흐름에서 실제로 중심이 되는 인물과 생활권만 추가로 확인한다.

- 용식의 돈, 선물, 호텔, 미래정보 판단이 필요하면 `01_world/돈과_미래정보.txt`와 `02_characters/김용식.txt`
- 학교, 야구부, 학원, 카페, 평택/수원/서울 이동이 중요하면 `01_world/대학생활과_동선.txt`와 `01_world/인물별_생활권.txt`
- 특정 인물이 직접 등장하거나 관계가 변하면 해당 `02_characters/[이름].txt`
- 새 성인씬, 말투 전환, 관계 단계 변화가 있으면 해당 인물의 `성인 특성`, 호칭, 피임 여부, 최근 관계 이력
- 세연의 압박, 은지의 시험, 민정의 관찰, 유진의 반지, 수진의 공범 위치, 서지수의 거래 관계처럼 특정 스레드가 중심이면 관련 캐릭터 파일과 로그

## 화별 개요 본문을 확인하는 경우

`05_outline/`는 기본 입력이 아니라 예외 입력이다. 아래 경우에만 필요한 화수만 확인한다.

- 직전 화 마지막 장소와 다음 화 시작 장소의 충돌을 피해야 할 때
- 바로 이어지는 대사, 문자, 전화, 소품, 선물, 신체 흔적의 표현을 정확히 맞춰야 할 때
- 상태 파일과 로그가 서로 맞지 않거나 누락이 의심될 때
- 사용자가 특정 화수의 장면을 직접 이어달라고 했을 때
- 개요 수정 작업처럼 해당 화수 자체를 고쳐야 할 때

## 판단 순서

1. 최신 기준 시점과 종료 상태를 `03_story_state/현재_진행상황_2009-01-23.txt`에서 잡는다.
2. `03_story_state/열린_스레드.txt`에서 다음 5화에 걸릴 압력을 고른다.
3. `02_characters/관계_요약표.txt`에서 호칭, 관계 단계, 성관계 횟수, 현재 관계 압력을 확인한다.
4. `03_story_state/정보_공개_현황.txt`과 `03_story_state/의심도_현황.txt`에서 누가 무엇을 알고, 무엇을 모르는지 확인한다.
5. `04_tracking/거짓말_로그.txt`와 `04_tracking/단서_흔적_로그.txt`에서 회수할 것, 묻어둘 것, 새로 만들면 위험한 것을 나눈다.
6. 중심 인물의 캐릭터 파일을 열어 외모, 말투, 욕망, 두려움, 성인 특성, 이동권을 확인한다.
7. 큰 흐름을 먼저 제안하고, 사용자 확인 후 개별 화 개요를 작성한다.
8. 개요 확정 후 `03_story_state/`, `04_tracking/`, `02_characters/관계_요약표.txt`에 새 상태를 반영한다.

## 개요 작성 시 놓치면 안 되는 고정 규칙

- 이 작품은 추리소설이 아니라 현실적인 일상, 연애, 관계극에 막장성이 섞인 이야기다.
- 인물은 직접 보거나 들은 것만 확정 정보로 가진다. 단서 하나로 진실을 단정하지 않는다.
- 학원 축과 학교/야구부 축은 용식을 통하지 않고 직접 연결하지 않는다.
- 연속 화는 같은 장소, 같은 자세, 같은 정지 상태에서 그대로 이어지지 않는다.
- 용식은 로또 1등 당첨금으로 큰돈이 있는 대학생이며, 숙박은 고급 호텔을 사용한다.
- 선물과 소비는 구체적인 브랜드와 가격감을 넣을 수 있지만, 모든 갈등을 자동으로 해결하지 않는다.
- 모든 성적 관계는 성인 간 자발적 관계로만 다룬다.
- 큰 사건 없이 관계의 온도, 침묵, 회피, 질투, 일상만 달라지는 화도 허용한다.

## 출력 원칙

- 바로 세부 개요를 쓰지 말고, 먼저 다음 5개 화의 큰 흐름을 사용자에게 확인받는다.
- 큰 흐름 단계에서는 장면 세부와 인물 프로필을 과하게 풀지 않는다.
- 세부 개요 단계에서는 `00_core/에피소드_개요_양식.txt`의 자기완결성 원칙을 따른다. 즉 최종 개요 파일 안에는 필요한 인물 정보와 상태를 실제 문장으로 옮겨 적고, "파일 참고"로 생략하지 않는다.
