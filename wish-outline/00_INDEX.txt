# 설정 패키지 색인

이 저장소는 소설 본문을 쓰는 곳이 아니라, 집필 AI에게 넘길 성인 장면 개요 기준과 인물 참고 자료를 관리하는 곳이다.

파일을 너무 잘게 쪼개면 관리가 어려워지므로, 다음 원칙으로 운영한다.

- 고정 규칙은 `00_core`
- 세계관과 생활 동선은 `01_world`
- 인물별 설정은 `02_characters`
- 현재 시점, 열린 사건, 정보 공개 상태는 `03_story_state` (연속성 요청 시 참고)
- 거짓말과 단서는 `04_tracking` (연속성 요청 시 참고)
- 화별 개요는 `05_outline` (연속성 요청 시 참고)

## 먼저 읽을 파일

성인 장면 개요를 만들 때는 먼저 `00_core/성인씬_개요_작성_기준.txt`를 읽는다. 이 파일은 앞뒤 화 연결 없이 매번 독립적인 성인 장면 개요를 생성하기 위한 공통 기준이다.

집필 AI에게 넘길 때는 기본적으로 아래 파일을 먼저 포함한다.

1. `00_core/성인씬_개요_작성_기준.txt`
2. `00_core/작품_핵심.txt`
3. `02_characters/2026_리부트_연령표.txt`
4. `00_core/성인씬_요청시_확장_참고규칙.txt` (장면 심리 곡선과 단계 유형이 필요할 때 참고)
5. 요청에 등장하는 인물의 `02_characters/` 파일
6. 필요한 경우 `01_world/2026년_세계관.txt`

연속성, 특정 화수, 기존 사건 반영을 사용자가 명시적으로 요청한 경우에만 `03_story_state/`, `04_tracking/`, `05_outline/`를 추가로 확인한다.

## 파일을 늘리는 기준

새 파일은 다음 경우에만 만든다.

- 여러 화에서 반복 참조해야 한다.
- 한 파일에 섞이면 집필 AI가 정보의 성격을 혼동한다.
- 캐릭터, 세계관, 현재 상태, 추적 로그 중 어디에도 자연스럽게 들어가지 않는다.

그 외에는 기존 파일에 항목을 추가한다.

## 독립 성인 장면 개요 작업 순서

1. `00_core/성인씬_개요_작성_기준.txt`에서 기본 출력 기준을 확인한다.
2. 요청에 등장하는 인물이 있으면 해당 캐릭터 파일을 읽는다.
3. 장소나 시대감이 중요하면 `01_world/2026년_세계관.txt`를 확인한다.
4. 필요한 경우 `00_core/성인씬_요청시_확장_참고규칙.txt`에서 심리 곡선 유형을 고른다.
5. 앞뒤 화 연결, 상태 갱신, 단서 누적 없이 요청된 장면 하나의 개요만 만든다.
