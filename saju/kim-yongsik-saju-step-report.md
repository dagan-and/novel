# 김용식 사주 STEP 1~8 확장 분석 리포트

기준일: 2026년 7월 13일

주의: 명리학 해석은 학파별 기준 차이가 있다. 아래 내용은 절기 기준 만세력, 지역시 보정, 일간 중심 십신, 월령 중심 격국 판단을 기준으로 정리한 운세 데이터셋이다.

## 공통 계산 기준

- 월주: 24절기 중 월을 바꾸는 12절 기준
- 대운 방향: 양년 남자/음년 여자 순행, 음년 남자/양년 여자 역행
- 대운수: 기준 절기와 출생시각의 차이를 3일 1년, 1일 4개월로 환산
- 12신살: 일지 삼합 기준
- 공망: 일주가 속한 순 기준
- 지장간: 월률분야식 초기 -> 중기 -> 본기 배열을 네 지지 모두에 적용
- 지지 십신: 해당 지지의 본기 기준
- 천간충: 천간 생극을 기본으로 보고, 적용 학파에서는 甲庚·乙辛·丙壬·丁癸를 천간충으로 보조 표기
- 세운 연도 경계: 입춘 기준
- 지장간 포함 오행 수치: 세력값이 아니라 단순 출현 빈도
- 지역시 보정: 사용자가 제공한 보정시각을 적용하되, 원자료의 보정 방식이 지방평균시인지 진태양시인지는 별도 확인 필요
- 데이터 구분: STEP 1~4는 계산 데이터 중심, STEP 5~8은 판정·해석값 포함

## 5. 신강·신약 분석

| 항목 | 평가 |
|---|---|
| 월령 | -1: 亥월은 辛金을 설기하는 수 월령 |
| 통근 | +1: 丑 중 辛, 巳 중 庚으로 뿌리 있음 |
| 투간 | 0: 일지 丑 중 己가 년간 편인으로, 癸가 시간 식신으로 드러나며, 辛은 일간과 동일하다. 인성 투출은 일간을 돕고 식신 투출은 일간을 설기하므로 이 항목에서는 서로 상쇄되는 것으로 보고 별도 가감하지 않음 |
| 생조 | +2: 토 인성, 금 지장간이 보조 |
| 극설 | -2: 수 식상, 목 재성, 화 관성이 모두 작동 |

최종 판정: **중화**

근거: 월령은 신약 쪽으로 기울지만, 일지 丑과 인성·비겁 지장간이 버팀을 제공한다. 다만 巳 공망과 巳亥沖 때문에 실제 체감은 운에 따라 신약 쪽으로 흔들릴 수 있다.

## 6. 용신 분석

① 조후: 亥월의 차고 습한 기운이 강하므로 화가 필요하다.  
② 억부: 중화이나 수 식상과 충이 강해 균형 조절이 중요하다.  
③ 병약: 특수 종격보다는 상관격/상관생재 성향으로 본다.

| 구분 | 선정 |
|---|---|
| 용신 | 화 |
| 희신 | 목 |
| 기신 | 수 과다 |
| 구신 | 토, 금 |

선정 근거: 화는 조후와 관성 균형에 필요하고, 목은 재성으로 화를 돕는다. 수가 과하면 설기가 지나치고 巳亥沖이 더 민감해질 수 있다.
