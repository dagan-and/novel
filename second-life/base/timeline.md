# 공통 연표

기록 파일은 `YYYY-MM`으로 구분한다. 나이는 사건 날짜의 만 나이로 계산한다. 생일이 있는 달은 사건 날짜에 따라 나이가 바뀐다. 당시 일상에서 쓰던 나이 표현이나 학년은 필요한 장면에서 따로 확인한다.

| 날짜·시기 | 만 나이 | 의미 |
| --- | --- | --- |
| 1989-12-07 | 0세 | 출생. 확정. |
| 2004-12-07 | 15세 | 만 15세 생일. |
| 첫 삶의 마지막 시점: 2026년, 정확한 날짜 미정 | 36~37세 | 그때까지 직접 경험한 모든 기억을 온전히 가지고 회귀한다. |
| **2005-01-01** | **15세** | **모든 편의 회귀일.** 중3 겨울에 돌아오며, 투자 편은 이 날 시작한다. |
| 2005년 3월 | 15세 | 용인 풍덕고등학교 1학년 입학. 학교명은 사용자 확인, 정확한 입학식 날짜는 미정. |
| 2005-12-07 | 16세 | 만 16세 생일. 같은 달에 기록하는 사건도 날짜에 따라 만 나이가 달라진다. |
| 2008년 3월 | 18세 | 일반적인 취학 경로에서 대학 신입학이 가능한 연령. 진학 여부는 편마다 결정한다. |
| 2009-12-07 | 20세 | 만 20세가 되는 날. 신체나 진로가 이 날 자동으로 완성되지는 않는다. |

회귀일에 관찰할 수 있는 신체·인지 조건은 공통 설정을 따른다. 이전 초안의 초6 겨울 고열과 만 14세 복싱 입문은 회귀 이후 사건에서 제외한다. 과거 이력으로 사용할지는 해당 편에서 정한다.
