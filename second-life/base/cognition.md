# 뇌·인지 설정

[완전한 세포](abilities.md)는 뇌에도 적용된다. 회귀 직후부터 기억·이해·주의·운동 학습이 압도적으로 좋다. 뇌의 신호 전달, 시냅스 가소성, 미세혈류, 에너지 공급, 노폐물 처리와 수면 중 정리가 함께 최적화됐다고 가정한다. **아래 수행 수치는 전부 작품용 설계값**이며, 뉴런 구조에서 이 점수가 계산으로 도출되는 것은 아니다.

## 측정하는 능력

| 지표 | 만 15세·회귀 직후 | 성인·해당 능력 훈련 완성 | 조건 |
| --- | --- | --- | --- |
| 단순 시각 반응 | **100~120ms** | **70~90ms** | 빛의 변화 → 버튼 입력 |
| 단순 청각 반응 | **80~100ms** | **60~80ms** | 소리 → 버튼 입력 |
| 네 가지 선택 반응 | **160~200ms** | **100~140ms** | 무작위 4신호, 정답률 98% 이상 |
| 즉시 숫자 기억 | **12~16자리** | **20~24자리** | 초당 1자리 청각 제시, 역순 아닌 순서 회상, 의도적 기억술 없이 |
| 핵심 사실 100개·당일 회상 | **95~98개** | **98~100개** | 새로운 짧은 사실, 30분 학습 |
| 같은 사실·7일 뒤 회상 | **90~95개** | **95~98개** | 중간 복습·재노출 없음 |
| 일반 한국어 설명문 독해 | **분당 3,000~4,000자** | **분당 6,000~8,000자** | 공백 포함, 객관식·서술형 이해도 90% 이상 |
| 새로운 교과·전공 입문서 독해 | **분당 800~1,500자** | **분당 1,500~3,000자** | 필요한 선수 지식 확보, 이해도 90% 이상 |
| 단순 새 운동 패턴의 습득 | **정확한 피드백 후 20~40회** | **5~15회** | 3~5요소 동작, 다음 날 20회 중 18회 성공 |
| 한 번의 깊은 집중 구간 | **90~120분** | **120~150분** | 해당 작업 정답률·속도를 유지한 뒤 휴식 |
| 휴식을 포함해 하루에 확보하는 순수 집중 시간 | **6~8시간** | **8~10시간** | 휴식·식사·수면을 별도로 확보 |

선택 반응 시간은 맞힌 시행의 중앙값과 오답률을 함께 적는다. 컴퓨터 지연을 보정하고 무작위 간격에서 50회 이상 측정한다. 익숙한 고정 순서를 외우거나 예측한 기록을 순수 반응으로 표시하지 않는다. 움직이기 시작하는 시간과 회피·스윙을 끝내는 시간은 별도다. 육상의 0.1초 판정 기준을 뇌의 보편적 한계로 쓰지 않는다. [S6](science-references.md#s6), [S16](science-references.md#s16)

‘숫자 24자리’는 이 작품에서 선택한 즉시 기억 과제 성적이다. 작업기억 전체가 24개 정보 단위를 아무 조건 없이 처리한다는 뜻이 아니다. 복잡한 논증·암산·동시 작업은 별도 과제로 평가한다. 기억술과 전문지식의 덩어리 묶기를 쓰는 성과도 따로 기록한다. 기억 선수 연구는 훈련과 수행의 구분에 참고한다. [S15](science-references.md#s15)

당일 검사 자체가 일주일 뒤 회상에 주는 영향을 피하려면 난이도를 맞춘 별도 항목 집합으로 각각 검사한다. 같은 항목을 당일과 일주일 뒤 모두 검사했다면 당일 회상 연습의 영향을 기록한다.

읽기 속도는 처음 보는 비슷한 난이도의 글로 확인한다. 표·수식·법조문·외국어는 위 자수 속도를 일괄 적용하지 않는다. 100개 사실 회상에는 정확한 숫자·날짜를 포함한 사전 채점 기준과 틀린 회상 수를 둔다. 이 표는 회귀 후 새로 접하는 자료의 학습 성적이다. 새 책을 훑는 것만으로 모든 문장을 완전히 저장하는 능력으로 확대하지 않는다. 첫 삶의 기억을 온전히 가져오는 회귀 특전은 아래의 별도 규칙을 따른다.

운동 학습의 반복 수는 단순 동작에만 적용한다. 투구 제구·다양한 구질·복싱의 거리 감각처럼 여러 요소가 상호 작용하는 기술과 실전 판단에는 훈련·상대 경험이 필요하다. 다만 기본 신체와 수정 능력이 매우 뛰어나서 정상적인 사람보다 빠르게 진전한다.

## 지능·감각·판단

- 표준 지능검사에서는 **해당 검사 상한에 도달하는 성적**을 설정한다. 상한이 160인 검사라면 ‘상한 도달’로 적고 IQ 200·300을 역산하지 않는다. 지능은 위의 기억·독해·새 문제 해결 과제를 묶어 표현한다.
- 시력의 가상 목표는 교정 상태 양안 각각 **소수시력 2.0~2.5**다. 조명·거리·검사표를 기록한다. 어둠 속 시야나 먼 거리 문자 판독에 그대로 배수 적용하지 않는다.
- 청력은 손상 없이 건강한 감도를 유지하고 소음 속 특정 소리에 주의를 집중하는 능력이 뛰어나다. 가청 범위 밖의 소리를 듣거나, 들리지 않은 대화를 알아내는 능력을 추가하지 않는다.
- 전문 지식·가치관·감정 조절은 경험과 학습에 따라 달라진다. 높은 처리 능력으로 자료 부족·거짓 전제·우연을 없애지는 못한다. 타인의 생각을 읽거나 항상 투자에 성공하는 능력은 아니다.

## 뇌의 에너지와 수면

| 단계 | 뇌 전체의 평균 대사 출력 가정 | 24시간 에너지 환산 |
| --- | --- | --- |
| 만 15세 기본 | 25~35W | 약 516~723kcal |
| 성인 기본 | 30~40W | 약 620~826kcal |
| 성인 훈련 완성 | 40~50W | 약 826~1,033kcal |

이 수치는 뇌의 정보 처리량을 W에 비례시켜 정한 것이 아니다. 구조 개선과 에너지 소비를 독립적으로 선택한 가상 설계값이다. 1W × 86,400초 ÷ 4,184 = 약 20.65kcal/일이다. 전력은 컴퓨터 연산 성능이나 체감 지능의 단위가 아니다.

실제 뇌가 포도당과 산소의 지속 공급을 요구한다는 연구를 바탕으로 에너지·혈류·냉각을 세계관에 포함한다. 하지만 이 뇌 소비량은 용식의 가정이며 현실 뇌 연구에서 예측된 값이 아니다. [S14](science-references.md#s14)

뇌 소비는 [영양표](nutrition.md)의 기초대사에 이미 포함한다. 공부하면 추가로 수천 kcal가 든다고 중복 계산하지 않는다. 만 15세는 **8.5~9.5시간**, 성인은 **7.5~8.5시간** 수면을 기본으로 둔다. 강한 학습·훈련 뒤에는 성인도 8.5~9시간을 확보한다. 잠을 줄여 능력을 유지하는 설정은 쓰지 않는다. 수면 중 학습 정리와 조직 유지가 일어난다. [S4](science-references.md#s4), [S7](science-references.md#s7)

## 첫 삶의 기억: 2026년까지 완전 보존

**첫 삶에서 2026년까지 직접 경험했던 모든 기억을 그대로 가지고 회귀한다.** 당시에는 잊었거나 지금까지 떠올리지 못했던 경험도 포함한다. 회귀 후에는 날짜·사람·장소·주제를 단서로 원하는 기억을 정확히 찾아 회상할 수 있다. 기억을 떠올릴 때마다 임의로 누락·왜곡·혼동시키지 않는다.

이 규칙은 인간의 일반적인 기억 연구나 위의 학습 회상률에서 도출한 능력이 아니다. **회귀 자체에 부여한 독립적인 세계관 특전**이다. 회귀 후에 새로 배울 때의 기억 과제 성적이 95%라고 해서 가져온 첫 삶의 기억 5%가 사라지는 것은 아니다. 2026년의 정확한 마지막 경험 날짜와 회귀 직전 사건은 미정이며, 2026년 전체의 아직 경험하지 않은 날까지 자동으로 포함한다고 정하지 않는다.

| 기억의 종류 | 가지고 오는 내용 | 적용 범위 |
| --- | --- | --- |
| 직접 겪은 일 | 대화, 장소, 사람, 선택, 성공·실패와 당시 감정 | 그때 자신이 보고 듣고 느꼈던 내용과 맥락을 정확히 회상 |
| 읽고 본 자료 | 기사, 책, 화면, 영상, 직접 확인한 가격·날짜·숫자 | 실제로 읽거나 인지한 문구·수치·장면을 정확히 꺼낼 수 있음 |
| 배운 지식과 경험 | 학업, 언어, 직업 지식, 문제 해결 방법과 실수 | 첫 삶에서 습득한 지식과 경험을 그대로 보유. 구체 전공·직업·숙련 목록은 별도 확정 |
| 운동·작업의 수행 기억 | 배웠던 동작, 감각, 절차와 교정 경험 | 기억은 보유하되 새로운 몸의 체격·근력·가동 범위에 맞춰 적응 |
| 당시 몰랐던 사실 | 접하지 않은 자료, 인지하지 못한 세부, 남의 속마음 | 기억에 새로 생성되지 않음. 본문의 글을 기억한다고 숨겨진 원인까지 알게 되지는 않음 |

한 번도 보지 않은 주가나 재무 숫자까지 자동으로 아는 것은 아니다. 반대로 실제로 확인했던 특정 날짜의 가격은 정확히 기억한다. 과거 숫자를 일부러 흐릿하게 만들어 투자 선택을 제한하지 않는다.

**기억의 정확성·당시 정보의 진실성·새 삶에서의 재현 여부는 서로 구분한다.** 거짓 기사도 읽었던 내용 그대로 기억한다. 당시 잘못 이해했던 설명도 그 이해와 원문을 회상해 새로 검토할 수 있다. 원래 삶의 기억은 2026년까지의 기록이며 새 삶의 미래가 바뀔 때 자동으로 갱신되는 예지 능력은 아니다. 사건이 얼마나 달라질 수 있는지의 세부 규칙은 본편 시작 전에 정한다.

투자 편은 `원래 삶에서 정확히 기억하는 정보 → 새 삶의 현재 조건 → 선택 → 실제 결과`를 남긴다. 제작 과정에서 시대 자료를 조사하는 것은 작가가 사실을 검증하는 절차다. 이를 용식이 모든 정보를 가물가물하게 기억하는 장면으로 바꾸지 않는다.

## 학업에서의 적용 · 사용자 추가 설정 2026-11-18

고등학교 교과서는 정독하고 내용을 이해해 학습한 범위가 머릿속에 안정적으로 구조화된다. 문제의 단어·조건을 단서로 해당 내용과 관련 개념을 바로 찾아 연결하고, 해법을 추론할 수 있다. 단순히 문장을 반복 암기하는 것보다 개념·조건·예외와 관계를 함께 기억하는 방식이다. 사용자가 선택한 학업 능력은 **압도적으로 높은 이해·기억·추론 성과**로 표현한다. 수업과 짧은 확인 학습으로 진도를 소화하며 반복 암기에 긴 시간을 쓰지 않는다.

이는 기존의 새로운 짧은 사실 100개를 한 번 학습하는 과제와 구분한다. 충분히 읽고 이해한 교과 내용의 장기 구조화와 단서 회상에 적용하는 설정이며, 아직 읽지 않은 교과서까지 이미 아는 것으로 쓰지 않는다. 실제 시험의 이름·날짜·점수·석차는 시험 사건이 생길 때 기록한다. 첫 삶 기억과 강화된 새 학습은 계속 구분한다.
