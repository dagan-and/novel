# 공통 능력 설정

김용식은 **2005년 1월 1일**, 만 15세의 몸으로 돌아온다. 첫 삶의 기억을 가지고 있으며 체력, 운동 학습, 집중과 회복의 잠재력이 높다. 성인 선수의 몸이나 직업 기술은 청소년기에 생략해서 얻을 수 없다. ‘완전한 세포’는 작품 속에서 용식이 변화에 붙일 수 있는 이름이다. 구체적인 작동 원리는 미정이다.

| 문서 | 관리하는 수치와 규칙 |
| --- | --- |
| [신체 설정](physiology.md) | 나이별 체격, 근력, 달리기, 심폐 지구력, 수면과 회복 |
| [인지 설정](cognition.md) | 감각, 반응 시간, 독해, 기억, 학습과 판단의 측정 기준 |
| [과학 자료](science-references.md) | 참고 문헌, 연구 대상과 적용 범위, 검증 상태 |

표의 숫자는 세 종류로 읽는다. **설정값**은 작가가 정한 공통 기준, **추정 범위**는 편별 상황에 맞게 달라지는 작품 설계값, **실측**은 극 중에서 조건을 기록하고 실제로 확인한 값이다. 추정 범위의 양끝은 최댓값이나 확률을 뜻하지 않는다. 통계상의 백분위나 의학적 기준이 필요한 경우에는 해당 연령·성별·측정법의 참조표를 확인한다.

각 편에서 실측한 기록은 해당 월에 남긴다. 날짜, 만 나이, 몸 상태, 측정 방식과 측정자, 결과를 함께 적는다. 세계관 파일에 있는 수치를 주인공이 처음부터 모두 알고 있는 것으로 쓰지 않는다.
