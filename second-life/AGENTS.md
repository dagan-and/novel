# 《완전한 두 번째 삶》 작업 규칙

새 세션은 `README.md` → `workflow/continuity.md` → 해당 편 `RESUME.md`를 먼저 읽는다. 투자 편은 `series/investing/RESUME.md`에서 시작한다.

- 형식은 **용식의 1인칭 세계관 탐색·월간 경험 기록**이다. 인물 대화, 따옴표 독백, 전지적 시점의 소설 장면을 추가하지 않는다. 1인칭은 연기하는 대화체가 아니라 내가 무엇을 경험·파악·선택·구축했는지 설명하는 서술이다.
- 풍부한 서술은 허용한다. 기존 설정을 읽고 능력의 작동, 생활과 시대의 제약, 선택의 근거, 구체적 진척과 남은 문제를 스스로 연결한다. 사용자가 말한 문장을 다시 쓰는 수준에 머무르지 않는다.
- 날짜별 계획표·기술 작업 목록·관리상 미정 사항은 제작 자료에서 관리한다. HTML 본문에는 월간 탐색 서술과 필요한 자산·진행 요약만 표시한다.
- 공통 설정은 `base/`가 기준이다. 첫 삶의 직업·기억은 사용자 확인 범위만 사용한다. 사후 조사 사실을 주인공의 경험으로 바꾸지 않는다.
- 편별 선택·사건·할 일의 구조화된 기록은 `series/<편>/data/records.json`이다. 사용자 확정 설정, 창작 초안 사건, 계획과 실제 완료를 구별한다. `state.json`은 마지막 확정 진행 위치다. 초안 생성·게시만으로 마감하거나 자금을 생성하지 않는다.
- 새 사건은 ID·이야기 날짜·상태·근거를 남긴다. 미확정 금액·사용 시간·완료율은 null로 두며 0으로 대신하지 않는다. 사용자에게 이미 확정받은 결정은 재질문하지 않는다.
- 변경 시 서술·구조화 기록·RESUME을 맞추고 검증 도구와 HTML 생성기를 실행한다. HTML을 직접 고쳐 본문 사본을 만들지 않는다.
- 게시 요청은 기존 GitHub Pages 흐름을 따른다. `main`과 `gh-pages`를 구분한다. 제작용 records·계획·연구·개인 기억은 Pages에 포함하지 않는다.
