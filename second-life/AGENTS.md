# 《완전한 두 번째 삶》 작업 규칙

새 세션의 투자 편 작업은 `series/investing/GUIDE.md`(작업 방법 전체) → `series/investing/RESUME.md`(현재 위치 한 장) 두 문서로 시작한다. 나머지 문서는 GUIDE가 가리킬 때 연다. 매달 본문 전에 시대 조사 기반 제안서를 먼저 낸다(D048).

- 새 사건·월별 지출·수익 정산·전개는 먼저 사용자와 의견을 조율한다. 아이디어나 검토 요청을 본문 작성·HTML 갱신·커밋·게시 지시로 확대하지 않는다. 명시적인 사용자 교정은 관리 원본에 기록할 수 있으나, 새 제안은 합의 전까지 확정 설정에 반영하지 않는다. 이 협의 단계에서는 본문·HTML 동기화보다 승인 범위를 우선한다.
- 형식은 **용식의 1인칭 세계관 탐색·월간 경험 기록**이다. 인물 대화, 따옴표 독백, 전지적 시점의 소설 장면을 추가하지 않는다. 1인칭은 연기하는 대화체가 아니라 내가 무엇을 경험·파악·선택·구축했는지 설명하는 서술이다.
- 풍부한 서술은 허용한다. 기존 설정을 읽고 능력의 작동, 생활과 시대의 제약, 선택의 근거, 구체적 진척과 남은 문제를 스스로 연결한다. 사용자가 말한 문장을 다시 쓰는 수준에 머무르지 않는다.
- 날짜별 계획표·기술 작업 목록·관리상 미정 사항은 제작 자료에서 관리한다. HTML 본문에는 월간 탐색 서술과 필요한 자산·진행 요약만 표시한다.
- 공통 설정은 `base/`가 기준이다. 첫 삶의 직업·기억은 사용자 확인 범위만 사용한다. 사후 조사 사실을 주인공의 경험으로 바꾸지 않는다.
- 편별 선택·사건·할 일의 구조화된 기록은 `series/<편>/data/records.json`이다. 사용자 확정 설정, 창작 초안 사건, 계획과 실제 완료를 구별한다. `state.json`은 마지막 확정 진행 위치다. 초안 생성·게시만으로 마감하거나 자금을 생성하지 않는다.
- 새 사건은 ID·이야기 날짜·상태·근거를 남긴다. 미확정 금액·사용 시간·완료율은 null로 두며 0으로 대신하지 않는다. 사용자에게 이미 확정받은 결정은 재질문하지 않는다.
- 변경 시 서술·구조화 기록·RESUME을 맞추고 검증 도구와 HTML 생성기를 실행한다. HTML을 직접 고쳐 본문 사본을 만들지 않는다.
- 합의한 변경의 구현과 검증을 마치면 별도 게시 요청 없이 `main`에 커밋·푸시하고, 변경된 공개 파일은 `gh-pages`에 반영한다(D036). 원격 브랜치와 Pages 배포 상태를 확인하고 실제 링크를 안내한다. 협의만 진행 중이면 이 규칙을 적용하지 않는다. 제작용 records·계획·연구·개인 기억은 Pages에 포함하지 않는다.

- 매달 `ongoing_threads`와 이전 달의 미완료 작업을 먼저 확인한다. 새 관심사나 사건은 기존 활동에 더한다. 사이트 구현·운영처럼 계속되는 일은 종료·보류 근거 없이 다음 달 서술에서 생략하지 않는다.

- 사이트를 기획할 때 자료원·데이터 가져오기/검수·자동 수집/갱신·예약 운영·호스팅 한도·비용·사람이 판단할 일을 함께 설계한다. 수작업 운영을 기본으로 가정하거나 당시 가능한 기술을 뒤늦게 처음 발견한 것처럼 구성하지 않는다. 과거 흐름을 고치면 보완 초안과 기존 채택 이력을 구분한다.

- 지표의 공통 기준은 해당 편 data/metrics.json이다. 새 월에는 방문·광고 발생·누적·현금 수령·성적·체격·투자 지표를 빠뜨리지 않는다. 7월부터 게임 플레이·대회·새 게임 지표는 추가하지 않는다(D035). 사용자 설정과 창작 추정·실측·미정을 구분하며 인기 점수를 임의 생성하지 않는다. 지표를 수정하면 refresh_metrics.py → check_continuity.py → render_investing.py로 갱신한다. 일별 모형값을 서버 로그로 부르지 않는다.

- 개인 현금 원본은 `series/investing/data/ledger.json`이다(D073). 본문이 없는 달도 월 총지출을 한 줄씩 기록하고 수령 월 환율을 채운다. 지출 추정치는 근거와 함께 표시한다. 현금 잔액은 생성기가 계산하며 원장 누락이나 미계산 잔액이 있으면 게시 전 검증을 통과할 수 없다.
