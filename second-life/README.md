# 완전한 두 번째 삶

**진행 형식: 용식의 1인칭 세계관 탐색·월간 경험 기록.** 대화·독백 없이 경험, 능력의 작동, 선택과 결과를 연결한다. 새 세션은 [진행 규칙](workflow/continuity.md)과 [투자 편 인계](series/investing/RESUME.md)를 먼저 읽는다. 구조화된 설정·사건·할 일은 [관리 기록](series/investing/data/records.json)이 기준이며 공통 설정은 base에서 참조한다.

1989년 12월 7일생 김용식이 2026년까지 첫 삶에서 경험한 모든 기억을 온전히 간직한 채 **2005년 1월 1일**로 돌아온다. 만 15세이며 그해 3월 고등학교에 입학한다. 첫 편은 투자다. 미래 생명공학 수준으로 최적화된 몸과 뇌를 가진다. 15세부터 훈련 없이 프로 선수급 체력을 발휘하고, 성장·전문 훈련 후에는 현재 인류의 기록을 넘어선다. 많은 식사와 충분한 수면이 필요하며 기술과 진로는 편마다 직접 배워 나간다. 제목은 가제다.

투자, 복싱, 야구, 검사 편은 같은 회귀일과 공통 설정에서 출발하는 독립된 이야기다. 각 편의 자산, 기술, 성적, 관계와 선택은 해당 편에서 관리한다. 새 편을 시작할 때는 [월별 관리 양식](workflow/monthly.md)의 폴더 구조를 재사용한다.

| 편 | 착수할 때 먼저 확인할 자료 |
| --- | --- |
| 복싱 | 당시 체육관과 청소년 대회, 입문일과 회귀 전 운동 이력. [복싱 편 구안](series/boxing/README.md) |
| 야구 | 해당 지역에서 중학생이 팀에 들어가는 방법, 학교 운동부와 대회, 포지션별 성장과 경기 기록 |
| 검사 | 해당 연도의 진학과 법조인 선발·임용 제도, 적용 법령과 경과 규정, 실제 직무와 사건 처리 절차 |

새 채팅에서 이 프로젝트를 이어갈 때는 다음처럼 말하면 된다.

> second-life/README.md와 second-life/series/investing/README.md를 읽고 투자 편의 2005년 1월을 이어가자.

HTML은 완성된 월을 기준으로 갱신할 예정이다. 첫 화면에는 본편 선택, 현재 날짜, 지난달 대비 변화와 최신 사건을 배치하고 월별 기록을 넘겨볼 수 있게 한다. 독자가 보는 정보는 각 월의 공개 요약과 사건만 사용한다. 조사 노트와 미공개 설정은 제작용 문서에 둔다.

2026-11-18: 공통 베이스를 미래 생명공학에 의한 신체·뇌 최적화 설정으로 갱신했다. 수치·에너지·식사량과 측정법은 위 공통 능력 문서에서 확인한다. 이번 변경은 로컬 문서이며 HTML 생성·커밋·푸시·배포는 수행하지 않았다.

추가 확정: 첫 삶의 기억은 잊었던 경험까지 완전 보존한다. 성인기 기능·감각·조절·회복 특성도 공통 신체에 반영했다. 기본 준비 상태와 남은 결정은 [공통 능력 설정](base/abilities.md#기본-준비-상태와-남은-결정)에 정리했다.

## HTML 게시 관리

GitHub Pages는 별도의 `gh-pages` 브랜치에서 이 작품의 화면과 화면에서 직접 연결하는 설정 문서만 게시한다. `main`을 갱신해도 게시 브랜치가 자동으로 갱신되지는 않으므로, 화면을 수정한 뒤 게시 파일을 갱신하고 실제 주소를 확인한다. 조사 자료와 다른 작품은 게시 브랜치에 포함하지 않는다.
