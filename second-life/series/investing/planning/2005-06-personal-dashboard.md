# 개인 현황판과 관계 프로필 · 사용자 요청 범위

사용자가 상단을 총자산·여자친구·차·집 등 개인 상태로 바꾸고 관계 인물을 상세 프로필에 연결하도록 요청했다. 현지는 고양이상에 더 예쁜 인상으로 교정하고, 외모는 스케치하듯 세부 묘사하며 성격은 공부를 잘하지 않고 약간 날라리 분위기라는 사용자 조건 아래 구체적으로 창작한다.

- [x] 기존 metrics·관계 기록과 Markdown 프로필을 유지하고 미확인 자산을 0원으로 확정하지 않는다.
- [x] 상단에 총자산·현금·투자·교제·차·집을 배치하고 기존 광고 핵심 지표는 수입 패널로 옮긴다.
- [x] 선택 월에 알려진 여자친구·썸·만남 기록만 표시하고 프로필 이름·사진에 링크를 연결한다. 월을 바꿔도 미래 관계를 과거에 노출하지 않는다.
- [x] 프로필 Markdown에서 HTML을 생성하며 검토용 이미지v2를 사용한다. 창작 외모·성격을 실제 사용자의 기억으로 단정하지 않는다.
- [x] 연속성·생성·미정 자산·월별 관계 링크를 확인하고 데스크톱·모바일에서 읽기와 왕복 이동을 확인한다.

기존 정적 HTML·녹색 계열 디자인을 유지한다. 별도 Sites 등록·호스팅 변경·커밋·푸시·Pages 게시를 수행하지 않는다. 과거 달 마감이나 새 연애 사건·현금 수령은 만들지 않는다.
