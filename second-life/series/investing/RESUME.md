# 투자 편 인계

## 현재 위치와 읽기 순서

2005년 5월 탐색·현황판 초안. 마지막 확정 스냅샷은 여전히2월이며 3~5월 금융 수치는 창작 기준안이다. state.next_month=2005-05. 사용자 설정으로 5월 초 중간고사 뒤 풍덕고 1학년에서 학년1등, 학교·학원 인지도 증가, 외모·체격으로 관심 증가, 교내 스타 최상위를 적용한다. 첫 삶 실제 성적·인기도 이력으로 옮기지 않는다.

프로젝트 AGENTS → workflow/continuity → 이 문서 → data/records.json → data/metrics.json → state.json → months/2005-05.md를 읽는다. 1인칭 탐색이며 대화·독백을 추가하지 않는다.

## 새로 정한 학교와 생활

학교는 용인 풍덕고등학교(사용자 확인). 수업에서 다른 학생들도 잠을 보충하는 시간에 함께 일부 수면하고, 밤5시간+학교2~3시간=하루7~8시간이라는 강화 신체 설정을 유지한다. 야자는 컴퓨터 없이 자습서·문제집 최고난도 문제풀이를 우선한다. 종이 사이트 설계는 필요할 때 병행 가능하다. 사이트를 위해 밤을 늦춘 날은 게임을 줄이고 수면을 보충한다.

시험은 사용자 지정 5월 초. 풍덕고2005 실제 시험표는 아직 못 찾았다. research/school/2005-05-midterms.md의 EBS2004 공식 자료는 같은7차 교육과정 고1의 국어(상)·영어·수학10-가·사회·과학·국사·도덕7과목을 확인해 준다. 해당 목록을 임시 성적 기준으로 사용했다. 기술·가정 등 추가 과목·정확한 일자·배점·학생 수는 미정이다. 99/100/100/100/100/99/100과99.71 단순평균은 창작안이지 학교 공식 평균이 아니다. 특정 최신 문제집을 과거에 넣지 않는다.

## 지속하는 사업과 게임

자동화는 초기부터 도입하는 흐름으로 1~3월 보완 초안(E024~E026)이 들어 있다. 4월은 안정화·자료원 확장, 5월은 정상일 짧은 관리·자료 검수와 패치/버그 시 집중 수정이다. 운영이 자동이라는 이유로 수집 데이터의 정확성·복원·신고 판단까지 사라지지 않는다. data/site_architecture.json을 참조한다.

스타 출발점은 FL-004~005: 테란, 용인시 학생부4강, APM약230, 세 빌드. 2월350~450·3월400~500·5월450~550은 작품용 후보이고4월은 미기록이다. 교내1등을 전국1등·프로전 승률로 환산하지 않는다.

## 지표의 기준과 한계

data/metrics.json이 월별/일별방문·광고·성적·체격·APM·자산의 기준이다. 지표가 그동안 충분히 누적 관리되지 않았음을 바로잡아1~5월 모형을 만들었다. 실제 서버 로그는 없다. 일별151일은 월별 가정에서 가중 배분한 값으로 모두 story_estimate다.

광고: 3월48USD(기존 scenarios/2005-03.json),4월144,5월262.50. 누적454.50. 5월 일평균 방문1500,전체PV210000,일평균광고8.47USD. 특정일은 dashboard에서 조회할 수 있지만 실측으로 부르지 않는다. 방문자-일 합계와 월간 고유 방문자는 다르다. 실제 수령0USD라는 시나리오이며 운영비·세금·환율·가족분배·개인잔액·순이익은 미정이다. 투자 종목·거래는 아직 없다.

5월178.5cm·76kg·체지방13%,7과목 상세점수도 창작 후보. 골격근량·인기도 점수·학년 인원은 null이다. 기본 회귀일 체격과 첫 삶 경험을 변경하지 않는다.

## 갱신·검증·게시

지표 수정 → python3 scripts/refresh_metrics.py → python3 scripts/check_continuity.py → python3 scripts/render_investing.py. refresh는3월 원본 수익·4월 원본 체격을 동기화하고 파생 일별값·누적·평균을 계산한다. check는 일별 합/월별/누적/시나리오/평균을 대조한다. render는 dashboard.html에 탐색과 지표를 통합 생성하고 index.html은 기존 월·앵커를 유지하는 연결 화면으로 만든다. 직접HTML 숫자를 수정하지 않는다.

현황판은 월/날짜/지표 선택·분류 필터·그래프·금융표를 제공한다. 월 선택은 과거에 미래의 성적을 보여 주지 않는다. 월별 탐색과 모든 수익·그래프는 하나의 현황판 안에서 같은 월 선택을 따른다. 새 월을 만들면 수익·방문·성적·체격·게임 지표를 갱신하거나 null을 명시한다.

main은 제작 자료 보관. gh-pages에는 기존 허용된 HTML/설정 문서와 새dashboard.html만 게시한다. data·research·planning·scenarios를 원본 그대로 Pages에 복사하지 않고 공개용 지표만 HTML에 포함한다. 링크: https://dagan-and.github.io/novel/series/investing/dashboard.html?month=2005-05 .

## 최신 화면 구성 · D020

탐색 기록과 현황판은 이제 dashboard.html 한 화면이다. 위의 월 선택을 바꾸면 수익·그래프·탐색 본문이 함께 바뀐다. 모두 보기/탐색 기록/전체 지표와 세부 분류로 같은 페이지 안에서 볼 수 있다. 원문은 months Markdown, 수치는 metrics JSON을 계속 기준으로 삼는다. story_rendering.py가 원화 환산·이스케이프한 본문을 만든다. 이전 index.html?month= 링크는 해당 월과 함께 dashboard.html#exploration으로 이동한다. 별도의 탐색 전용 화면을 다시 만들지 않는다. scripts/templates/investing.html은 과거 보존 템플릿이며 현재 생성에 쓰지 않는다.
