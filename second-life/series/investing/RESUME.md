# 투자 편 인계

## 먼저 확인할 것

- 표현 방식: **1인칭 세계관 탐색·월간 경험 기록**. 대화·독백·소설 연출은 제외. 사용자 최신 요청은 능동적으로 내용을 연결하면서 설정과 진행 기록을 함께 관리하는 것이다.
- 현재 작업 월: 2005년 1월. 마지막 확정 월은 아직 없다. state.json의 next_month는 2005-01이다.
- 읽기 순서: 프로젝트 AGENTS → workflow/continuity → 이 문서 → data/records.json → state.json → months/2005-01.md. 능력·기억은 필요할 때 base의 해당 문서를 읽는다.

## 이번에 만든 내용

D001~D004: 표현·관리·사업 방향은 사용자 선택. E001은 공통 회귀 사실. E002~E004는 이번에 구체화한 **창작 초안 사건**이다. 1월 말 내부 시험판에서 공통 회원·게시판, 디아블로 조합 검색, WoW 안내·체크리스트가 연결되는 흐름으로 서술했다. 이는 사용자 확인을 받은 완료 실적이 아니다. DB 작업 상태 역시 아직 planned이며 실제 시간·완료율은 null이다.

외부 공개·사이트 이름·호스팅 지출·광고 신청/승인·매출/입금·투자 거래는 확정하지 않았다. 개인 보유금 약 10만 원은 잠정치이며 확정 잔액 10만 원으로 바꾸지 않는다. 인물의 첫 삶 기억은 완전하지만 작가가 모든 세부 경험을 사용자에게 확인받은 것은 아니다.

## 다음 행동

사용자 의견을 반영해 1월 탐색 기록을 다듬는다. 진척을 확정하거나 2월로 넘어가는 요청이면 초안 사건의 채택 범위를 판단하고, 미결 U001~U004 중 다음 행동에 꼭 필요한 내용만 정한다. 외부 공개와 비용을 구체화할 때 당시 환경 자료를 먼저 조사한다. 새 월 서술을 쓰면 records와 해당 월 인계를 같은 턴에 갱신한다.

## 생성·검증·게시

`python3 scripts/check_continuity.py` 후 `python3 scripts/render_investing.py`로 기록을 확인하고 1월 HTML을 만든다. 월 추가 시 생성기의 대상 월도 확장한다. 생성기는 commit/push를 하지 않는다. `main`에 제작 자료를 보관하고 `gh-pages`에는 HTML과 이미 허용한 설정 파일만 반영한다. 사이트 주소: https://dagan-and.github.io/novel/series/investing/ .
