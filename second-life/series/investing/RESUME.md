# 투자 편 인계

## 현재 위치

2005년 2월 탐색 초안. 1월 질적 사건 E002~E004는 사용자의 “좋아졌네, 2월 하자”에 따라 채택했다. state.json은 last_confirmed_month=2005-01, next_month=2005-02이며 1월 스냅샷은 snapshots/2005-01.json이다. 자금·비용·실제 사용시간은 null로 보존했다.

읽기 순서: 프로젝트 AGENTS → workflow/continuity → 이 문서 → data/records.json → state.json → months/2005-02.md. 표현은 용식의 1인칭 세계관 탐색이며 대화·독백을 추가하지 않는다.

## 이번 달 내용과 사용자 경험

2월의 본줄기는 디아블로·WoW 사이트 구현·자료 보강·시험공개·질문 대응·오류 수정·운영이다(D006). 스타는 병행하는 능력 탐색이며 기존 사업을 대체하지 않는다. E006~E011은 초안이다. 실제 서비스 개통·지출·유입·매출로 확정하지 않는다.

사용자 확인 FL-004~005 / E005: 당시 테란, 용인시 대회 학생부 4강, APM 약 230. 2팩 벌처 / 1팩1스타 견제 / 1배럭1팩 마린·벌처·탱크 1기 진출과 앞마당 운영 경험. 사용자 개인 경험이며 대회 개최일·이름·측정 도구는 미정이다.

강화 후 평균 APM 350~450, 짧은 구간 500~600은 작품용 후보다. 뇌 수치에서 도출한 연구 결과나 실제 측정값으로 쓰지 않는다. 프로급 이상의 조작 잠재력을 표현하되 실전 성적·프로전 승률을 생성하지 않는다. 세 빌드에서 견제·생산·보급·정찰 판단을 병행하는 변화가 핵심이다. 미래의 모든 빌드나 프로 경기를 보았다고 가정하지 않는다.

## 이어지는 활동

data/records.json의 ongoing_threads를 확인한다. 새 관심사가 추가돼도 구현·운영·수익화 준비 같은 기존 활동을 매달 자연스럽게 이어 간다. 종료·보류가 명시되지 않은 일을 삭제하거나 이미 끝난 것으로 처리하지 않는다.

## 다음 행동

사용자 의견에 따라 2월 내용을 다듬는다. 미결 U001~U005를 확인한다. 호스팅·사이트 이름·비용 부담과 공개일이 실제 진행에 필요하면 당시 조건을 조사하고 결정한다. 스타 평가를 구체화하면 경기·맵·도구·측정 조건을 함께 정한다. 사이트는 세 게임 전체 DB로 급격히 확대하지 않는다.

## 생성·검증·게시

python3 scripts/check_continuity.py → python3 scripts/render_investing.py. 생성기는 data/records.json의 months 목록과 각 월 Markdown에서 HTML을 만든다. 새 월 추가 시 months 메타데이터와 본문을 함께 작성한다. 최신 월이 기본 표시이며 ?month=2005-01 또는 ?month=2005-02로 직접 연결할 수 있다. HTML 직접 본문 수정 금지.

main은 제작 자료, gh-pages는 허용된 HTML·설정 문서만 게시한다. 진행 문서와 data·research·planning은 Pages에 게시하지 않는다. 현재 사이트 https://dagan-and.github.io/novel/series/investing/ .
