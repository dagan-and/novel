# 투자 편 인계

## 현재 위치

2005년 4월 검토 초안. 마지막 채택 월은 2월이며 3월 수익·광고 승인·경기 수치는 여전히 초안이다. state.json은 last_confirmed_month=2005-02, next_month=2005-04다. 3월을 통째로 확정하거나 48달러를 현금으로 전환하지 않는다.

읽기 순서: 프로젝트 AGENTS → workflow/continuity → 이 문서 → data/records.json → state.json → months/2005-04.md. 표현은 1인칭 세계관 탐색이며 대화·독백을 넣지 않는다. 진행 중 활동은 ongoing_threads에서 확인한다.

## 이번 사용자 선택

D010: 점심·야자 전 식사 뒤 학교 철봉·푸시업 등으로 운동하고 외모를 신경 쓰기. D011: 교실 컴퓨터 사용 불가가 확인됨. 야자에는 종이 설계·자료 독해·할 일 정리, 밤에는 구현·검증. D012: 야자 21시 종료, 귀가 후 22~02시 사이트, 학교에서 수면 보충이라는 희망 패턴이다.

수면 선택 D014가 확정됐다. 기존 청소년8.5~9.5시간 대신 밤5시간+학교2~3시간=총7~8시간을 적용한다. 분할수면에서도 기억 정리·조직 회복을 유지하는 가상 생체 효율을 추가했다. 밤5시간만 충분하다고 확대하지 않는다. 정확한 기상·학교 보충수면 구간·학원 시간표는 U007이다. 수면량 선택을 다시 묻지 않는다.

## 체격과 자동화

E018~E023은 4월 초안. 4월 초 177.5cm·73kg·14%, 말 178cm·74.5kg·13.5% 체지방 후보다. scenarios/2005-04-body.json을 읽는다. 제지방 64.44kg를 골격근량으로 쓰지 않는다. 체격은 투자 편 성장 후보이고 공통 회귀 초기 176cm·70kg를 덮어쓰지 않는다.

사용자가 초기 기획에서 자동화 조사가 빠진 점을 지적했다. D013에 따라 1월 수집·자료구조·검수·예약 설계와 표본 → 2월 수집/중복 검사/백업 연결 → 3월 개학 중 자동 실행·야간 검수 → 4월 안정화·자료원 확장으로 교정했다. E024~E026은 기존 월의 보완 초안이며 revision_status로 표시한다. 과거 채택 스냅샷에 몰래 완료 이력으로 넣지 않았다.

data/site_architecture.json과 research/technology/2005-automation.md가 기술·운영 구조의 목록이다. 특정 자료원의 당시 RSS 제공·수집 형식·호스팅 한도는 확인 전이다. 자동 수집은 검수 목록을 만들고 사람은 버전·내용을 판단한다. AI 공략 작성으로 확대하지 않는다. 자동화 덕분에 정상일 운영 부담은 줄고 밤4시간은 개발·게임·휴식에 나눌 수 있다. 운영30분+검수30분+개발90분+스타90분은 배분 예시이며 실측 아님.
