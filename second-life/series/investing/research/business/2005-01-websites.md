# 2005년 1월 웹사이트 수입 경로

- 조사일: 2026-11-18
- 전제: 초기 자금 잠정 약 100,000원, 기존 PC·인터넷 사용 가능, 첫 삶의 웹·앱 개발 경험 보유.
- 상태: 초기 후보 조사. 이후 사용자가 WoW·디아블로 게임 정보·커뮤니티를 선택했다. 최신 기능·일정·정산 방향은 [게임 커뮤니티 분석](2005-01-game-community.md)을 따른다. 실제 사이트 공개·광고 승인·수익·계약은 아직 발생하지 않았다.

## 당시 가능한 광고 모델

2004-10-05의 당시 보도는 한국어 콘텐츠 페이지에 광고를 붙여 수입을 나누는 애드센스를 소개하며 개인 운영자도 대상으로 설명한다. 한 운영자의 2006-01-10 회고는 2004년 10월부터 사용했다고 밝힌다. 따라서 2005년 1월의 한국어 개인 사이트 광고 수익 모델은 시대에 맞는 후보다. 각 사이트의 실제 승인과 수익을 보장하지는 않는다. [B01](https://www.inews24.com/view/125330), [B02](https://www.palgle.com/2006/01/10/google-adsense-incoming/)

2005-12-07 제출 법원 문서에 첨부된 Google 약관에는 참가자의 18세 이상 요건과 누적 100달러 이상일 때의 지급 조항이 확인된다. **이는 2005년 말 자료이며 1월에 동일한 문구였는지까지 입증하지 않는다.** 현행 Google 안내는 미성년자의 부모·보호자가 자신의 계정으로 신청하고 성인이 지급받는 경로를 명시하지만 이 현행 절차도 2005년 1월의 직접 증거로 쓰지 않는다. [B03](https://docs.justia.com/cases/federal/district-courts/california/candce/5%3A2004cv01497/19466/391/2.html), [B04](https://support.google.com/adsense/answer/14230?hl=en-GB)

사용자는 어머니가 계약·정산을 맡고 수익을 어머니와 용식이 50:50으로 나누는 방향을 선택했다. 1월 당시 약관·한국 지급 방식·소득 귀속의 세부는 추가 확인한다. 이름만 빌려 혼자 가입한 것으로 처리하지 않는다. 2005년 수익을 현대 모바일 광고·현행 지급수단·수익배분 정책으로 계산하지 않는다.

## 최초에 검토했던 사이트 주제 후보

아래 수요 평가는 조사 통계가 아니라 개발 경험·비용·반복 사용 가능성에 근거한 제작 판단이다.

| 후보 | 첫 기능 | 장점 | 필요한 확인 |
| --- | --- | --- | --- |
| 생활·학습용 웹 도구와 사용 안내 | 비율·퍼센트 계산, 날짜 간격, 글자 수, 간단한 문자 정리 | 작은 기능을 직접 만들고 기능별 설명과 예제로 확장 가능. 초기 검토 후보; 이후 게임 커뮤니티 선택 | 검색 수요·경쟁·광고 적합성·당시 브라우저 사용성 |
| 개발 팁·코드 도구 | 웹 제작 설명·직접 만든 예제·작은 변환 도구 | 사용자 직업 경험과 연결 | 당시 실제 사용하는 기술과 독자 유입 경로 |
| 게임 정보·도구 | 사용자가 실제 해본 게임의 직접 작성 공략·계산 도구 | 첫 삶의 게임 경험이 확인되면 지속 콘텐츠 확보 | 어떤 게임을 경험했는지, 당시 게임 규칙과 이용 수요 |

처음부터 포털·커뮤니티 전체를 구현하기보다 한 주제의 작은 도구 3~5개와 직접 작성한 안내를 만든다. 이는 개발 목표이며 광고 승인의 필수 페이지 수나 보장 조건이 아니다. 방문자 확보와 운영은 별도 작업이다. 2026년 플랫폼·API를 그대로 사용하는 대신 2005년에 가능한 PC 웹 형태로 설계한다. 구체 기술과 호스팅 제품은 선택 시 당시 지원 여부를 확인한다.

## 돈과 유입의 크기

다음 표는 **2005년 실제 광고 단가를 확인한 예측이 아니다.** 수익 규모를 이해하기 위해 페이지 1,000회당 순수 광고 발생액을 가상의 1,000원으로 놓고, 모든 해당 페이지에 동일하게 적용된다고 가정한 민감도 예시다. 비용·세금·지급 지연은 별도다.

| 하루 페이지뷰(PV) | 30일 PV | 가정 광고 발생액 |
| --- | --- | --- |
| 100 | 3,000 | 3,000원 |
| 1,000 | 30,000 | 30,000원 |
| 10,000 | 300,000 | 300,000원 |
| 50,000 | 1,500,000 | 1,500,000원 |

PV는 방문자 수와 다르다. 첫날부터 이 유입을 확보했다고 쓰지 않는다. 광고 단가·채움률·광고 대상 페이지가 달라지면 수입도 달라진다. 실제 입금 전 광고 발생액은 현금 잔액으로 계산하지 않는다.

초기 10만 원의 예산안은 도메인 최대 2만 원, 초기 호스팅·테스트 최대 2만 원, 예비비 최소 6만 원이다. **당시 업체 견적이 아닌 지출 한도 배분안**이다. 비싼 서버·유료 광고 구매를 먼저 확정하지 않는다. PC 전기·인터넷·식비를 누가 부담하는지는 생활 조건으로 별도 확인한다.

## 첫 달 성공 기준

최소 사이트 공개, 사용 가능한 기능과 설명, 실제 이용자의 반응·유입 기록, 반복 사용 여부, 광고 신청·계약 조건의 확인, 지출과 현금의 구분을 첫 달 기준으로 둔다. 광고 승인·첫 입금·흑자는 그 결과를 확인한 뒤 확정한다. 보조 수입을 원하면 이 사이트를 샘플로 작은 웹 제작 의뢰의 수요를 확인할 수 있으나 고객·단가·입금을 임의로 만들지 않는다.
