# 2008년 3월 시대 조사

| 항목 | 근거와 적용 |
| --- | --- |
| 연세대 입학 | [연세대 2007학년도 요람](https://www.yonsei.ac.kr/bbs/sc/61/982004/download.do)은 전년도 3월 초 입학식과 개강을 기록한다. 2008년 신촌 학부 입학식의 정확한 날짜는 확인하지 못했다. 사용자 설정에 따라 3월 초 입학식으로 쓰고 날짜는 특정하지 않는다. |
| 탁구 | [연세대 새내기 안내서](https://yonseirc.yonsei.ac.kr/uc/guidance/click-yonsei.do?articleNo=12467&attachNo=12802&mode=download)는 탁구 동아리 IMPACT의 창립일을 2005년 8월 11일로 기록한다. 2008년의 활동 장소와 실제 회원은 확인하지 않았으며 두 사람의 혼합복식은 창작이다. |
| 생활과 요금 | [2008년 수도권 숙박 취재](https://sports.khan.co.kr/article/200804302006536)는 대실 2~3만원, 숙박 4~10만원 선을 보도했다. 사용자 기준 대실 3만원·숙박 6만원을 적용한다. |
| 던파 | [중국 서비스 당시 공지](https://news.17173.com/content/2008-03-13/20080313173746618%2C1.shtml)와 [운영사 연혁 수록본](https://games.sina.com.cn/o/n/2009-06-17/1321319645.shtml)에서 3월 12일 기술 비공개 테스트 확인. 6월 정식 서비스는 [텐센트 연차보고서](https://static.www.tencent.com/storage/uploads/2019/11/09/4807bdfa33558713354ad05c1ba7c715.pdf) 기준. 공개된 중국어 공지의 표기와 버전을 대조하는 단계로 쓰며 직접 테스트 계정 이용은 설정하지 않는다. |
| 환율 | [FRED EXKOUS](https://fred.stlouisfed.org/data/EXKOUS) 981.7348원/USD. 원장에는 981.73원/USD. |
| 계절과 학교생활 | 이른 봄과 새 학기를 배경으로 삼는다. 당일 날씨·강의실과 실제 동아리 모임 날짜는 미확인이다. 직접 스타 플레이와 주식 거래는 추가하지 않는다. |
