# 2008년 5월 시대 조사

| 항목 | 확인 근거와 적용 |
| --- | --- |
| 학교 일정 | [연세대 2008년도 대학요람](https://www.yonsei.ac.kr/bbs/sc/61/982005/download.do) 첫 쪽에 5월 8일 연세인 연합채플, 10일 창립기념일, 12일 석가탄신일, 14일 학기 2/3선이 명시된다. 일반휴학 등 학생 개인에게 적용되지 않는 일정은 배경으로 둔다. |
| 축제 | [연세대 입학홍보 자료](https://admission.yonsei.ac.kr/seoul/upload/info/20150828183828B4G46H.PDF)는 5월 대동제와 아카라카의 연관을 설명한다. [당시 5월 보도](https://www.donga.com/news/Culture/article/all/20080520/8580159/1)로 2008년 5월 15일 아카라카 개최를 확인했다. 2008년 대동제의 전체 일정과 개별 부스는 미확인이다. |
| 신촌 저녁 | [경향신문의 신촌 현장 기사](https://www.khan.co.kr/article/200108092358561/amp)에서 대학가 단체 모임과 호프집을 확인했다. [2008년 축제 보도](https://www.seoul.co.kr/news/plan/20N30/2008/05/20/20080520023002)는 학생 주점과 축제 뒤 교류를 당시 대학가의 풍경으로 다룬다. 본문의 술집, 합석, 방문 빈도는 창작이다. |
| 탁구 | [연세대 학교 안내서](https://yonseirc.yonsei.ac.kr/uc/guidance/click-yonsei.do?articleNo=12467&attachNo=12802&mode=download)는 IMPACT의 창립일이 2005년이라고 기록한다. 당시 축제에서 탁구 행사를 했는지는 미확인이다. 작품 내 친선 복식은 일반 동아리 연습을 바탕으로 제안한다. |
| 중국 던파 | [5월 27일 2차 테스트 계정 배포 안내](https://news.17173.com/content/2008-05-27/20080527094944813_all.shtml)와 [텐센트 연차보고서](https://static.www.tencent.com/storage/uploads/2019/11/09/4807bdfa33558713354ad05c1ba7c715.pdf)를 참고한다. 5월 말은 출시 전 버전 확인, 6월은 출시 시점이다. 국내 3개 게임의 5월 특정 패치 효과는 적용하지 않는다. |
| 언어와 운동 학습 | [공통 인지 설정](../../../../base/cognition.md) 기준 기억과 동작 교정이 빠르다. 첫 삶의 일본어 학습 이력과 실전 탁구 전적은 미확인이다. 일본어 학습 시간과 탁구 수준은 달성 가능한 작품 기준안으로 쓴다. |
| 환율·경제 및 생활 | [FRED EXKOUS](https://fred.stlouisfed.org/data/EXKOUS) 5월 월평균 1,034.1333원/USD. 원장에 쓰는 값은 1,034.13원이다. 5월 봄과 통학을 배경으로 하며 날짜별 날씨, 스타 경기 전적과 새 주식 거래는 추가하지 않는다. |
