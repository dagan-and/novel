# 복싱 편

복싱 편은 투자 편 다음에 착수한다. 다른 편과 같은 [공통 회귀일](../../base/timeline.md)인 2005년 1월 1일에서 출발한다. 복싱 입문일, 회귀 전 운동 이력 및 학교와 체육관의 지역은 착수할 때 정한다. 타고난 체력은 연습과 회복에 도움이 되며, 기술과 경기 경험은 시간을 들여 쌓는다.

| 작업 | 파일 |
| --- | --- |
| 시작 시점·다음 달·확정 상태 | [상태](state.json) |
| 재검토할 시대 자료와 확인 항목 | [이전 조사 기록](research/2003-youth-boxing.md) |
| 이전 장면 아이디어 | [2003년 12월 구안](months/2003-12.md) |
| 공통 진행 양식 | [월별 관리](../../workflow/monthly.md) |

첫 달 장면에는 체육관 선택, 학교와의 일정 조율, 처음 배워야 할 것을 활용할 수 있다. 기록을 시작하기 전에 공통 회귀일과 해당 연도의 자료로 재검토한다. 성장기 체급은 측정한 체중과 나이, 주최기관 기준을 확인한 뒤 정한다.

나중에 HTML로 보여줄 복싱 편의 변화는 체육관에 낯설었던 첫 달, 익숙해진 다음 달, 실제 경기까지의 간격처럼 시간의 흐름이 읽히게 구성한다. 이번 달 일정, 기술 단계, 컨디션, 공식 경기와 주요 관계를 기록에 근거해 표시한다.
