# 기록 업데이트 규칙

## 적용 범위

- 원고 작성 이후 캐릭터 파일, `관계망.md`, `연대기.md`를 갱신할 때 적용한다.
- 현재 세팅 단계에서는 초기값만 작성한다.

## 업데이트 순서

1. 완성 원고 확인
2. 캐릭터 [가변] 항목 변경점 정리
3. `characters/` 파일 갱신 (새 인물 등장 시 생성)
4. `states/연대기.md` 갱신
5. 호칭 변화 확인
6. 관계 친밀도 변화 확인
7. 다음 5화에 넘길 복선 확인

## 연대기 기록 형식

```text
| ep | 연도/계절 | 장소 | 등장 | 한줄 요약 | 성인씬 | 돌발 이벤트 |
```

## 관계망 기록 원칙

- 관계 진도보다 현재 감정 상태를 우선 기록한다.
- 질투, 오해, 숨긴 사실, 생활권 변화는 복선 트래커에 남긴다.
- 메인/서브 구분은 반복 선택과 생활 중심성을 기준으로 조정한다.
- 성인씬은 단순 발생 여부보다 이후 관계 변화, 합의 상태, 질투나 안도 같은 감정 변화를 기록한다.

## 5화 점검 항목

- 최근 5화에서 Scene 없이 Sequel만 반복된 화가 있는지
- 각 화 끝에 Hook이 있었는지
- 현실 화가 최소 1개 포함됐는지
- 소재 축이 3화 연속 같은 축으로 이어지지 않았는지
- 관계 변화가 기록에 반영됐는지
