# 워크플로우

## 현재 단계

- 이 폴더는 새 시리즈 세팅 단계다.
- 사용자가 명시적으로 요청하기 전까지 화별 개요와 시나리오는 작성하지 않는다.

## 요청별 처리

### "세팅 정리해줘" / "설정 구축해줘"

1. `AGENTS.md` 확인
2. `planning/` 문서 확인
3. `setting/세계관.md` 확인
4. `setting/독서흐름개선규칙.md` 확인
5. 문체/읽힘 변경이 있으면 `setting/라노벨문체규칙.md` 확인
6. 성인씬 운영 변경이 있으면 `setting/성인씬작성규칙.md` 확인
7. 필요한 설정 문서만 수정
8. 원고 생성 금지

### "캐릭터 세팅해줘"

1. `planning/캐릭터운영원칙.md` 확인
2. `characters/캐릭터양식.md` 확인
3. 해당 캐릭터 파일 작성 또는 수정
4. `관계망.md`에는 확정된 초기 관계만 반영
5. 원고 생성 금지

### "소설 시작해줘"

1. `planning/시리즈개요.md`
2. `planning/핵심컨셉.md`
3. `setting/개요작성규칙.md`
4. `setting/독서흐름개선규칙.md`
5. `setting/라노벨문체규칙.md`
6. `setting/시나리오작성규칙.md`
7. 성인씬 컨텍스트가 필요할 경우 `setting/성인씬작성규칙.md`
8. `관계망.md`
9. `연대기.md`

이 순서로 읽은 뒤, 먼저 다음 5화 개요안을 제시하고 사용자 확인을 받는다.

### "소설 진행해줘"

- 사용자 확인 없이 자동 진행하는 요청으로 취급한다.
- 단, 새 시리즈 초반 첫 진행에서는 먼저 현재 세팅이 충분한지 점검한다.

12. `연대기.md`

## 파일 저장 규칙

- 일반 에피소드: `episodes/[001-100|101-200|201-300]/ep.[번호].md`
- 성인씬 컨텍스트 포함 에피소드: `episodes/[001-100|101-200|201-300]/ep.[번호]_a.md`
- 같은 번호의 일반 파일과 `_a` 파일을 동시에 만들지 않는다.
- 시나리오 작성 요청 전에는 `episodes/`에 파일을 만들지 않는다.

## 기록 업데이트

- 원고 5화 작성 후에만 `관계망.md`, `연대기.md`, 캐릭터 [가변] 항목을 일괄 업데이트한다.
- 설정 변경과 원고 진행 기록을 섞지 않는다.
