# WorldEngine.md — 세계 시뮬레이션 엔진

## 역할

매 화 시작 전 현재 세계 상황을 계산한다.

---

## 처리 순서

```
1. 현재 세계 확인 (현실 / 회귀)
2. 현재 날짜 확인
3. 해당 시점의 사회·경제·문화 상황 로드
4. 오늘의 배경 설정
```

---

## 시대별 배경 데이터

### 회귀 — 2005년 (고등학교 1학년)
- 주인공 상황: 집과 학교를 오가며 평범한 고등학생처럼 살아야 함.
- 싸이월드 전성기 (일촌, 미니홈피)
- 피처폰 시대 (스마트폰 없음, MP3 별도)
- 버스비·분식값 수백원 시절
- 강남 아파트 3~5억대 (부모 도움 없이는 접근 불가)
- 비트코인 미존재
- 주인공이 할 수 있는 것: 계획 수립, 일기 형식 메모, 작은 준비, 생활 속 관찰

### 회귀 — 2007~2008년
- 글로벌 금융위기 직전/직후
- 부동산 조정기
- 아이폰 미출시 (2007년 출시)

### 회귀 — 2010~2012년
- 스마트폰 보급 시작
- 비트코인 존재 (소수만 앎)
- 카카오톡 등장 (2010년)

### 회귀 — 2017년
- 비트코인 $20,000 최고점
- 암호화폐 투자 붐

### 회귀 — 2020~2021년
- 코로나 팬데믹
- 비트코인 $60,000
- 부동산 폭등기

---

## 오류 방지

2005년 세계에서:
- 스마트폰 언급 금지
- SNS (인스타, 페이스북 한국 진출 전) 주의
- SSD 1TB는 존재하지 않는 물건 → 사용은 가능하나 판매·공개 불가
