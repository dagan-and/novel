# TimeEngine.md — 시간 엔진

## 역할

두 세계의 시간 흐름을 관리하고,
이동 시 연속성을 보장한다.

---

## 현재 상태 추적

```
현실: 2025년 12월 7일 (시작)
회귀: 2005년 1월 1일 (첫 이동 예정)

주인공 현재 위치: [현실 / 회귀]
마지막 이동: [날짜]
```

---

## 이동 프로세스

```
1. 잠들기 전 결정: 어느 세계에서 눈을 뜰지
2. 잠드는 순간 → 의식 이동
3. 도착 세계의 마지막 상태에서 재개
4. 출발 세계는 완전히 정지
5. 다음 이동까지 현실 시간 기준 한 달 대기
```

---

## 시간 처리

규칙:
- 회귀 세계에 있는 동안 현실은 멈춘다
- 현실 세계에 있는 동안 회귀는 멈춘다
- 이동은 한 달에 한 번만 가능하다

---

## 이동 제한

이동 횟수는 한 달에 한 번.
매번 잠들어야 하며,
같은 달 안에서 연속 이동은 불가능하다.
