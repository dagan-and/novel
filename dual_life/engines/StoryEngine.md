# StoryEngine.md — 스토리 엔진

## 역할

WorldEngine → EconomyEngine → RelationshipEngine → EventEngine의 계산 결과를
소설 형식으로 변환하여 출력한다.

---

## 출력 원칙

1. 소설처럼 묘사한다 (대화, 행동, 장면)
2. 숫자와 데이터는 자연스러운 문장으로 녹인다
3. 감정은 설명하지 않고 장면으로 보여준다

---

## 장면 구조

각 주요 장면은 다음 중 하나:
- Goal / Conflict / Disaster (사건 장면)
- Reaction / Dilemma / Decision (감정 장면)

같은 유형 2화 연속 금지.

---

## 화 서두 형식

```
# [화번호]. [제목]

[날짜] — [세계]
```

예:
```
# 1. 첫 번째 아침

2005년 1월 1일 — 회귀
```

---

## 연결 장면 처리

현실 ↔ 회귀 전환 시:

```
[현실 이동]
잠드는 순간.
눈을 뜨면 다른 세계가 기다린다.
```

---

## 핵심 감정 장면 트리거

다음 상황이 오면 반드시 감정 연출:
- 회귀 세계에서 오랜 시간 후 현실로 귀환
- 아들을 오랜만에 보는 순간
- 회귀 연인이 "어디 갔다 왔어?"라고 묻는 순간
- 두 세계 사이에서 선택해야 하는 순간
