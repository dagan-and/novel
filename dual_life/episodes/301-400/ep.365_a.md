# 365. 체감온도 기준

나윤은 편의점 냉동고 앞에서 영수증을 흔들었다.

`체감 30도 이상: 오빠 가능`

[김시안] "아직 밤인데요."

[서나윤] "냉동고 앞은 기준 외예요."

[김시안] "왜요?"

[서나윤] "제가 정했으니까."

강했다.

나윤은 얼음컵을 꺼내 시안 손에 쥐여 줬다.

[서나윤] "부스 날, 더우면 이거 먼저 생각나요?"

[김시안] "나윤 씨가 먼저 생각날 것 같습니다."

나윤의 손이 멈췄다.

그녀는 바로 고개를 돌렸다.

[서나윤] "그런 말은 계산대 밖에서 해요."

[김시안] "여기가 계산대 밖입니다."

나윤은 뒤늦게 주변을 봤다.

창고 앞 좁은 통로.

확실히 계산대 밖이었다.

[서나윤] "치사하네."

그녀는 얼음컵 뚜껑을 손끝으로 눌렀다.

[서나윤] "그럼 오늘은 체감온도 넘은 걸로 해요."

## [성인씬 #14 - ep.365]

- 장소: 야간 편의점 냉동고 옆 좁은 통로와 창고 앞, 얼음컵 행사 박스가 쌓인 자리
- 등장인물:
  - 김시안: 홍보 부스 준비와 호칭 변화 후폭풍 사이에서 나윤의 얼음컵 기준을 장난으로만 넘기지 않는 상태
    - 누적 성인씬 횟수: 해당 없음
  - 서나윤: `손님`과 `오빠`를 체감온도 기준으로 나누며, 장난처럼 보이지만 자기 쪽 호칭을 분명히 아껴 두는 상태
    - 누적 성인씬 횟수: 13회
    - 외형 참고: 균형 잡힌 키에 운동으로 다져진 탄탄한 슬림 체형이라, 시원한 어깨선과 자연스럽게 조여드는 허리, 길게 뻗은 다리선이 먼저 눈에 들어온다. 과한 굴곡보다 가볍고 단단한 근육선이 살아 있어, 얇은 옷차림에서도 몸을 쓰던 사람 특유의 탄력과 긴장감이 바로 느껴진다. 편의점 조명 아래 높게 묶은 머리와 얼음컵을 쥔 손이 직진하는 기세를 만든다.
    - 성격 참고: 직진 / 승부욕 / 장난처럼 던지지만 자기 영역을 놓치지 않음
- 의상:
  - 김시안: 퇴근 후 셔츠와 슬랙스
  - 서나윤: 편의점 유니폼 조끼, 운동화, 묶은 머리
- 이미지 포인트: 나윤이 `체감 30도 이상: 오빠 가능` 영수증을 접지 않고 얼음컵 아래에 끼워 넣는 순간

  - 김시안: 농담으로 넘기려다 진심을 알아차리는 얼굴
  - 서나윤: 이긴 척하지만 먼저 생각난다는 말에 흔들리는 얼굴
- 손 / 시선 포인트:
  - 김시안: 차가운 얼음컵을 놓지 않음
  - 서나윤: 컵뚜껑을 누른 채 시안의 대답을 기다림
- 복장 상태: 유니폼 조끼, 셔츠 소매, 냉동고 앞 생활감 중심
- 배경 소품 강조: 얼음컵, 체감온도 영수증, 냉동고 행사 박스
- 소품 / 환경: 야간 편의점, 냉장고 소음, 창고 앞 좁은 통로
- 분위기 키워드: 체감온도, 오빠 가능, 얼음컵 선점, 장난 속 독점욕

  - 시안 → 서나윤: 나윤 씨
  - 서나윤 → 시안: 평소에는 손님, 독점욕과 장난이 올라올 때 오빠
- 직전 맥락: 홍보 부스 티셔츠와 하린의 한 글자 후폭풍 속에서 나윤이 자기 방식의 `오빠` 기준을 만듦
