# AGENTS.md - 리부트 세션 가이드

## 사용 원칙

- 이 폴더는 기존 `reunion/`의 개편본이 아니라, 같은 세계관과 컨셉을 바탕으로 새로 시작하는 별도 시리즈다.
- 기존 `reunion/episodes/` 원고, 기존 `관계망.md`, 기존 `연대기.md`는 새 시리즈의 확정 맥락으로 사용하지 않는다.
- 새 시리즈 작업은 이 폴더 내부 문서를 기준으로 진행한다.
- 시나리오 작성 요청이 있기 전까지는 `episodes/` 원고를 생성하지 않는다.
- 세부 작업 순서는 `setting/워크플로우.md`를 따른다.
- 세계관 고정 규칙은 `setting/세계관.md`, 시리즈 방향은 `planning/` 문서를 우선 참조한다.
- 술술 읽히는 장면 추력과 화말 훅은 `setting/독서흐름개선규칙.md`를 항상 함께 참조한다.
- 일본 라이트노벨처럼 가볍게 읽히는 문체 기준은 `setting/라노벨문체규칙.md`를 함께 참조한다.
- 성인씬 컨텍스트가 필요한 경우 `setting/성인씬작성규칙.md`를 참조한다.
- 캐릭터 개별 고정/가변 정보는 `characters/` 파일을 따른다.

## 리부트 핵심 방향

- 중심 감정: 생활 밀착 하렘
- 시작 시점: 2014년 3월, 대학 4학년 학기 초
- 주인공 상태: 취업 압박을 느끼지만 결정은 자꾸 미루는 타입
- 초반 생활권: 학교
- 초반 관계 엔진: 박미현을 메인 히로인 축으로 두고, 첫 방문과 반복 방문이 기대와 독점욕으로 커지는 구조
- 진행 원칙: 감정 정리보다 장면 목표, 충돌, 다음 화 유입력을 우선한다.

## 금지 사항

- 기존 시리즈의 사건을 새 시리즈의 확정 과거로 가져오지 않는다.
- 초반부터 관계를 완성된 상태로 시작하지 않는다.
- 상담, 회의, 감정 정리만으로 한 화를 끝내지 않는다.
- 새 인물을 단순 인원 보충용으로 투입하지 않는다.
- 시안이 모든 장면에서 정답만 주는 해결사로 고정되지 않게 한다.
