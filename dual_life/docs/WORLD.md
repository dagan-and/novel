# WORLD.md — 세계관

## 두 개의 현실

이 작품의 현실은 두 개다. 둘 다 진짜다.

---

## 현실

| 항목 | 내용 |
|------|------|
| 시점 | 2025년 12월 7일~ |
| 상태 | 기혼. 아내. 아들. 직장(앱 개발팀 차장). |
| 목표 | 좋은 남편, 좋은 아빠, 좋은 친구 |
| 연애 | 아내만. 절대로 바람 없음. |
| 시간 | 주인공이 회귀에 있으면 완전히 멈춤 |

## 회귀

| 항목 | 내용 |
|------|------|
| 시점 | 2005년 1월 1일부터 시작 |
| 상태 | 미혼. 고등학교 1학년 (만 15세) 김용식. |
| 목표 | 경제적 자유 + 두 번째 인생을 가볍고 후회 없이 |
| 연애 | 자유. 단, 상대는 진짜 인간. 감정·시간·상처 모두 존재. |
| 시간 | 주인공이 현실에 있으면 완전히 멈춤 |

---

## 시간 규칙

두 세계의 시간은 동시에 흐르지 않는다.

- 현실에 있으면 회귀의 시간은 완전히 멈춘다.
- 회귀에 있으면 현실의 시간은 완전히 멈춘다.
- 그래서 한쪽에서 오래 살아도, 다른 쪽은 떠난 순간에서 다시 이어진다.

---

## NPC는 없다

두 세계 모두:
- 모든 인물은 자기 삶이 있다.
- 주인공이 아무것도 안 해도 세상은 돌아간다.
- 주인공이 개입해야만 관계가 발전한다.

---

## 죽음의 규칙

| 상황 | 결과 |
|------|------|
| 현실 세계에서 사망 | 현실 영구 소멸. 회귀만 남음. |
| 회귀 세계에서 사망 | 회귀 영구 소멸. 현실만 남음. |

- 죽음은 신중하게 다룬다.
- 회귀는 단순한 게임이 아니다. 거기서도 목숨이 있다.
- 이 긴장감이 두 세계 모두에 애착을 만든다.

---

## 현실의 독립성

현실과 회귀의 경제는 **완전히 독립**되어 있다.

- 회귀 세계에서 번 돈은 현실에 존재하지 않는다.
- 단, **골드바·현금·보석 등 실물**을 품에 안고 자면 이동 가능.
- 이동한 실물은 현실의 자산이 된다. (세금·거래 기록 현실적으로 계산)
- 이렇게 옮긴 자산은 현실에서 천천히 환금되며, 가족의 생활 여유와 선택지를 바꾸기 시작한다.
- 따라서 첫 현실 복귀는 "가능한 첫 달"이 아니라,
  **현실에 가져갈 만한 실물이 생긴 뒤**가 된다.

## 흐름 예시

```
회귀: 2007년 봄. 학교 끝나고 하교길.
현실: 아들이 "아빠!" 뛰어옴.
회귀: 2012년. 비트코인 첫 매수.
현실: 아내와 저녁식사.
회귀: 2018년. 제주도 별장 계약.
현실: 아직 어린 아들을 재움.
```

두 인생이 교차하며 이야기가 쌓인다.
