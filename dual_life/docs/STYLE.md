## 김용식 소설 고유 규칙

공유 규칙에 추가 또는 우선 적용:

### 화자 태그
- 1:1 대화: 태그 생략 가능 (문맥으로 구분)
- 3인 이상: 반드시 `[이름] "대사"` 사용
- 기억 속 회상은 이탤릭체 없이 평문으로 처리

### 화 서두
```
# [화번호]. [제목]

[날짜] — [현실 / 회귀]
```

### 화 구조
```
[날짜 / 세계]
2007년 4월 15일 — 회귀

[도입]
현재 압력 또는 오늘의 선택. 설명 아닌 장면으로.

[본문]
사건 → 대화 → 감정 → 행동

[마무리]
이 화 끝에 달라진 것 하나.

[마무리]
다음 장면이 궁금해지도록 작은 걸림을 남긴다.
```

### 시간·날짜 표기
- 세계 전환 시 명시: `[현실 이동]`
- 날짜는 항상 첫 줄에

### 속마음 (나이별 톤)

용식의 속마음은 **회귀에서 몇 살이냐**에 따라 달라진다.
같은 사람이지만 말투와 무게감이 다르다.

**고1~고3 (15~17세) — 회귀 초반**
겉은 또래처럼 행동하지만 속은 36살이다.
이 간극 자체가 소재다. 너무 어른스러운 판단을 혼자 삼킨다.
```
급식이 맛없다. 그런데 옆자리 애가 웃어서 그냥 넘어갔다.
문제는 밥이 아니라 그거였다.
```

**대학~20대 (18~29세) — 회귀 중반**
행동 반경이 넓어진다. 돈이 생기기 시작한다.
조급함과 여유가 섞이는 시기.
```
계좌에 처음으로 천만 원이 찍혔다.
실감이 없다. 숫자일 뿐이다.
```

**30대 이후 (현실의 자신과 같아질 때)**
두 세계 사이의 감각이 흐릿해지기 시작한다.
어느 쪽에서 더 오래 살았는지 잠깐 흐려지는 순간이 생긴다.
```
그래봤자 내 돈이 실제로 불어난 건 아니다.
```
```
그래도 집에 오면 아들은 아직 세 살이다.
```

**현실 세계에서의 속마음**
회귀를 다녀온 뒤의 감각. 무게감이 다르다.
아들을 안을 때, 아내 목소리를 들을 때.
```
5년이 지났는데 아직 세 살이다.
```

## 일상 소재 (나이별 구분)

매 화는 거창한 사건이 아니어도 된다.
단, **회귀의 나이에 맞는 소재**를 쓴다.

**회귀 — 고1~고3 (15~17세)**
학교 급식, 자습실, 피시방, 친구 관계,
용돈 모으기, 작은 준비, 수능 공부하는 척, 아르바이트 고민,
첫사랑, 썸, 하교길, 문자 기다림

**회귀 — 대학~20대 초 (18~25세)**
자취방, 학교 앞 식당, 첫 계좌 개설, 소액 투자 첫 경험,
미팅·소개팅, 군대 문제, 아르바이트·인턴, 친구 결혼식

**회귀 — 20대 후반~30대 (25세~)**
부동산 발품, 와인 배우기, 골프 첫 레슨, 새 차 계약,
사업 아이디어, 직원 채용, 해외여행, 연인과의 일상

**현실**
아들과 목욕, 아내와 저녁, 직장 일상, 생일, 준비 과정

이것 자체가 이야기다.
