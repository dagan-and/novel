# 개요 작성 규칙 — 김용식 / 이중 현실

## 적용 범위

- `소설 시작해줘`, `다음 화 써줘`, `개요 짜줘` 요청 시 적용한다.
- 현재 세팅 단계에서는 개요를 작성하지 않는다.

---

## 기본 참조

개요 작성 전 반드시 확인:
- `../setting/독서흐름개선규칙.md` — Scene/Sequel 균형, 화말 훅, 개요 전 체크
- `docs/SYSTEM.md` — 절대 규칙 (주인공 편 들지 않기, 결말로 달려가지 않기)
- `states/current_state.json` — 현재 세계, 날짜, 자산, 관계 상태
- `states/연대기.md` — 회귀 타임라인 (설정 충돌 방지)
- `states/recent_topics.json` — 최근 20화 소재 (패턴 반복 방지)

---

## 이 소설의 개요가 다른 이유

일반 연재소설은 **플롯**이 화를 만든다.
이 소설은 **삶**이 화를 만든다.

개요의 목적은 극적 사건을 배치하는 것이 아니라,
오늘 용식이 어느 세계에서 무엇을 하며 살아가는지를 설계하는 것이다.

---

## 매 화 체크리스트

| 항목 | 질문 |
|------|------|
| 세계 | 현실인가, 회귀인가? |
| 날짜 | 정확한 날짜는? (회귀는 연도·나이 확인) |
| 오늘의 사건 | 용식이 오늘 하려는 것은? (1~2개) |
| 방해 | 뜻대로 안 되는 요소는? |
| 달라진 것 | 화 끝에 전과 달라진 것 하나는? |
| 훅 | 다음 화가 궁금해지는 이유는? |

---

## 5화 미니 아크 규칙

5화 단위로 다음 균형을 맞춘다:

| 조건 | 기준 |
|------|------|
| 세계 균형 | 현실 화 최소 1개 포함 |
| 감정 화 | 두 세계 간 감정 교차 최소 1회 |
| 소재 다양성 | 같은 소재 축 3화 연속 금지 |
| 누적 변화 | 5화 끝에 되돌리기 어려운 변화 하나 (자산, 관계, 결정) |
| 훅 유형 | 같은 훅 유형 3화 연속 금지 |

---

## 훅 유형 (이 소설 전용)

일반 로맨스 훅과 다르다. 다음 유형 중 선택:

| 훅 유형 | 예시 |
|---------|------|
| 투자 타이밍 | "내일 사야 하는데 돈이 아직 안 모였다" |
| 관계 변화 | 회귀 친구가 오늘 이상하게 굴었다 |
| 세계 전환 예고 | 오늘 밤 회귀로 간다 / 현실로 돌아간다 |
| 준비 압박 | 12월 31일이 다가온다 |
| 기억 불일치 | 분명히 이 날짜인데 기억과 다르다 |
| 현실의 순간 | 회귀에서 오래 있다가 돌아왔더니 아들이 "아빠!" 한다 |

---

## 나이별 개요 방향

### 회귀 — 고1~고3 (15~17세)
- 투자 직접 불가 → 준비, 관찰, 종잣돈 고민이 주요 갈등
- 학교 생활 + 36살 어른의 속마음 간극이 핵심 재미
- 5화 단위: 학교 일상 3화 + 관계 변화 1화 + 현실 귀환 1화

### 회귀 — 대학~20대 초 (18~25세)
- 첫 계좌, 첫 투자, 첫 자취가 소재 축
- 친구 관계, 연애 첫 시도가 등장 가능
- 5화 단위: 경제 2화 + 관계 2화 + 현실 귀환 1화

### 회귀 — 20대 후반 이후
- 자유로운 일상 + 취미 + 사업 참여 + 연애
- 5화 단위: 취미/여행 2화 + 투자 1화 + 관계 1화 + 현실 귀환 1화

### 현실 화
- 아들, 아내, 직장, 준비 과정 중심
- 회귀에서 오래 있다가 돌아오는 귀환 감정을 반드시 살린다
- 직장 일상도 가능 (단, 2화 연속 금지)

---

## 세계 전환 화 특별 규칙

현실 → 회귀, 회귀 → 현실 이동 화는 별도로 설계한다.

필수 포함:
- 이동 직전 장면 (무엇을 하다가 잠드는가)
- 이동 직후 장면 (어느 세계에서 눈을 뜨는가)
- 이동 순간의 감정 (기대, 망설임, 그리움 중 하나)

```
ep.XXX — [세계] [날짜]
제목:
오늘의 사건:
방해 요소:
달라진 것:

ep.XXX — ...
```

## 금지 패턴

| 금지 | 이유 |
|------|------|
| 5화 연속 회귀만 | 현실이 사라지면 감정 축이 무너짐 |
| 투자 성공 나열 | 숫자가 이야기를 대신하면 안 됨 |
| 고1에서 성인 소재 | 나이 오류. EventEngine 소재 풀 참조 |
| "몇 달 후" 요약 점프 | 날짜를 정확히 써야 설정 충돌 방지 가능 |
| 감정 정리만으로 화 마무리 | 독서흐름개선규칙.md Sequel 연속 금지 적용 |
