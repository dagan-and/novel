# CLAUDE.md — 세션 가이드

## 세션 시작 시 참조 순서

1. `setting/세계관.md` — 루프 구조 / 픽업 원칙 / 호칭 규칙 / 하렘 시스템
2. `setting/워크플로우.md` — STEP 1~3 / 성인씬 구역 / 파일 형식 / 루프 전환 / 첨부 원칙
3. `관계망.md` — 현재 하렘 현황
4. `연대기.md` — 에피소드 연대기

## 파일 구조

```
reunion/
├── CLAUDE.md            세션 가이드 (이 파일)
├── 관계망.md          하렘 현황 + 멤버 간 관계망 + 복선 트래커
├── 연대기.md           에피소드 연대기
├── characters/          캐릭터 개별 파일
│   ├── 김시안.md
│   ├── 캐릭터양식.md
│   └── [이름].md
├── episodes/            에피소드 원고
│   ├── ep.[번호].md      성인씬 없는 화
│   └── ep.[번호]_a.md   성인씬 포함 화
└── setting/
    ├── 세계관.md          세계관 규칙 + 하렘 시스템
    └── 워크플로우.md       작업 절차 + 파일 형식 + 성인씬 구역
```
