# CLAUDE.md — 세션 가이드

## 트리거 명령어

### "소설 진행해줘"

아래 순서로 5화를 자동 처리한다. 단계별로 사용자 확인 없이 연속 실행한다.

1. **STEP 1** — 다음 5화 개요 작성 (세계관.md + 연대기.md + 관계망.md 참조)
2. **STEP 2 × 5** — 개요 순서대로 5화 시나리오 작성 및 `episodes/` 파일 저장
3. **STEP 3** — 캐릭터 파일 [가변] 항목 / 관계망.md / 연대기.md 일괄 업데이트
4. **STEP 4** — HTML 변환 3종 실행 → Git 커밋·푸시
5. **5화 점검** — 연대기.md + 관계망.md 기준 점검 항목 출력

> 각 STEP 세부 규칙은 `setting/워크플로우.md` 준수

-----

## 세션 시작 시 참조 순서

1. `setting/세계관.md` — 루프 구조 / 픽업 원칙 / 호칭 규칙 / 하렘 시스템
2. `setting/워크플로우.md` — STEP 1~3 / 성인씬 구역 / 파일 형식 / 루프 전환 / 첨부 원칙
3. `관계망.md` — 현재 하렘 현황
4. `연대기.md` — 에피소드 연대기

## 파일 구조

```
reunion/
├── CLAUDE.md            세션 가이드 (이 파일)
├── 관계망.md          하렘 현황 + 멤버 간 관계망 + 복선 트래커
├── 연대기.md           에피소드 연대기
├── characters/          캐릭터 개별 파일
│   ├── 김시안.md
│   ├── 캐릭터양식.md
│   └── [이름].md
├── episodes/            에피소드 원고
│   ├── ep.[번호].md      성인씬 없는 화
│   └── ep.[번호]_a.md   성인씬 포함 화
└── setting/
    ├── 세계관.md          세계관 규칙 + 하렘 시스템
    └── 워크플로우.md       작업 절차 + 파일 형식 + 성인씬 구역
```
