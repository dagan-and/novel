## 멤버 간 관계망

### 임소율 × 이하은
- 현재: 감정과 실무를 각자 다른 방식으로 지탱하는 안정적 공존
- 최근 변화: 소율은 가족선 앞에서도 자기 감정을 숨기지 않았고, 하은은 다온과의 협업을 늘리며 소율이 감정적으로 흔들릴 자리를 조금 더 비워 두기 시작했다
- 예정 분기: 바빠지는 봄 일정 속에서도 둘이 서로의 빈틈을 얼마나 자연스럽게 메우는지 확인
- 호칭: 소율 → 하은 `하은아` / 하은 → 소율 `소율 언니` (동갑이지만 소율 생일 빠름)

### 임소율 × 한서진
- 현재: 운영 현장과 가족선 위기 앞에서 서로를 자연스럽게 받쳐 주는 같은 편
- 최근 변화: 서진은 소율의 가족 긴장 앞에서 공간 전체의 분위기를 정리해 주었고, 소율은 서진이 만든 기준 안에서 더 직접적으로 자기 자리를 드러내기 시작했다
- 예정 분기: 외부 압박과 개인 감정이 동시에 밀려올 때 둘이 얼마나 빠르게 같은 편으로 정렬되는지 확인
- 호칭: 서진 → 소율 `소율아` / 소율 → 서진 `서진 언니`

### 이하은 × 한서진
- 현재: 새 변수들이 읽는 기준선이자, 그 의미를 서열이 아닌 공동 규칙으로 다시 세운 핵심 메인 동맹
- 최근 변화: 다온이 외부 기사 방향을 끊어 내는 순간을 함께 받아 낸 뒤, 하은과 서진은 먼저 쌓인 시간의 무게를 직접 확인하고 같은 편의 기준으로 다시 묶었다
- 예정 분기: 새 서브 후보들이 더 깊이 들어올수록 둘이 공동 기준을 얼마나 흔들림 없이 유지하는지 확인
- 호칭: 서진 → 하은 `하은아` / 하은 → 서진 `서진 언니`

### 임소율 × 정다온
- 현재: 경계를 인정한 채 서로의 자리를 지켜 주는 직접 합의 단계
- 최근 변화: 다온은 외부 제안을 끊고 태준 방문 때도 빠지지 않으며 말보다 행동으로 약속을 지켰고, 소율은 그런 다온을 완전히 밀어내지 않은 채 자기 기준을 더 뚜렷하게 세웠다
- 예정 분기: 다온이 생활권 안에 더 깊게 들어올수록 둘이 질투보다 합의의 언어를 얼마나 유지하는지 확인
- 호칭: 소율 → 다온 `다온 씨` / 다온 → 소율 `소율 씨`

### 이하은 × 정다온
- 현재: 창작과 실무를 함께 돌리면서도, 내부 질서를 바깥 언어로 소비하지 않는다는 합의까지 공유한 협업 관계
- 최근 변화: 다온은 외부 기사 방향을 직접 끊어 냈고, 하은은 그 선택을 받아 공간 안쪽 사람의 판단으로 인정했다
- 예정 분기: 하은이 다온에게 표현과 기록의 더 민감한 판단까지 얼마나 맡길 수 있을지 확인
- 호칭: 하은 → 다온 `다온 씨` / 다온 → 하은 `하은 씨`

### 한서진 × 정다온
- 현재: 외부 시선을 직접 걸러 내며 공간의 체면과 내부 질서를 함께 지키는 실무적 신뢰 관계
- 최근 변화: 다온은 기사 방향을 끊어 내며 안쪽 사람의 기준을 행동으로 다시 증명했고, 서진은 그 선택을 공간을 지키는 판단으로 분명히 받아들였다
- 예정 분기: 다온이 단순 기록자를 넘어 공간 운영의 더 민감한 설명 방식까지 함께 잡을 수 있을지 확인
- 호칭: 서진 → 다온 `다온 씨` / 다온 → 서진 `서진 씨`

### 한서진 × 박미현
- 현재: 웃는 얼굴로 선을 건드리는 쪽과, 그 선을 웃으면서도 정확히 되돌려 놓는 쪽의 공개 견제 단계
- 최근 변화: 서진이 세운 선은 그대로지만, 미현은 첫 입맞춤 이후에도 물러서지 않았고 이제는 순서를 훔치기보다 불릴 만한 자리를 만들겠다는 쪽으로 욕심의 방향을 바꾸기 시작했다
- 예정 분기: 미현이 달라진 방식으로 다시 들어올 때 서진이 그것을 어디까지 허용하고 어디서 끊을지 확인
- 호칭: 서진 → 박미현 `미현 씨` / 박미현 → 서진 `한서진 씨`

### 임소율 × 박미현
- 현재: 먼저 쌓인 시간의 무게를 숨기지 않는 쪽과, 제일 늦게 들어온 순서를 견디지 못하는 쪽의 직접 대면 단계
- 최근 변화: 소율은 미현을 직접 찾아가 자기 자리를 숨기지 않았고, 미현은 그 앞에서 순서를 훔치고 싶진 않지만 자기 이름이 불릴 자리는 갖고 싶다고 처음 분명히 말했다
- 예정 분기: 미현이 실제로 방식을 바꿔 들어올 때 소율이 그 변화를 인정할지, 아니면 더 날카롭게 거를지 확인
- 호칭: 소율 → 박미현 `미현 씨` / 박미현 → 소율 `소율 씨`

### 이하은 × 오연서
- 현재: 생활 동선과 결과물의 결을 함께 맞춰 보며, 실무 신뢰가 감각적 친밀감으로 천천히 번지기 시작한 관계
- 최근 변화: 하은은 연서를 마감 뒤까지 붙잡아 실제 서비스 흐름을 같이 보게 했고, 연서는 그 안에서 시안과의 첫 접촉까지 겪으며 더 오래 남아 볼 이유를 얻었다
- 예정 분기: 하은이 연서를 단순 납품자가 아니라 생활권 안쪽 감각 담당으로 얼마나 더 끌어들일지 확인
- 호칭: 하은 → 오연서 `연서 씨` / 오연서 → 하은 `하은 씨`

### 한서진 × 오연서
- 현재: 공간 동선과 식기 기준을 바로 공유할 수 있는 담백한 실무 호흡의 시작
- 최근 변화: 연서는 마감까지 남아 실제 서비스 흐름을 끝까지 확인했고, 서진은 그 느리지만 집요한 감각이 단순 납품 이상으로 이어질 수 있음을 더 분명히 봤다
- 예정 분기: 연서가 느린 속도 그대로도 공간 안쪽 협력자로 자리를 만들 수 있을지 확인
- 호칭: 서진 → 오연서 `연서 씨` / 오연서 → 서진 `서진 씨`
