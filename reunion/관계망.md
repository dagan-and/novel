## 멤버 간 관계망

### 임소율 × 이하은
- 타입: 동맹
- 현재: 먼저였던 시간의 무게와 지금의 역할을 분리해도 같은 편으로 설 수 있는 안정적 공존
- 최근 변화: 소율은 생활 안에서 뒤로 밀릴까 무섭다는 속내를 하은에게 직접 꺼낸 데서 더 나아가, 이제는 월요일 아침 시간과 주간 정산·예약 체크를 자기 몫으로 직접 가져가며 그 불안을 실제 역할로 묶기 시작했다
- 예정 분기: 소율이 새로 가져간 생활 리듬의 고정축을 하은이 기존 기준선과 어떻게 자연스럽게 맞물리게 할지 확인
- 호칭: 소율 → 하은 `하은아` / 하은 → 소율 `소율 언니` (동갑이지만 소율 생일 빠름)

### 임소율 × 배수인
- 타입: 긴장
- 현재: 먼저 들어온 시간의 무게를 아는 메인과, 늦게 들어온 불안을 숨기지 못하는 후보가 기준을 직접 주고받은 뒤의 긴장 섞인 승인 초입
- 최근 변화: 소율은 수인에게 시안을 흔들어 빨리 눈에 띄는 쪽이 아니라 그의 생활이 무너지지 않게 서는 쪽을 택하라고 말했고, 수인은 없는 사람 취급은 받지 않되 어느 편에 서는지로 버티겠다고 답했다
- 예정 분기: 수인이 실제 서브로 들어온 뒤에도 소율이 그녀를 경계보다 역할 쪽으로 더 받아들이게 될지, 수인이 그 신뢰를 계속 지켜 낼지 확인
- 호칭: 소율 → 배수인 `수인 씨` / 배수인 → 소율 `소율 씨`

### 임소율 × 한서진
- 타입: 동맹
- 현재: 운영 현장과 가족선 위기 앞에서 서로를 자연스럽게 받쳐 주는 같은 편
- 최근 변화: 서진은 소율의 가족 긴장 앞에서 공간 전체의 분위기를 정리해 주었고, 소율은 서진이 만든 기준 안에서 더 직접적으로 자기 자리를 드러내기 시작했다
- 예정 분기: 외부 압박과 개인 감정이 동시에 밀려올 때 둘이 얼마나 빠르게 같은 편으로 정렬되는지 확인
- 호칭: 서진 → 소율 `소율아` / 소율 → 서진 `서진 언니`

### 이하은 × 한서진
- 타입: 동맹
- 현재: 새 변수들이 읽는 기준선이자, 그 의미를 서열이 아닌 공동 규칙으로 다시 세운 핵심 메인 동맹
- 최근 변화: 다온이 외부 기사 방향을 끊어 내는 순간을 함께 받아 낸 뒤, 하은과 서진은 먼저 쌓인 시간의 무게를 직접 확인하고 같은 편의 기준으로 다시 묶었다
- 예정 분기: 새 서브 후보들이 더 깊이 들어올수록 둘이 공동 기준을 얼마나 흔들림 없이 유지하는지 확인
- 호칭: 서진 → 하은 `하은아` / 하은 → 서진 `서진 언니`

### 임소율 × 정다온
- 타입: 긴장
- 현재: 역할과 감정을 분리해 읽으며 서로의 자리를 실제 운영 안에서 인정하는 직접 합의 단계
- 최근 변화: 다온은 시안 부재 시간대를 끝까지 받아 내며 안쪽 중심축 역할을 증명했고, 소율은 그 사실을 위협으로만 읽지 않은 채 자기 앞자리를 역할로도 지키는 쪽으로 태도를 조정했다
- 예정 분기: 시안의 부재 시간이 더 늘어날수록 둘이 감정과 실무를 얼마나 자연스럽게 같은 편 언어로 묶는지 확인
- 호칭: 소율 → 다온 `다온 씨` / 다온 → 소율 `소율 씨`

### 이하은 × 정다온
- 타입: 동맹
- 현재: 시각 언어와 안쪽 질서를 함께 조정하는 공동 운영 동맹
- 최근 변화: 하은은 연서를 따로 검증하는 와중에도 다온과 안내 문장과 배치 기준을 함께 조정했고, 여름 시음회 뒤에는 그녀를 바깥 기록자가 아니라 기준을 같이 세우는 안쪽 사람으로 더 분명히 받아들였다
- 예정 분기: 다온이 하은의 감각 언어를 얼마나 더 자연스럽게 이어받아, 하은 부재 시에도 같은 결을 유지할 수 있을지 확인
- 호칭: 하은 → 다온 `다온 씨` / 다온 → 하은 `하은 씨`

### 이하은 × 배수인
- 타입: 탐색
- 현재: 안쪽 기준을 직접 건넨 사람과, 그 기준을 이제 자기 손으로 문장까지 잘라 내며 받아들이기 시작한 서브의 관계
- 최근 변화: 하은은 수인에게 브랜드 문장을 직접 고치게 하며 바깥 언어를 안쪽 공기로 바꾸는 방식을 시험했고, 수인은 절충 대신 직접 지우고 남길 말을 고르며 그 기준을 통과했다
- 예정 분기: 수인이 하은의 언어를 단발성 통과가 아니라 반복 가능한 감각으로 익혀, 바깥 시스템과 안쪽 공간 사이를 어디까지 정확히 번역할 수 있을지 확인
- 호칭: 하은 → 배수인 `수인 씨` / 배수인 → 이하은 `하은 씨`

### 한서진 × 정다온
- 타입: 동맹
- 현재: 입구와 바깥 시선을 함께 걸러 내며, 실제 운영 시간표까지 나눠 맡는 실무적 핵심 동맹
- 최근 변화: 시안의 하반기 취업 일정이 실제로 겹치자 다온은 입구 응대와 예약 명단 정리를 먼저 떠안겠다고 나섰고, 서진은 그 선택을 자연스럽게 받아들이며 처음으로 `다온아`라고 불렀다. 다온 역시 `서진 언니`로 받아치며 두 사람 사이의 거리감이 한 단계 줄었다
- 예정 분기: 다온이 서진과 함께 시안 부재 시간대의 현장 운영까지 흔들림 없이 굴려, 메인 승격 이후 역할 재편을 완전히 자기 것으로 만들 수 있을지 확인
- 호칭: 서진 → 다온 `다온아` / 다온 → 서진 `서진 언니`

### 한서진 × 박미현
- 타입: 긴장
- 현재: 실제 기여는 인정하지만, 미현이 생활 안쪽까지 욕심내는 순간 어디서 선을 끊어야 하는지 서로 더 분명히 의식하는 경계 섞인 승인 단계
- 최근 변화: 미현은 냉장고 고장과 단체 예약 변동 속에서도 디저트 라인을 다시 살려 냈지만, 동시에 준비실 안쪽 수납과 생활 동선을 자기 것처럼 익히려 드는 조짐까지 드러냈다. 서진은 그 기여는 인정하되 보이는 것과 손대도 되는 것은 다르다고 선을 다시 그었다
- 예정 분기: 미현이 서진의 경계를 넘지 않으면서도 자기 역할을 더 깊게 고정할 수 있을지, 혹은 안쪽 자리 욕심이 다시 실무선 긴장으로 번질지 확인
- 호칭: 서진 → 박미현 `미현 씨` / 박미현 → 서진 `한서진 씨`

### 임소율 × 박미현
- 타입: 긴장
- 현재: 생활의 고정축을 이미 쥔 메인과, 그 안사람 자리를 정면으로 탐내기 시작한 서브가 서로의 시선을 더 숨기지 않는 직접 긴장 단계
- 최근 변화: 소율은 운영 위기 속에서 다시 한 번 아침 리듬을 먼저 붙잡아 자기 자리를 증명한 뒤, 미현에게 안쪽 자리는 흉내가 아니라 시간으로 남는 것임을 직접 못 박았다. 미현도 그 말을 피하지 않고, 소율의 자리를 베끼는 대신 자기 시간대를 따로 만들겠다고 방향을 틀었다
- 예정 분기: 미현이 정말로 자기 방식의 안쪽 자리를 만들어 소율의 경계를 누그러뜨릴지, 아니면 더 집요하게 소율의 자리를 의식하며 긴장을 키울지 확인
- 호칭: 소율 → 박미현 `미현 씨` / 박미현 → 소율 `소율 씨`

### 이하은 × 오연서
- 타입: 우정
- 현재: 실사용 기준을 공유한 데서 더 나아가, 연서가 먼저 다음 계절 운영 감각을 제안하기 시작한 협력 관계
- 최근 변화: 하은은 결과물을 평가하는 쪽에만 머물지 않고 연서가 장마철 동선과 디저트 라인까지 함께 보는 제안을 받아들였고, 연서는 그제야 될지 모르는 아이디어도 먼저 꺼내 놓기 시작했다
- 예정 분기: 연서가 생활 식기와 공간 감각을 넘어, 메뉴와 체류 시간까지 읽는 제안을 어디까지 자연스럽게 넓힐 수 있을지 확인
- 호칭: 하은 → 오연서 `연서야` / 오연서 → 하은 `하은 언니`

### 한서진 × 오연서
- 타입: 우정
- 현재: 공간 동선과 식기 기준을 넘어, 먼저 손대고 수정해도 되는 실무 신뢰까지 확보한 안쪽 운영 호흡
- 최근 변화: 장마 저녁의 평일 운영에서 연서는 선반 표식과 접시 판단으로 미현 라인을 끝까지 받쳐 냈고, 서진은 그 결과를 보고 처음으로 `연서야`라고 부르며 직접 고쳐도 되는 권한까지 넘겼다
- 예정 분기: 연서가 실무 신뢰를 바탕으로 계절 메뉴와 체류 감각까지 얼마나 자연스럽게 먼저 제안할 수 있을지 확인
- 호칭: 서진 → 오연서 `연서야` / 오연서 → 서진 `서진 씨`

### 정다온 × 박미현
- 타입: 긴장
- 현재: 같은 사람을 의식하는 긴장을 남긴 채, 안쪽 통로를 운영 기준으로 넘길 수 있는지까지 검증을 마친 승인 단계
- 최근 변화: 다온은 냉장 보관 위기 때 미현을 바로 호출해 실제 준비 인력처럼 움직이게 했고, 미현이 그 기대를 메뉴와 속도로 받아낸 걸 끝까지 확인했다
- 예정 분기: 새 외부 인력이 안쪽으로 들어올 때도 둘이 같은 편 언어를 유지한 채 미현의 역할을 더 분명히 세울 수 있을지 확인
- 호칭: 다온 → 박미현 `미현 씨` / 박미현 → 다온 `다온 씨`

### 박미현 × 오연서
- 타입: 탐색
- 현재: 늦게 들어온 순서와 느린 속도를 각자 다르게 의식하면서도, 실제 평일 라인을 함께 맡는 서브 공존의 고정 단계
- 최근 변화: 장마 저녁의 실전 운영에서 미현은 예비 디저트와 손님 표정을 먼저 읽었고, 연서는 선반 표식과 접시 온도를 바로 바꿔 그 흐름을 받쳐 냈다. 둘은 이제 서로를 보조가 아니라 같은 라인의 사람으로 부를 수 있게 됐다
- 예정 분기: 둘이 장기 운영에서도 서로의 속도 차이를 강점으로 굴리며, 디저트·식기 라인을 자기들 언어로 어디까지 정교하게 고정할 수 있을지 확인
- 호칭: 연서 → 박미현 `미현 씨` / 박미현 → 오연서 `연서 씨`

### 한서진 × 배수인
- 타입: 탐색
- 현재: 외부 운영 인력을 시험하던 단계를 넘어, 어느 편에 설지 스스로 고른 사람을 실제 안쪽 인력으로 받아들인 승인 관계
- 최근 변화: 서진은 수인이 자기 이름을 남길 수 있는 후원 행사 기획을 스스로 끊어 내고 그 문서를 먼저 와인바로 가져온 걸 확인한 뒤, 후보 단계를 끝내고 서브 진입을 직접 판정했다
- 예정 분기: 수인이 서브로 들어온 뒤에도 서진의 현장 기준을 일시적 선택이 아니라 생활 리듬으로 계속 지켜 낼 수 있을지 확인
- 호칭: 서진 → 배수인 `수인 씨` / 배수인 → 한서진 `한서진 씨`

### 정다온 × 배수인
- 타입: 탐색
- 현재: 같은 현장을 다른 언어로 읽던 둘이, 어느 문장을 살리고 자를지 함께 판정해 볼 수 있게 된 탐색 이후 단계
- 최근 변화: 다온은 브랜드 VIP 요구 때 수인이 애매한 절충 대신 직접 잘라 내는 선택을 하자, 그 문장을 처음으로 안쪽 기준 위에서 통과시켰다
- 예정 분기: 수인이 서브 진입 이후에도 문장과 현장을 흐리지 않을지, 다온이 그녀를 바깥 번역자가 아니라 안쪽 기록 언어의 일부로까지 받아들일지 확인
- 호칭: 다온 → 배수인 `수인 씨` / 배수인 → 정다온 `정다온 씨`

### 박미현 × 배수인
- 타입: 탐색
- 현재: 늦게 들어온 사람만이 아는 조급함을 서로 다른 방식으로 읽어 낸 첫 직접 대면
- 최근 변화: 미현은 수인에게 빨리 불리고 싶은 마음을 버려야 오래 간다고 못 박았고, 수인은 그 말을 받아들인 채 결과물과 선택으로 자기 자리를 만들겠다는 쪽으로 한 번 더 방향을 틀었다
- 예정 분기: 수인이 실제로 사람보다 결과물과 기준으로 먼저 불릴 수 있을지, 미현이 그 변화를 경계보다 인정 쪽으로 읽게 될지 확인
- 호칭: 미현 → 배수인 `수인 씨` / 배수인 → 박미현 `미현 씨`
