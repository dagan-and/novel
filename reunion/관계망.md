## 멤버 간 관계망

### 임소율 × 이하은
- 현재: 각자 다른 방식으로 감정을 앞에 내놓으면서도, 외부 시선과 내부 피로를 함께 분담하는 안정적 공존
- 최근 변화: 소율은 이해하는 사람 역할에만 머물지 않겠다고 했고, 하은은 다온에게 사진 셀렉을 실제로 맡기며 혼자 읽어내던 부담을 나누기 시작했다
- 예정 분기: 둘이 각각 자신의 욕심과 한계를 더 분명히 드러낼수록 조율 감각이 더 단단해지는지 확인
- 호칭: 소율 → 하은 `하은아` / 하은 → 소율 `소율 언니` (동갑이지만 소율 생일 빠름)

### 임소율 × 한서진
- 현재: 운영 현장과 대외 압박 앞에서 서로 다른 방식으로 중심을 세우는 같은 편
- 최근 변화: 소율은 공간 안 사람 냄새가 남는 언어를 보탰고, 서진은 외부 홍보 제안을 혼자 받지 않고 소율까지 포함한 내부 기준으로 되받아치기 시작했다
- 예정 분기: 외부 제안이 더 커질수록 두 사람이 실무와 감정 양쪽에서 얼마나 자연스럽게 역할을 나누는지 확인
- 호칭: 서진 → 소율 `소율아` / 소율 → 서진 `서진 언니`

### 이하은 × 한서진
- 현재: 공간의 미감과 운영 기준을 함께 지키는 실무 동맹
- 최근 변화: 하은은 보여 줄 수 있는 것과 없는 것을 문장으로 정리했고, 서진은 외부 홍보 제안을 그 기준선 안으로 끌어와 둘의 판단을 공동 기준으로 만들었다
- 예정 분기: 공간이 더 알려질수록 두 사람이 미감과 브랜딩의 선을 어디까지 같이 고수하는지 확인
- 호칭: 서진 → 하은 `하은아` / 하은 → 서진 `서진 언니`

### 임소율 × 정다온
- 현재: 경계와 호의를 동시에 인정한 직접 합의 단계
- 최근 변화: 소율은 다온을 따로 불러 자기 불안과 욕심을 숨기지 않겠다고 분명히 말했고, 다온은 소율이 자기 자리를 설명하느라 지치게 만들지 않겠다고 답했다
- 예정 분기: 다온이 실제 행동으로 그 약속을 얼마나 지키는지, 소율이 그 앞에서 더 자연스럽게 욕심을 드러내는지 확인
- 호칭: 소율 → 다온 `다온 씨` / 다온 → 소율 `소율 씨`

### 이하은 × 정다온
- 현재: 기준 검증을 넘어 실제로 일을 나누기 시작한 조용한 협업 관계
- 최근 변화: 하은은 다온에게 사진 셀렉과 캡션 초안을 맡기며 부담을 나눴고, 다온은 그 기준을 이해한 채 외부 홍보 문구를 함께 걸러 냈다
- 예정 분기: 하은이 다온에게 더 넓은 실무를 맡길 수 있을 만큼 신뢰를 쌓는지 확인
- 호칭: 하은 → 다온 `다온 씨` / 다온 → 하은 `하은 씨`

### 한서진 × 정다온
- 현재: 외부 언어를 함께 막아내는 실무적 신뢰 형성 단계
- 최근 변화: 서진은 홍보 제안 압박을 다온 앞에 그대로 꺼냈고, 다온은 기사와 브랜딩 문구를 직접 걸러 내며 공간 쪽 사람으로 행동했다
- 예정 분기: 외부 노출의 유혹이 더 커질수록 두 사람이 상업성보다 기준을 우선하는 같은 편으로 남는지 확인
- 호칭: 서진 → 다온 `다온 씨` / 다온 → 서진 `서진 씨`
