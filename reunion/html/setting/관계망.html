하렘 현황

이름구분친밀도관계 진도현재 상태
임소율메인깊은3단계활성 — 새 변수 앞에서도 자기 불안과 자리를 직접 말하며, 애매한 거리보다 분명한 합의를 더 선호하기 시작함
이하은메인깊은3단계활성 — 외부 시선의 결을 가장 먼저 읽어내되, 이제는 버거운 부담을 혼자 떠안지 않고 자기 기준을 먼저 말하려 함
한서진메인깊은3단계활성 — 운영과 외부 노출의 기준을 붙잡는 동시에, 버거운 순간에는 시안에게 먼저 기대는 쪽으로 조금 더 이동함
정다온서브 후보보통2단계활성 — 취재자의 선을 넘는 첫 확인 뒤에도 물러서지 않고, 이 생활권 안에 솔직한 사람으로 남고 싶다고 직접 밝힘

멤버 간 관계망

임소율 × 이하은

  • 현재: 서로 다른 강점을 유지한 채 오픈 이후의 외부 시선까지 함께 감당하는 안정적 공존
  • 최근 변화: 소율은 운영 리듬 안에서 자기 자리를 더 직접 요구했고, 하은은 바깥 기록자의 시선이 공간 안으로 들어오는 방식을 먼저 읽어 냄
  • 예정 분기: 새 변수 정다온이 반복적으로 드나들 때도 지금의 조율 감각이 유지되는지 확인
  • 호칭: 소율 → 하은 하은아 / 하은 → 소율 소율 언니 (동갑이지만 소율 생일 빠름)

임소율 × 한서진

  • 현재: 운영 현장에서 서로 다른 긴장을 나눠 맡는 같은 편
  • 최근 변화: 소율은 역할에만 묶이지 않겠다는 요구를 분명히 했고, 서진은 그런 소율의 자리를 실무 안에서 자연스럽게 비워 두기 시작함
  • 예정 분기: 오픈 이후 바쁜 일상 속에서도 두 사람이 경쟁보다 보완 쪽으로 계속 정렬되는지 확인
  • 호칭: 서진 → 소율 소율아 / 소율 → 서진 서진 언니

이하은 × 한서진

  • 현재: 공간의 기준과 표현 방식을 함께 지키는 실무 동맹
  • 최근 변화: 하은은 다온의 취재 시선을 빠르게 읽어 냈고, 서진은 기사 제목까지 직접 걸러 내며 외부 노출의 기준선을 세움
  • 예정 분기: 가게가 더 알려질수록 두 사람이 어디까지 공개하고 어디서부터 닫을지 기준을 맞춰 가는지 확인
  • 호칭: 서진 → 하은 하은아 / 하은 → 서진 서진 언니

임소율 × 정다온

  • 현재: 경계와 호의가 동시에 놓인 첫 합의 단계
  • 최근 변화: 소율은 다온 앞에서 자기 자리를 먼저 밝히며 애매한 거리보다 솔직한 합의를 택했고, 다온은 그 말을 피하지 않고 받아들였다
  • 예정 분기: 다온이 시안을 향한 호기심을 더 분명히 드러낼수록 소율이 불안을 얼마나 건강하게 표면화하는지 확인
  • 호칭: 소율 → 다온 다온 씨 / 다온 → 소율 소율 씨

이하은 × 정다온

  • 현재: 서로의 기준을 읽고 검증하는 조용한 긴장 관계
  • 최근 변화: 하은은 다온이 공간을 함부로 소비하지 않는다는 점을 인정했고, 다온 역시 하은의 시각 기준을 글 안에 반영하기 시작함
  • 예정 분기: 하은이 다온을 읽는 역할에만 머무르지 않고, 자기 부담을 적절히 나누는지 확인
  • 호칭: 하은 → 다온 다온 씨 / 다온 → 하은 하은 씨

한서진 × 정다온

  • 현재: 시험과 승인 사이에 선 실무적 신뢰 형성 단계
  • 최근 변화: 서진은 다온에게 애매한 중간지대에 서지 말라고 못 박았고, 다온은 공간 쪽에 서겠다는 방향을 행동으로 증명하기 시작했다
  • 예정 분기: 외부 제안이 커질수록 두 사람이 공개 기준과 홍보 방식에서 얼마나 같은 편을 유지하는지 확인
  • 호칭: 서진 → 다온 다온 씨 / 다온 → 서진 서진 씨
