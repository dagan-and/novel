# AGENTS.md — 세션 가이드

## 사용 원칙

- `"소설 시작해줘"`, `"소설 자동으로 시작해줘"`, `"소설 진행해줘"` 트리거와 세션 진행 순서는 `setting/워크플로우.md`를 기준으로 처리한다
- 요청별 세부 규칙은 `setting/워크플로우.md`의 "요청별 추가 참조" 섹션을 먼저 확인한 뒤 해당 파일까지 함께 읽는다
- 세계관 고정 규칙은 `setting/세계관.md`, 현재 상태와 감정선은 `관계망.md`, 누적 사건은 `연대기.md`를 기준으로 본다
- 캐릭터 개별 고정/가변 정보는 `characters/` 파일을 따른다
- 중복 규칙은 이 파일에 반복해서 적지 않고, 실제 작업 규칙은 `setting/워크플로우.md`와 `setting/` 하위 규칙 파일에 우선 통합한다

## 파일 구조

```text
reunion/
├── AGENTS.md            세션 가이드 (이 파일)
├── 관계망.md            하렘 현황 + 멤버 간 관계망 + 복선 트래커
├── 연대기.md            에피소드 연대기
├── characters/          캐릭터 개별 파일
│   ├── 김시안.md
│   ├── 캐릭터양식.md
│   └── [이름].md
├── episodes/            에피소드 원고
│   ├── ep.[번호].md
│   └── ep.[번호]_a.md
└── setting/
    ├── 세계관.md
    ├── 워크플로우.md
    ├── 개요작성규칙.md
    ├── 시나리오작성규칙.md
    ├── 대사태그정리.md
    ├── 기록업데이트규칙.md
    └── 연대기압축규칙.md
```
