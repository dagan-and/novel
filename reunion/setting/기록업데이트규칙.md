# 기록 업데이트 규칙

## 적용 범위

- `소설 진행해줘`의 STEP 3 이후 단계에서 적용한다

## STEP 3 — 기록 업데이트

- 첨부 기준: 완성 원고 5편 + 등장 캐릭터 파일 + `관계망.md` + `연대기.md`
- 아래 순서로 반영한다
  1. `[캐릭터].md` [가변] 항목: 변경 전 → 변경 후
  2. `관계망.md` 변동 반영
  3. `연대기.md` 추가: ep / 연도·계절 / 장소 / 등장 / 한줄 요약 / 성인씬 / 돌발 이벤트 유형
  4. 관계 진도 변동 반영
  5. 프로필용 성인씬 누적 횟수 점검 — 새로 추가된 성인씬 참여 인물들의 누적 횟수가 episodes 기준으로 올바르게 반영되는지 확인
  6. **연도 경과 시 나이·직업 갱신**
     - 전년도 대비 연도가 바뀐 경우, 등장한 모든 캐릭터 파일 [가변]의 직업 항목을 현재 연도 기준으로 갱신한다
     - 학년 진급 / 재학 상태 변화 / 졸업 / 졸업 유예 / 취업 / 이직 등을 반영한다
     - 학생 캐릭터는 학년과 재학 여부를, 사회인은 소속·직무를 현재 시점에 맞게 반드시 갱신한다
     - 김시안도 예외 없이 포함한다
     - `관계망.md` 김시안 현재 상태의 연도·나이·학적/직업 상태도 함께 갱신한다
     - 연나이 공식: `현재 연도 - 출생 연도 + 1`
  7. **여성 간 호칭 변화 반영**
     - 멤버 간 호칭 변화가 있었다면, 해당 캐릭터 파일 [가변] 멤버 간 호칭과 `관계망.md` 멤버 간 관계망 섹션 호칭 항목을 모두 갱신한다

> STEP 3 완료 후 STEP 4 → 5화 점검 순서로 실행

## STEP 4 — HTML 변환 + Git 푸시

- STEP 3 완료 직후 실행한다
- 순서: 변환 3종 → 커밋 → 푸시

### 변환 스크립트

| 스크립트 | 대상 | 실행 조건 |
|---|---|---|
| `publish.py` | 모든 변경 파일 | 5화마다 |

## 5화 점검 항목

- 첨부 기준: `연대기.md` + `관계망.md`
- 아래 항목을 점검한다
  1. 캐릭터 성격 일관성 유지 여부
  2. 하렘 내부 관계 변화 요약
  3. 복선 트래커 점검
  4. 다음 5화 복선/이벤트 제안
  5. 메인 → 서브 이동 예정 멤버 여부
  6. 서브 → 메인 승격 검토
  7. 새 서브 멤버 투입 시점 제안
  8. **호칭 일관성** — 캐릭터 파일 [가변] 멤버 간 호칭과 `관계망.md` 멤버 간 관계망 섹션 호칭이 일치하는지 확인
