# 워크플로우

## 파일 구조

```
reunion/
├── CLAUDE.md            세션 가이드 (인덱스)
├── RELATION.md          하렘 현황 + 멤버 간 관계망 + 복선 트래커
├── HISTORY.md           에피소드 연대기
├── characters/          캐릭터 개별 파일
│   └── [이름].md
├── episodes/            에피소드 원고
│   ├── ep.[번호].md      성인씬 없는 화
│   └── ep.[번호]_a.md   성인씬 포함 화
└── setting/
    ├── 세계관.md
    ├── 포맷.md
    └── 워크플로우.md
```

## 파일별 역할

|파일                   |역할                       |
|---------------------|-------------------------|
|CLAUDE.md            |세션 가이드 인덱스               |
|RELATION.md          |하렘 현황 + 멤버 간 관계망 + 복선 트래커|
|HISTORY.md           |루프 최종 상태 요약 + 에피소드 연대기   |
|김시안.md               |김시안 고정 / 가변 정보           |
|character_template.md|신규 캐릭터 작성 템플릿            |
|캐릭터.md               |개별 캐릭터 프로필 + 관계 + 수정     |
|episodes/            |회차별 원고 (_a 파일은 성인씬 포함 화) |
|setting/세계관.md       |세계관 규칙 + 하렘 시스템          |
|setting/포맷.md        |파일 형식 + 태그 + 성인씬 구역      |
|setting/워크플로우.md     |작업 절차 + 프롬프트 모음          |

-----

## 신규 캐릭터 규칙

- 스토리 진행 중 하렘에 새 캐릭터가 필요한 경우, 반드시 `character_template.md` 기준으로 캐릭터 파일을 먼저 생성한 뒤 등장시킨다
- 파일 없이 이름만 임의로 만들어 사용하는 것은 금지
- STEP 1 개요 단계에서 신규 캐릭터 투입이 예정된 경우, 개요 출력 후 시나리오 작성 전에 캐릭터 생성을 먼저 요청한다

```
신규 캐릭터 생성 프롬프트 (복붙용):

첨부:
- character_template.md
- 김시안.md          (김시안 설정 참조용)
- RELATION.md      (기존 멤버와 중복 방지 참조용)

신규 [메인 / 서브] 캐릭터를 생성해줘
- 배경 / 직업군: [작가 지정 또는 AI 자율]
- 등장 예정 화수: ep.[번호]
- RELATION.md의 기존 멤버와 몸매 계열 / 표면 성격 / 김시안 앞 반응이 겹치지 않도록 설계
```

## 에피소드 워크플로우

### 파일 저장 규칙

```
성인씬 없는 화: episodes/ep.[번호].md
성인씬 있는 화: episodes/ep.[번호]_a.md
```

- 파일명 뒤 `_a`로 성인씬 포함 여부 구분
- 상태 업데이트는 5화 단위로 일괄 처리 (STEP 3)

-----

### STEP 1 — 개요 작성

**첨부 파일**

```
- HISTORY.md
- RELATION.md
```

**프롬프트 (복붙용)**

```
첨부:
- HISTORY.md
- RELATION.md

흐름을 바탕으로 다음 ep.[번호] 개요를 작성해줘

출력 형식:
- 루프 / 연도·계절
- 장소
- 등장 멤버
- 장면 요약 (3~5줄)
- 성인씬 예상 위치 (있을 경우)
- 복선 또는 관계 변화 포인트
```

-----

### STEP 2 — 시나리오 작성

**첨부 파일**

```
- 김시안.md
- [등장 캐릭터 이름].md  (메인 등장 인물만, 최대 2~3개)
```

**프롬프트 (복붙용)**

```
첨부:
- 김시안.md
- [등장 캐릭터 이름].md

에피소드 정보:
- 루프: [ ]
- 연도/계절: [ ]
- 장소: [ ]
- 등장 멤버: [ ]
- 에피소드 번호: ep.[ ]
- 장면 요약: [ ]

작성 규칙:
1. 캐릭터 성격은 [고정] 영역 기준 유지
2. 김시안은 항상 주도권 유지
3. 대화 흐름 자연스럽게, 감정은 서술로 표현
4. 2인 이상 대화 시 [이름] 명시
5. 호칭은 캐릭터 파일 현재 호칭 기준 — 감정적 전환점에서 AI 자율 변경 가능, 변경 시 [수정] 기록
6. 그 외 인물 대사는 태그 없이 서술
7. 성인씬 트리거 조건 도달 시 → 구역 포맷만 삽입, 묘사 없음, <progress> 태그만 기재
8. 시나리오 완성 후 업데이트 출력 없음 — 별도 요청 처리
9. 모든 출력은 반드시 한국어로 작성

문체 기준:
- 단문으로 끊지 않고 호흡이 긴 문장 위주로 작성
- 심리와 감정은 직접 서술하지 않고 행동과 신체 반응으로 간접 표현
- 행동 → 신체 반응 → 감각 순서로 층위를 쌓아 묘사
- 후각 / 촉각 / 청각 등 감각 디테일을 구체적 단어로 표현
- 템포 전환이 필요할 때만 짧은 한 줄 문장 사용
- 인물의 의지와 본능이 충돌하는 방식으로 반응 묘사

분량 기준:
- 성인씬 있는 화: 2,000~3,000자 (씬에 집중)
- 성인씬 없는 화: 4,000~5,000자
  - 단순히 텍스트를 늘리지 않음
  - 관계 변화 / 복선 / 감정 누적 / 사건 전진이 실질적으로 이루어져야 함
  - 화가 끝날 때 이전과 달라진 것이 반드시 하나 이상 있어야 함
```

-----

### STEP 3 — 기록 업데이트

**첨부 파일**

```
- 완성된 ep.[번호] 원고 5편 (_a 파일은 성인씬 포함 화)
- [등장 캐릭터 이름].md
- RELATION.md
- HISTORY.md
```

**프롬프트 (복붙용)**

```
첨부:
- ep.[번호]~ep.[번호] 완성 원고 5편 (_a 파일은 성인씬 포함 화)
- [등장 캐릭터 이름].md
- RELATION.md
- HISTORY.md

5화 묶음 원고 기준으로 아래 항목 업데이트 출력해줘:

1. [캐릭터].md [수정] 항목: 변경 전 → 변경 후
2. RELATION.md 변동: 내용
3. HISTORY.md 추가: ep.번호 / 한줄 요약 / 성인씬 번호 (#번호 또는 -)
4. 관계 진도 변동 반영
5. 모든 출력은 반드시 한국어로 작성
```

> STEP 3 완료 후 아래 5화 점검 프롬프트 이어서 실행

**5화 점검 프롬프트 (복붙용)**

```
첨부:
- HISTORY.md
- RELATION.md

ep.[번호] 기준 점검 요청
점검 항목:
1. 캐릭터 성격 일관성 유지 여부
2. 하렘 내부 관계 변화 요약
3. 복선 트래커 점검 (회수 예정 복선 확인)
4. 다음 5화 복선/이벤트 제안
5. 메인 → 서브 이동 예정 멤버 여부
6. 서브 → 메인 승격 검토
7. 새 서브 멤버 투입 시점 제안
```

## 루프 전환

**첨부 파일**

```
- 김시안.md
- HISTORY.md
- RELATION.md
```

1. HISTORY.md 상단에 직전 루프 최종 상태 요약 추가
1. RELATION.md 김시안 현재 상태 갱신
1. RELATION.md 하렘 현황 초기화
1. RELATION.md 관계망 초기화 / 복선 트래커 완료 처리
1. 각 캐릭터 파일 [수정] 영역 초기화
1. 각 캐릭터 파일 [가변] 영역 갱신
