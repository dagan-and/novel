# 워크플로우

## 신규 캐릭터 규칙

- 하렘에 새 캐릭터가 필요한 경우, 반드시 `캐릭터양식.md` 기준으로 파일을 먼저 생성한 뒤 등장시킨다
- 파일 없이 이름만 임의로 사용하는 것은 금지
- STEP 1 개요 단계에서 신규 캐릭터 투입이 결정되면, 개요 출력 후 시나리오 작성 전에 캐릭터 파일을 자동 생성하고 작업을 계속한다
- 생성 시 `관계망.md`의 기존 멤버와 몸매 계열 / 표면 성격 / 김시안 앞 반응이 겹치지 않도록 설계
- **나이 설정**: 관계망.md의 현재 연도 기준 연나이로 설계한다. 생년도 공식: `생년도 = 현재 연도 - 목표 연나이 + 1` — 예) 2014년에 20세 = 1995년생. 세계관 연령 제한(20~25세)도 연나이 기준으로 적용한다
- 신규 캐릭터는 첫 등장부터 하렘 멤버로 확정하지 않고 서브 후보로 시작하며, 기존 관계에 어떤 새로운 역할과 갈등을 만드는지가 장면 안에서 드러나야 한다

### 하렘 구성 판정

- STEP 1을 시작할 때마다 관계망.md와 연대기.md를 기준으로 아래 항목을 모두 판정한다
  - 기존 메인 멤버: 메인 유지 / 서브 이동 검토
  - 기존 서브 멤버: 서브 유지 / 메인 승격 검토
  - 신규 캐릭터: 투입 / 보류
- 메인 → 서브 이동은 커리어, 유학, 장기 부재, 개인적 사정, 심리적 거리감처럼 관계의 중심성이 실제로 낮아지는 흐름이 누적될 때만 적용한다
- 신규 캐릭터 투입이나 메인 정원 확보만을 이유로 기존 메인을 임의로 서브로 이동시키지 않는다
- 서브 → 메인 승격은 친밀도나 관계 진도만으로 결정하지 않는다. 반복적인 선택, 위기에서의 재접근, 기존 멤버와의 관계 정립, 시안의 생활에서 맡는 중심 역할이 확인되어야 한다
- 승격·이동 후보가 있으면 다음 5화 개요에 이를 확정하거나 시험하는 사건을 최소 1개 포함하고, 변화가 확정되면 STEP 3에서 캐릭터 파일과 관계망.md에 반영한다
- 신규 캐릭터 판정을 위해 연대기.md에서 마지막 신규 주요 여성의 첫 등장 화수를 확인한다
- 아래 조건 중 하나라도 해당하면 다음 5화 안에 신규 캐릭터 투입을 우선 검토한다
  - 기존 멤버들의 관계가 합의·공존 등 안정 국면에 진입해 같은 갈등이나 관계 확인이 반복될 가능성이 높음
  - 계절, 방학, 졸업, 취업, 여행, 이사 등 생활권 전환으로 새로운 만남을 만들 자연스러운 사건이 발생함
  - 활성 주요 여성 캐릭터가 2명 이하라 관계 구도가 장기간 고정됨
- 마지막 신규 주요 여성의 첫 등장 후 **20화 이상** 지났다면, 하렘 정원 초과나 명확한 서사적 불가능 사유가 없는 한 다음 5화 안에 신규 서브 후보를 반드시 등장시킨다
- 연간 기본 등장 상한을 넘기는 경우에는 여행, 직장, 소개, 우연한 재회 등 사건 기반의 추가 등장으로 설계하고 개요에 그 근거를 명시한다
- 단순 인원 보충은 금지한다. 기존 멤버와 역할 / 성격 / 생활권 / 시안과의 관계 패턴 중 최소 2개 이상이 달라야 한다

## 에피소드 워크플로우

### 파일 저장 규칙

- 1단계(스킨십)만 있는 화: `episodes/ep.[번호].md` — 본문 직접 묘사, 성인씬 구역 불필요
- 2단계 이상 성인씬 있는 화: `episodes/ep.[번호]_a.md` — **같은 번호의 일반 파일 생성 금지**
- 상태 업데이트는 5화 단위로 일괄 처리 (STEP 3)
- **이전 에피소드 파일 읽기 금지** — 직전 화 포함 모든 episodes/ 파일 열람 불가. 맥락은 연대기.md로만 파악

### 돌발 이벤트 규칙

- 5화마다 최소 1회 발생
- 아래 세 유형 중 상황에 가장 적합한 것을 선택하며, 동일 유형의 연속 반복은 피한다

| 유형 | 설명 |
|------|------|
| 약한 변화 | 분위기·관계 온도의 소규모 전환 |
| 관계 전환 | 멤버 간 역학 변화 / 새 인물 개입 / 호칭·거리감 변화 |
| 중대한 위기 | 서사 방향을 바꾸는 갈등·사건·이별 위기 |

- 이벤트는 서사 방향이나 인물 관계에 실질적인 영향을 남겨야 한다
- 발생 이벤트 유형은 STEP 3 업데이트 시 연대기.md에 기록

-----

### STEP 1 — 개요 작성

**첨부:** 세계관.md + 연대기.md + 관계망.md

개요 작성 기준:
- 계절과 시간의 흐름을 반영한다. 시험 기간, 방학, 축제, 명절 등 시대적 이벤트를 적극 활용한다
- 동일 메인 캐릭터가 3화 이상 연속 중심이 되지 않도록 조정
- 장기 미등장 캐릭터는 자연스럽게 재투입
- 5화 중 최대 1화는 **여캐 관계화 에피소드**로 구성할 수 있다 — 김시안이 등장하지 않고 여캐 2인이 단독으로 만나는 장면. 시안을 두고 견제·탐색·감정 충돌 등을 다루며 각 캐릭터의 내면을 간접 노출. 개요 장면 요약에 `[여캐 단독]` 태그 명시
- 하렘 구성 판정을 먼저 수행한다
- 신규 캐릭터 판정 결과가 `투입`이면 첫 만남과 재접촉 중 최소 하나를 이번 5화 개요에 포함한다
- 승격·이동 후보가 있으면 해당 변화의 계기 또는 검증 사건을 이번 5화 개요에 포함한다

출력 형식:
- 하렘 구성 판정 — 각 멤버별 메인 유지 / 서브 이동 검토 / 서브 유지 / 메인 승격 검토와 판단 근거
- 신규 캐릭터 판정 — 투입 / 보류, 마지막 신규 등장 화수, 판단 근거
- 루프 / 연도·계절
- 장소
- 등장 멤버 — 관계망.md 하렘 현황과 연대기.md 최근 출연 빈도를 기준으로 조절. 김시안 제외 최대 3명
- 장면 요약 (3~5줄)
- 성인씬 예상 위치 (있을 경우)
- 복선 또는 관계 변화 포인트

-----

### STEP 2 — 시나리오 작성

**첨부:** 등장 인물 파일만 (김시안.md 포함, 최대 4명)

**작성 규칙:**
1. 캐릭터 성격은 [고정] 영역 기준 유지
2. 김시안은 항상 주도권 유지
3. 대화 흐름 자연스럽게, 감정은 서술로 표현
4. **대화 화자 태그 사용 가능** — `[이름] "대사"` 형식으로 표기할 수 있다. 2인 대화에도 사용 가능하며, HTML에서는 이름만 작고 은은한 색으로 표시된다. 태그를 쓰지 않는 장면은 기존처럼 지문과 문맥으로 발화자를 특정한다
5. 호칭은 캐릭터 파일 현재 호칭 기준 — 감정적 전환점에서 AI 자율 변경 가능, 변경 시 [가변] 기록
6. 단역·배경 인물 대사는 화자가 명확하면 태그 없이 서술 가능 — 구분이 필요하면 `[학생]`, `[점원]`처럼 간단 표기를 사용한다
7. 성인씬은 트리거 조건 외, 단둘인 상황 / 감정 고조 직후 / 갑작스러운 스킨십에서 발전하는 자연 발생 상황에서도 진행한다 → 구역 포맷만 삽입, 묘사 없음, `<progress>` 태그만 기재
   - **1단계(스킨십) 예외**: 손잡기·포옹 등 스킨십은 성인씬 구역 포맷 없이 본문에 최대한 묘사해 자연스럽게 서술한다. `_a` 파일 불필요, 연대기.md 성인씬 표기 `-`. `<progress>1단계</progress>` 태그는 해당 장면 말미에 기재한다
8. 성인씬 빈도 — **모든 연속 3화 구간에 2단계 이상 성인씬이 최소 1회 반드시 포함되어야 한다.** 2단계+ 성인씬 없는 화는 최대 2화까지만 연속 허용하며, 2화 연속 없었다면 바로 다음 화에는 반드시 배치한다. 이는 권장 사항이 아닌 필수 규칙이다. 1단계(스킨십)는 이 빈도 계산에 포함되지 않는다
9. 시나리오 완성 후 업데이트 출력 없음 — 별도 요청 처리
10. 모든 출력은 반드시 한국어로 작성
11. "지난화에서", "앞서", "이전 화에서" 등 화수를 직접 언급하는 표현 금지 — 맥락은 장면 안에서 자연스럽게 녹여낼 것
12. 사투리 금지 — 출신 지역과 무관하게 모든 인물은 표준어로 작성
13. **김시안은 처음 만나는 인물에게 반드시 존댓말을 사용한다** — 반말 전환은 아래 조건이 충족된 이후에만 가능:
   - 연하 캐릭터: 시안 호칭이 `오빠`로 바뀐 시점부터 반말 사용 가능
   - 동갑 캐릭터: 호칭이 `[이름]`으로 바뀐 뒤, 서로 반말을 허락하는 장면이 있어야 반말 가능

**대화 구성 규칙:**
- 대사 사이에 짧은 지문(행동 / 표정 / 침묵)을 삽입해 리듬을 유지한다 — 대사가 2연속 이상 이어지면 반드시 지문을 끼운다
- 동일 인물이 연속 발화할 경우 사이에 상대방의 반응(시선·호흡·표정 등)을 한 줄 이상 삽입한다
- 감정·의도·관계 변화는 대사만으로 처리하지 않는다 — 행동이나 신체 반응이 반드시 동반되어야 한다

**문체 기준:**
- 단문으로 끊지 않고 호흡이 긴 문장 위주
- 심리와 감정은 행동과 신체 반응으로 간접 표현
- 행동 → 신체 반응 → 감각 순서로 층위를 쌓아 묘사
- 후각 / 촉각 / 청각 등 감각 디테일을 구체적 단어로 표현
- 템포 전환이 필요할 때만 짧은 한 줄 문장 사용
- 인물의 의지와 본능이 충돌하는 방식으로 반응 묘사

**분량 기준:**
- 성인씬 있는 화: 2,000~3,000자
- 성인씬 없는 화: 4,000~5,000자 — 관계 변화 / 복선 / 감정 누적 / 사건 전진이 실질적으로 이루어져야 하며, 화가 끝날 때 이전과 달라진 것이 반드시 하나 이상 있어야 함

#### 에피소드 태그

```
<progress>[단계]</progress>   관계 진도 — 성인씬 구역 말미에만 기재

진도 단계 기준:
1단계 — 스킨십 (손잡기 / 포옹) ← 본문 직접 묘사, 성인씬 구역 불필요
2단계 — 키스 ← 성인씬 구역 포맷 적용, _a 파일 저장
3단계 — 성관계 ← 성인씬 구역 포맷 적용, _a 파일 저장
```

#### 성인씬 구역 포맷

> AI는 씬 컨텍스트만 구성한다. 묘사는 작가가 직접 작성한다.

씬 트리거 조건 도달 시 묘사 없이 아래 형식만 삽입:

```
---
## [성인씬 #번호 — ep.번호]

- 장소:
- 등장인물:
  - 김시안: (현재 감정/상태)
  - [이름]: (현재 감정/상태)
    - 외형 참고: 캐릭터 파일 외형 설정을 읽고 수치 대신 관용적 표현으로 자세히 서술
    - 성격 참고: 성격 키워드 / 감정 표현 방식 / 김시안 앞에서의 반응 패턴
- 호칭:
  - 시안 → [이름]: (이 씬에서 사용하는 호칭)
  - [이름] → 시안: (이 씬에서 사용하는 호칭)
- 의상:
  - 김시안: (씬 진입 시점 착용 의상)
  - [이름]: (씬 진입 시점 착용 의상)
- 직전 맥락: (이 씬 직전에 어떤 일이 있었는지 한 줄)
- 관계 단계: (현재 친밀도 기준 이 씬의 의미)
- 분위기 키워드: (예: 지배적 / 긴장 / 애절 / 장난스러운)
- 소품 / 환경: (조명, 공간 특이사항 등)
- 씬 이후 감정 방향: (이 씬이 끝난 뒤 관계가 어떻게 변화할지)
- <progress>[단계]</progress>

---
```

운영 규칙:
- AI는 구역 내부에 묘사를 절대 작성하지 않는다
- 씬 이후 감정 방향은 다음 장면 연결을 위한 참고값
- 김시안과 상대 캐릭터의 착용 의상은 에피소드 흐름에서 파악해 구역에 반영
- `<progress>` 태그는 구역 말미에만 기재
- **씬 종료 후 연결 규칙**: 구역 `---` 이후 이어지는 서술에서 "씬이 끝난 뒤", "장면이 끝나고", "씬 이후" 등 메타 표현 사용 금지 — 씬이 끝난 시점의 인물 행동이나 감각으로 직접 이어질 것

### STEP 3 — 기록 업데이트

**첨부:** 완성 원고 5편 + 등장 캐릭터 파일 + 관계망.md + 연대기.md

1. [캐릭터].md [가변] 항목: 변경 전 → 변경 후
2. 관계망.md 변동 반영
3. 연대기.md 추가: ep / 연도·계절 / 장소 / 등장 / 한줄 요약 / 성인씬 / 돌발 이벤트 유형
4. 관계 진도 변동 반영

## 연대기.md 압축 루틴

### 50화 단위 압축 (자동 트리거)

> 완성 화수가 50의 배수일 때 (50화, 100화, 150화…) 반드시 실행

- **압축 대상**: 가장 오래된 50화 테이블 행
- **압축 형식**: `### 요약 (ep.{n}~ep.{n+49})` 헤더 아래 간결 테이블
  - 컬럼: 화수 / 핵심 사건 / 관계 변화
  - 결정적 장면 5개 이내만 남기고 나머지 생략
- **유지 대상**: 최근 50화는 상세 테이블 그대로 유지

### 대규모 병합 (100화 단위, 200화부터 트리거)

> 완성 화수가 100의 배수일 때 (200화, 300화…) 반드시 실행

- **병합 대상**: 100화 이상 지난 50화 단위 요약 블록 전체
- **병합 형식**: `### 초기 흐름 (ep.{n}~ep.{n+99})` 단일 테이블
  - 컬럼: 화수 / 사건 / 의미
  - 전체 기간에서 결정적 전환점 10개 이내만 유지
- **유지 대상**: 최근 100화 블록은 기존 50화 단위 요약 그대로 유지
