# 워크플로우

## 신규 캐릭터 규칙

- 하렘에 새 캐릭터가 필요한 경우, 반드시 `캐릭터양식.md` 기준으로 파일을 먼저 생성한 뒤 등장시킨다
- 파일 없이 이름만 임의로 사용하는 것은 금지
- STEP 1 개요 단계에서 신규 캐릭터 투입이 예정된 경우, 개요 출력 후 시나리오 작성 전에 캐릭터 생성을 먼저 요청한다
- 생성 시 `관계망.md`의 기존 멤버와 몸매 계열 / 표면 성격 / 김시안 앞 반응이 겹치지 않도록 설계

-----

## 에피소드 워크플로우

### 파일 저장 규칙

- 성인씬 없는 화: `episodes/ep.[번호].md`
- 성인씬 있는 화: `episodes/ep.[번호]_a.md`
- 상태 업데이트는 5화 단위로 일괄 처리 (STEP 3)

### 돌발 이벤트 규칙

- 5화마다 최소 1회 발생
- 아래 세 유형 중 상황에 가장 적합한 것을 선택하며, 동일 유형의 연속 반복은 피한다

| 유형 | 설명 |
|------|------|
| 약한 변화 | 분위기·관계 온도의 소규모 전환 |
| 관계 전환 | 멤버 간 역학 변화 / 새 인물 개입 / 호칭·거리감 변화 |
| 중대한 위기 | 서사 방향을 바꾸는 갈등·사건·이별 위기 |

- 이벤트는 서사 방향이나 인물 관계에 실질적인 영향을 남겨야 한다
- 발생 이벤트 유형은 STEP 3 업데이트 시 연대기.md에 기록

-----

### STEP 1 — 개요 작성

**첨부:** 세계관.md + 연대기.md + 관계망.md

개요 작성 기준:
- 계절과 시간의 흐름을 반영한다. 시험 기간, 방학, 축제, 명절 등 시대적 이벤트를 적극 활용한다
- 동일 메인 캐릭터가 3화 이상 연속 중심이 되지 않도록 조정
- 장기 미등장 캐릭터는 자연스럽게 재투입

출력 형식:
- 루프 / 연도·계절
- 장소
- 등장 멤버 — 관계망.md 하렘 현황과 연대기.md 최근 출연 빈도를 기준으로 조절. 김시안 제외 최대 3명
- 장면 요약 (3~5줄)
- 성인씬 예상 위치 (있을 경우)
- 복선 또는 관계 변화 포인트

-----

### STEP 2 — 시나리오 작성

**첨부:** 등장 인물 파일만 (김시안.md 포함, 최대 4명)

**작성 규칙:**
1. 캐릭터 성격은 [고정] 영역 기준 유지
2. 김시안은 항상 주도권 유지
3. 대화 흐름 자연스럽게, 감정은 서술로 표현
4. 2인 이상 대화 시 [이름] 명시
5. 호칭은 캐릭터 파일 현재 호칭 기준 — 감정적 전환점에서 AI 자율 변경 가능, 변경 시 [가변] 기록
6. 단역·배경 인물 대사는 화자가 명확하면 태그 없이 서술 — 혼동 가능성 있을 경우 [학생], [점원] 등 간단 표기
7. 성인씬 트리거 조건 도달 시 → 구역 포맷만 삽입, 묘사 없음, `<progress>` 태그만 기재
8. 시나리오 완성 후 업데이트 출력 없음 — 별도 요청 처리
9. 모든 출력은 반드시 한국어로 작성
10. "지난화에서", "앞서", "이전 화에서" 등 화수를 직접 언급하는 표현 금지 — 맥락은 장면 안에서 자연스럽게 녹여낼 것
11. 사투리 금지 — 출신 지역과 무관하게 모든 인물은 표준어로 작성

**문체 기준:**
- 단문으로 끊지 않고 호흡이 긴 문장 위주
- 심리와 감정은 행동과 신체 반응으로 간접 표현
- 행동 → 신체 반응 → 감각 순서로 층위를 쌓아 묘사
- 후각 / 촉각 / 청각 등 감각 디테일을 구체적 단어로 표현
- 템포 전환이 필요할 때만 짧은 한 줄 문장 사용
- 인물의 의지와 본능이 충돌하는 방식으로 반응 묘사

**분량 기준:**
- 성인씬 있는 화: 2,000~3,000자
- 성인씬 없는 화: 4,000~5,000자 — 관계 변화 / 복선 / 감정 누적 / 사건 전진이 실질적으로 이루어져야 하며, 화가 끝날 때 이전과 달라진 것이 반드시 하나 이상 있어야 함

#### 에피소드 태그

```
<progress>[단계]</progress>   관계 진도 — 성인씬 구역 말미에만 기재

진도 단계 기준:
1단계 — 스킨십 (손잡기 / 포옹)
2단계 — 키스
3단계 — 성관계
```

#### 성인씬 구역 포맷

> AI는 씬 컨텍스트만 구성한다. 묘사는 작가가 직접 작성한다.

씬 트리거 조건 도달 시 묘사 없이 아래 형식만 삽입:

```
---
## [성인씬 #번호 — ep.번호]

- 장소:
- 등장인물:
  - 김시안: (현재 감정/상태)
  - [이름]: (현재 감정/상태)
    - 외형 참고: 캐릭터 파일 외형 설정을 읽고 수치 대신 관용적 표현으로 자세히 서술
    - 성격 참고: 성격 키워드 / 감정 표현 방식 / 김시안 앞에서의 반응 패턴
- 의상:
  - 김시안: (씬 진입 시점 착용 의상)
  - [이름]: (씬 진입 시점 착용 의상)
- 직전 맥락: (이 씬 직전에 어떤 일이 있었는지 한 줄)
- 관계 단계: (현재 친밀도 기준 이 씬의 의미)
- 분위기 키워드: (예: 지배적 / 긴장 / 애절 / 장난스러운)
- 소품 / 환경: (조명, 공간 특이사항 등)
- 씬 이후 감정 방향: (이 씬이 끝난 뒤 관계가 어떻게 변화할지)
- <progress>[단계]</progress>

---
```

운영 규칙:
- AI는 구역 내부에 묘사를 절대 작성하지 않는다
- 씬 이후 감정 방향은 다음 장면 연결을 위한 참고값
- 김시안과 상대 캐릭터의 착용 의상은 에피소드 흐름에서 파악해 구역에 반영
- `<progress>` 태그는 구역 말미에만 기재

-----

### STEP 3 — 기록 업데이트

**첨부:** 완성 원고 5편 + 등장 캐릭터 파일 + 관계망.md + 연대기.md

1. [캐릭터].md [가변] 항목: 변경 전 → 변경 후
2. 관계망.md 변동 반영
3. 연대기.md 추가: ep / 연도·계절 / 장소 / 등장 / 한줄 요약 / 성인씬 / 돌발 이벤트 유형
4. 관계 진도 변동 반영

> STEP 3 완료 후 STEP 4 (HTML 변환 + Git 푸시) → 5화 점검 순서로 실행

-----

### STEP 4 — HTML 변환 + Git 푸시

> STEP 3 완료 직후 실행. 변환 3종 → 커밋 → 푸시 순서.

#### 변환 스크립트 3종

| 스크립트 | 대상 | 실행 조건 |
|----------|------|-----------|
| `convert_html.py` | `episodes/ep.[번호].md` → `html/ep.[번호].html` | 5화마다 |
| `convert_profiles.py` | `characters/[이름].md` → `html/characters/[이름].html` + `characters.html` | 5화마다 |
| `convert_setting.py` | `관계망.md` / `연대기.md` / `setting/세계관.md` → `html/setting/` + `html/index.html` | 해당 파일 수정 시 (매 5화마다 실행) |

#### 실행 규칙

- 성인씬 있는 화(`ep.[번호]_a.md`)도 `convert_html.py`로 동일하게 변환
- images/ 폴더에 신규 파일 추가 시 → 함께 스테이징

#### Git 커밋·푸시

```bash
git add episodes/ html/ characters/ images/ 관계망.md 연대기.md
git commit -m "Add ep.[N]~[N+4] with HTML conversion and updates"
git push origin main
```

- 커밋 메시지: 포함된 화수 범위 명시
- 변환 파일(html/)과 원고(episodes/)는 항상 같은 커밋에 묶어서 푸시

**5화 점검 항목** (첨부: 연대기.md + 관계망.md)
1. 캐릭터 성격 일관성 유지 여부
2. 하렘 내부 관계 변화 요약
3. 복선 트래커 점검
4. 다음 5화 복선/이벤트 제안
5. 메인 → 서브 이동 예정 멤버 여부
6. 서브 → 메인 승격 검토
7. 새 서브 멤버 투입 시점 제안

## 연대기.md 압축 루틴

### 50화 단위 압축 (자동 트리거)

> 완성 화수가 50의 배수일 때 (50화, 100화, 150화…) 반드시 실행

- **압축 대상**: 가장 오래된 50화 테이블 행
- **압축 형식**: `### 요약 (ep.{n}~ep.{n+49})` 헤더 아래 간결 테이블
  - 컬럼: 화수 / 핵심 사건 / 관계 변화
  - 결정적 장면 5개 이내만 남기고 나머지 생략
- **유지 대상**: 최근 50화는 상세 테이블 그대로 유지

### 대규모 병합 (100화 단위, 200화부터 트리거)

> 완성 화수가 100의 배수일 때 (200화, 300화…) 반드시 실행

- **병합 대상**: 100화 이상 지난 50화 단위 요약 블록 전체
- **병합 형식**: `### 초기 흐름 (ep.{n}~ep.{n+99})` 단일 테이블
  - 컬럼: 화수 / 사건 / 의미
  - 전체 기간에서 결정적 전환점 10개 이내만 유지
- **유지 대상**: 최근 100화 블록은 기존 50화 단위 요약 그대로 유지

## 루프 전환

**첨부:** 김시안.md + 연대기.md + 관계망.md

1. 연대기.md 상단에 직전 루프 최종 상태 요약 추가
2. 관계망.md 김시안 현재 상태 갱신
3. 관계망.md 하렘 현황 초기화
4. 관계망.md 관계망 초기화 / 복선 트래커 완료 처리
5. 재회 캐릭터 파일 [가변] 영역 초기화 및 갱신 — 재회 없으면 생략
