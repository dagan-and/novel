# 워크플로우

## 신규 캐릭터 규칙

- 하렘에 새 캐릭터가 필요한 경우, 반드시 `캐릭터양식.md` 기준으로 파일을 먼저 생성한 뒤 등장시킨다
- 파일 없이 이름만 임의로 사용하는 것은 금지
- STEP 1 개요 단계에서 신규 캐릭터 투입이 예정된 경우, 개요 출력 후 시나리오 작성 전에 캐릭터 생성을 먼저 요청한다
- 생성 시 `관계망.md`의 기존 멤버와 몸매 계열 / 표면 성격 / 김시안 앞 반응이 겹치지 않도록 설계

-----

## 에피소드 워크플로우

### 파일 저장 규칙

- 성인씬 없는 화: `episodes/ep.[번호].md`
- 성인씬 있는 화: `episodes/ep.[번호]_a.md`
- 상태 업데이트는 5화 단위로 일괄 처리 (STEP 3)

### 돌발 이벤트 규칙

- 5화마다 최소 1회 발생
- 아래 세 유형 중 상황에 가장 적합한 것을 선택하며, 동일 유형의 연속 반복은 피한다

| 유형 | 설명 |
|------|------|
| 약한 변화 | 분위기·관계 온도의 소규모 전환 |
| 관계 전환 | 멤버 간 역학 변화 / 새 인물 개입 / 호칭·거리감 변화 |
| 중대한 위기 | 서사 방향을 바꾸는 갈등·사건·이별 위기 |

- 이벤트는 서사 방향이나 인물 관계에 실질적인 영향을 남겨야 한다
- 발생 이벤트 유형은 STEP 3 업데이트 시 연대기.md에 기록

-----

### STEP 1 — 개요 작성

**첨부:** 연대기.md + 관계망.md + 김시안.md 포함 캐릭터 파일 최대 4명

- 루프 / 연도·계절
- 장소
- 등장 멤버
- 장면 요약 (3~5줄)
- 성인씬 예상 위치 (있을 경우)
- 복선 또는 관계 변화 포인트

-----

### STEP 2 — 시나리오 작성

**첨부:** 김시안.md 포함 캐릭터 파일 최대 4명

**작성 규칙:**
1. 캐릭터 성격은 [고정] 영역 기준 유지
2. 김시안은 항상 주도권 유지
3. 대화 흐름 자연스럽게, 감정은 서술로 표현
4. 2인 이상 대화 시 [이름] 명시
5. 호칭은 캐릭터 파일 현재 호칭 기준 — 감정적 전환점에서 AI 자율 변경 가능, 변경 시 [수정] 기록
6. 단역·배경 인물 대사는 화자가 명확하면 태그 없이 서술 — 혼동 가능성 있을 경우 [학생], [점원] 등 간단 표기
7. 성인씬 트리거 조건 도달 시 → 구역 포맷만 삽입, 묘사 없음, `<progress>` 태그만 기재
8. 시나리오 완성 후 업데이트 출력 없음 — 별도 요청 처리
9. 모든 출력은 반드시 한국어로 작성
10. "지난화에서", "앞서", "이전 화에서" 등 화수를 직접 언급하는 표현 금지 — 맥락은 장면 안에서 자연스럽게 녹여낼 것

**문체 기준:**
- 단문으로 끊지 않고 호흡이 긴 문장 위주
- 심리와 감정은 행동과 신체 반응으로 간접 표현
- 행동 → 신체 반응 → 감각 순서로 층위를 쌓아 묘사
- 후각 / 촉각 / 청각 등 감각 디테일을 구체적 단어로 표현
- 템포 전환이 필요할 때만 짧은 한 줄 문장 사용
- 인물의 의지와 본능이 충돌하는 방식으로 반응 묘사

**분량 기준:**
- 성인씬 있는 화: 2,000~3,000자
- 성인씬 없는 화: 4,000~5,000자 — 관계 변화 / 복선 / 감정 누적 / 사건 전진이 실질적으로 이루어져야 하며, 화가 끝날 때 이전과 달라진 것이 반드시 하나 이상 있어야 함

-----

### STEP 3 — 기록 업데이트

**첨부:** 완성 원고 5편 + 등장 캐릭터 파일 + 관계망.md + 연대기.md

1. [캐릭터].md [수정] 항목: 변경 전 → 변경 후
2. 관계망.md 변동 반영
3. 연대기.md 추가: ep.번호 / 한줄 요약 / 성인씬 번호 / 돌발 이벤트 유형
4. 관계 진도 변동 반영

> STEP 3 완료 후 5화 점검 이어서 실행

**5화 점검 항목** (첨부: 연대기.md + 관계망.md)
1. 캐릭터 성격 일관성 유지 여부
2. 하렘 내부 관계 변화 요약
3. 복선 트래커 점검
4. 다음 5화 복선/이벤트 제안
5. 메인 → 서브 이동 예정 멤버 여부
6. 서브 → 메인 승격 검토
7. 새 서브 멤버 투입 시점 제안

-----

## 루프 전환

**첨부:** 김시안.md + 연대기.md + 관계망.md

1. 연대기.md 상단에 직전 루프 최종 상태 요약 추가
2. 관계망.md 김시안 현재 상태 갱신
3. 관계망.md 하렘 현황 초기화
4. 관계망.md 관계망 초기화 / 복선 트래커 완료 처리
5. 각 캐릭터 파일 [수정] 영역 초기화
6. 각 캐릭터 파일 [가변] 영역 갱신
