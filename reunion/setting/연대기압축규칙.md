# 연대기 압축 규칙

## 50화 단위 압축

> 완성 화수가 50의 배수일 때 (50화, 100화, 150화…) 반드시 실행

- **압축 대상**: 가장 오래된 50화 테이블 행
- **압축 형식**: `### 요약 (ep.{n}~ep.{n+49})` 헤더 아래 간결 테이블
  - 컬럼: 화수 / 핵심 사건 / 관계 변화
  - 결정적 장면 5개 이내만 남기고 나머지 생략
- **유지 대상**: 최근 50화는 상세 테이블 그대로 유지

## 200화 이상 누적 후 대규모 병합

> 완성 화수가 100의 배수일 때 (200화, 300화…) 반드시 실행

- **병합 대상**: 100화 이상 지난 50화 단위 요약 블록 전체
- **병합 형식**: `### 초기 흐름 (ep.{n}~ep.{n+99})` 단일 테이블
  - 컬럼: 화수 / 사건 / 의미
  - 전체 기간에서 결정적 전환점 10개 이내만 유지
- **유지 대상**: 최근 100화 블록은 기존 50화 단위 요약 그대로 유지
