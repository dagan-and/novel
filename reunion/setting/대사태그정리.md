# 대사 태그 정리 규칙

## 트리거

- 사용자가 `ep.[번호] ~ ep.[번호] 대사 태그 정리해줘`처럼 특정 화수 범위를 지정해 요청했을 때 적용한다

## 작업 범위

- 지정된 `episodes/` 파일 범위만 읽고 수정한다
- 성인씬 포함 여부, `_a` 파일 여부와 무관하게 **파일 전체 본문**을 검사 대상으로 본다
- 지문, 서술, 문단 순서, 사건 내용은 건드리지 않고 **화자 표기와 대사 태그만 수정**한다

## 정리 기준

- 기본 원칙은 **모든 장면에서만 화자 태그 사용**다
- **사용자 예외 지시가 있는 요청**에서는 그 요청을 우선한다
  - 예: `이미 있는 [이름] "대사" 형식은 유지`, `태그 정리만`처럼 명시한 경우
- 아래 형식은 모두 `[이름] "대사"` 형식으로 통일한다
  - `**이하은**: 대사`, `**시안**: 대사` 같은 강조형 화자 표기
  - `이하은: 대사`, `시안: 대사` 같은 콜론형 화자 표기
  - 이름만 한 줄로 따로 놓인 화자 표시 뒤에 이어지는 대사
  - `[연서]`, `[하은]`, `[시안]`, `[다온]`처럼 성이 빠진 약식 태그
  - 화자가 문맥상 명확한데 따옴표로만 시작하는 줄 `"..."`
- 화자 태그는 기본적으로 **캐릭터 파일명 기준 풀네임**을 쓴다
  - 예: `[오연서]`, `[이하은]`, `[김시안]`, `[정다온]`, `[박미현]`, `[한서진]`, `[임소율]`
  - 단역은 문맥상 필요할 때만 `[손님]`, `[학생]`, `[점원]`처럼 간단 표기 허용
- 신음, 짧은 반응, 성인씬 내부 대사도 예외 없이 같은 규칙을 적용한다
- 화자가 모호한 줄은 앞뒤 대사, 행동 주체, 시선 처리, 바로 직전 서술을 기준으로 가장 자연스러운 화자로 맞춘다

## 검수 규칙

- 1차 수정 후 바로 끝내지 말고 **반드시 2차 검수**를 수행한다
- 아래 항목을 모두 다시 확인한다
  - 2인 장면에 불필요한 화자 태그가 남아 있는지
  - 약식 화자 태그가 남아 있는지
  - `**이름**:` / `이름:` 형식이 남아 있는지
  - 이름 한 줄 단독 화자 표시가 남아 있는지
  - 따옴표로만 시작하는 무태그 대사가 남아 있는지

## 최종 보고

- 최종 보고에는 아래 3가지를 포함한다
  - 수정한 파일 목록
  - 성인씬 구간 포함 추가로 잡아낸 누락 유형
  - 무태그 대사 잔여 여부
