# 세계관 설정

## 루프 구조

- 주인공 이름: 김시안
- 0차 삶: 38살까지 살다 2013년 25살로 귀환
- 루프: 25살~35살 활동 후 잠들어 25살로 귀환 반복
- 루프 기간: 2013년~2023년 (10년 단위)
- 38년치 기억 완전 보유, 루프마다 누적
- 인물 상세 정보는 김시안.md 참조

## 픽업 원칙

- 치트 능력 없음
- 0차 38년 경험과 루프 경험으로 여성 유형 즉시 파악
- 김시안은 항상 주도권 유지
- 모든 여성은 결국 김시안에게 빠짐
- 난공불락 캐릭터 없음
- 김시안이 휘둘리는 관계 없음
- 접근 방식과 전개는 AI 자율

## 호칭 규칙

- 여성의 김시안 호칭은 관계 흐름에 따라 AI가 자율 변경
- 변경 기준: 감정적으로 중요한 장면 직후, 또는 전반적으로 관계가 한 단계 깊어졌다고 판단될 때
- 한 번 바뀐 호칭은 이전으로 돌아가지 않음
- 호칭이 바뀐 경우 캐릭터 파일 [수정] 항목에 변경 사항 기록
- 김시안이 여성을 부를 때: 성 빼고 이름만 (박미현 → 미현)

# 하렘 시스템

- 동시 유지 인원: 최대 9명
- **메인 5명**: 김시안과 깊은 관계를 유지하는 핵심 멤버
- **서브 4명**: 관계는 유지되나 거리가 생긴 멤버 / 신규 진입 대기
- 결혼은 없음 — 하렘 내 모든 여성은 김시안과의 관계를 유지
- **루프 시작 시**: 메인 3명으로 시작 — 이후 관계 진전에 따라 최대 5명까지 확장

## 메인 → 서브

- 커리어 / 유학 / 개인적 사정 / 심리적 거리감 등으로 자연스럽게 이동
- 김시안이 먼저 밀어내지 않음 — 상황과 감정의 흐름으로만 발생

## 서브 → 메인 승격

- 서브 멤버에게 승격 기회 부여 가능
- 승격 조건: 재접근 계기 / 감정선 재점화 / 사건을 통한 관계 재정립
- 승격 여부는 AI가 흐름에 따라 판단

## 하렘 내부

- 멤버들은 서로의 존재를 인지할 수 있음
- 질투 / 경쟁 / 동맹 / 서브 멤버의 승격 시도 등 감정 반응은 AI 자율
- 외부 위협 (경쟁 남성 / 전 남친 / 가족 압박) 활용 가능
- 루프를 넘어 재등장 가능한 멤버는 AI가 판단해 설계
