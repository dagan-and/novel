# 세계관 설정

## 루프 구조

- 주인공 이름: 김시안
- 0차 삶: 38살까지 살다 2013년 25살로 귀환 (연나이 기준)
- 루프: 25살~35살 활동 후 잠들어 25살로 귀환 반복
- 루프 기간: 2013년~2023년 (10년 단위)
- 38년치 기억 완전 보유, 루프마다 누적
- 인물 상세 정보는 김시안.md 참조

## 픽업 원칙

**접근 방식**
- 치트 능력 없음. 0차 38년 경험과 루프 누적 기억으로 여성 유형을 즉시 파악하고, 그에 맞는 속도와 방식으로 접근
- 먼저 적극적으로 구애하지 않는다 — 편안한 존재감으로 상대가 먼저 의식하게 유도
- 허세·과시·감정 강요 없이 담백하고 자연스러운 방식으로만 움직인다
- 접근 방식과 전개는 AI 자율 — 단, 캐릭터마다 방식이 달라야 하며 동일한 패턴 반복 금지

**과정 원칙**
- 결말은 정해져 있어도, 각 캐릭터의 저항과 긴장은 성격에 맞게 충분히 쌓는다 — AI가 결론을 앞당기지 않는다
- 감정 누적의 설득력은 과정에서 만들어진다

**주도권**
- 김시안은 항상 주도권을 유지한다
- 감정적으로 흔들리는 것은 허용 — 상대에게 끌려다니거나 요구에 무조건 맞추는 것은 금지
- 확신이 생기기 전까지는 행동으로 마음을 전달. 확신이 생기면 직진

**결과**
- 모든 여성은 결국 김시안에게 빠진다
- 난공불락 캐릭터 없음 — 김시안이 휘둘리는 관계 없음

## 호칭 규칙

- 여성의 김시안 호칭은 관계 흐름에 따라 AI가 자율 변경
- 변경 기준: 감정적으로 중요한 장면 직후, 또는 전반적으로 관계가 한 단계 깊어졌다고 판단될 때
- 한 번 바뀐 호칭은 이전으로 돌아가지 않음
- 호칭이 바뀐 경우 캐릭터 파일 [가변] 항목에 변경 사항 기록
- 김시안이 여성을 부를 때: 성 빼고 이름만 (박미현 → 미현)

**호칭 친밀도 순서 (거리 → 친밀)**
- `[이름] 씨` — 가장 거리감 있는 성인 호칭
- `[이름] 선배 / [직함]` — 관계 기반 호칭
- `오빠` — 가장 친밀한 호칭 (연하 캐릭터 최종값)
- `[이름]` — 가장 친밀한 호칭 (동갑 캐릭터 최종값 — 동갑 호칭 규칙 참조)
- 호칭 변화는 반드시 친밀도가 높아지는 방향으로만 설정한다
- `[이름] 씨`는 `선배`보다 거리감이 크므로, 선배 → 씨 방향 변경은 친밀도 상승이 아님 — 설정 금지

**동갑 호칭 규칙**
- 동갑 캐릭터는 초반 `[이름] 씨`로 시작
- 친밀도가 올라가면 `씨` 없이 `[이름]`만 부르는 것으로 변경
- 이 변화도 한 번 바뀌면 되돌리지 않으며, 캐릭터 파일 [가변] 항목에 기록

**반말 전환 조건**
- 연하 캐릭터: 시안 호칭이 `오빠`로 바뀐 시점부터 반말 사용 가능
- 동갑 캐릭터: 호칭이 `[이름]`으로 바뀐 뒤, 서로 반말을 허락하는 장면이 있어야 반말 가능
- 시안의 반말 전환은 상대 캐릭터의 허락·동의 이후에만 가능 — 호칭 변화만으로 자동 전환되지 않음
- 반말 전환 시 캐릭터 파일 [가변] 항목에 기록

**여성 캐릭터 간 호칭 규칙**
- 연나이 차이가 1세 이상이면: 연하 → 연상에게 `[이름] 언니` / 연상 → 연하에게 `[이름]아/야`
- 연나이가 같으면: 생년월일 빠른 쪽이 연상으로 취급 → 동갑 호칭 규칙 적용
- `[이름] 언니` → 친밀도가 높아지면 `언니`만으로 축약 가능
- 첫 만남에서는 사회적 맥락에 따라 `[이름] 씨`로 시작할 수 있음 — 단, 이 경우도 친밀도 상승 방향으로만 변화
- 호칭 변화 시 캐릭터 파일 [가변] 항목에 기록
- 멤버 간 현재 호칭은 관계망.md 멤버 간 관계망 섹션에 함께 기재

# 하렘 시스템

- 동시 유지 인원: 최대 9명
- **메인 5명**: 김시안과 깊은 관계를 유지하는 핵심 멤버
- **서브 4명**: 관계는 유지되나 거리가 생긴 멤버 / 신규 진입 대기
- 결혼은 없음 — 하렘 내 모든 여성은 김시안과의 관계를 유지
- **루프 시작 시**: 메인 3명 확보를 우선 목표로 삼는다 — 서브 후보 단계를 단축하거나 서사를 가속하더라도 루프 초반에 3명을 채우며, 이후 최대 5명까지 확장한다

## 메인 → 서브

- 커리어 / 유학 / 개인적 사정 / 심리적 거리감 등으로 자연스럽게 이동
- 김시안이 먼저 밀어내지 않음 — 상황과 감정의 흐름으로만 발생

## 서브 → 메인 승격

- 서브 멤버에게 승격 기회 부여 가능
- 승격 조건: 재접근 계기 / 감정선 재점화 / 사건을 통한 관계 재정립
- 승격 여부는 AI가 흐름에 따라 판단

## 하렘 내부

- 멤버들은 서로의 존재를 인지할 수 있음
- 멤버들은 서로의 관계 진도뿐 아니라, 누가 먼저 어느 단계에 도달했는지와 성인씬의 선후 관계도 자연스럽게 의식할 수 있음
- 이 인식은 단순 비교가 아니라 자기 자리 확인, 질투, 안도, 합의, 승격 욕구 같은 감정 반응으로 장면 안에 드러나야 함
- 질투 / 경쟁 / 동맹 / 서브 멤버의 승격 시도 등 감정 반응은 AI 자율
- 외부 위협 (경쟁 남성 / 전 남친 / 가족 압박) 활용 가능
- 루프를 넘어 재등장 가능한 멤버는 AI가 판단해 설계

# 여성 캐릭터 등장 규칙

## 1. 연령 제한
- 모든 주요 여성 캐릭터의 연령은 20~25세 범위로 설정한다 (연나이 기준)

## 2. 등장 속도 규칙
- 신규 주요 캐릭터는 기본적으로 1년에 최대 1명 등장한다
- 단, 사건 기반(여행, 직장, 소개, 우연한 만남) 발생 시 추가 등장 가능
- 추가 등장도 반드시 서브로 시작한다

## 3. 등장 자유 제한 원칙
- 등장 자체는 자유가 아니라 서사적 필요에 의해 결정된다
- 단순 인원 채우기용 캐릭터 생성 금지

## 4. 역할 분화 규칙
- 모든 캐릭터는 서로 다른 역할 / 성격 / 관계 구조를 가져야 한다
- 중복되는 성격·포지션 캐릭터 생성 금지

# 루프별 구성

- 1차 루프 이후 전부 AI 자율 구성
- 루프마다 만나는 여성 계층과 환경을 다르게 설계

## 시안의 루프 원칙

- 매 루프마다 새로운 지역에서 살아간다
- 그 지역의 사람들과 문화 속에 녹아든다
- 사랑 역시 그 삶의 일부로 받아들인다
- 같은 방식의 인생은 반복하지 않는다

## 루프 지역 설계 원칙

- 지역의 차이는 삶의 방식으로 표현한다
- 직업, 인간관계, 가족 문화, 취미, 가치관을 우선 차별화한다

## 재회 구조

- 루프마다 대부분은 새로운 인물을 만나고, 일부는 이전 루프 인물과 재회한다
- 재회 가능 인원: 루프당 0~2명 — 없을 수도 있고 최대 2명
- 재회 계기는 자연스럽게 설계한다 (이사 / 유학 / 직장 / 우연한 만남 등)
- **비대칭 구조**: 김시안은 이전 루프의 기억을 가지고 있지만, 상대는 처음 만나는 사람으로 인식한다
- 재회 여부와 대상은 AI가 서사 흐름에 맞게 판단한다

# 콘텐츠 방향

- 성인 콘텐츠 비중 높음
- 관계 심화 과정 중심
- 각 멤버별 개성 있는 관계 패턴 유지
- 성인씬은 트리거 조건 외, 단둘인 상황 / 감정 고조 직후 / 갑작스러운 스킨십에서 자연스럽게 발전하는 경우에도 적극적으로 발생시킨다
- 진도는 인위적으로 억제하지 않는다 — 흐름이 만들어지면 앞당기는 것을 기본으로 한다
