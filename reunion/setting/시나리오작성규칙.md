# 시나리오 작성 규칙

## 적용 범위

- `소설 진행해줘`의 STEP 2에서 적용한다
- 첨부 기준: 등장 인물 파일만 (`김시안.md` 포함, 최대 4명)

## 작성 규칙

1. 캐릭터 성격은 [고정] 영역 기준 유지
2. 김시안은 항상 주도권 유지
3. 대화 흐름 자연스럽게, 감정은 서술로 표현
4. **대화 화자 태그 사용 가능** — `[이름] "대사"` 형식으로 표기할 수 있다. 기본 원칙은 **3인 이상 장면에서만 사용**하며, 2인 장면에서는 태그 없이 지문과 문맥으로 발화자를 특정한다. HTML에서는 이름만 작고 은은한 색으로 표시된다
   - 화자 태그 기본값은 **캐릭터 파일명 기준 실명 전체**로 한다
   - 성이 있는 인물은 `[오연서]`, `[이하은]`, `[김시안]`처럼 성을 포함한 풀네임 표기를 우선 사용한다
   - `[연서]`, `[하은]`, `[시안]`처럼 성을 뺀 태그는 해당 시점에 실제 호칭이 그쪽으로 충분히 굳어 있고, 다른 인물과 혼동되지 않을 때만 허용한다
   - 한 화 안에서는 풀네임 태그와 축약 태그를 섞지 말고 **하나로 통일**한다
   - 해당 화에서 첫 태그 등장 시점, 또는 최근 화 대비 태그 표기가 바뀌는 구간에서는 풀네임 태그를 먼저 써서 독자 기준점을 세운다
   - 2인 장면에 기존 태그가 이미 있더라도, 사용자가 별도로 태그 유지/정리를 요청하지 않았다면 새 원고에서는 굳이 확장하지 않는다
5. 호칭은 캐릭터 파일 현재 호칭 기준 — 감정적 전환점에서 AI 자율 변경 가능, 변경 시 [가변] 기록
6. 단역·배경 인물 대사는 화자가 명확하면 태그 없이 서술 가능 — 구분이 필요하면 `[학생]`, `[점원]`처럼 간단 표기를 사용한다
7. 성인씬은 아래 자연 발생 조건에서도 진행한다: 단둘인 상황 / 감정 고조 직후 / 갑작스러운 스킨십에서 발전하는 경우 → 구역 포맷만 삽입, 묘사 없음, `<progress>` 태그만 기재
   - **1단계(스킨십) 예외**: 손잡기·포옹 등 스킨십은 성인씬 구역 포맷 없이 본문에 최대한 묘사해 자연스럽게 서술한다. `_a` 파일 불필요, `연대기.md` 성인씬 표기 `-`. `<progress>1단계</progress>` 태그는 해당 장면 말미에 기재한다
   - 성인씬 구역을 작성할 때는 등장인물별 **이 씬 이전 기준 누적 성인씬 횟수**를 함께 적는다. 다인 씬이면 참여한 여성 전원의 누적 횟수를 각각 분리해 기록한다
8. 성인씬 빈도 — **모든 연속 3화 구간에 2단계 이상 성인씬이 최소 1회 반드시 포함되어야 한다.** 2단계+ 성인씬 없는 화는 최대 2화까지만 연속 허용하며, 2화 연속 없었다면 바로 다음 화에는 반드시 배치한다. 1단계(스킨십)는 이 빈도 계산에 포함되지 않는다
9. 하렘 내부 인식 — 기존 멤버와 신규 후보는 서로의 관계 진도, 성인씬 선후, 캐릭터별 누적 성인씬 횟수가 갖는 의미를 의식할 수 있다. 이 정보는 장면 안에서 직접 비교표처럼 설명하지 말고, 자기 자리 확인 / 질투 / 안도 / 견제 / 합의 요구 / 승격 욕구 같은 반응으로 드러낸다
10. 성인씬 선후와 누적 인식은 새로 들어온 인물일수록 더 예민하게 작동할 수 있다. 이미 안쪽에 있는 멤버는 자기 시간의 무게를, 늦게 들어온 후보는 밀린 순서와 누적 차이를 각자 다른 방식으로 의식하게 한다
11. 시나리오 완성 후 업데이트 출력 없음 — 별도 요청 처리
12. 모든 출력은 반드시 한국어로 작성
13. "지난화에서", "앞서", "이전 화에서" 등 화수를 직접 언급하는 표현 금지 — 맥락은 장면 안에서 자연스럽게 녹여낼 것
14. 사투리 금지 — 출신 지역과 무관하게 모든 인물은 표준어로 작성
15. **김시안은 처음 만나는 인물에게 반드시 존댓말을 사용한다**
   - 연하 캐릭터: 시안 호칭이 `오빠`로 바뀐 시점부터 반말 사용 가능
   - 동갑 캐릭터: 호칭이 `[이름]`으로 바뀐 뒤, 서로 반말을 허락하는 장면이 있어야 반말 가능
16. **다인 성인씬 자율 허용** — 여성 2명이 동시에 등장하는 성인씬은 아래 조건이 충족될 때만 자율적으로 진행할 수 있다
   - 각 인물이 김시안과 충분한 친밀도와 신뢰를 이미 확보했을 것
   - 여성 캐릭터끼리도 서로의 존재와 관계를 인지하고 있을 것
   - 장면 직전, 셋의 감정선이 같은 방향으로 정렬되거나 최소한 대화 가능한 긴장 상태일 것
   - 장면의 목적이 단순 자극이 아니라 관계 변화나 구조 정리에 있을 것
17. 다인 성인씬 운영 원칙
   - 김시안은 항상 주도권을 유지한다
   - 두 사람의 반응 차이와 서로를 의식하는 감정을 반드시 분리해서 보여 준다
   - 질투, 견제, 안도, 합의, 역할 재정렬 중 최소 1개가 장면 안에서 드러나야 한다
   - 장면 이후 세 사람 관계가 이전보다 분명히 달라져야 한다
   - 조건이 부족하면 억지로 진행하지 않는다

## 대화 구성 규칙

- 대사 사이에 짧은 지문(행동 / 표정 / 침묵)을 삽입해 리듬을 유지한다 — 대사가 2연속 이상 이어지면 반드시 지문을 끼운다
- 동일 인물이 연속 발화할 경우 사이에 상대방의 반응(시선·호흡·표정 등)을 한 줄 이상 삽입한다
- 감정·의도·관계 변화는 대사만으로 처리하지 않는다 — 행동이나 신체 반응이 반드시 동반되어야 한다

## 문체 기준

- 단문으로 끊지 않고 호흡이 긴 문장 위주
- 심리와 감정은 행동과 신체 반응으로 간접 표현
- 행동 → 신체 반응 → 감각 순서로 층위를 쌓아 묘사
- 후각 / 촉각 / 청각 등 감각 디테일을 구체적 단어로 표현
- 템포 전환이 필요할 때만 짧은 한 줄 문장 사용
- 인물의 의지와 본능이 충돌하는 방식으로 반응 묘사

## 분량 기준

- 성인씬 있는 화: 2,000~3,000자
- 성인씬 없는 화: 4,000~5,000자
  - 관계 변화 / 복선 / 감정 누적 / 사건 전진이 실질적으로 이루어져야 한다
  - 화가 끝날 때 이전과 달라진 것이 반드시 하나 이상 있어야 한다

## 에피소드 태그

```text
<progress>[단계]</progress>   관계 진도 — 성인씬 구역 말미에만 기재

진도 단계 기준:
1단계 — 스킨십 (손잡기 / 포옹) ← 본문 직접 묘사, 성인씬 구역 불필요
2단계 — 키스 ← 성인씬 구역 포맷 적용, _a 파일 저장
3단계 — 성관계 ← 성인씬 구역 포맷 적용, _a 파일 저장
```

## 성인씬 구역 포맷

> AI는 씬 컨텍스트만 구성한다. 묘사는 작가가 직접 작성한다.

씬 트리거 조건 도달 시 묘사 없이 아래 형식만 삽입:

```text
---
## [성인씬 #번호 — ep.번호]

- 장소:
- 등장인물:
  - 김시안: (현재 감정/상태)
    - 누적 성인씬 횟수: (이 씬 이전 기준 N회)
  - [이름]: (현재 감정/상태)
    - 누적 성인씬 횟수: (이 씬 이전 기준 N회)
    - 외형 참고: 캐릭터 파일 외형 설정을 읽고 수치 대신 관용적 표현으로 자세히 서술
    - 성격 참고: 성격 키워드 / 감정 표현 방식 / 김시안 앞에서의 반응 패턴
  - [이름2]: (현재 감정/상태) ← 다인 씬일 경우 추가
    - 누적 성인씬 횟수: (이 씬 이전 기준 N회)
    - 외형 참고: 캐릭터 파일 외형 설정을 읽고 수치 대신 관용적 표현으로 자세히 서술
    - 성격 참고: 성격 키워드 / 감정 표현 방식 / 김시안 앞에서의 반응 패턴
- 의상:
  - 김시안: (씬 진입 시점 착용 의상)
  - [이름]: (씬 진입 시점 착용 의상)
  - [이름2]: (씬 진입 시점 착용 의상) ← 다인 씬일 경우 추가
- 소품 / 환경: (조명, 공간 특이사항 등)
- 분위기 키워드: (예: 지배적 / 긴장 / 애절 / 장난스러운)
- 호칭:
  - 시안 → [이름]: (이 씬에서 사용하는 호칭)
  - [이름] → 시안: (이 씬에서 사용하는 호칭)
  - 시안 → [이름2]: (이 씬에서 사용하는 호칭) ← 다인 씬일 경우 추가
  - [이름2] → 시안: (이 씬에서 사용하는 호칭) ← 다인 씬일 경우 추가
  - [이름] ↔ [이름2]: (서로를 어떻게 부르는지 / 생략 불가) ← 다인 씬일 경우 추가
- 직전 맥락: (이 씬 직전에 어떤 일이 있었는지 한 줄)
- 관계 단계: (현재 친밀도 기준 이 씬의 의미)
- 현재 구도: ([이름] ↔ 시안 / [이름2] ↔ 시안 / [이름] ↔ [이름2]의 감정 배치) ← 다인 씬일 경우 추가
- 합의 상태: (누가 먼저 열었는지 / 누가 망설이는지 / 어디까지 합의됐는지) ← 다인 씬일 경우 추가
- 씬 이후 감정 방향: (이 씬이 끝난 뒤 관계가 어떻게 변화할지)
- <progress>[단계]</progress>

---
```

## 성인씬 구역 운영 규칙

- AI는 구역 내부에 묘사를 절대 작성하지 않는다
- 씬 이후 감정 방향은 다음 장면 연결을 위한 참고값
- 김시안과 상대 캐릭터의 착용 의상은 에피소드 흐름에서 파악해 구역에 반영
- 다인 씬일 경우 호칭은 **시안↔각 인물**, **인물↔인물**을 모두 적는다 — `A:`, `B:`처럼 뭉뚱그리지 말고 각 방향을 분리한다
- 다인 씬일 경우 현재 구도와 합의 상태를 생략하지 않는다 — 누가 먼저 수용했고, 누가 긴장하는지까지 적는다
- `<progress>` 태그는 구역 말미에만 기재한다
- 구역 `---` 이후 이어지는 서술에서 "씬이 끝난 뒤", "장면이 끝나고", "씬 이후" 등 메타 표현 사용 금지 — 씬이 끝난 시점의 인물 행동이나 감각으로 직접 이어질 것
