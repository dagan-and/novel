낯을 가림 / 거절을 잘 못함 / 남을 쉽게 믿음 / 사람을 잘 믿지 못함 /
타인의 시선을 지나치게 의식함 / 의심이 많음 / 속마음을 숨기지 못함 /
반대로 속내를 절대 드러내지 않음 / 부탁받으면 끝까지 책임지려 함

**집착·욕구 계열**
질투심이 강함 / 독점욕이 강함 / 집착하는 성향 / 인정욕구가 강함 /
칭찬에 약함 / 비난에 취약함 / 승부욕이 지나침

**자기 관리 계열**
완벽주의 성향 / 지나친 책임감 / 자기희생적임 / 중요한 순간 자신보다 타인을 우선함 /
스스로를 돌보지 못함 / 체력이 약함 / 압박 상황에 취약함

**행동·성향 계열**
우유부단함 / 성급함 / 충동적임 / 고집이 셈 / 융통성이 부족함 /
현실 도피 성향 / 유혹에 약함 / 거짓 연기를 못함 / 쉽게 얼굴에 드러남

**특정 대상·상황 계열**
특정 사람에게 지나치게 약해짐 / 가족에게 약함 / 칭찬 한마디에 쉽게 넘어감 /
버려지는 것에 대한 두려움 / 사랑에는 서툼 / 혼자 있는 것을 무서워함

**로맨스·서사 조합 예시** *(참고용 — 그대로 쓰거나 변형)*
강인하지만 가족에게 약함 / 냉정하지만 칭찬에 약함 / 당당하지만 버려지는 것이 두려움 /
완벽해 보이지만 실패 공포가 심함 / 도도하지만 사랑에는 서툼 /
밝고 명랑하지만 혼자 있을 때 외로움을 탐 / 상냥하지만 거절을 못해 손해를 봄 /
자신감 넘치지만 특정 인물 앞에서는 쉽게 흔들림 / 무심해 보이지만 정이 많아 쉽게 상처받음

**약점 통합 예시** *("~한 상황에서 ~하는 경향" 형태로)*
> "거절을 잘 못해 손해 보는 일이 잦다. 싫다는 말 대신 억지로 웃어넘기다가 나중에 혼자 지쳐버리는 패턴이다. 또한 한번 상처받으면 오래 품고, 티를 내지 않으면서도 관계에서 서서히 거리를 둔다."

## 성격 샘플

*(표면 2~3개 + 내면 2~3개 선택 — 두 그룹이 방향이 어긋나야 함)*

**표면 성격** (타인에게 보이는 모습)

**성격 통합 예시** *(표면 + 내면 대비를 한 문단으로)*
> "겉으로는 활발하고 붙임성이 좋아 누구와도 금방 친해지지만, 사실 혼자 있을 때 외로움을 많이 탄다. 시끄러운 자리가 끝난 뒤 조용히 자취방으로 돌아가면 그때서야 텅 빈 기분이 밀려오는 타입이다."
> "처음에는 무뚝뚝하고 도도한 인상이라 쉽게 다가가기 어렵지만, 한번 마음을 열면 누구보다 헌신적이고 집착에 가까운 애정을 쏟는다."
