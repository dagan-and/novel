필터 조합 방식 — 어떤 구조가 더 직관적일까요?

캐릭터 필터 + 관계 타입 필터를 어떻게 배치할지 선택해주세요

B1

타입 탭 (상단) + 캐릭터 칩 (하단)

관계 타입이 메인 탭, 캐릭터는 보조 필터. "동맹 탭에서 소율 관련만" 식으로 좁혀서 보기

전체 동맹 우정 긴장 탐색
인물: 소율 ✕ 하은 서진 다온 미현
동맹 소율 × 하은
안정적 공존 · 소율→하은아 / 하은→소율 언니
동맹 소율 × 서진
운영 현장에서 서로 받쳐주는 같은 편
타입으로 먼저 분류 캐릭터로 세부 필터
B2

캐릭터 탭 (상단) + 타입 뱃지 색상

캐릭터가 메인 탭, 카드마다 관계 타입 뱃지를 색상으로 표시. 한 인물의 모든 관계를 타입 색상으로 한눈에 파악

소율 하은 서진 다온 미현
소율 × 하은 동맹
안정적 공존 · 소율→하은아 / 하은→소율 언니
소율 × 서진 동맹
운영 현장에서 서로 받쳐주는 같은 편
소율 × 미현 긴장
먼저 쌓인 시간의 무게와 긴장 섞인 인정 단계
인물 중심 탐색 색상으로 타입 직관
B3

두 필터 동시에 (독립 작동)

캐릭터 + 타입 필터 각각 독립적으로 AND 작동. "소율 선택 + 동맹 선택 = 소율의 동맹 관계만" 표시
