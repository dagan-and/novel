관계망 HTML — 어떻게 개선할까요?

현재: 텍스트 카드 15장이 그냥 나열됨. 한눈에 파악하기 힘든 구조.

A

인터랙티브 네트워크 그래프

노드(캐릭터)와 엣지(관계선)를 SVG/Canvas로 그려서, 클릭하면 관계 상세가 펼쳐지는 실제 그래프 시각화

시안
소율
하은
서진
다온
미현
연서
→ 노드 클릭 시 관계 상세 패널 오픈
한눈에 전체 파악 구현 복잡도 높음
B

캐릭터 필터 + 카드 뷰

상단에 캐릭터 버튼을 두고, 클릭하면 해당 캐릭터와 연관된 관계 카드만 필터링. 현재 레이아웃 유지하며 탐색성 개선

소율 하은 서진 다온 미현
소율 × 하은 — 안정적 공존
소율 → 하은아 / 하은 → 소율 언니
소율 × 서진 — 같은 편
소율 → 서진 언니 / 서진 → 소율아
빠른 구현 기존 디자인 유지 전체 구조는 텍스트
C

매트릭스 + 슬라이드오버 패널

상단에 7×7 관계 매트릭스 테이블로 전체 연결 강도를 색으로 한눈에 보여주고, 셀 클릭 시 옆에서 상세 패널이 슬라이드로 열리는 구조

전체 구조 파악 쉬움 클릭 상세 탐색 중간 복잡도
