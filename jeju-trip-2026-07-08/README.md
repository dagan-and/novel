# 제주도 가족 여행 문서

## 버전 규칙

- 캐시 문제를 피하기 위해 HTML/MD 파일명 끝에 버전을 붙인다.
- 첫 버전은 `_v1`로 시작한다.
- 내용을 크게 수정하거나 공유 링크 캐시를 피해야 할 때는 `_v2`, `_v3`처럼 새 파일로 저장한다.

## 현재 파일

- `jeju-trip-2026-07-08_v6.html`: 최신 보기용 HTML 문서
- `jeju-trip-2026-07-08_v6.md`: 최신 원본 정리용 Markdown 문서
- `jeju-trip-2026-07-08_v5.html`: 이전 보기용 HTML 문서
- `jeju-trip-2026-07-08_v5.md`: 이전 원본 정리용 Markdown 문서

- `jeju-trip-2026-07-08_v2.html`: 이전 보기용 HTML 문서
- `jeju-trip-2026-07-08_v2.md`: 이전 원본 정리용 Markdown 문서
