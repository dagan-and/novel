# 제주도 가족 여행 문서

## 버전 규칙

- 캐시 문제를 피하기 위해 HTML/MD 파일명 끝에 버전을 붙인다.
- 첫 버전은 `_v1`로 시작한다.
- 내용을 크게 수정하거나 공유 링크 캐시를 피해야 할 때는 `_v2`, `_v3`처럼 새 파일로 저장한다.
