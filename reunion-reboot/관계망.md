# 관계망

## 김시안 현재 상태

- 루프: 리부트 1차, 시안은 아직 루프의 존재를 모름
- 연도: 2014년
- 계절: 3월 말
- 나이: 26세 (연나이)
- 학적: 대학 4학년
- 거주지: 서울 자취방
- 현재 상태: 박미현, 유하린, 서나윤, 정다은 네 축이 모두 열렸다. 문채영의 실수로 만들어진 단체방을 통해 서로의 존재가 공개됐고, ep.050에서 특정 인물에게 가지 않는 밤을 선택하며 새 시간표 정리 단계로 넘어갔다.

## 멤버 간 관계망

### 박미현 x 유하린

- 현재: 서로 시안의 시간을 나눠 갖는 관계임을 인지
- 최근 변화: 하린은 `수요일은 제 거`라고 말했고, 미현은 `화요일은 제 거`를 확인받았다.
- 예정 분기: 단체방에서 서로의 선택과 답장 지연을 보며 직접 견제 가능
- 호칭: 미정

### 박미현 x 서나윤

- 현재: 우산과 편의점 밤 동선을 통해 간접 견제
- 최근 변화: 나윤의 편의점 우산이 카페 소품으로 넘어갔고, 이후 나윤도 단체방에 들어왔다.
- 예정 분기: 카페 마감 후 루틴과 야간 편의점 루틴이 같은 밤에 충돌 가능
- 호칭: 미정

### 유하린 x 서나윤

- 현재: 하린은 양보 후 불편함을 말하기 시작했고, 나윤은 통보식 호출로 치고 들어온다.
- 최근 변화: ep.042에서 하린이 나윤에게 시안을 보내 줬지만 `괜찮았던 건 아니에요`라고 밝혔다.
- 예정 분기: 하린의 조심스러운 요구와 나윤의 빠른 통보가 같은 날 충돌 가능
- 호칭: 미정

### 박미현 x 정다은

- 현재: 카페와 커리어센터 축으로 직접 접촉
- 최근 변화: 정다은이 카페에 오고, 시안의 넥타이를 고쳐 준 사실을 미현이 확인했다.
- 예정 분기: 화요일 카페 시간과 금요일 스터디 시간이 서로 침범할 때 충돌 가능
- 호칭: 미정

### 유하린 x 정다은

- 현재: 직접 접촉은 제한적이나 단체방에서 서로 인지
- 최근 변화: 정다은의 정확한 일정 관리가 하린의 기다림과 충돌하기 시작했다.
- 예정 분기: 하린의 감정 요구와 다은의 정리 요구가 서로 반대 압력으로 작동
- 호칭: 미정

### 서나윤 x 정다은

- 현재: 단체방에서 서로 인지
- 최근 변화: 나윤의 통보식 호출과 다은의 정확한 일정 통제가 동시에 시안을 압박한다.
- 예정 분기: 목요일 야간 편의점과 금요일 스터디가 연속으로 붙으며 피로와 질투를 동시에 유발
- 호칭: 미정
