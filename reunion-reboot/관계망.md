# 관계망

## 김시안 현재 상태

- 루프: 리부트 1차
- 연도: 2014년
- 계절: 3월 초
- 나이: 26세 (연나이)
- 학적: 대학 4학년
- 거주지: 서울 자취방
- 현재 상태: 학기 초와 취업 준비 압박이 동시에 시작된 상태. 박미현의 카페를 반복 방문하며 첫 관계 축이 열렸고, 유하린과 금요일 추가 접수 약속이 생기면서 학교 안팎 일정이 겹치기 시작했다.

## 하렘 현황

| 이름 | 구분 | 친밀도 | 관계 진도 | 현재 상태 |
|------|------|--------|-----------|-----------|
| 박미현 | 1번 여주인공 / 메인 후보 | 낮음+ | 0.5단계 | 시안의 반복 방문, 연한 커피, 창가 자리, 상담 회피를 기억함. 금요일 방문 여부를 기다리는 상태 |
| 유하린 | 후보 | 낮음 | 0.3단계 | 캠퍼스 신입생 생활권. 시안에게 길과 동아리 추천 선배 도움을 받으며 기대기 시작 |
| 서나윤 | 후보 | 없음 | 0단계 | 갓 사회로 나온 편의점 야간 알바. 야간 귀가길 생활권 확장용 보류 히로인 |

## 멤버 간 관계망

### 박미현 x 유하린

- 현재: 직접 대화는 거의 없음
- 최근 변화: ep.004에서 하린이 카페까지 시안을 찾아와 `선배`라고 부르는 장면을 미현이 목격했다.
- 예정 분기: 금요일 18시, 하린의 추가 접수 약속과 미현의 카페 기다림이 겹치며 첫 견제 가능
- 호칭: 미정

### 박미현 x 서나윤

- 현재: 미접촉
- 최근 변화: 없음
- 예정 분기: 카페에서 쌓인 친밀감과 편의점 야간 생활 리듬이 충돌할 때 견제 가능
- 호칭: 미정

### 유하린 x 서나윤

- 현재: 미접촉
- 최근 변화: 없음
- 예정 분기: 캠퍼스 생활권과 야간 편의점 생활권이 시안의 늦은 귀가 동선에서 겹칠 때 협력 또는 견제 가능
- 호칭: 미정
