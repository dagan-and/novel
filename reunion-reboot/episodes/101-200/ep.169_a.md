# ep.169 - 제출 버튼 앞에서

지원서 제출 버튼 앞에서 시안의 손이 멈췄다.

문제는 제출이 아니었다.

제출한 뒤 누구에게 먼저 말할지였다.

동시에 말하면 공평할까.
아니면 또 아무도 먼저가 아닌 사람이 생길까.

다은은 자취방 책상 옆에 앉아 있었다.

[정다은] "고르는 순간 누군가는 밀립니다."

[김시안] "그럼 동시에 보내면요?"

[정다은] "동시에 보내는 것도 선택입니다."

맞는 말.
오늘은 특히 더 잔인한 맞는 말.

시안은 제출 버튼을 눌렀다.

완료 화면이 떴다.

시안은 숨을 내쉬었다.

다은은 그 옆에서 노트를 닫지 않았다.

[정다은] "이제 공유하십시오."

[김시안] "다은 씨는요?"

[정다은] "저는 이미 봤습니다."

[김시안] "그래서 더 먼저 말해야 할 것 같은데요."

다은이 시안을 봤다.

[정다은] "김시안 씨."

[김시안] "네."

[정다은] "저를 기록 담당으로만 두지 마십시오."

말로 다 정리할 수 없는 확인이 필요해진 순간이었다.

제출 완료 화면과 닫히지 않은 노트가 같은 책상 위에 있었다.

    - 누적 성인씬 횟수: 6회

    - 성격 참고: 정확한 기준으로 밀어붙이지만, 자신이 뒤로 밀릴 때는 목소리보다 노트를 닫지 않는 행동으로 먼저 드러난다.
