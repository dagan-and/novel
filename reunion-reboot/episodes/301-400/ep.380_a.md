# 380. 부스 뒤의 두 기준

행사가 끝난 뒤, 부스 뒤에는 얼음컵과 리플릿이 남았다.

나윤은 접힌 테이블에 기대 있었다.

하린은 리플릿 더미를 끈으로 묶고 있었다.

[서나윤] "오늘 오빠 소리 작게 했죠?"

하린의 손이 멈췄다.

[유하린] "들었어요?"

[서나윤] "제가 귀가 좋아요."

[김시안] "저는 지금 정리 중입니다."

[서나윤] "도망 중 아니고요?"

[유하린] "정리 중 맞아요. 도망이면 제가 잡았어요."

둘이 동시에 시안을 봤다.

시안은 테이블 다리를 접었다.

테이블은 접혔다.

상황은 접히지 않았다.

나윤은 얼음컵을 들어 올렸다.

[서나윤] "저는 더우면 오빠."

하린은 부채를 손에 쥐었다.

[유하린] "저는... 조용할 때요."

둘의 기준이 달랐다.

그래서 이상하게 같이 놓일 수 있었다.

## [성인씬 #17 / #15 - ep.380]

- 장소: 홍보 부스 행사 종료 뒤, 접힌 테이블과 리플릿 상자가 남은 부스 뒤편
- 등장인물:
  - 김시안: 부스 운영을 마치고 하린과 나윤의 다른 `오빠` 기준을 동시에 마주하는 상태
    - 누적 성인씬 횟수: 해당 없음
  - 유하린: 부스 안내를 해내고, 조용한 순간에만 `오빠`를 부르는 자기 기준을 말하는 상태
    - 누적 성인씬 횟수: 16회
    - 외형 참고: 아담하고 여린 체형. 가녀린 어깨선에 허리와 상체 라인은 부드럽게 잘록하고, 가슴은 체구에 비해 은근히 도드라지는 편이라 전체적으로 보호본능을 자극하는 청순한 볼륨감이 느껴진다. 부채와 리플릿을 쥔 손끝이 조용하지만 물러서지 않는 긴장을 만든다.
    - 성격 참고: 조심스러움 / 조용한 반격 / 기대고 싶은 마음을 자기 속도로 말함
  - 서나윤: 얼음컵으로 부스 더위를 잡고, 장난처럼 `오빠`를 공개할 수 있는 자기 기준을 밀어붙이는 상태
    - 누적 성인씬 횟수: 14회
    - 외형 참고: 균형 잡힌 키에 운동으로 다져진 탄탄한 슬림 체형이라, 시원한 어깨선과 자연스럽게 조여드는 허리, 길게 뻗은 다리선이 먼저 눈에 들어온다. 과한 굴곡보다 가볍고 단단한 근육선이 살아 있어, 얇은 옷차림에서도 몸을 쓰던 사람 특유의 탄력과 긴장감이 바로 느껴진다. 얼음컵을 든 자세와 묶은 머리가 더위 속에서도 직진하는 생기를 남긴다.
    - 성격 참고: 직진 / 승부욕 / 공개 장난으로 독점욕을 드러냄
- 의상:
  - 김시안: 노란 부스 티셔츠 위에 걸친 셔츠, 명찰을 뗀 상태
  - 유하린: 가벼운 여름 원피스와 부채
  - 서나윤: 편의점 유니폼 조끼를 벗은 가벼운 티셔츠, 운동화
- 이미지 포인트: 하린의 부채와 나윤의 얼음컵이 접힌 테이블 위에 나란히 놓이는 순간
- 표정 포인트:
  - 김시안: 둘의 기준이 다르다는 걸 알아차리고 쉽게 요약하지 못하는 얼굴
  - 유하린: 부끄러워하지만 조용한 기준을 물러서지 않는 얼굴
  - 서나윤: 장난처럼 웃지만 자기 기준을 빼앗기지 않는 얼굴
- 손 / 시선 포인트:
  - 김시안: 접힌 테이블 다리를 붙잡고 멈춤
  - 유하린: 부채 끝을 시안 쪽으로 둠
  - 서나윤: 얼음컵 뚜껑을 손끝으로 두드림
- 복장 상태: 부스 티셔츠, 명찰을 뗀 목선, 부채와 얼음컵 중심
- 배경 소품 강조: 접힌 테이블, 리플릿 상자, 얼음컵, 부채
- 소품 / 환경: 행사 종료 뒤 조용해진 캠퍼스 부스 뒤편, 남은 테이프와 현수막
- 분위기 키워드: 두 가지 오빠 기준, 공개와 조용함, 부스 뒤 재정렬
- 호칭:
  - 시안 → 유하린: 하린 씨
  - 유하린 → 시안: 평소에는 선배, 둘만 있거나 조용한 순간 오빠
  - 시안 → 서나윤: 나윤 씨
  - 서나윤 → 시안: 평소에는 손님, 더위와 독점욕이 올라오면 오빠
  - 유하린 ↔ 서나윤: 하린 씨 / 나윤 씨
- 직전 맥락: 홍보 부스 행사 중 하린은 작게, 나윤은 공개적으로 각각 `오빠`를 사용함
- 관계 단계: 유하린 2.4단계 / 서나윤 2.3단계
- 현재 구도: 유하린 ↔ 시안 ↔ 서나윤, 같은 호칭을 다른 기준으로 쓰며 충돌보다 병렬 구도가 생김
- 합의 상태: 두 사람이 서로의 기준을 완전히 동의하진 않지만 지우지 않고, 시안은 하나로 정리하지 않음
- 씬 이후 감정 방향: 381화 이후 단체방과 다른 히로인들이 두 기준을 어떻게 받아들일지가 후폭풍이 됨
