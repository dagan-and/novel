# 524. 드레스코드 검사

결혼식 전날, 단체방은 드레스코드로 터졌다.

[박미현] 밝은 색 괜찮아요?

[유하린] 너무 튀면 안 되겠죠?

[서나윤] 운동화는 안 되죠?

[정다은] 운동화는 이동용으로만 허용됩니다.

[이재인] 회사 테이블은 무난함이 미덕입니다.

[김시안] "이 방에 스타일리스트가 몇 명이야."

문채영이 사진을 하나 올렸다.

[문채영] 참고로 신랑 측 친구석에서 이상한 삼각관계 표정 잡히면 제가 박제합니다.

시안은 휴대전화를 내려놓았다.

그때 윤서에게서 문자가 왔다.

[최윤서] 내일 촬영은 신부 입장보다 하객 반응이 더 어려워요. 특히 늦게 깨닫는 표정.

시안은 거울 앞에 섰다.

정장은 어울렸다.

그런데 표정은 아직 어디 테이블에도 앉지 못했다.
