# 545. 이번엔 고르기

카페는 닫힌 뒤에도 환했다.

벽에는 컵 메모들이 붙어 있었다.

시안은 `이번엔 고르기` 앞에서 멈췄다.

[박미현] "떼고 싶어요?"

[김시안] "조금."

[박미현] "그럼 고르면 돼요."

말이 쉽다.

언제나 말은 쉽고, 컵은 무겁다.

미현은 새 컵을 꺼냈다.

아무 메모도 붙어 있지 않은 컵이었다.

[박미현] "이번엔 시안 씨가 적어요."

시안은 펜을 들었다.

빈 컵이 빈칸보다 더 넓어 보였다.

## [성인씬 #31 - ep.545]

- 장소: 홍대 카페 마감 후, 컵 메모 전시 벽 앞
- 등장인물:
  - 김시안: 오래된 메모들이 한 자리에 모인 것을 보고, 더 이상 메모를 받기만 할 수 없음을 느낀다.
    - 누적 성인씬 횟수: 해당 없음
  - 박미현: 컵 메모를 증거물처럼 전시하고, 이번에는 시안이 직접 적게 만든다.
    - 누적 성인씬 횟수: 30회
    - 외형 참고: 슬림하고 여린 체형. 가는 어깨선과 잘록한 허리선이 먼저 눈에 들어오고, 가슴은 적당한 볼륨이라 전체적으로 청순하면서도 은근히 시선을 끄는 인상이다. 이 장면에서는 마감 조명 아래 새 컵을 내미는 손과 벽 앞에 선 여린 실루엣이 중심이다.
    - 성격 참고: 밝지만 물러서지 않음 / 컵으로 관계를 남김 / 선택받는 이름을 요구함
- 의상:
  - 김시안: 편한 셔츠와 코트
  - 박미현: 카페 앞치마와 니트
- 이미지 포인트: 미현이 빈 컵을 내밀고, 시안이 처음으로 자기 손으로 메모를 적는 순간
- 표정 포인트:
  - 김시안: 웃으려다 진지해진 얼굴
  - 박미현: 기대와 불안을 같이 숨긴 얼굴
- 손 / 시선 포인트:
  - 김시안: 펜을 든 손이 잠깐 멈춤
  - 박미현: 컵보다 시안의 손끝을 봄
- 복장 상태: 앞치마 끈, 셔츠 소매, 펜과 컵 가장자리 중심
- 배경 소품 강조: 컵 메모 전시, 빈 컵, `이번엔 고르기`
- 소품 / 환경: 마감한 카페, 전시 벽, 펜
- 분위기 키워드: 받기만 한 약속, 직접 적는 대답, 마무리 아닌 재흔들림
- 호칭:
  - 시안 → 박미현: 미현
  - 박미현 → 시안: 시안 씨
- 직전 맥락: 미현은 오래된 컵 메모를 전시하고, 시안에게 이번에는 직접 적으라고 요구한다.
- 관계 단계: 3.1단계에서 3.15단계로 미세 상승
- 현재 구도: 박미현 ↔ 시안
- 합의 상태: 미현이 먼저 선택을 요구하고, 시안이 빈 컵에 자기 문장을 적기로 한다.
- 씬 이후 감정 방향: 미현은 후반부 중심축으로 다시 강하게 올라오지만, 결론은 아직 열어 둔다.

[박미현] "일단 보관."

[김시안] "검수는?"

[박미현] "살면서 할게요."
