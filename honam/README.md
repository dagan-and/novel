# Honam

기원후 0년, 목포 상공에 다른 차원의 외계문명 기체를 빌려 탄 모함이 나타난다. 모함은 의체를 가진 불로불사의 왕과, 핵융합 리액터를 품은 5m급 호위 안드로이드 500기를 내려준 뒤 곧바로 하늘 너머로 사라진다.

이 프로젝트는 예수의 출현이 전해지는 서방의 기원후 원년과, 한반도 남서부에서 시작된 초월기술 백제의 탄생을 나란히 놓는 대체고대사 세계관이다. 핵심 무대는 목포와 영산강 유역이며, 초기 정체성은 신화와 하드 SF가 동시에 성립하는 고대 호남 초문명이다.
