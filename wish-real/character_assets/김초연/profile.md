# 김초연 캐릭터 이미지 기준

## 목적

김초연의 삽화 일관성을 유지하기 위한 이미지 참조 폴더다.
소설 삽화 생성 시 `characters/김초연.md`의 고정 설정과 이 폴더의 기준 이미지, 프롬프트를 함께 참고한다.

## 기준 이미지

- `references/main.png`: 삽화 생성 시 우선 참고하는 김초연 기준 이미지. 사용자가 AI로 만든 이미지를 그대로 사용한다.
- `references/originals/cafe-street.png`: 카페 앞 거리, 흰 니트와 스커트 분위기.
- `references/originals/cafe-smile.png`: 카페 실내, 김초연의 대표 얼굴과 미소 기준.
- `references/originals/winter-vsign.png`: 겨울 패딩, 장난스러운 셀카 표정.
- `references/originals/resort-drink.png`: 여행지, 흰 민소매와 음료, 여름 분위기.
- `references/originals/street-fullbody.png`: 거리 전신, 흰 블라우스와 청반바지, 슬렌더 체형 기준.

## 사용 우선순위

1. `characters/김초연.md`의 확정 외형과 성격
2. `references/main.png`
3. `references/originals/`의 상황별 이미지
4. `prompts/base_prompt.md`
5. `prompts/negative_prompt.md`

제공된 이미지는 이미 AI로 생성된 김초연 기준 이미지이므로, 새 기준 이미지를 다시 만들지 않는다.
회차 삽화에서는 이 이미지들의 얼굴 계열, 긴 흑갈색 머리, 앞머리, 맑은 눈, 청순하지만 장난기 있는 분위기를 유지한다.

## 고정 인상

- 한국 여성, 1989년생, 2008년 기준 김용식과 동갑.
- 작고 부드러운 얼굴형과 동안 인상.
- 긴 검은색 또는 흑갈색 머리와 자연스러운 앞머리.
- 맑고 또렷한 눈, 웃을 때 귀여움이 살아나는 표정.
- 슬렌더 체형, 과장된 볼륨보다 가늘고 청순한 실루엣.
- 여성스럽고 단정한 옷차림이 잘 어울리지만, 말투와 게임 성향은 거침없다.
