# 나카타 유즈키 캐릭터 이미지 기준

## 목적

나카타 유즈키의 삽화 일관성을 유지하기 위한 이미지 참조 폴더다.
소설 삽화 생성 시 `characters/나카타_유즈키.md`의 고정 설정과 이 폴더의 기준 이미지, 프롬프트를 함께 참고한다.

## 기준 이미지

- `references/main.png`: 삽화 생성 시 우선 참고하는 나카타 유즈키 기준 이미지. 캐릭터 설정을 바탕으로 생성한 메인 레퍼런스다.

## 사용 우선순위

1. `characters/나카타_유즈키.md`의 확정 외형과 성격
2. `references/main.png`
3. `prompts/base_prompt.md`
4. `prompts/negative_prompt.md`

회차 삽화에서는 이 기준 이미지의 밝게 웃는 얼굴, 밝은 밤색 머리, 아담하지만 몸매가 좋은 체형, 신입 멘토다운 어색한 친밀감, 생활 지원실의 현실적인 분위기를 유지한다.
사용자가 제공한 참고 이미지는 유즈키의 눈웃음, 활짝 웃는 얼굴, 건강한 허리선과 균형 잡힌 몸매, 활기 있는 여성성을 조정하는 참고로만 사용한다. 사진 속 인물, 의상, 로고, 스포츠 행사 배경, 무대 포즈를 그대로 복제하지 않는다.

## 고정 인상

- 일본 여성, 1988년생, 생일은 7월 24일, 2008년 기준 스무 살.
- 키 약 158cm의 아담하지만 몸매가 좋은 체형. 마른 모델형은 아니고, 작은 골격에 허리선과 볼륨감이 자연스럽게 살아나는 건강한 실루엣이다.
- 동그란 얼굴형, 도톰한 볼, 작고 낮은 코, 도톰한 입술과 자연스럽게 올라간 입꼬리.
- 크고 둥근 눈, 또렷한 쌍꺼풀, 살짝 처진 눈꼬리, 웃으면 반달처럼 접히는 눈.
- 하얀 피부와 옅은 홍조, 부끄러우면 귀끝부터 빨개지는 인상.
- 밝은 밤색의 폭신한 미디엄 보브 또는 낮게 묶은 양갈래 느낌의 생활 머리. 안쪽으로 말린 끝, 짧고 촘촘한 앞머리, 얼굴 옆 잔머리가 정다은의 짙은 짧은 단발과 구분된다.
- 옷은 한 벌로 고정하지 않는다. 2008년 일본 어학원 생활권과 계절에 맞춰 부드럽고 여성스러운 옷을 입되, 살짝 붙는 니트, 자연스럽게 목선이 열리는 블라우스, 허리선이 살아나는 여름 원피스, 무릎 위 스커트, 낮은 하이힐이나 펌프스처럼 몸매 라인이 자연스럽게 드러나는 핏을 우선한다. 너무 긴 정장 치마나 성숙한 오피스룩은 피한다.
- 화려하거나 도도한 미인이 아니라, 처음부터 다가가기 쉽고 거리 두는 법을 잘 모르는 따뜻한 인상.
