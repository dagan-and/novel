# 한서윤 캐릭터 이미지 기준

## 목적

한서윤의 삽화 일관성을 유지하기 위한 이미지 참조 폴더다.
소설 삽화 생성 시 `characters/한서윤.md`의 고정 설정과 이 폴더의 기준 이미지, 프롬프트를 함께 참고한다.

## 기준 이미지

- `references/main.png`: 삽화 생성 시 우선 참고하는 한서윤 기준 이미지.

## 사용 우선순위

1. `characters/한서윤.md`의 확정 외형과 성격
2. `references/main.png`
3. `prompts/base_prompt.md`
4. `prompts/negative_prompt.md`

회차 삽화에서는 긴 달걀형 얼굴, 가늘고 긴 눈매, 왼쪽 눈 아래 작은 점, 풀어둔 짧은 흑갈색 머리, 진주귀걸이, 조용히 오래 남는 시선을 유지한다.

## 고정 인상

- 한국 여성, 1988년생, 생일은 2월 20일, 2008년 기준 스물한 살.
- 키 약 166cm의 마른 편이지만 빈약하지 않은 긴 실루엣.
- 달걀형에 가까운 긴 얼굴, 얇게 정리된 턱선.
- 가늘고 긴 눈매, 진하지 않은 속쌍꺼풀, 살짝 올라간 눈꼬리.
- 왼쪽 눈 아래 광대에 닿기 전쯤 작은 점.
- 짙은 흑갈색의 짧게 자른 머리. 실내에서는 거의 검게 보이고, 턱선 아래에서 목덜미 위로 떨어지는 쇼트 보브나 짧은 레이어드컷을 묶지 않고 풀어둔다.
- 얇게 붙는 니트, 목선이 조금 드러나는 블라우스, 허리선이 드러나는 카디건, 짧은 스커트나 몸선을 따라 떨어지는 원피스, 정리된 필통, 일본 잡지, 캔커피 같은 소품이 잘 어울린다. 작은 진주귀걸이가 얼굴 옆의 고정 포인트다.
- 김초연보다 덜 따뜻하고 덜 즉각적이다. 조용히 옆자리에 있다가 뒤늦게 신경 쓰이기 시작하는 인상이다.
