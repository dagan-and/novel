# 김용식 캐릭터 이미지 기준

## 목적

김용식의 삽화 일관성을 유지하기 위한 이미지 참조 폴더다.
소설 삽화 생성 시 `characters/김용식.md`의 고정 설정과 이 폴더의 기준 이미지, 프롬프트를 함께 참고한다.

## 기준 이미지

- `references/main.png`: 삽화 생성 시 우선 참고하는 라이트노벨풍 기준 이미지.
- `references/originals/front-id.JPG`: 실제 얼굴 정면 참고용 원본.
- `references/originals/cap-selfie.JPG`: 실제 인상, 눈매, 모자 착용 분위기 참고용 원본.
- `references/originals/stadium-selfie.JPG`: 실제 얼굴선, 머리 형태, 일상 사진 분위기 참고용 원본.

## 사용 우선순위

1. `characters/김용식.md`의 확정 외형과 성격
2. `references/main.png`
3. `prompts/base_prompt.md`
4. `prompts/negative_prompt.md`
5. `references/originals/`의 실제 사진

원본 사진은 신원과 인상 참고용이다. 회차 삽화에서는 원본 사진을 그대로 복제하지 않고, 김용식이라는 소설 캐릭터의 일관된 얼굴 계열과 분위기를 유지하는 데만 사용한다.

## 고정 인상

- 한국 남성, 2008년 기준 만 18세.
- 부드러운 둥근 얼굴형과 정리된 얼굴선.
- 검은 머리, 자연스러운 앞머리와 적당한 볼륨.
- 차분하고 어두운 눈매.
- 입술선은 또렷하지만 과하게 꾸미지 않는다.
- 표정은 크게 웃기보다 조용하고 관찰하는 느낌이 강하다.
- 매력적으로 보정되었지만 기존 김용식의 인상을 완전히 벗어나지 않는다.
