# 연대기

(세계관 확정 전. 화별 사건 타임라인을 여기에 순서대로 기록한다.)

| 화 | 인게임 날짜 | 핵심 사건 |
|---|---|---|
| 001 | 2008-01-01 | 김용식이 2026년 기억을 가진 채 용인 수지의 자기 방에서 깨어난다. 현재 날짜와 2008년의 몸을 확인하고, 로또 267회 번호를 암호처럼 수첩에 남긴다. 현관에서 아버지와 마주치며 집 안의 오래된 압력이 다시 살아난다. |
| 002 | 2008-01-01 | 김용식이 김종규, 송기훈과 PC방에서 어울리며 평소처럼 보이려 애쓴다. 음료수를 사러 나온 김에 로또 267회 번호를 수동으로 구매한다. |
| 003 | 2008-01-12 | 김용식이 방 컴퓨터로 로또 267회 당첨번호를 확인하고 1등 당첨을 확정한다. 기쁨보다 돈을 숨기고 설명해야 하는 압박이 먼저 커진다. |
| 004 | 2008-01-14 | 김용식이 은행에서 로또 267회 1등 당첨금을 세후 2,215,634,741원으로 수령한다. 가족에게 티 내지 않고 돈을 천천히 숨기기로 정한다. |
| 005 | 2008-03-03 | 김용식이 평택대학교 입학식에 참석한다. 패션디자인및브랜딩학과 줄 근처에서 김초연을 멀리서 처음 보고, 기억으로 앞서가지 않으려 일부러 개입하지 않는다. |
| 006 | 2008-03-03 | 입학식 뒤풀이 후 김용식이 PC방 카운터 앞에서 김초연과 첫 대화를 나눈다. 김초연은 자리 양보를 고마워하며 이름과 학과를 묻고, 나중에 게임 한 판 하자는 말을 남긴다. |
| 미래 사건 | 2015년 | 김용식과 어머니가 아버지와 떨어져 따로 살게 된다. 초반 원고에서는 직접 설명하지 않고 장기 서사 카드로 남긴다. |
| 미래 사건 | 2022년 | 김용식이 일본 이시카와현 가나자와시의 카페에서 한국어를 공부하던 사쿠라이 미사키와 처음 만난다. |
| 미래 사건 | 2024년 | 김용식과 사쿠라이 미사키가 약 2년간의 연애 끝에 결혼하는 흐름으로 둔다. 구체적인 결혼식 날짜는 미정이다. |
| 미래 사건 | 2025년 이후 | 딸 사쿠라이 유우의 출생 가능성을 열어 둔다. 정확한 출생일과 성씨 사용 방식은 미정이다. |
