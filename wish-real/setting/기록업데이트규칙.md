# 기록 업데이트 규칙

## 적용 범위

- 원고 작성 이후 캐릭터 파일, `관계망.md`, `연대기.md`를 갱신할 때 적용한다.
- 설정 보강 요청만 처리하는 경우에는 진행 기록을 새로 갱신하지 않는다.

## 업데이트 순서

1. 완성 원고 확인
2. `states/current_state.json`에 반영할 가변 정보 정리
3. 큰돈을 쓴 장면이 있으면 `states/finance_state.json`의 `transactions`, `monthly_spending_summary`, 잔액을 갱신. 소액 생활비와 일반 데이트 비용은 금융 장부에 반영하지 않음
4. `관계망.md` 갱신
5. `연대기.md` 갱신
6. 호칭 변화 확인
7. 관계 진도 변화 확인
8. 성인 장면 처리가 있었다면 참여 인물별 누적 횟수 확인
9. 다음 5화에 넘길 복선 확인

## 연대기 기록 형식

```text
| ep | 시간대/계절 | 장소 | 등장 | 한줄 요약 | 성인 장면 | 돌발 이벤트 |
```

## 관계망 기록 원칙

- 관계 진도보다 현재 감정 상태를 우선 기록한다.
- 질투, 오해, 숨긴 사실, 생활권 변화는 복선 트래커에 남긴다.
- 메인/서브 구분이 필요할 경우 반복 선택과 생활 중심성을 기준으로 조정한다.
- 성인 장면은 단순 발생 여부보다 이후 관계 변화, 합의 상태, 질투나 안도 같은 감정 변화를 기록한다.

## 5화 점검 항목

- 최근 5화에서 Scene 없이 Sequel만 반복된 화가 있는지
- 각 화 끝에 Hook이 있었는지
- 캐릭터 욕망이 기능보다 먼저 보였는지
- 주인공이 핵심 약점을 실제로 드러냈는지
- 관계 변화가 기록에 반영됐는지
- 차량, 고가 선물, 학원·유학, 여행·숙박 예약, 투자처럼 큰 기록만 월별 지출과 잔액에 반영됐는지
