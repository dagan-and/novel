# 개요 작성 규칙

## 적용 범위

- `소설 시작해줘`, `소설 진행해줘`, `소설 자동으로 시작해줘` 요청의 개요 작성 단계에 적용한다.
- 설정 보강 요청만 처리하는 경우에는 개요를 작성하지 않는다.

## 최우선 원칙

- 개요 작성 전 이 문서의 매 화 체크리스트를 먼저 채운다.
- 매 화는 Scene과 Sequel의 균형을 가진다.
- 감정 정리만으로 한 화를 끝내지 않는다.
- 화 끝에는 다음 화를 읽을 이유가 남아야 한다.
- 첫 1~3화는 설정 설명보다 현재 압력, 주인공의 장점/약점, 주요 인물과의 첫 접점을 우선 보여 준다.
- 5화 단위 개요는 "5화 미니 아크 규칙"에 맞춰 누적 변화가 보이게 설계한다.

## 매 화 체크리스트

1. Goal: 이번 화에서 누가 무엇을 원하는가?
2. Conflict: 그것을 방해하는 사람, 상황, 감정은 무엇인가?
3. Stakes: 실패하면 무엇을 잃는가?
4. Disaster: 화 끝에서 무엇이 더 어려워졌는가?
5. Hook: 다음 화를 눌러야 하는 이유는 무엇인가?

## 5화 단위 체크리스트

- 최소 1회 이상 관계가 꼬이는 사건을 넣는다.
- 최소 1명은 감정을 정리하지 못한 상태로 남긴다.
- 최소 1개 이상의 목격, 오해, 일정 충돌, 메시지, 숨긴 선택을 배치한다.
- 같은 훅 유형을 3화 연속 반복하지 않는다.
- 5화 끝에는 되돌리기 어려운 작은 변화가 남아야 한다.
- 같은 인물 중심 화가 과도하게 반복되지 않도록 조절한다.
- 생활권, 돈, 일/학업, 주거, 가족, 평판, 건강, 이동 시간 중 최소 하나가 실제 장면 갈등으로 작동해야 한다.

## 초반 개요 방향

- 시작 시점은 세계관 확정 후 정한다.
- 초반 생활권은 주인공의 현실 압력이 가장 잘 보이는 곳으로 잡는다.
- 첫 핵심 관계는 고백보다 편한 관계, 업무상 관계, 우연한 반복 접점이 어긋나는 순간을 우선한다.
- 장면은 추상적인 감정 설명보다 일정, 행동, 메시지, 물건, 돈, 이동 문제로 연다.

## 출력 형식

- 시간대 / 계절 / 생활권
- 이번 5화의 중심 생활권
- 이번 5화 미니 아크의 되돌릴 수 없는 변화
- 등장 인물
- 각 화별 Goal / Conflict / Stakes / Disaster / Hook
- 각 화별 Opening Hook
- 각 화별 주요 인물의 상반된 목표
- 관계 변화 포인트
- 기록 반영 예정 사항
