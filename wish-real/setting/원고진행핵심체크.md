# 원고 진행 핵심 체크

## 목적

소설 진행 요청을 받았을 때 가장 먼저 확인하는 1페이지짜리 최상위 체크리스트다. 상세 규칙이 많아도 이 문서의 우선순위가 가장 앞선다.

## 0순위 원칙

아래 항목은 장면 재미, 갈등, 화말 훅보다 우선한다. 하나라도 어기면 원고를 수정한 뒤 다시 검토한다.

1. 캐릭터가 모르는 정보를 알게 하지 않는다.
2. 캐릭터별 말투와 호칭을 유지한다.
3. 새 물증, 새 발각, 문자 훔쳐보기로 갈등을 억지로 만들지 않는다.
4. 가변 정보는 상태 파일에만 기록하고 캐릭터 파일에 중복하지 않는다.
5. 회귀·미래 지식은 원고 표면에 정답처럼 드러내지 않는다.

## 집필 전 필수 확인

소설 진행 전에는 아래 파일을 먼저 확인한다.

1. `states/current_state.json`
2. `states/knowledge_state.json`
3. `연대기.md`
4. `관계망.md`
5. 필요한 경우 해당 `characters/` 고정 정보

상세 규칙은 필요할 때만 확인한다.

- 문체: `setting/문체규칙.md`
- 정보 접근: `setting/정보접근잠금규칙.md`
- 관계 서스펜스: `setting/욕망관계서스펜스규칙.md`
- 성인 장면: `setting/성인장면처리규칙.md`
- 삽화: `setting/삽화생성규칙.md`

## 정보 접근 잠금

원고 작성 전 `states/knowledge_state.json`을 기준으로 이번 화의 정보 접근 잠금표를 내부 기준으로 만든다.

반드시 분리한다.

- 각 인물이 아는 것
- 각 인물이 모르는 것
- 이번 화에 새로 들켜도 되는 것
- 이번 화에 절대 들키면 안 되는 것
- 대사에 나오면 안 되는 이름, 지명, 관계 진실

의심은 정답이 아니다. 물증은 표면 단서에서 출발해 질문을 만들 수 있을 뿐, 지명·이름·동행자·관계 진실을 자동으로 만들지 않는다.

## 호칭·말투 잠금

- 용식·초연·다은: 친한 동갑 생활권은 기본 반말.
- 용식→한서윤: 159화 전까지는 기본 `서윤 씨`와 존댓말. 159화에서 사귀기 시작한 뒤 163화부터는 서로 반말을 기본으로 한다. 감정이 흔들릴 때 기존 호칭 잔상으로 `서윤 씨`, `용식 씨`가 한두 번 섞이는 것은 허용한다.
- 초연→한서윤: 거리감 있는 `한서윤 씨`.
- 유즈키와 한국 인물 사이: 직접 만난 적 없는 인물 이름을 단정해서 말하지 않는다.

호칭 변화는 장면 압력이 있을 때만 허용하고, 한 번 나온 뒤 바로 전면 교체하지 않는다.

## 갈등 생성 제한

갈등은 반드시 새 발각으로 만들 필요가 없다.

허용되는 갈등:

- 용식이 답장을 미룬다.
- 약속을 흐린다.
- 한쪽에게 먼저 기대고 다른 한쪽을 방치한다.
- 상대는 모른 채 외로워진다.
- 소문과 시선이 배경 압력으로 쌓인다.
- 물건이 들키지 않아도 용식이 숨기는 행동 때문에 관계 온도가 변한다.

반복 금지:

- 문자 훔쳐보기
- 폰 검사
- 우연히 열린 문자함
- 잠깐 보인 미리보기
- 새 영수증·쪽지·사진으로 5화마다 발각
- 촉만으로 이름·지명·관계 진실을 맞히는 장면
- 한서윤과 정다은이 서로를 잘 아는 사람처럼 견제하거나, 서로의 구체 정보를 근거로 갈등하는 장면. 두 사람은 이름 정도만 알고, 직접 아는 듯한 구도는 금지한다.

## 퇴장·비중 축소 기준

- 공식 이별 후 초연은 주연급 감시자 데이터로 계속 부풀리지 않는다.
- 초연 관련 가변 기록은 공식 이별 상태, 민준과의 새 관계, 용식의 이중잣대를 비추는 최소 압력만 남긴다.
- 초연이 모르는 일본·서윤·다은 비밀은 `states/knowledge_state.json`의 모름 목록으로만 유지하고, 새 갈등을 위해 다시 전면화하지 않는다.

## 원고 후 필수 검사

원고 작성 후 최소한 아래 검사를 한다.

```bash
python3 tools/check_knowledge_leaks.py [원고파일...] --knowledge-state states/knowledge_state.json
```

추가로 확인한다.

- 대사 태그가 `[이름] "대사"` 형식인지
- 문자 태그가 `[발신자] 내용` 형식인지
- 화당 3,000자 이상인지
- 금지 메타 표현이 없는지
- `states/current_state.json`, `states/knowledge_state.json`, `연대기.md`, `관계망.md` 업데이트가 원고와 충돌하지 않는지

## 완료 문장

작업 내부 기준으로 아래 문장을 만족해야 한다.

```text
핵심 체크 완료: 정보 접근, 호칭·말투, 억지 발각 금지, 상태 기록, 문체, 화말 훅에서 중대한 충돌 없음.
```
