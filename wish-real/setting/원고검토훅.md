# 원고 검토 훅

## 목적

소설 진행 요청에서 새 원고를 작성한 뒤, 기록 업데이트·삽화 후보 선정·HTML 변환·푸시로 넘어가기 전에 세계관 설정, 캐릭터성, 호칭, 시간 흐름, 문체, 화말 훅의 붕괴와 원치 않는 새 설정 생성을 자동으로 잡기 위한 필수 검토 절차다.

이 문서는 실제 실행 코드가 아니라 집필 워크플로우의 고정 훅이다. 새 세션에서 AI가 `AGENTS.md`와 `setting/워크플로우.md`를 읽으면, 원고 작성 직후 반드시 이 검토를 수행해야 한다.

## 실행 위치

- 원고 초안 작성 직후 실행한다.
- `states/current_state.json`, `연대기.md`, `관계망.md`, `finance_state.json` 업데이트 전 실행한다.
- 삽화 후보 선정, imagegen 생성, HTML 변환, git push 전에 실행한다.
- 5화 이상 묶음 진행 시 각 화별 검토를 먼저 하고, 마지막에 묶음 전체 검토를 한 번 더 한다.

## 필수 참조 파일

검토자는 아래 파일을 기준으로 원고를 대조한다.

1. `AGENTS.md`
2. `states/current_state.json`
3. `연대기.md`
4. `관계망.md`
5. `states/knowledge_state.json`
6. `setting/문체규칙.md`
7. `setting/시나리오작성규칙.md`
8. `setting/욕망관계서스펜스규칙.md`
9. `setting/성인장면처리규칙.md`
10. `setting/정보접근잠금규칙.md`
11. 필요한 경우 `characters/` 고정 설정

## 검토 항목

### 1. 세계관·설정 충돌

- 2008년 한국 대학생 생활권, 폴더폰, 문자, PC방, 학생식당, 수원·평택·분당·서울 동선이 시대감과 맞는가?
- BMW, 학원, 유학, 백화점, 호텔, 선물, 숙박 같은 돈 쓰는 장면이 기존 재정 상태와 충돌하지 않는가?
- 회귀나 미래 지식이 원고 표면에 초능력, 예언, 정답을 아는 사람처럼 드러나지 않는가?
- 기존 사건의 물증, 영수증, 주차권, 통화 기록, 사진, 저장명 같은 단서가 갑자기 사라지거나 다른 의미로 바뀌지 않는가?

### 1-1. 새 설정 생성 금지

- 개요, 상태 파일, 연대기, 캐릭터 고정 정보에 없는 재수 경험, 학력 변동, 가족사, 과거 연애, 오래된 인연, 큰 구매 이력, 투자 성과가 원고에 새로 확정되지 않았는가?
- `재수하던 시절`, `예전에 사귀었던`, `어릴 때부터 알던`, `아버지가 늘 하던`, `전에 다녔던`, `이미 한 번 망했던 투자`처럼 새 과거사를 만들어내는 표현이 없는가?
- 숫자나 기록이 필요한 돈, 시세, 복권, 투자, 환율 정보가 상태 파일 없이 즉흥적으로 추가되지 않았는가?
- 새 사실처럼 보이는 문장이 필요할 때 확정 과거가 아니라 감정, 분위기, 추측, 감각으로 처리했는가?

### 2. 캐릭터 성격·욕망 유지

- 김용식은 빠르게 판단하지만 감정 문제에서는 회피와 자기합리화를 반복하는가?
- 김초연은 믿고 싶은 마음과 확인하려는 충동이 함께 보이는가?
- 정다은은 물증 없이 빈틈과 피로를 찌르는 방식으로 접근하는가?
- 한서윤은 조용히 거리 조절을 하며, 필요할 때만 불리는 위치에 분노하는가?
- 나카타 유즈키는 국내 관계를 모른 채 겨울 약속을 믿고 기다리는 축으로 유지되는가?
- 인물이 장면 편의를 위해 갑자기 너무 똑똑해지거나, 너무 순해지거나, 자기 욕망을 잃지 않는가?

### 3. 호칭·말투 일관성

- 용식과 초연, 용식과 다은처럼 친한 동갑 생활권은 기본 반말을 유지하는가?
- 용식이 한서윤에게는 기본적으로 `서윤 씨`와 존댓말을 쓰는가?
- 초연이 한서윤을 부를 때는 거리감 있는 `한서윤 씨`가 자연스럽게 유지되는가?
- 감정이 흔들린 순간의 호칭 변화가 있다면, 그 변화가 장면의 압력으로 설명되는가?
- 문자 형식은 `[발신자] 내용`, 실제 대사는 `[이름] "대사"` 형식을 지키는가?

### 4. 시간 흐름·원인 결과

- 화수 순서, 날짜, 요일, 계절감이 `states/current_state.json`과 `연대기.md`에 맞는가?
- 직전 화의 사건 결과가 다음 화 초반 행동이나 감정에 남아 있는가?
- 아직 일어나지 않은 사건을 인물이 이미 알고 있거나, 이전에 알 수 없었던 정보를 근거로 말하지 않는가?
- 같은 날 이동 거리, 수업 시간, 귀가 시간, 통화·문자 타이밍이 무리 없이 이어지는가?

### 5. 정보 접근·시점 검토

- 원고 작성 전에 이번 화 또는 묶음의 정보 접근 잠금표를 만들었는가?
- 잠금표는 `states/knowledge_state.json`의 최신 지식 상태를 기준으로 했는가?
- 잠금표에 등장 인물별 `아는 것/모르는 것`, `새로 들켜도 되는 정보`, `절대 들키면 안 되는 정보`, `대사에 나오면 안 되는 금지 단어/이름/지명`이 분리되어 있는가?
- 각 인물은 자신이 직접 봤거나 들었거나 충분히 추론 가능한 정보만 말하는가?
- 정다은처럼 촉이 좋은 인물도, 실제로 알 수 없는 세부 절차나 문구를 단정하지 않는가?
- 초연의 의심은 물증, 표정, 답장 지연, 동선 차이처럼 장면 안 단서에서 출발하는가?
- 서윤의 압박은 자신이 겪은 무시, 숨김, 선물, 호텔, 영수증 같은 기억에서 출발하는가?
- 대사와 장면 연출은 자율적으로 풍부해졌더라도, 그 과정에서 고정 사실이나 비공개 정보가 새로 생기지 않았는가?
- 각 대사 줄에서 화자가 말한 고유명사, 지명, 날짜, 숫자, 관계명, 과거 사건이 화자의 `아는 것`에 들어 있는가?
- 물증을 본 캐릭터가 표면 단서에서 곧바로 구체 정보나 관계 진실로 점프하지 않았는가?
- 잠금표의 금지 단어/이름/지명은 `rg` 또는 `python3 tools/check_knowledge_leaks.py [원고파일...] --knowledge-state states/knowledge_state.json`로 검사했는가?
- 문자 훔쳐보기, 폰 검사, 우연히 열린 문자함, 미리보기 노출로 새 핵심 정보를 얻는 장치를 반복하지 않았는가?
- 5화 묶음의 갈등을 만들기 위해 인물에게 억지로 새 정보를 알게 하지 않았는가?

### 6. 문체·장면 리듬

- 장면은 설명보다 시간, 장소, 행동, 문자, 대화 같은 현재 압력으로 시작하는가?
- 감정 설명이 3문단 이상 이어지면 행동, 물건, 동선, 침묵으로 바뀌었는가?
- 단문만 연속되어 감정이 얕아지지 않는가?
- 대사가 상담, 회의, 조건표처럼 굳어질 때 생활 소품이나 외부 압력이 섞이는가?
- 같은 소재가 20화 안에 중심 사건으로 반복되지 않는가?
- 화당 3,000자 이상이며, 3,000자 미만이면 장면을 보강했는가?

### 7. 관계 서스펜스·화말 훅

- 한 화가 이전보다 달라진 상태로 끝나는가?
- 화말에는 다음 화로 넘어갈 구체적 압력, 물건, 문자, 약속, 거짓말, 목격 가능성이 남는가?
- 관계가 봉합되더라도 완전한 해결보다 남은 비용과 다음 뇌관이 보이는가?
- 성인 장면이나 강한 스킨십은 노골 묘사 없이 합의, 죄책감, 흔적, 후폭풍으로 처리되는가?

## 발견 시 처리

- P1: 세계관, 날짜, 인물 정보 접근, 관계 상태, 고정 사실 잠금 항목이 정면 충돌하면 원고를 즉시 수정한 뒤 다시 검토한다. 특히 캐릭터가 알 수 없는 지명·이름·관계 진실을 대사로 말한 경우는 무조건 P1이다.
- P2: 호칭, 말투, 기록 요약, 물증 흐름이 어색하면 기록 업데이트 전 수정한다.
- P3: 문체 반복, 소재 반복, 화말 훅 약화는 가능하면 같은 작업 안에서 보강한다.
- 수정 후에는 수정한 줄 주변을 다시 읽고, 같은 문제가 다른 화나 기록 파일에 남아 있지 않은지 확인한다.

```text
원고 검토 훅 완료: 정보 접근 잠금표 작성, 대사별 정보 접근 검수, 세계관, 캐릭터성, 호칭, 시간 흐름, 문체, 화말 훅, 새 설정 생성 금지에서 중대한 충돌 없음.
```
