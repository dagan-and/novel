# 의심도 현황판

`00_core/에피소드_개요_양식.md` 3번 항목의 공통 척도(0~8단계)를 기준으로, 인물별 현재 의심 단계를 여기서 관리한다.

새 화를 쓰기 전에 반드시 이 파일에서 시작 단계를 확인하고, 화 완성 후 여기를 갱신한다. AI가 화 하나 안에서 임의로 여러 단계를 건너뛰지 못하게 하는 것이 목적이다.

## 공통 척도 (참고용)

```text
0단계: 전혀 의심하지 않음
1단계: 설명할 수 없는 이물감만 느낌
2단계: 사소한 단서를 기억하기 시작함
3단계: 확인 질문을 함
4단계: 특정 인물을 의심하기 시작함
5단계: 거짓말 가능성을 의식함
6단계: 직접 확인 행동에 들어감
7단계: 상당한 확신
8단계: 물증 또는 직접 목격
```

## 세연의 "카드" 보유 현황 (별도 관리)

- 보유 물건: 없음. 유진의 반지 한쪽은 106-107화에서 수진을 통해 용식 쪽으로 회수됐다.
- 세연이 아는 것: 은지 외에 최소 한 명(정체 불명)이 더 있다는 것. 은지의 얼굴을 84화에서 직접 확인했다. 103화에서 용식과 은지가 다시 가까워졌다는 것을 심증으로 확신했다(직접 목격은 아님). 107화에서 반지가 사라졌고, 전날 수진이 다녀갔다는 사실을 연결하기 시작했다.
- 세연이 모르는 것: 그 여자가 누구인지(유진이라는 이름, 학원 스터디 관계 등). 은지가 12월 27일 저녁 자리를 사진으로 확보했다는 것. 12월 31일 자신이 남긴 흔적이 이미 발견되고 해명까지 오갔다는 것. 1월 3일 은지·용식 사이의 정면 대면과 거리두기 선언, 1월 10일 조건부 화해의 구체적 내용.
- 진행 상태: 11월 18일(확보, 침묵) -> 11월 25일(말로 언급) -> 12월 1일(직접 캐묻기) -> 12월 6일(구체적 요구, 명시적 기한 확정) -> 12월 10일(기한 만료, 카페 방문) -> 12월 16일(은지와 직접 대면) -> 12월 29일(물리적 증거 요구, 흔적 실제로 남김) -> 1월 12일(반지 존재 재언급 + 은지 접촉 가능성을 처음으로 명시적 위협으로 꺼냄) -> 1월 16~17일(수진을 통해 반지 회수, 세연은 실종 인지) -> 1월 19일(수진 개입 상당히 의심) -> 1월 23일(은지 카페 재방문으로 애매한 흔들기 재개).
- 아직 결정되지 않은 것: 세연이 수진을 직접 추궁할지, 용식에게 다시 만남을 요구할지, 은지를 계속 흔들되 어느 선까지 갈지.

## 민정의 "선택" 상태 (별도 관리)

- 아는 것: 용식과 유진이 실제로 얽혀 있다는 것(8단계 확정). 관계의 정확한 성격(섹파 여부)까지는 모른다.
- 선택: 89화에서 확정된 확신을 폭로가 아니라 접근의 계기로 쓰기로 결심(90화). 91화에서 용식에게 직접 안다고 밝히되 침묵을 약속했고, 92화에서 실제 관계로 진전됐다. 95화, 98화에서 유진의 상담과 근접 위험에 대응했다. 101화에서 처음으로 "이 관계를 계속 이어가는 게 맞나" 하는 내적 회의를 느끼기 시작했다 -- 단순한 흥미·승부욕을 넘어서는 감정으로 번지고 있다는 것을 스스로 자각했다.
- 아직 결정되지 않은 것: 학원 축 내부(유진과의 물리적 근접)에서 발생하는 위험을 계속 어떻게 관리할지, 111화에서 들은 반지 이야기를 어떻게 보관할지, 스스로 자각한 감정 변화를 어떻게 할지. 114화 이후 개요에서 필요 시 정한다.

## 다음 화(114화)에서 허용되는 범위

- 김은지: 8단계(숫자) 유지. 세연의 카페 재방문과 용식의 선제 전화를 가지고 조용히 시험할 수 있다.
- 김민정: 8단계 유지. 유진의 반지 이야기를 기억하고 있으나 실제 행방은 모른다.
- 박세연: 물증은 없지만 은지 흔들기를 재개했다. 직접 폭로보다 애매한 흔적 운영이 어울린다.
- 최유진: 반지 분실과 관계 정의 미해결 유지. 다음에 둘 중 하나를 더 구체적으로 물을 수 있다.
- 이수진: 공범 위치 유지. 세연에게 의심받는다는 것을 알고 있다.
- 한나영: 호칭/반말 확정. 다음 만남에서 더 깊어질 수 있지만, 성인씬 전에는 피임약 여부 등 고정 정보가 먼저 필요하다.
