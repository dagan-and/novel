# 불사자의 연대기 — 게임 이어하기

새 Claude 세션에서 아래 문장을 입력하세요:

> "불사자 게임 이어서. novel-repo/immortal-game/ 의 game-state.json 과 events.json 읽고 현재 상황 요약 후 다음 턴 선택지 보여줘."

---

## 파일 구조

| 파일 | 내용 |
|------|------|
| `game-state.json` | 현재 연도·신분·세력·관계·기술·위협 현황 |
| `events.json` | 전체 사건 연대기 (서사·결과) |
| `tech-tree.json` | 기술 도입 현황 및 보급률 |
| `generate.py` | chronicle.html 생성 스크립트 (`python generate.py`) |
| `RESUME.md` | 이 파일 |

---

## 턴 구조 (Turn Format)

매 턴 아래 형식으로 선택지를 제공한다.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📅 AD XX년  |  인구 X명  |  군사 X명
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【주행동】 (하나 선택 — 서사+결과)
1. ...  [카테고리]
2. ...  [카테고리]
3. ...  [카테고리]

【부행동】 (하나 선택 — 한 줄 결과)
4. ...  [카테고리]
5. ...  [카테고리]

【치트키 — 현대 지식 전용】 (선택 시 추가 효과)
6. ★ ...  [카테고리]
7. ★ ...  [카테고리]

0. 직접 입력 (어떤 현대 기술이든 가능)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 선택 방법

- **주행동 + 부행동**: `2+4`
- **주행동 + 치트키**: `1+6`
- **주행동 + 부행동 + 치트키**: `3+5+7`
- **직접 입력**: `0` 또는 원하는 내용을 직접 타이핑
- **같은 카테고리 중복 불가** (주행동은 반드시 1개)

### 번호 체계

| 번호 | 종류 | 결과 방식 |
|------|------|-----------|
| 1~3 | 주행동 | 서사 + 결과 (풀 내러티브) |
| 4~5 | 부행동 | 결과 한 줄 |
| 6~7 | 치트키 ★ | 추가 효과 (현대 지식 전용) |
| 0   | 직접 입력 | 유저가 기술·전략 직접 제안 |

---

## 자동저장 규칙

- 매 턴 결과가 확정되면 `game-state.json`, `events.json`, `tech-tree.json`은 즉시 자동 저장한다.
- 자동저장은 같은 응답 흐름 안에서 처리하며, 다음 턴 선택지 제시는 끊지 않는다.
- `chronicle.html` 재생성과 Git 반영은 자동저장에 포함하지 않는다.
- HTML/Git 반영이 필요할 때만 유저가 따로 요청한다.

## 게임 기본 설정

- **캐릭터**: 금휘 (金煇) — 현대 지식을 가진 불로불사의 방랑자
- **시작**: AD 1년, 영산강 하구 소촌락
- **목표**: 마한 통일 → 한반도 통일
- **턴 단위**: 평시 1년/턴 | 전시 1개월/턴
- **사망 연기**: 50~60세 즈음 "병사"로 신분 세탁 후 재등장

---

## 수동 발행 시

유저가 HTML 또는 Git 반영을 요청하면:
1. `game-state.json` 업데이트
2. `events.json` 이번 턴 사건 추가
3. `tech-tree.json` 기술 상태 변경 반영
4. `chronicle.html`은 직접 수정하지 않고, 반드시 `generate.py` 실행으로 재생성
