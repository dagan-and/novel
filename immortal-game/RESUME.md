## 턴 구조 (Turn Format)

게임은 `혼합형 워게임`으로 진행한다.

- 기본 진행은 항상 `작전 턴`
- 결정적 충돌이 벌어질 때만 `전술 턴`으로 확대
- 결과는 반드시 `전과표 우선, 서사 후행`

기본 흐름:

1. 전황 보고
2. 작전 명령 선택
3. 적 반응 판정
4. 필요 시 전술 턴 진입
5. 결과 집계
6. 상태 파일 반영
7. 다음 턴 제시

### 작전 턴 입력 방식

평소 턴은 전선 전체를 다루는 `작전 턴`으로 제시한다.

- `주공축 1개`
- `보조작전 1개`
- `예비대 운용 1개`
- `태세 1개`

입력 예시: `1+5+8+11`

작전 턴 화면은 아래 순서를 따른다.

1. 전선 개요
2. 아군 전력
3. 보급 상태
4. 적 정세
5. 이번 턴 명령

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AD 52년 2분기  |  한강 전역 작전 턴
목표: 교두보 유지 및 본토 길목 확장
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[전선 개요]
- 한강 하구 교두보: 안정
- 서안 포대선: 긴장
- 내륙 길목: 돌파 가능
- 남쪽 보급로: 과부하 조짐

[아군 전력]
- 보병: 380 전투 가능 / 90 주둔 / 40 회복 중
- 쇠뇌대: 160 전투 가능
- 기병: 70 전투 가능 / 18 전달·정찰
- 포대병: 88 전투 가능
- 예비대: 54 대기

[보급]
- 군량: 6
- 마초: 4
- 포대 부품: 5
- 수송 여력: 3

[적 정세]
- 목지국 본대: 서쪽 집결 추정
- 적 기병: 북쪽 우회 가능성 높음
- 하구 민심: 불안정
- 적 증원: 1턴 내 도착 가능성 있음

[이번 턴 명령]
주공축 (1개)
1. 내륙 길목 추가 점령
2. 서안 적 집결지 선제 타격
3. 교두보 방어선 증설

보조작전 (1개)
4. 포대 전진 배치
5. 기병 우회 정찰
6. 점령 촌락 회유·숙정

예비대 운용 (1개)
7. 중앙 대기
8. 주공축 후속 투입
9. 교두보 고정 방어

태세 (1개)
10. 신중
11. 표준
12. 강행
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
입력 예시: 1+5+8+11
```

### 전술 턴 입력 방식

아래 상황이 생기면 특정 전장을 확대하는 `전술 턴`을 연다.

- 주공축에서 적 주력이 실제로 맞붙음
- 나루, 포구, 성채, 보급거점 같은 중요 지점 점유가 걸림
- 플레이어가 강행, 야간 기습, 우회 돌파, 질서 철수 같은 고위험 명령을 고름
- 적이 예비대를 꺼내 반격하거나 예상 밖 증원이 도착함
- 손실이 커져 전선 붕괴 여부를 직접 판단해야 함

전술 턴에서는 아래 세 가지를 고른다.

- `주행동 1개`
- `지원행동 1개`
- `리스크 규칙 1개`

입력 예시: `2+6+12`

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AD 52년 2분기  |  한강 서안 전술 턴
전투 목표: 내륙 길목 확보 후 적 반격 차단
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[전장]
- 좌익: 숲지대, 우회 가능
- 중앙: 좁은 흙길, 정면 충돌
- 우익: 얕은 개울, 이동 둔화
- 후방: 포대선, 아직 안전
- 퇴로: 교두보 방면 유지

[즉응 전력]
- 중앙 보병: 140
- 쇠뇌대: 90
- 기병: 48
- 포대: 6기
- 예비대: 36

[승리 조건]
- 중앙 길목 점령
- 적 반격 1회 저지
- 포대 4기 이상 유지

[전술 명령]
주행동 (1개)
1. 중앙 고정
2. 좌익 우회
3. 포대 집중사격
4. 우익 견제 후 중앙 돌파
5. 질서 철수

지원행동 (1개)
6. 쇠뇌 엄호
7. 공병 장애물 설치
8. 기병 추격 대기
9. 예비대 투입 준비

리스크 규칙 (1개)
10. 손실 최소
11. 균형
12. 돌파 우선
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
입력 예시: 2+6+12
```

### 결과 보고 원칙

결과는 다음 순서를 우선한다.

1. 전선 변화
2. 손실
3. 보급 소모
4. 확보 지형
5. 사기와 민심
6. 장기 영향

```text
[전투 결과]
- 전선 변화: 내륙 길목 확보, 교두보 안정도 상승, 적 반격 1턴 지연
- 아군 손실: 보병 28, 기병 6
- 적 손실 추정: 보병 60+, 기병 12
- 보급 소모: 군량 1, 마초 1
- 확보 지형: 길목 확보 성공
- 포대 상태: 1기 손상, 5기 유지

[전장 기록]
짧은 서사 3~5문장
```

## 자동저장 규칙

- 매 턴 결과가 확정되면 `game-state.json`, `events.json`, `tech-tree.json`은 즉시 자동 저장한다.
- 자동저장은 같은 응답 흐름 안에서 처리하며, 다음 턴 선택지 제시는 끊지 않는다.
- `chronicle.html` 재생성과 Git 반영은 자동저장에 포함하지 않는다.
- HTML/Git 반영이 필요할 때만 유저가 따로 요청한다.

## 게임 기본 설정

- **캐릭터**: 금휘 (金煇) — 현대 지식을 가진 불로불사의 방랑자
- **시작**: AD 1년, 영산강 하구 소촌락
- **목표**: 마한 통일 → 한반도 통일
- **턴 단위**: 작전 리듬 기준으로 평시 `반년~1년`, 공세 준비기 `1분기`, 총력전은 `1개월까지 축소 가능`
- **사망 연기**: 50~60세 즈음 "병사"로 신분 세탁 후 재등장

---

## 수동 발행 시

유저가 HTML 또는 Git 반영을 요청하면:
1. `game-state.json` 업데이트
2. `events.json` 이번 턴 사건 추가
3. `tech-tree.json` 기술 상태 변경 반영
4. `chronicle.html`은 직접 수정하지 않고, 반드시 `generate.py` 실행으로 재생성
