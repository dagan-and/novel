# 불사자의 연대기 — 게임 이어하기

새 Claude 세션에서 아래 문장을 입력하세요:

> "불사자 게임 이어서. novel-repo/immortal-game/ 의 game-state.json 과 events.json 읽고 현재 상황 요약 후, 항상 1·2·3 세 개 선택지로만 다음 턴을 진행해줘."

짧게 아래처럼만 말해도 같은 의미로 처리한다:

> "게임 시작해줘."

이 저장소에서 `게임 시작해줘`는 아래 요청의 축약형으로 간주한다.

> `game-state.json`과 `events.json`을 읽고 현재 상황을 요약한 뒤, 항상 `1 / 2 / 3` 세 개 선택지로만 다음 턴을 진행한다.

## 현재 진행 규칙

이 문서의 규칙이 이전 설계 문서보다 우선한다.

- 새 세션에서 유저가 `게임 시작해줘`라고만 말해도, 위의 축약 규칙을 자동 적용한다
- 앞으로 선택지는 항상 `1 / 2 / 3`만 제시한다
- 알파벳 선택지(`A/B/C`)와 다중 조합 입력(`1+5+8+11`)은 더 이상 쓰지 않는다
- 기본 흐름은 `짧은 턴 + 강한 결과`다
- 결과는 `압살 포인트`를 반드시 포함한다

## 턴 구조 (Turn Format)

게임은 `불사의 왕 정복 캠페인`으로 진행한다.

- 기본 진행은 항상 `간략 턴`
- 필요할 때만 `결전 턴`으로 확대
- 결과는 반드시 `전과표 우선, 압살 포인트 포함`

기본 흐름:

1. 전황 보고
2. 세 가지 선택지 제시
3. 적 반응 판정
4. 필요 시 결전 턴 진입
5. 결과 집계
6. 상태 파일 반영
7. 다음 턴 제시

### 기본 턴 입력 방식

평소 턴은 아래 형식으로 제시한다.

- `1. 안전하거나 정석적인 선택`
- `2. 공격적이거나 확장 중심 선택`
- `3. 현대 지식 또는 불사의 왕의 전쟁 감각을 활용한 선택`

입력 예시: `2`

기본 턴 화면은 아래 순서를 따른다.

1. 현재 상황 한줄 요약
2. 이번 장의 목표
3. 선택지 3개
4. 결과

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AD 52년 3분기  |  불사의 왕 공개
상황: 목지국은 다시 병력을 모으고 있지만, 영산은 먼저 전쟁의 속도를 쥐었다.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[이번 장의 목표]
- 목지국의 다음 반격을 무너뜨리고 마한 패권전의 주도권을 확정한다.

[선택지]
1. 보루와 보급선을 다지며 적 반격을 흡수한다.
2. 적 집결지를 먼저 쳐서 전선을 더 넓힌다.
3. 유인, 기만, 규격화된 화력으로 적 주력을 섬멸한다.

[입력]
2
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 결전 턴 입력 방식

아래 상황이 생기면 특정 전장을 확대하는 `결전 턴`을 연다.

- 적 주력이 실제로 맞붙음
- 핵심 거점이나 왕의 결전 선언이 걸림
- 승패가 한 번에 갈릴 수 있는 순간임

결전 턴에서도 선택지는 항상 세 개다.

- `1. 정면 고정 또는 방어`
- `2. 우회 또는 강공`
- `3. 왕의 방식으로 전장 규칙 자체를 바꾸는 선택`

입력 예시: `3`

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AD 52년 3분기  |  목지국 주력 결전
전투 목표: 적 주력군 섬멸 후 반격 의지 붕괴
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[전장]
- 좌익: 숲지대, 우회 가능
- 중앙: 좁은 흙길, 정면 충돌
- 우익: 얕은 개울, 이동 둔화
- 후방: 포대선, 아직 안전
- 퇴로: 교두보 방면 유지

[선택지]
1. 중앙 고정으로 적 선봉을 닳게 만든다.
2. 좌익 우회로 적 포대와 지휘선을 찢는다.
3. 포대, 쇠뇌, 기병 차단선을 겹쳐 적 주력 자체를 포위 섬멸한다.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
입력 예시: 3
```

### 결과 보고 원칙

결과는 다음 순서를 우선한다.

1. 전선 변화
2. 손실
3. 보급 소모
4. 확보 지형
5. 압살 포인트
6. 장기 영향

```text
[전투 결과]
- 전선 변화: 내륙 길목 확보, 교두보 안정도 상승, 적 반격 1턴 지연
- 아군 손실: 보병 28, 기병 6
- 적 손실 추정: 보병 60+, 기병 12
- 보급 소모: 군량 1, 마초 1
- 확보 지형: 길목 확보 성공
- 압살 포인트: 적은 숫자를 모았지만, 영산은 집결 전에 사거리와 신호로 적 전열을 무너뜨렸다.

[전장 기록]
짧은 서사 3~5문장
```

## 자동저장 규칙

- 매 턴 결과가 확정되면 `game-state.json`, `events.json`, `tech-tree.json`은 즉시 자동 저장한다.
- 자동저장은 같은 응답 흐름 안에서 처리하며, 다음 턴 선택지 제시는 끊지 않는다.
- `chronicle.html` 재생성과 Git 반영은 자동저장에 포함하지 않는다.
- HTML/Git 반영이 필요할 때만 유저가 따로 요청한다.

## 게임 기본 설정

- **캐릭터**: 금휘 (金煇) — 현대 지식을 가진 불사의 왕
- **출발 해석**: 지금까지의 성장기는 힘을 숨기고 기반을 정비한 준비기
- **현재 목표**: 목지국 붕괴 → 마한 패권 확정 → 한반도 통일 → 세계 정복
- **턴 단위**: 작전 리듬 기준으로 평시 `반년~1년`, 공세 준비기 `1분기`, 총력전은 `1개월까지 축소 가능`
- **핵심 재미**: 불사의 왕이 전쟁의 규칙 자체를 바꿔 적을 압살하는 장면

---

## 수동 발행 시

유저가 HTML 또는 Git 반영을 요청하면:
1. `game-state.json` 업데이트
2. `events.json` 이번 턴 사건 추가
3. `tech-tree.json` 기술 상태 변경 반영
4. `chronicle.html`은 직접 수정하지 않고, 반드시 `generate.py` 실행으로 재생성
