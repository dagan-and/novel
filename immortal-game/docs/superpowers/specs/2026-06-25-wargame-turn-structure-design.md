# 워게임형 턴 구조 설계

## 목적

현재 `immortal-game`은 연대기와 국가 운영 서사 비중이 커서, 플레이 감각이 `워게임`보다는 `서사 진행 + 수치 반영`에 가깝다.

이번 설계의 목적은 진행 방식을 다음처럼 바꾸는 것이다.

- 평시에는 전역 단위의 작전 판단을 하는 `작전 턴`
- 결정적 충돌이 벌어질 때만 확대되는 `전술 턴`
- 결과는 긴 서사보다 `전선 변화`, `손실`, `보급`, `지형 확보`를 우선 표시
- 서사는 분위기 보조용으로 짧게 유지

사용자가 원하는 감각은 `혼합형 워게임`이다. 따라서 모든 턴을 세부 전술로 무겁게 만들지 않고, 평소엔 전역 지휘를 하다가 중요한 전투만 확대한다.

## 목표 플레이 감각

- 플레이어는 국가 운영자보다 `전역 지휘관`에 가깝게 행동한다.
- 매 턴 선택은 `무엇을 할까`보다 `어디에 힘을 싣고 무엇을 포기할까`에 초점을 둔다.
- 승리는 단순한 영토 증가가 아니라 `교두보 유지`, `보급선 유지`, `적 증원 지연`, `손실 관리`로 판단한다.
- 실패도 단순 실패가 아니라 `전선 얇아짐`, `예비대 고갈`, `민심 이반`, `포대 노출` 같은 후속 문제를 남긴다.

## 핵심 구조

게임은 항상 `작전 턴`을 기본으로 진행한다.

- `작전 턴`: 전선 전체를 다루는 상위 판단 턴
- `전술 턴`: 특정 전장만 확대해서 다루는 결전 턴

기본 흐름은 아래와 같다.

1. 전황 보고
2. 작전 명령 선택
3. 적 반응 판정
4. 필요 시 전술 턴 진입
5. 결과 집계
6. 상태 파일 반영
7. 다음 턴 제시

## 작전 턴 설계

### 역할

작전 턴은 전역 지도 위에서 이루어지는 상위 지휘 단계다.

이 턴에서 플레이어는 다음을 판단한다.

- 주공축을 어디에 둘지
- 보조작전을 어디에 붙일지
- 예비대를 어디에 묶어둘지
- 얼마나 공격적으로 밀어붙일지

### 시간 단위

- 평시: 반년~1년
- 공세 준비기: 1분기
- 총력전: 1개월 단위까지 축소 가능

정확한 월수보다 중요한 것은 `작전 리듬`이다. 전황이 급하면 턴 단위를 짧게 잡고, 소강 상태면 길게 잡는다.

### 표시 정보

작전 턴 화면은 아래 순서로 제시한다.

1. 전선 개요
2. 아군 전력
3. 보급 상태
4. 적 정세
5. 이번 턴 명령

### 전선 개요

전장을 3~5개 구역으로 나눈다.

예시:

- 한강 하구 교두보
- 서안 포대선
- 내륙 길목
- 남쪽 보급로
- 북쪽 우회축

각 구역은 짧은 상태값으로 표현한다.

- 안정
- 긴장
- 돌파 가능
- 붕괴 위험
- 보급 취약
- 적 집결 중

### 아군 전력

총병력만 보여주지 않고 실제 용도를 나눈다.

- 보병
- 쇠뇌대
- 기병
- 포대병
- 공병
- 예비대

표기 원칙:

- `전투 가능`
- `주둔 중`
- `회복 중`
- `후방 대기`

이렇게 나누면 플레이어가 “병력이 몇 명인가”보다 “지금 무엇을 바로 쓸 수 있는가”를 보게 된다.

### 보급 상태

보급은 세밀한 장부 대신 판단용 단계 수치로 보여준다.

대상:

- 군량
- 마초
- 포대 부품
- 수송 여력

표기:

- `1~7 단계`
- 또는 `충분 / 긴장 / 위험`

둘 중 하나만 일관되게 쓴다. 혼용하지 않는다.

### 적 정세

적 정세는 불확실성을 포함해야 한다.

표기 예:

- 목지국 본대: 서쪽 집결 추정
- 적 기병: 북쪽 우회 가능성 높음
- 적 증원: 1턴 내 도착 가능성
- 하구 민심: 불안정

정보 신뢰도는 필요할 때만 붙인다.

- 확실
- 추정
- 불명

### 작전 턴 선택 구조

플레이어는 매 턴 아래 네 가지를 고른다.

1. 주공축 1개
2. 보조작전 1개
3. 예비대 운용 1개
4. 태세 1개

예시:

- 주공축: 내륙 길목 추가 점령 / 적 집결지 선제 타격 / 교두보 방어선 증설
- 보조작전: 포대 전진 / 기병 우회 정찰 / 점령 촌락 회유·숙정
- 예비대 운용: 중앙 대기 / 주공축 후속 투입 / 교두보 고정 방어
- 태세: 신중 / 표준 / 강행

## 전술 턴 설계

### 역할

전술 턴은 특정 충돌 지점을 확대해 직접 지휘하는 단계다.

작전 턴이 전역 판단이라면, 전술 턴은 `이 전투에서 무엇을 지키고 무엇을 버릴지`를 결정하는 단계다.

### 사용 원칙

전술 턴은 매번 열지 않는다.

- 작은 소탕전
- 무저항 진주
- 후방 정리
- 이미 승패가 굳은 추격전

이런 경우는 작전 턴 결과로 요약한다.

전술 턴은 중요한 충돌에서만 열린다.

### 전장 정보

전술 턴은 전장을 4~6구역으로 나눈다.

예시:

- 좌익
- 중앙
- 우익
- 후방
- 도하지점
- 포대선

각 구역은 짧은 상태와 지형 정보를 함께 보여준다.

- 숲지대, 우회 가능
- 좁은 흙길, 정면 충돌
- 얕은 개울, 이동 둔화
- 후방 포대선, 아직 안전

### 즉응 전력

전술 턴은 총전력이 아니라 `이번 전장에 반응 가능한 전력`을 보여준다.

- 중앙 보병
- 쇠뇌대
- 기병
- 포대
- 예비대

필요하면 `이미 지친 부대`, `회복 중`, `탄약 부족` 같은 상태를 붙일 수 있다.

### 승리 조건

전술 턴에는 반드시 명시적 목표가 있어야 한다.

예시:

- 중앙 길목 점령
- 적 반격 1회 저지
- 포대 4기 이상 유지
- 질서 있는 철수 성공

목표를 명시하면 모든 전투가 전멸전으로 흐르지 않는다.

### 전술 턴 선택 구조

플레이어는 아래 세 가지를 고른다.

1. 주행동 1개
2. 지원행동 1개
3. 리스크 규칙 1개

예시:

- 주행동: 중앙 고정 / 좌익 우회 / 포대 집중사격 / 우익 견제 후 중앙 돌파 / 질서 철수
- 지원행동: 쇠뇌 엄호 / 공병 장애물 설치 / 기병 추격 대기 / 예비대 투입 준비
- 리스크 규칙: 손실 최소 / 균형 / 돌파 우선

## 작전 턴과 전술 턴의 전환 규칙

기본은 항상 `작전 턴`이다.

아래 조건이 생기면 `전술 턴`으로 확대한다.

- 주공축에서 적 주력이 실제로 맞붙음
- 나루, 포구, 성채, 보급거점 같은 중요 지점 점유가 걸림
- 플레이어가 강행, 야간 기습, 우회 돌파, 질서 철수 같은 고위험 명령을 고름
- 적이 예비대를 꺼내 반격하거나 예상 밖 증원이 도착함
- 손실이 커져 전선 붕괴 여부를 직접 판단해야 함

전술 턴 없이 끝나는 경우:

- 약한 적을 밀어내는 국지전
- 후방 장악
- 행정 정리
- 추격 정리전

작전 턴의 선택은 전술 턴의 초기 조건으로 이어진다.

예:

- 주공축이 내륙 길목 차단이면 전장은 좁은 길목이 된다.
- 포대 전진을 고르면 전술 턴에서 포대는 전방 배치되지만 노출 위험이 커진다.
- 예비대 중앙 대기를 고르면 즉시 반응은 늦지만 재난 수습 여지는 커진다.
- 태세 강행은 초반 기세를 높이지만 손실 위험을 키운다.

전술 턴은 보통 한 번의 충돌로 끝내고 다시 작전 턴으로 복귀한다.

예외:

- 상륙 첫 3일
- 결정적 포위전
- 연속 반격전

이런 경우만 2~3회 연속 전술 턴을 허용한다.

### 결과 출력 포맷

결과는 항상 `전과표 우선, 서사 후행`으로 제시한다.

```text
[전투 결과]
- 길목 확보: 성공
- 아군 손실: 보병 28, 기병 6
- 적 손실 추정: 보병 60+, 기병 12
- 포대 상태: 1기 손상, 5기 유지
- 보급 소모: 군량 1, 마초 1
- 전선 상태: 교두보 안정도 상승, 적 반격 1턴 지연

[전장 기록]
짧은 서사 3~5문장
```

원칙:

- 결과는 다음 턴 판단에 바로 쓰일 수 있어야 한다.
- 서사는 분위기를 살리되 수치와 상태를 덮지 않는다.

## 상태 반영 원칙

기존 상태 파일은 유지하되, 플레이 감각에 맞는 해석을 우선한다.

반영 우선순위:

1. 전선 변화
2. 손실
3. 보급 소모
4. 확보 지형
5. 사기와 민심
6. 장기 영향

상태 파일에 바로 숫자로 넣기 어려운 요소는 설명형 상태로 남긴다.

예:

- 교두보 안정도 상승
- 적 반격 1턴 지연
- 민심 불안정
- 예비대 피로 누적

## 실패와 대가 설계

워게임 감각을 살리려면 매 선택이 항상 대가를 남겨야 한다.

예시:

- 강행: 돌파 확률 상승, 손실 증가
- 포대 전진: 화력 상승, 노출 위험 증가
- 예비대 즉시 투입: 현재 전선 안정, 다음 반격 대응력 감소
- 회유·숙정: 후방 안정화 가능, 점령지 민심 악화 위험

즉, 좋은 선택이 아니라 `상황에 맞는 선택`만 존재하도록 설계한다.

## 범위 제한

이번 설계는 `플레이 진행 형식`만 정의한다.

포함:

- 작전 턴 구조
- 전술 턴 구조
- 전환 규칙
- 출력 포맷

비포함:

- 지도 엔진
- 자동 전투 계산식 세부 수학 모델
- UI 렌더링 변경
- 파일 스키마 전면 개편

## 결정 사항 요약

- 플레이 방향은 `혼합형 워게임`

- 결전 상황만 `전술 턴`으로 확대
- 결과는 `전과표 우선`
- 서사는 짧고 강하게 보조
- 선택지는 `전선 운용`, `예비대`, `보급`, `위험 감수` 중심으로 구성
