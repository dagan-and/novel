## 핵심 연쇄 효과

| 트리거 | 결과 |
|---|---|
| T-AGR 윤작 + T-ENG 수로 | → 식량 잉여 + 민심 → 인구 유입 기반 |
| T-COM 봉화망 + T-MIL 기마 | → 말갈 억지 완성. 전투 없이 철수 (EP038) |
| T-ENG 철광맥 + 수차 풀무 + 제련로 1+2호 | → 철 약 5배 생산 → 기마 장비·쇠뇌 자급 |
| T-MIL 쇠뇌 + 나율 교범 | → 창병+쇠뇌 합동 훈련 완성. 숙련 기간 단축 |
| T-ENG 도정 수차 + 도량형 | → 인력 절감 + 세수 23% 향상 |
| T-ENG 교각 다리 + 군용 도로망 | → 전 거점 기마 기동 최적화 |
| T-ENG 염전 + T-COM 제지 | → 소금 자급 완성 + 행정 문서 비용 절감 → 낙랑 의존도 제로 |
| T-MIL 연노차 + 궁수 선제 사격 | → 성벽 위 제압 + 연노차 전진 → 야전 거점 30분 이내 돌파 |
| T-MIL 투석차 + 연노차 합동 | → 성벽 안쪽 타격 → 수비 붕괴 → 창병 돌격 연계 |
| T-MIL 투석차 불덩이 + 목조 성벽 | → 목성 1발 점화 가능 |
