# 백제 전황 연대기 HTML 설계

## 목표

짧은 턴 데이터만 추가하면, 사용자는 한글 전황 브리핑 화면에서 이전 턴과 다음 턴을 넘겨보며 읽을 수 있어야 한다.

## 요구사항

- 데이터는 길어질수록 토큰 사용이 적게 드는 구조여야 한다.
- 화면은 한글 중심이어야 한다.
- 출력 형식은 드라마틱한 전황 브리핑 톤이어야 한다.
- 한 페이지 안에서 턴별로 좌우 넘김이 가능해야 한다.
- 이후 11턴, 20턴, 100턴으로 쉽게 확장 가능해야 한다.

## 접근 방식

`turns.json`에 턴별 핵심 데이터만 짧게 저장하고, `generate.py`가 이를 읽어 단일 HTML 파일을 생성한다. HTML은 각 턴을 카드형 브리핑 슬라이드로 렌더링하고, 자바스크립트로 이전/다음 턴 이동을 처리한다.

## 데이터 구조

각 턴은 아래 필드만 가진다.

- `turn`: 턴 번호
- `year`: 기준 연도 문자열
- `codename`: 작전명
- `headline`: 가장 큰 한 줄 요약
- `summary`: 도입 브리핑 문장
- `actions`: 주요 조치 목록
- `outcome`: 결과 문장
- `state_changes`: 국가 변화 목록
- `risks`: 다음 턴 위험 목록

## 화면 구조

- 상단 헤더: 제목, 현재 선택 턴, 작전명
- 중앙 본문: 헤드라인, 전황 브리핑, 주요 조치, 결과, 국가 변화, 다음 위험
- 하단 또는 측면 컨트롤: 이전 턴, 다음 턴

## 제약

- 정적 HTML만으로 열람 가능해야 한다.
- 외부 라이브러리 없이 동작해야 한다.
- 기존 마크다운 로그는 보존하되, HTML 생성의 정본은 JSON 데이터로 둔다.
