# Rules

## Campaign Style

This is an observer-friendly strategy simulation. Each turn should generate events that are militarily plausible but also narratively interesting.

## Core Factors

Each turn should consider:

- military strength
- supply and logistics
- agricultural output
- elite loyalty
- public stability
- naval reach
- diplomatic pressure
- technology adoption

## Turn Flow

1. Strategic decision phase
2. Domestic reform and resistance phase
3. Diplomacy and espionage phase
4. Campaign and battle phase
5. Consequence phase
6. Chronicle output

## Resolution Principles

- A stronger state still suffers friction from distance and administration.
- Early reforms have delayed payoff but compound over time.
- Conquest without integration raises revolt risk.
- The transcendent improves state capacity, but cannot skip material limits.
- Unexpected events are encouraged if they emerge naturally from the current situation.

## Output Format

Each turn log should include:

1. strategic posture
2. major actions
3. battlefield or political outcomes
4. state changes
5. risks entering the next turn
