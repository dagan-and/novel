신하

기본 정보

| 항목 | 내용 |

|---|---|

| 이름 | 봉수 |

| 성별 | 남 |

| 나이 | 30대 초반 추정 |

| 출신 | 위례성 인근 장인 가문 |

| 신분 | 기술단 — 쇠뇌·연노차 계열 담당 |

이력

  • EP087 이전: 소아 장터 분업 체계의 물자 수급 보좌관 (봉수·갑돌·춘이 공식 등록)
  • EP097: 쇠뇌 격발 각도를 독자적으로 개선 → 시안 "봉수 이름으로 교범에 넣어라" — 장터 보좌에서 기술 쪽으로 이동하는 계기
  • EP110: 쇠뇌 각도 개선 교범 정식 등록. 기술단 쇠뇌 계열 담당으로 사실상 전환
  • EP142~: 연노차 5호 경량형 자율 설계 착수. 시안에게 직접 원리를 물으러 찾아옴
  • EP145: 5호 시제 완성. 경량화 과정에서 조준 재조정 속도 향상을 스스로 발견 → 가르친 것 이상을 해낸 첫 사례

성격

  • 말수가 적고 손이 먼저 움직이는 사람
  • 모르는 것은 묻는다 — 체면을 차리지 않음
  • 한 번 이해하면 응용까지 스스로 한다

시안과의 관계

  • 장터 보좌관 시절에는 소아를 통해 간접 접촉
  • EP097 쇠뇌 개선 이후 시안에게 이름이 직접 불림 — 그것이 전환점
  • EP142 처음으로 시안을 직접 찾아와 원리를 물음 — 기술단 장인으로 완전 전환
  • 시안에 대한 태도: 존경보다는 신뢰. 원리를 주는 사람으로 인식

현재 상태 (EP150)

  • EP147 연노차 5호 2차 시제 — 바퀴 축 기름 달리 바르는 방법 독자 발견 → 조준 재조정 속도 추가 향상
  • EP148 연노차 기마 사각지대 대응 나율 교범 등재 기여 (봉수 발견 → 나율 전술 추가)
  • EP149 연노차 3호 설계 완성 — 조준 반경 좌우 30도→45도 확장. 시제는 겨울 전 예정. 목재 이미 1년 전부터 준비.
  • 연노차 계열 기술의 실질적 계승자. 시안이 원리를 주면 봉수가 그것을 넘어서는 사람.
