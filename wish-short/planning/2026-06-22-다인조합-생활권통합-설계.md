## 9. 다음 에피소드 조합 선택 가이드

### 9.1 점수 해석 (Interpretation)

가중치 점수는 **다음 등장 필요도**를 나타냅니다. 점수가 낮을수록 미등장이거나 최근 등장하지 않았고, 성인씬과 다인 조합 참여가 적다는 뜻입니다.

```
40점대:
- 특징: 미등장 또는 매우 오래 미등장
- 회사: 임소율, 배수인
- 동네: 이하은, 한서진, 박소연, 이주은
- 권고: 다음 회차 즉시 투입 추천

45~55점대:
- 특징: 최근 10회차 미등장, 성인씬 5~6회, 다인 참여 0~1회
- 회사: 이유주(45점)
- 동네: 박다정(49점), 유하린(50점), 박미현(52점), 채수빈(53점), 이채영(54점)
- 권고: 2~3회차 내 투입 권장

60~70점대:
- 특징: 중간 우선순위, 최근 등장 또는 성인씬 중간~많음
- 회사: 이주희(80점은 예외, 고려 보류)
- 동네: 김초연(62점), 최윤서(66점), 서나윤(70점)
- 권고: 특별한 스토리 이유 있을 때만 선택

70점 이상:
- 특징: 최근 등장 또는 성인씬 많음, 다인 참여 여러 번
- 동네: 노은화(72점)
- 권고: 높은 등장 필요도 낮음. 특별한 창작 의도가 있을 때만 배치
```

#### Rule 2: 점수대별 선택 전략
```
회사 조합:
- 40~45점 범위 내 선택 강력 권장 (신규 및 미등장 히로인)
- 60점 이상은 필요할 때만 (최근 등장 히로인)

동네 조합:
- 40~55점 범위 내 선택 권장 (신규 및 최근 등장 필요 히로인)
- 60~70점: 중간 우선순위, 적절히 배분
- 70점 이상: 특별한 이유 있을 때만
```

#### Rule 3: 균형 유지
```
기본 배치: 매 2회차마다 회사 조합 1개 + 동네 조합 1개
예시:
  ep.061: 회사 조합 + 동네 조합
  ep.062: 단편 또는 다인 미포함
  ep.063: 회사 조합 + 동네 조합

예외:
- 신규 히로인 도입 시 1회차 연속 배치 가능
- 특정 스토리 라인이 필요한 경우 유연하게 조정
```

#### Rule 4: 신규 히로인 우선
```
1순위 도입 (40점):
  회사: 임소율, 배수인
  동네: 이하은, 한서진, 박소연, 이주은

이후 배치 (45~55점):
  회사: 이유주
  동네: 박다정, 유하린, 박미현, 채수빈, 이채영
```

### 9.3 단편별 예시 (Examples)

#### ep.061 후보 (신규 히로인 2명 동시 도입)

**회사 조합:**
- **임소율 × 배수인** (점수: 40점, 최고 우선순위)
  - 용식 동선: 회사 건물 앞·지하식당·1층 카페
  - 배경: 미등장 신규 히로인 2명 첫 등장
  - 권고: 회사 다인 시리즈 첫 선택

**동네 조합:**
- **이하은 × 한서진** (점수: 40점, 최고 우선순위)
  - 용식 동선: 독립서점·와인바 골목·카페 마감 후
  - 배경: 미등장 신규 히로인 2명 첫 등장
  - 권고: 동네 신규 라인 개척

#### ep.062 후보 (회사 신규 + 동네 기존 재조합)

**회사 조합:**
- **이유주 × 임소율** (점수: 42.5점, 매우 높음)
  - 용식 동선: 탕비실·엘리베이터·회사 복도
  - 배경: 신규 히로인 임소율과 기존 히로인 이유주의 첫 조합
  - 권고: 임소율 도입 후 2회차 배치

**동네 조합:**
- **박미현 × 이하은** (점수: ~48점, 높음)
  - 용식 동선: 동네 카페·독립서점 공동 골목
  - 배경: 신규 히로인 이하은과의 두 번째 조합, 박미현 재등장
  - 권고: 동네 카페·서점 라인 확장

#### ep.063 후보 (회사 기존 재조합 + 동네 신규 도입)

**회사 조합:**
- **이주희 × 임소율** (점수: 60점, 높음)
  - 용식 동선: 탕비실·엘리베이터·회사 복도
  - 배경: 신규 히로인 임소율과 기존 다인 경험 히로인 이주희의 첫 조합
  - 권고: 임소율 도입 후 3회차 배치

**동네 조합:**
- **박다정 × 유하린** (점수: ~49.5점, 높음)
  - 용식 동선: 약국·아파트 공용 동선
  - 배경: ep.028에서 이미 사용된 조합이므로 대신 다른 조합 추천
  - 대체: **박다정 × 박미현** (점수: ~50.5점, 높음)
    - 용식 동선: 약국 근처 카페, 동네 골목

### 9.4 활용 팁 (Tips)

#### 팁 1: 점수 기반 자동 필터링
```
실무 절차:
1. 다음 에피소드 기획 시 "조합 선택" 단계에서 가중치 점수표 참조
2. "이 회차에는 어떤 조합을 배치할까?" → 40~55점 범위에서 자동 추천
3. 점수가 낮은 히로인부터 우선 선택

예:
- ep.061: 점수 40점대 미등장 히로인부터 선택
- ep.062: 점수 42~50점 범위에서 새로운 조합 찾기
- ep.063: 점수 45~60점 범위에서 조합 다양화
```

#### 팁 2: 스토리와의 균형
```
가중치 점수는 "객관적 필요도"를 나타냄
창작 의도가 더 우선할 수 있음:
- 특정 히로인의 스토리 라인 전개 필요 시: 점수 무시 가능
- 다만, 점수가 높은(70점대) 히로인을 3회차 연속 배치하지 않기
- 또는 70점대 히로인 다음은 반드시 40~55점대 히로인 배치

균형 조정 예:
- 서나윤(70점) 등장 → 다음 회차는 40~50점 히로인 선택
- 노은화(72점) 참여 시 → 이후 2회차는 저점수 히로인 우선
```

#### 팁 3: 가중치 업데이트 주기
```
초기: 매 5회차마다 (ep.065, 070, 075...)
  - 최근 등장 패널티 재계산
  - 성인씬 횟수 누적 반영
  - 다인 조합 참여도 업데이트

중기: 매 10회차마다 (ep.070, 080, 090...)
  - 히로인 성인씬 기록 정산
  - 다인 씬 운영 규칙 적용률 확인
  - 새 히로인 도입 후 초기화

신규 히로인 추가:
- 즉시 40점으로 초기화 (미등장 상태)
- 첫 등장 후 성인씬 횟수만 누적 반영
```

#### 팁 4: 조합 다양성 유지
```
기본 원칙:
- 같은 조합 반복 지양 (단편 독립 완결 원칙)
- 기존 다인 씬 운영 규칙 준용
- 미사용 조합이 충분하므로 (회사 9개, 동네 47개) 순환 배치

체크리스트:
1. 이번 회차 선택 조합이 이전에 사용되었는가?
   → Yes: 다른 조합으로 변경
2. 같은 생활권 히로인이 연속 3회차 이상 등장했는가?
   → Yes: 다른 생활권 조합 우선 배치
3. 점수 70점 이상 히로인이 2회차 연속 등장했는가?
   → Yes: 다음 회차는 점수 55점 이하 히로인으로 균형

실제 사용 예:
- ep.060 배치: 노은화(72점) × 최윤서
- ep.061 계획: 노은화 제외, 점수 40점 미등장 히로인 우선 선택
  → 이하은(40점) × 한서진(40점) 배치 추천
```
