# 핵심 컨셉

## 한 줄 컨셉

김용식이 자주 드나드는 생활권마다 그를 짝사랑하는 여자가 있고, 한 편 안에서 그 마음이 핑계와 소품을 통해 드러나는 독립 단편 로맨스.

## 기본 약속

- 각 편은 독립 단편이다.
- 파일 번호는 정렬용이며, 관계 진도는 이어지지 않는다.
- 히로인은 시작 시점부터 용식을 좋아하고 있다.
- 용식은 그 마음을 바로 확신하지 못하고, 장면 안에서 뒤늦게 알아차린다.
- 외형 설정은 캐릭터 파일의 `### 외형`을 그대로 따른다.
- 장면은 생활권의 소품과 행동으로 움직인다.

## 히로인별 기본 축

- 박미현: 자주 가는 카페 알바 / 마감 / 자취 / 교대시간 / 교대 후 / 창고 / 모텔
- 유하린: 같은 아파트 여성 / 퇴근길 / 출근전 / 마주침 / 계단 / 옥상 / 늦은 귀가 / 자취
- 서나윤: 자주 가는 편의점 알바 / 창고 / 통로 / 늦은 귀가 / 자취 / 골목 / 야간 교대 / 모텔
- 정다은: 직장 동료 / 회의실 / 탕비실 / 비상계단 / 화장실 / 점심시간 / 야근 / 외근 / 모텔
- 이재인: 직장 동료 / 회의실 / 탕비실 / 비상계단 / 화장실 / 점심시간 / 야근 / 모텔 / 외근
- 최윤서: 같은 출근버스 타는 여성 / 버스 안 / 화장실 / 반차 / 모텔 / 늦은 귀가 / 자취 

## 단편 엔진

```text
용식의 회피 또는 생활 곤란
↓
히로인의 사소한 핑계와 접근
↓
용식이 호감을 장난으로 넘기려 함
↓
생활 소품 때문에 마음이 들킴
↓
용식의 작은 선택
↓
사건은 닫히고 관계는 여운으로 남음
```

## 성인씬 운영

- 성인씬은 작품의 결말 후보 중 하나다.
- 직접 묘사보다 성인씬 컨텍스트 구역으로 기록한다.
- 성인씬이 없어도 스킨십 직전, 질투, 다음 약속, 남겨진 물건으로 관계 진도 체감을 남긴다.
