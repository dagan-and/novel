# 단편 개요

## 한 줄 정의

2020년 8월, 큰 불만 없이 하루하루를 미루며 사는 30살 직장인 김용식이 자주 드나드는 생활권에서 자신을 짝사랑하던 히로인의 마음을 뒤늦게 알아차리는 독립 단편 로맨스.

## 형식

- 기본 목표: 1편 완결 단편
- 확장 가능 범위: 같은 설정과 인물로 여러 독립 단편을 만들 수 있지만, 각 편은 서로 이어지지 않는다.
- 원고 생성 전 단계: 먼저 단편 개요를 확정한다.
- 완결감: 사건은 닫되, 관계의 여운은 남긴다.
- 모든 단편은 성인씬 1번으로 마무리한다
- 단편의 성인씬은 직접 묘사 대신 `_a` 파일과 `setting/성인씬작성규칙.md`의 컨텍스트 구역으로 처리한다.

## 핵심 전제

- 김용식은 2020년 3월 기준 30살 직장인이다.
- 회사, 자취방, 자주 가는 카페와 편의점, 같은 아파트 이웃, 출근버스 동선 안에서 사람을 만난다.
- 뚜렷한 불만은 없지만 삶에서 뭔가 중요한 결정을 자꾸 미룬다.
- 각 히로인은 자기 생활권에서 이미 용식을 짝사랑하고 있다.
- 각 히로인의 생활권과 성격 정보는 `characters/` 폴더의 각 파일을 참조한다. 새 히로인 추가 시 해당 파일만 만들면 된다.
- 이야기는 히로인이 마음을 숨기는 핑계와 용식이 뒤늦게 알아차리는 순간으로 움직인다.
- 이야기는 거대한 사건보다 작은 생활 행동으로 관계 변화를 보여 준다.

## 중심 감정

- 아무렇지 않던 사람이 갑자기 신경 쓰이는 순간
- 미뤄 둔 일상이 누군가의 방문으로 들켜 버리는 민망함
- 편한 장난으로 넘기려다 실패하는 공기
- 다음을 약속하지 않았는데도 다음이 생길 것 같은 느낌


## 단편 엔진

```text
뭔가를 미루는 용식
↓
평소보다 가까이 들어오는 히로인
↓
장난으로 넘길 수 없는 생활 침범
↓
용식의 작은 선택
↓
완결감 있는 하루와 다음 방문의 여운
```

## 제목 후보

- 박미현은 자꾸 내 방에 온다
- 3월의 방문자
- 편의점 야간은 길다

## 운영 메모

- 중심 히로인은 단편마다 1명~2명으로 둔다.
- 히로인별 핵심 소품은 `planning/핵심컨셉.md`와 캐릭터 파일을 따른다.
- 도입부와 성인씬 본문 모두 대화를 쓰지 않는다. 행동과 감각 묘사만으로 구성한다.
- 이전 단편의 결말, 관계 진도, 성인씬 컨텍스트 횟수는 다음 단편에 자동 계승하지 않는다.
- 각 단편은 "이번 한 편 안에서" 시작 관계, 충돌, 가까워짐, 여운을 새로 닫는다.
- 단편 안에서는 관계를 확정하지 않는다. 대신 독자가 "다음에 또 만나겠네"라고 느끼게 한다.

## 다인 씬 운영 규칙

### 기본 원칙

- 2인 히로인 단편은 **생활권이 자연스럽게 겹치는 조합**에서만 허용한다.
- 씬 구도는 **용식 + 히로인A + 히로인B 동시** 3인 구도를 기본으로 한다.
- 다인 씬 단편도 단편 독립 원칙을 따른다. 이전 단편의 관계 진도를 자동 계승하지 않는다.
- 파일명은 일반 다인 씬과 동일하게 `_a` 파일로 저장한다.
- 성인씬 컨텍스트 포맷은 `setting/성인씬작성규칙.md`의 다인 씬 항목을 따른다.
- **다인 씬 발생 조건은 랜덤이다.** 히로인 중 한 명이 다른 생활권에 목적을 가지고 들어가는 방식을 쓰지 않는다. 두 히로인이 같은 공간에 우연히 놓이는 상황에서만 발생한다.

### 도입부 구성 주의

- 두 히로인이 서로 아는 사이인지 모르는 사이인지를 도입부 첫 장면에서 행동으로 명확히 한다.
- 각 히로인의 감정 압력이 독립적으로 쌓인 뒤 같은 공간에서 교차하는 방식으로 구성한다.
- 히로인끼리 용식을 두고 경쟁하는 구도가 아닌, 각자의 방식이 같은 공간에서 충돌하는 구도를 기본으로 한다.
- 두 히로인이 서로를 알아보는 순간, 용식의 반응보다 히로인A·B가 서로를 읽는 짧은 장면이 먼저 온다.
