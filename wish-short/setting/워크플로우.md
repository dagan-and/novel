# 단편 작업 워크플로우

핵심컨셉.md의 단편 엔진을 기반으로 한 편을 구성하는 순서.

---

## STEP 0 — 세션 시작 시 필독 / 접근 금지

### 반드시 읽어야 할 파일 (순서대로)

1. `setting/에피소드샘플.md` — 포맷·구조·문체 기준
2. `히스토리.md` — 전체 에피소드 현황, 인물별 요약, 성인씬 횟수
3. `characters/[이번 히로인].md` — 개별 히스토리 (최근 변화·다음 압력·성인씬 기록)
4. `characters/김용식.md` — 용식 누적 성인씬 횟수

### 읽지 않는 파일

> **`episodes/` 폴더의 원고 파일을 읽지 않는다.**
> 위 4개 파일로 내용 파악이 완결된다.
> 사용자가 특정 에피소드 번호를 직접 지정한 경우에만 해당 파일을 읽는다.

---

## STEP 1 — 히로인과 트리거 선택

`planning/핵심컨셉.md`의 히로인별 기본 축에서 이번 편의 히로인과 장소 키워드를 고른다.

```
히로인: ____
키워드: ____ / ____ / ____
```

히로인 캐릭터 파일(`characters/`)에서 확인:
- 담당 생활권
- 장면 트리거
- 보유 소품

**확장 공간 사용 여부 결정 (`setting/확장공간카탈로그.md` 참조)**

기원 생활권 단편이 반복될 경우, 아래 조합을 카탈로그에서 선택한다.

```
공간 유형: 기원 생활권 / 확장 공간 → ____
히로인 동행 상태: 혼자 / 남자친구와 / 친구들과 / 기타 → ____
히로인 상태: ____
조우 맥락: ____
```

같은 히로인이라도 공간×동행×상태 조합이 달라지면 완전히 다른 단편이 된다.

---

## STEP 2 — 단편 엔진 채우기

`planning/핵심컨셉.md`의 단편 엔진 6단계를 이번 편 기준으로 구체화한다.

```
1. 용식이 무엇을 미루고 있는가?
   → ____

2. 히로인이 어떤 핑계로 동선에 끼어드는가?
   → ____

3. 용식이 장난으로 넘기려는 순간은?
   → ____

4. 생활 소품 때문에 마음이 들키는 방식은?
   → ____

5. 용식의 작은 선택은?
   → ____

6. 히로인이 남기는 다음 방문의 여운은?
   → ____
```

---

## STEP 3 — 도입부 구성

- 대화 없이 상황만으로 구성한다. (`setting/단편구성포맷.md`)
- 장소, 인물 자세, 빛, 온도, 소리를 먼저 설정한다.
- STEP 2의 1~4단계 흐름을 행동과 감각 묘사로 쌓아 간다.
- 성인씬 진입 직전 관계 압력이 충분히 쌓이면 도입부를 닫는다.

---

## STEP 4 — 성인씬 컨텍스트 헤더 작성

`setting/성인씬작성규칙.md`의 구역 포맷을 따라 헤더를 채운다.

```
## [성인씬 컨텍스트]
- 화수: ep.___ 1회차
- 장소: ____
- 시간: ____
- 등장인물: 김용식 / ____
- 현재 구도: ____
- 진입 계기: ____
- 의상: ____
- 표정 포인트: ____
- 손/시선 포인트: ____
- 성격 참고: ____
```

---

## STEP 5 — 성인씬 본문 작성

- 대화 없이 행위와 감각만으로 구성한다. (`setting/단편구성포맷.md`)
- 행위 주체와 순서를 명확히 한다.
- 신체 반응, 감각, 속도, 온도, 압력, 리듬 기준으로 서술한다.
- 씬이 끝난 뒤 인물의 신체 상태와 공간 변화로 마무리한다.

---

## STEP 6 — 파일 저장

```
episodes/001-100/ep.001_a.md   ← 성인씬 포함 단편
episodes/001-100/ep.001.md     ← 성인씬 없는 단편
```

번호는 정렬용 ID. 이어지는 서사를 의미하지 않는다.

---

## STEP 7 — 캐릭터 파일 갱신

단편을 닫은 뒤 해당 히로인의 캐릭터 파일(`characters/`)을 업데이트한다.

**갱신 항목:**

```
[가변] 섹션
- 최근 변화: ep.번호 — 한 줄 요약 (예: 반차 버스 동승 후 골목에서 첫 확인)
- 다음 압력: 다음 편에서 쓸 수 있는 미결 감정이나 상황

[성인씬 기록] 섹션
- 총 성인씬: N회 (이 편 포함 누적)
- ep.번호: 장소 — 한 줄 메모
```

**갱신하지 않는 항목:**
- 감정 수치 — 각 단편은 독립이므로 수치를 이어받지 않는다. 0으로 유지.
- 고정 섹션 (외형, 성격, 서사 기능) — 단편이 끝나도 바뀌지 않는다.

---

## STEP 8 — publish.py 실행

STEP 7까지 완료한 뒤 반드시 아래 명령을 실행한다.

```bash
python3 publish.py
```

- 에피소드 HTML 변환 → 캐릭터 프로필 변환 → 세계관·관계망·인덱스 변환 → 삽화 갤러리 변환 → git commit & push 순서로 자동 처리된다.
- 변환만 확인하고 git을 건너뛰려면 `python3 publish.py --dry`를 사용한다.
- 이 단계를 생략하면 신규 에피소드가 배포되지 않는다.
