# 워크플로우

## 현재 단계

- 이 폴더는 독립 단편 작업 공간이다.
- 각 원고는 이어지는 화가 아니라 한 편씩 끊어지는 완결 단편으로 작성한다.
- 사용자가 명시적으로 요청하기 전까지 단편 원고를 작성하지 않는다.

## 요청별 처리

### "세팅 정리해줘" / "설정 구축해줘"

1. `AGENTS.md` 확인
2. `planning/` 문서 확인
3. `setting/세계관.md` 확인
4. `setting/독서흐름개선규칙.md` 확인
5. 문체/읽힘 변경이 있으면 `setting/라노벨문체규칙.md` 확인
6. 성인씬 운영 변경이 있으면 `setting/성인씬작성규칙.md` 확인
7. 필요한 설정 문서만 수정
8. 원고 생성 금지

### "캐릭터 세팅해줘"

1. `planning/캐릭터운영원칙.md` 확인
2. `characters/캐릭터양식.md` 확인
3. 해당 캐릭터 파일 작성 또는 수정
4. `관계망.md`에는 확정된 초기 관계만 반영
5. 원고 생성 금지

### "단편 써줘" / "소설 시작해줘"

1. `planning/단편개요.md`
2. `planning/핵심컨셉.md`
3. `setting/개요작성규칙.md`
4. `setting/독서흐름개선규칙.md`
5. `setting/라노벨문체규칙.md`
6. `setting/시나리오작성규칙.md`
7. 성인씬 컨텍스트가 필요할 경우 `setting/성인씬작성규칙.md`
8. `characters/`
9. `관계망.md`
10. `연대기.md`

이 순서로 읽은 뒤, 요청이 "바로 써줘"가 아니면 먼저 해당 단편 1편의 개요안을 제시하고 사용자 확인을 받는다.

### "바로 써줘" / "하나 만들어줘"

- 독립 단편 1편을 바로 작성하는 요청으로 취급한다.
- 이전 단편의 사건을 다음 단편의 확정 과거로 자동 연결하지 않는다.
- 같은 인물과 소품을 다시 써도 관계 진도, 성인씬 횟수, 사건 결과는 해당 단편 안에서 새로 닫는다.

## 파일 저장 규칙

- 일반 독립 단편: `episodes/[001-100|101-200|201-300]/ep.[번호].md`
- 성인씬 컨텍스트 포함 독립 단편: `episodes/[001-100|101-200|201-300]/ep.[번호]_a.md`
- 같은 제목의 일반 파일과 `_a` 파일을 동시에 만들지 않는다.
- `ep.001`, `ep.002` 같은 번호는 링크/목록 정렬용 ID이며, 내용이 이어진다는 뜻이 아니다.
- 각 파일 제목 줄에는 실제 단편 제목을 함께 적는다.
- 시나리오 작성 요청 전에는 `episodes/`에 파일을 만들지 않는다.

## 기록 업데이트

- 독립 단편 1편이 완성된 뒤 `관계망.md`, `연대기.md`, 캐릭터 [가변] 항목에 단편별 기록을 남긴다.
- 단편별 기록은 서로 이어지는 사건처럼 쓰지 않고, 작품명/파일명 단위로 구분한다.
- 설정 변경과 원고 진행 기록을 섞지 않는다.
