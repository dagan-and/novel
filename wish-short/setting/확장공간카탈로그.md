# 확장 공간 & 상황 카탈로그

## 원칙

- 히로인의 **기원 생활권**은 첫 만남의 맥락이자 관계의 출발점이다. 유일한 만남의 장소가 아니다.
- 실제 사람이 갈 수 있는 **모든 공간**에서 용식과 히로인은 마주칠 수 있다.
- 히로인이 **누구와 함께 있는지**, **어떤 상태인지**에 제한이 없다.
- 단편 개요를 잡을 때 기원 생활권에 묶이지 말고 이 카탈로그를 먼저 훑는다.

|---|---|
| 대형마트·이마트·홈플러스 | 주말 오후, 카트 밀다 복도에서 마주침 |

| 미용실·네일샵 | 용식이 지나가다 창문으로 눈이 마주침 |
| 안경원 | 히로인이 렌즈 착용 중, 시야 흐릿한 상태에서 발견 |
| 꽃집 | 누군가를 위한 것인지 아닌지 모를 꽃다발 |

## 상황 유형 카탈로그

### 히로인 동행 상태

| 동행 상태 | 단편 긴장 포인트 |
|---|---|
| 혼자 | 가장 무방비한 상태 |
| 여자 친구 1명과 | 친구가 용식을 먼저 알아보거나, 반대로 히로인이 숨기려 함 |
| 여자 친구들 2명+ | 여러 명의 시선이 모이는 상황, 히로인이 반응을 숨기기 더 어려움 |
| **남자친구와 데이트 중** | 용식과 눈이 마주치는 순간, 남자친구는 모름 |
| **소개팅 상대와 만남 직전·직후** | 서로 단장하거나 혹은 실망한 기색 |
| 전 남자친구와 마주침 직후 | 감정이 흐트러진 상태에서 용식을 봄 |
| 직장 동료들과 회식 중 | 평소 직장 캐릭터와 다른 모습이 노출됨 |
| 가족과 (언니·엄마·동생) | 가족 앞에서 반응을 숨겨야 함 |
| 혼자 취해서 귀가 중 | 판단이 느슨해진 상태 |

### 히로인 감정·신체 상태

| 상태 | 단편 긴장 포인트 |
|---|---|
| 평범한 일상 중 (예상 못 한 마주침) | 준비 없이 들킨 민낯 |
| **취해 있음** | 말이 앞서거나 몸이 비틀거림 |
| **울다 그친 후** | 눈이 빨개진 것을 들킴 |
| 급하게 서두르는 중 | 뭔가 흘리거나 놓치는 계기 |
| **뭔가 잃어버린 상태** (지갑·우산·열쇠) | 용식이 우연히 발견하거나 찾아줌 |
| **아픔** (얼굴 창백·비틀거림) | 평소와 다른 취약한 모습 |
| 방금 누군가와 싸우고 나옴 | 전화 끊고 나온 직후, 감정이 날것 |
| **생일인데 혼자 있음** | 챙겨주는 사람 없는 날 들킴 |
| 비를 맞고 있음 | 우산이 없는 쪽 |
| 짐이 너무 많음 | 들어주는 계기 |
| 기다리다 지침 (약속 펑크) | 혼자 남겨진 상태에서 용식과 마주침 |
| 살짝 기분 좋게 취함 | 평소보다 말이 많아지거나 솔직해짐 |
| 막 운동 끝난 직후 | 열기와 땀, 평소 모습과 다름 |
| 이사 중 (박스·짐 들고 이동) | 공간 이동의 계기 |

### 조우 맥락

| 맥락 | 설명 |
|---|---|
| 완전 우연 | 둘 다 예상 못 함 |
| 히로인만 미리 인식 | 히로인이 먼저 봤지만 용식은 모름, 히로인이 피하거나 말 거는 선택 앞에 놓임 |
| 용식이 먼저 발견 | 이름을 부를지 말지 잠깐 망설임 |
| 같은 줄·대기에서 | 뒤늦게 알아봄, 이미 줄이 길어서 피하기 어색 |
| 제3자가 연결 | 공통 지인이 소개하거나 불러옴 |
| 전화 중에 시야에 들어옴 | 상대방과 통화하면서 용식을 봄, 말이 끊김 |
| 남친·소개팅 상대와 있다가 잠깐 혼자 된 순간 | 화장실 간 사이, 계산하러 간 사이 |

## 활용 방법 (STEP 1 연동)

단편 개요를 잡을 때 아래 순서로 선택한다.

```
1. 히로인 선택
2. 기원 생활권 단편인가 / 확장 공간 단편인가 결정
3. 확장 공간 단편이면 → 이 카탈로그에서 공간 선택
4. 히로인 동행 상태 선택 (혼자 / 남친과 / 친구들과 / 등)
5. 히로인 감정·신체 상태 선택
6. 조우 맥락 선택
7. 위 조합을 STEP 2 단편 엔진에 대입
```

같은 히로인이라도 공간×동행×상태 조합이 달라지면 완전히 다른 단편이 된다.
