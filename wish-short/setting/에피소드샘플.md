# 에피소드 샘플 (포맷 템플릿)

> **용도:** 신규 에피소드 작성 시 구조·문체·성인씬 컨텍스트 포맷 기준.
> ep.035를 바탕으로 만든 템플릿이다. `episodes/` 폴더 원고를 읽는 대신 이 파일을 참조한다.

---

## 1. 파일 헤더

```
# ep.번호 — 제목 (장소 + 핵심 소품 조합)

히로인: 이름
키워드: A / B / C / D
```

**ep.035 예시:**
```
# ep.035 — 야근, 빈 사무실, 에너지 음료

히로인: 이유주
키워드: 야근 / 빈 사무실 / 에너지 음료 / 멈추지 않은 것
```

---

## 2. 도입부 구조

```
[시간대·장소·물리 상황 — 첫 문단에서 확정]

[용식의 현재 행동 — 미루고 있는 것 또는 끝낸 것]

[히로인의 등장 — 생활권 접점에서 자연스럽게]

[두 사람의 거리 좁힘 — 소품·시선·신체 위치로만]

[성인씬 진입 직전 긴장 — 행동이 멈추거나 물건이 놓이는 순간]
```

**문체 원칙:**
- 문장을 짧게 끊는다.
- 대화(`"대사"`, 문자, 알림) 한 줄도 쓰지 않는다.
- 감정 해설 대신 물리적 사실을 앞에 둔다.
- 같은 신체 어휘가 3문장 이상 반복되면 청각·온도·압력으로 교체한다.

**ep.035 도입부 흐름 예시:**
- 시간: 저녁 아홉 시, 사무실 인원이 전부 빠진 뒤
- 용식: 파일 수정을 마무리하고 모니터를 끔
- 히로인 등장: 야근이 잦지 않은데 아직 자리에 앉아 있었던 이유주
- 거리 좁힘: 자판기 → 에너지 음료 → 이유주 책상 앞에 놓음 → 옆 빈 의자를 당겨 앉음
- 긴장: 노트 끄트머리 한 칸 간격에 두 손이 각각 놓임, 음료를 열지 않은 채 들고 있음

---

## 3. 성인씬 컨텍스트 포맷

```
---

## [성인씬 #번호 - ep.번호]

- 장소: [도입부 장소와 동일] / [세부 위치]
- 등장인물:
  - 김용식: [직전 행동] / [이 씬에서의 자세·태도]
    - 누적 성인씬 횟수: N회  ← characters/김용식.md 기준
  - [히로인]: [직전 상태] / [이 씬에서의 자세·태도]
    - 누적 성인씬 횟수: N회  ← characters/[히로인].md 기준
    - 외형 참고: 체형 원문 그대로 + 얼굴·헤어·분위기 1~2문장 압축
    - 성격 참고: 이 씬과 관련된 성격·행동 패턴
- 의상:
  - 김용식: [현재 복장]
  - [히로인]: [현재 복장]
- 이미지 포인트: [한 컷으로 압축한 장면 — 긴장이 가장 높은 순간]
- 표정 포인트:
  - 김용식: [표정·행동]
  - [히로인]: [표정·행동]
- 손 / 시선 포인트:
  - 김용식: [손 위치] / [시선 방향]
  - [히로인]: [손 위치] / [시선 방향]
- 복장 상태: [흐트러짐·변화 — 소매·목선·단추 등 간단히]
- 배경 소품 강조: [생활권 드러내는 소품 1~3개]
- 소품 / 환경: [공간 상태 한 줄]
- 분위기 키워드: [A / B / C — 짧은 이미지 단위]
- 직전 맥락: [도입부 마지막 행동 이어받은 상황]
- 관계 단계: [두 사람의 관계 규정 — 직업·접점·거리감]
- 현재 구도: [히로인] ↔ 용식
- 합의 상태: [씬 진입이 납득되는 행동적 근거 — 명시적 동의 아닌 행동·선택으로]
- 씬 이후 감정 방향: [씬이 끝난 뒤 두 사람의 행동 예측]
- <progress>[sex]</progress>

---
```

**ep.035 채운 예시 (참고용):**
- 장소: 야근 후 빈 사무실 / 인턴 자리 책상 앞
- 이미지 포인트: 노트 끄트머리 한 칸 간격에 두 손이 각각 놓인 순간, 사무실에 이 자리만 불이 켜져 있다
- 합의 상태: 야근이 아닌데 남아 있었던 히로인 / 나가지 않고 의자를 당겨 앉은 용식 / 사무실에 두 사람만 있다 / 노트가 반쯤 닫혀 있다
- 씬 이후 감정 방향: 이유주는 음료 캔을 책상에 내려놓을 것이다 / 용식은 노트에서 손을 옮길 것이다

---

## 4. 작성 전 체크리스트

### 도입부
- [ ] 시간대·장소·물리 상황이 첫 문단 안에 있는가
- [ ] 용식의 '미루는 것' 또는 '막 끝낸 것'이 행동으로 드러나는가
- [ ] 히로인 진입이 생활권 접점에서 자연스럽게 오는가
- [ ] 대화가 한 줄도 없는가
- [ ] 관계 압력이 소품·시선·신체 위치로만 쌓이는가
- [ ] 성인씬 진입이 납득될 만큼 긴장이 도입부 끝에 있는가

### 성인씬 컨텍스트
- [ ] 장소가 도입부 장소와 일치하는가
- [ ] 누적 횟수가 `characters/` 파일 기록과 맞는가
- [ ] 이미지 포인트가 도입부의 절정 순간을 가리키는가
- [ ] 합의 상태가 명시적 대화 없이 행동으로만 기술되었는가
- [ ] `<progress>[sex]</progress>` 태그가 마지막 줄에 있는가
