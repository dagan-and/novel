# 에피소드 샘플 (포맷 템플릿)

> **용도:** 신규 에피소드 작성 시 구조·문체·성인씬 컨텍스트 포맷 기준.
> ep.035를 바탕으로 만든 템플릿이다. `episodes/` 폴더 원고를 읽는 대신 이 파일을 참조한다.

---

## 1. 파일 헤더

```
# ep.번호 — 제목 (장소 + 핵심 소품 조합)

히로인: 이름
키워드: A / B / C / D
```

**ep. 예시:**
```
# ep. — 야근, 빈 사무실, 에너지 음료

히로인: 이유주
키워드: 야근 / 빈 사무실 / 에너지 음료 / 멈추지 않은 것
```

---

## 2. 도입부 구조

**규칙:**
- 7~10줄로 쓴다. 넘기지 않는다.
- 대화(`"대사"`, 문자, 알림) 한 줄도 쓰지 않는다.
- "누가 어디 있다가 → 무슨 계기로 → 어떻게 이 장소에 함께 있게 됐는지"를 행동 순서대로 직접 쓴다.
- 감정 해설, 분위기 묘사, 심리 설명을 따로 달지 않는다.
- 마지막 줄에서 두 사람이 같은 공간에 단둘인 상태가 확정되어야 한다.

**ep. 도입부 예시 (10줄):**

열 시가 넘은 사무실이었다. 이유주는 혼자 남겨진 것이 싫었다. 야근 일정이 아닌데도 자리에 앉아 있었다. 손가락이 떨리고 있었다. 용식이 가방을 들다가 이유주 책상에 에너지 음료를 내려놓았다. 이유주는 그것을 열지 않았다. 용식이 옆 빈 의자를 당겨 앉았다. 두 사람 사이에 노트 한 권이 반쯤 닫힌 채 있었다. 이유주가 노트에서 손을 뗐다. 용식 쪽을 봤다.

---

**다른 패턴 예시 (참고용):**

> 퇴근 후 나윤이 편의점 봉투에 맥주 캔 두 개를 넣었다. 회사 앞 공원 벤치에 앉아 같이 비웠다. 한 캔 더 사 왔고 나윤이 용식 팔에 기댔다. 막차 시간이 지나 있었다. 택시 앱 대기가 30분이라고 떴다. 나윤이 먼저 골목 안 모텔 간판 쪽으로 걸었다.

> 점심 전에 다은이 사내 메신저로 비상계단 층수만 찍어 보냈다. 용식이 10분 뒤 올라갔다. 다은이 먼저 와 있었고 문을 등으로 닫았다. 노트가 없었다.

> 퇴근길 정류장에서 윤서와 버스에 같이 탔다. 옆자리였다. 대화하다가 윤서가 손가락으로 용식 손등을 툭툭 쳤다. 분위기가 이상하게 흘렀다. 다음 정류장에서 같이 내렸다. 모텔은 골목 두 번 꺾으면 있었다.

## 3. 성인씬 컨텍스트 포맷

```

## [성인씬 #번호 - ep.번호]

- 장소: [도입부 장소와 동일] / [세부 위치]
- 등장인물:
  - 김용식: [직전 행동] / [이 씬에서의 자세·태도]
    - 누적 성인씬 횟수: N회  ← characters/김용식.md 기준
  - [히로인]: [직전 상태] / [이 씬에서의 자세·태도]
    - 누적 성인씬 횟수: N회  ← characters/[히로인].md 기준
    - 외형 참고: 체형 원문 그대로 + 얼굴·헤어·분위기 1~2문장 압축
    - 성격 참고: 이 씬과 관련된 성격·행동 패턴
    - 남자친구 유무: characters/[히로인].md 의 `남자친구` 항목 참고
- 의상:
  - 김용식: [현재 복장]
  - [히로인]: [현재 복장]
- 이미지 포인트: [한 컷으로 압축한 장면 — 긴장이 가장 높은 순간]
- 표정 포인트:
  - 김용식: [표정·행동]
  - [히로인]: [표정·행동]
- 손 / 시선 포인트:
  - 김용식: [손 위치] / [시선 방향]
  - [히로인]: [손 위치] / [시선 방향]
- 복장 상태: [흐트러짐·변화 — 소매·목선·단추 등 간단히]

- 소품 / 환경: [공간 상태 한 줄]
- 분위기 키워드: [A / B / C — 짧은 이미지 단위]
- 관계 단계: [두 사람의 관계 규정 — 직업·접점·거리감]
- 현재 구도: [히로인] ↔ 용식
- 합의 상태: [씬 진입이 납득되는 행동적 근거 — 명시적 동의 아닌 행동·선택으로]
- 씬 이후 감정 방향: [씬이 끝난 뒤 두 사람의 행동 예측]
- <progress>[sex]</progress>

---
```

**ep. 채운 예시 (참고용):**
- 장소: 야근 후 빈 사무실 / 인턴 자리 책상 앞
- 이미지 포인트: 노트 끄트머리 한 칸 간격에 두 손이 각각 놓인 순간, 사무실에 이 자리만 불이 켜져 있다
- 합의 상태: 야근이 아닌데 남아 있었던 히로인 / 나가지 않고 의자를 당겨 앉은 용식 / 사무실에 두 사람만 있다 / 노트가 반쯤 닫혀 있다
- 씬 이후 감정 방향: 이유주는 음료 캔을 책상에 내려놓을 것이다 / 용식은 노트에서 손을 옮길 것이다

## 4. 작성 전 체크리스트

### 도입부
- [ ] 7~10줄 안에 끝났는가
- [ ] 대화가 한 줄도 없는가
- [ ] 두 사람이 이 장소에 함께 있게 된 경위가 행동 순서대로 드러나는가
- [ ] 감정 해설·분위기 묘사 없이 사실만 서술했는가
- [ ] 마지막 줄에서 두 사람이 단둘인 상태가 확정됐는가

### 성인씬 컨텍스트
- [ ] 장소가 도입부 장소와 일치하는가
- [ ] 누적 횟수가 `characters/` 파일 기록과 맞는가
- [ ] 이미지 포인트가 도입부의 절정 순간을 가리키는가
- [ ] 합의 상태가 명시적 대화 없이 행동으로만 기술되었는가
- [ ] 남자친구 유무가 기재됐는가
- [ ] `<progress>[sex]</progress>` 태그가 마지막 줄에 있는가
