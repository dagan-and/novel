# 대사 태그 정리 규칙

## 트리거

- 사용자가 `ep.[번호] ~ ep.[번호] 대사 태그 정리해줘`처럼 특정 화수 범위를 지정했을 때 적용한다.

## 정리 기준

- 대사는 `[이름] "대사"` 형식으로 통일한다.
- 문자, 단체방 공지, 시스템 알림은 `[발신자] 내용` 형식으로 두고 대사로 바꾸지 않는다.
- 화자 태그는 캐릭터 파일명 기준 풀네임을 우선한다.
- 약식 태그는 해당 화 안에서 혼동이 없고, 관계상 자연스러울 때만 허용한다.
- 무태그 대사는 앞뒤 문맥을 기준으로 화자를 명확히 한다.

## 검수 항목

- 무태그 대사 잔여 여부
- 약식 태그 혼용 여부
- 콜론형 화자 표기 잔여 여부
- 같은 화 안에서 풀네임 태그와 약식 태그가 섞였는지
- 문자/알림이 따옴표 대사나 코드블록으로 남아 있는지
