# ep.112 — 외근, 이면도로, 빈 봉투

히로인: 이주희
키워드: 외근 귀가 / 에너지바 / 빈 봉투 / 이면도로

---

외근이 끝난 오후였다. 버스 정류장에서 용식보다 먼저 내린 쪽이 주희였다. 편의점 봉지를 들고 있었다. 에너지바 두 개가 들어 있었다. 걸으면서 하나를 꺼내 용식 손에 올렸다. 용식이 포장 끝을 뜯었다. 주희가 자기 것을 열다가 가방 안에서 구겨진 봉투 하나를 꺼냈다. 저번 외근 때 접어 넣어 뒀던 것이었다. 주희가 봉투를 다시 가방 안으로 밀어 넣었다. 용식이 십자로 앞에서 멈췄다. 이면도로 쪽을 한 번 봤다. 주희가 용식보다 반 걸음 먼저 그쪽으로 틀었다. 에너지바 포장지가 아직 손에 있었다.

---

## [성인씬 #1 - ep.112]

- 장소: 외근 귀가 이면도로 / 골목 안 모텔
- 등장인물:
  - 김용식: 외근 보고서를 내일로 밀고 귀가 중 / 에너지바를 든 채 이면도로 앞에 서 있다가 주희 뒤를 따른 상태
    - 누적 성인씬 횟수: 132회
  - 이주희: 에너지바 두 개를 사 들고 외근 귀가 중 / 저번 외근 빈 봉투를 가방에서 꺼냈다가 다시 넣고 이면도로로 먼저 걸어든 상태
    - 누적 성인씬 횟수: 10회
    - 외형 참고: 골반에 비해 허리가 가늘고 잘록하게 파여 굴곡이 확실히 도드라지며, 살집 없이 마른 편인데도 엉덩이나 허벅지, 종아리로 이어지는 다리 라인이 길고 미끈하게 뻗어 있어 전체적으로 슬림하면서도 탄탄한 탄력이 고스란히 드러나는 몸매. 다크브라운 웨이브 머리가 쇄골까지 내려온 채 외근 끝 무렵 약간 흐트러진 상태.
    - 성격 참고: 몸으로 먼저 움직이는 현장형 / 필요한 것을 챙기는 방식으로 마음을 표현 / 저번 빈 봉투를 아직 가방에 두고 다닌 것이 감정의 노출
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 외근용 셔츠, 가방
  - 이주희: 큼직한 캔버스백, 외근 복장
- 이미지 포인트: 이면도로 입구에서 주희가 반 걸음 먼저 틀어선 순간 — 에너지바 포장지가 아직 손에 있다
- 표정 포인트:
  - 김용식: 이면도로를 보다가 주희 쪽으로 시선을 옮기는 순간
  - 이주희: 가방 끈을 고쳐 잡으며 앞을 보는 순간, 웃지 않음
- 손 / 시선 포인트:
  - 김용식: 에너지바를 든 손 / 이면도로와 주희 사이
  - 이주희: 포장지 든 손 / 골목 안쪽
- 복장 상태: 주희 캔버스백 끈이 한쪽 어깨로 내려온 상태
- 배경 소품 강조: 에너지바 두 개 / 접힌 빈 봉투 / 이면도로 골목 간판
- 소품 / 환경: 오후 늦게 사람이 없는 이면도로 입구, 골목 안쪽으로 이어지는 좁은 길
- 분위기 키워드: 외근 끝 피로 / 두고 온 봉투 / 반 걸음 먼저
- 직전 맥락: 주희가 저번 외근 빈 봉투를 가방에서 꺼냈다가 다시 넣었다. 용식이 이면도로 쪽을 봤다. 주희가 먼저 그쪽으로 걸었다.
- 관계 단계: 같은 회사 직장 동료 — 외근 귀가 동선이 겹치는 거리
- 현재 구도: 이주희 ↔ 용식
- 합의 상태: 주희가 빈 봉투를 접어 가방에 두고 다닌 것 / 용식이 이면도로 방향을 먼저 본 것 / 주희가 반 걸음 먼저 그쪽으로 틀어선 것
- 씬 이후 감정 방향: 주희는 에너지바 포장지를 골목 안에 두고 나올 것이다 / 용식은 봉투 얘기를 꺼내지 않을 것이다
