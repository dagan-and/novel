# ep.084 — 비 오는 이자카야, 젖은 어깨, 채워진 잔

히로인: 노은화
키워드: 비 오는 밤 / 우산 없이 온 손님 / 미리 채워진 잔 / 마감 직전 단둘

---

비가 내리기 시작했다. 이자카야 창문에 빗소리가 먼저 왔다. 손님 두 테이블이 남아 있었다가 하나가 계산을 마치고 나갔다. 카운터 안 은화가 잔을 닦다가 문 쪽을 봤다. 용식이 혼자 들어왔다. 우산이 없었다. 어깨 쪽이 젖어 있었다. 은화가 잔을 선반 위에 올려놓았다. 남은 테이블 손님이 마지막 주문을 불렀다. 은화가 그쪽으로 갔다가 카운터로 돌아왔다. 카운터 바 자리에 잔이 놓여 있었다. 은화가 채운 것이었다. 용식이 잔을 들지 않고 카운터 앞에 앉았다. 빗소리가 더 커졌다. 마지막 테이블 손님이 일어나는 소리가 났다.

  - 김용식: 우산 없이 혼자 들어옴 / 채워진 잔을 들지 않고 카운터 앞에 앉는다

  - 노은화: 마지막 손님이 나가기 전 잔을 미리 채워 둠 / 묻지 않고 채워 놓은 것을 들킨다
    - 누적 성인씬 횟수: 10회
    - 외형 참고: 작은 키 아담한 체형으로 카운터 안에서 빠르게 움직이는 동선이 눈에 잘 들어온다. 키가 작아도 자세가 무너지지 않으며 가슴과 골반에 은근한 볼륨이 있어 실루엣이 분명하다. 작고 동그란 얼굴형에 아래로 살짝 처진 눈꼬리, 통통한 입술. 비 오는 날이라 앞머리를 핀으로 올린 상태.
    - 성격 참고: 밝음이 방어막인 경우가 많지만 진짜 감정이 걸리는 순간엔 웃음이 멈추고 말이 줄어든다 / 안주를 미리 내놓거나 잔을 먼저 채우는 방식이 감정의 언어 / 마지막 손님이 나가는 타이밍을 기다리는 것
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 가을 밤 외출복 — 재킷 / 어깨 쪽이 빗물에 젖은 상태
  - 노은화: 이자카야 알바 앞치마 / 비 오는 날이라 앞머리를 핀으로 올린 상태
