# ep.129 — 야근 후 로비, 마지막 스위치

히로인: 박소연 × 임소율
키워드: 야근 후 1층 / 마지막 스위치 / 에코백 / 텅 빈 로비 / 프론트데스크 카운터

---

야근 후였다. 소연이 1층 로비 스위치를 번호 순서대로 끄고 있었다. 하나가 남았다. 엘리베이터 문이 열렸다. 소율이 에코백을 어깨에 걸친 채 나왔다. 용식이 그 뒤를 따라 나왔다. 소연이 마지막 스위치 위에 손을 얹었다. 끄지 않았다. 소율이 에코백 끈을 손가락에 걸었다가 내렸다. 셋이 텅 빈 로비에 섰다. 마지막 스위치가 아직 켜져 있었다. 소연이 스위치에서 손을 치우지 않았다. 소율이 로비 소파 팔걸이에 에코백을 올렸다. 용식이 출구 방향으로 걷지 않았다.

## [성인씬 #1 - ep.129]

- 장소: 야근 후 1층 로비 / 마지막 스위치 켜진 상태
- 등장인물:
  - 김용식: 엘리베이터에서 내려 출구로 가지 않고 로비에 선 상태 / 소연과 소율 두 사람이 있다는 것을 확인함
    - 누적 성인씬 횟수: 150회
  - 박소연: 마지막 스위치에 손을 얹은 채 끄지 않고 로비에 서 있는 상태
    - 누적 성인씬 횟수: 3회
    - 외형 참고: 골격 자체가 아담하고 어깨가 좁아 상체가 한 품에 안길 듯 가냘픈데, 군살 하나 없이 매끄러운 복부에서 잘록한 허리로 이어지는 굴곡이 선명하며, 슬림한 힙 아래로 허벅지부터 발목까지 군더더기 없이 곧고 길게 뻗은 다리 라인이 탄탄하고 날씬한 태를 고스란히 드러내는 몸매예요. 맑고 화사한 피부, 웃을 때 달게 휘어지는 순한 눈매, 붉은 기 도는 브라운 단발.
    - 성격 참고: 감정이 격해지면 더 많이 웃으려다 눈을 제대로 못 마주치는 타입 / 마지막 스위치를 끄지 않은 것이 아직 나갈 준비가 안 됐다는 신호 / 좋아하는 사람 앞에서 짧은 접촉에도 귀 끝이 붉어짐
    - 남자친구 유무: 없음
  - 임소율: 에코백을 소파 팔걸이에 올린 채 로비에 서 있는 상태
    - 누적 성인씬 횟수: 5회
    - 외형 참고: 볼륨감 있으면서도 생기 있고 활동적인 인상을 주어 과하게 느껴지지 않는 체형. 균형 잡힌 어깨와 존재감 있는 볼륨. 둥근 얼굴형에 강아지상 눈매와 선명한 보조개, 야근 끝자락에 S컬 웨이브 헤어가 살짝 흐트러진 상태.
    - 성격 참고: 혼자 있을 때 외로움이 폭발적으로 몰려오는 타입 / 에코백을 팔걸이에 올린 것이 나갈 생각이 없다는 무의식적 행동 / 용식 앞에서 말이 많아지다 갑자기 멈추는 패턴
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 야근 후 근무복
  - 박소연: 프론트데스크 근무복, 마지막 스위치 쪽에 서 있음
  - 임소율: 야근 후 근무복, 에코백을 소파 팔걸이에 올린 상태
- 이미지 포인트: 마지막 스위치가 켜진 텅 빈 로비에서 소연이 스위치에 손을 얹고 소율이 에코백을 내려두고 용식이 출구 방향을 향하지 않은 채 셋이 선 순간
- 표정 포인트:
  - 김용식: 소연이 스위치를 끄지 않은 것과 소율이 에코백을 내려둔 것을 번갈아 보는 표정
  - 박소연: 스위치 위에 손을 올린 채 용식이 출구로 가지 않는 것을 확인하는 표정, 귀 끝이 붉어지려는 직전
  - 임소율: 에코백을 올려두고 용식과 소연 사이 거리를 보다가 멈추는 표정, 보조개가 사라진 진지한 얼굴
- 손 / 시선 포인트:
  - 김용식: 손 빈 상태 / 소연 스위치와 소율 에코백 사이
  - 박소연: 스위치 위 손 / 용식 방향
  - 임소율: 소파 팔걸이에 에코백 올린 상태 / 용식과 소연 사이
- 복장 상태: 소연 프론트데스크 유니폼 그대로, 소율 야근 후 재킷이 느슨해진 상태
- 배경 소품 강조: 마지막 켜진 스위치 / 소파 팔걸이 위 에코백 / 텅 빈 1층 로비
- 소품 / 환경: 야근 후 1층 로비, 스위치 하나만 켜진 조용한 공간
- 분위기 키워드: 야근 후 텅 빈 로비 / 마지막 스위치 / 나가지 않은 셋
- 직전 맥락: 야근 후 소연이 로비 스위치를 끄는 중 마지막 하나가 남았을 때 엘리베이터에서 소율과 용식이 내려왔다. 소연이 마지막 스위치에 손을 얹었다. 소율이 에코백을 소파 팔걸이에 올렸다. 용식이 출구로 걷지 않았다.
- 관계 단계: 프론트데스크 직원과 같은 건물 다른 층 직원 — 야근 후 1층 로비에서 마지막 스위치를 사이에 두고 셋이 선 거리
- 현재 구도: 박소연 ↔ 용식 / 임소율 ↔ 용식 / 박소연 ↔ 임소율
- 합의 상태: 소연이 마지막 스위치를 끄지 않은 것 / 소율이 에코백을 내려둔 것 / 용식이 출구로 가지 않은 것
- 씬 이후 감정 방향: 소연은 다음날 아침 스위치 번호를 확인할 때 마지막 번호를 먼저 보게 될 것이다 / 소율은 에코백을 소파 팔걸이에 올렸다는 사실을 귀가하다가 떠올릴 것이다

마지막 스위치가 꺼졌다. 소연이 스위치 패널에서 물러나 데스크 안쪽으로 들어갔다. 소율이 소파 팔걸이에 올려둔 에코백을 두고 데스크 쪽으로 걸어왔다. 카운터 위에 팔꿈치를 올렸다. 용식이 출구로 걷지 않고 카운터 앞에서 멈췄다. 소연이 데스크 안쪽 서랍을 열었다가 닫지 않았다. 카운터를 사이에 두고 셋이 있었다.

## [성인씬 #2 - ep.129]

- 장소: 1층 프론트데스크 카운터 안쪽 / 로비 마지막 스위치가 꺼진 직후
- 등장인물:
  - 김용식: 카운터 앞에서 출구로 가지 않고 멈춘 상태 / 소연이 데스크 안쪽에, 소율이 카운터 바깥쪽에 있다는 것을 확인함
    - 누적 성인씬 횟수: 151회
  - 박소연: 데스크 안쪽에서 서랍을 열고 닫지 않은 상태
    - 누적 성인씬 횟수: 4회
    - 외형 참고: 골격 자체가 아담하고 어깨가 좁아 상체가 한 품에 안길 듯 가냘픈데, 군살 하나 없이 매끄러운 복부에서 잘록한 허리로 이어지는 굴곡이 선명하며, 슬림한 힙 아래로 허벅지부터 발목까지 군더더기 없이 곧고 길게 뻗은 다리 라인이 탄탄하고 날씬한 태를 고스란히 드러내는 몸매예요. 카운터 안쪽에 선 자세로 조명이 줄어든 로비에 서 있는 상태.
    - 성격 참고: 진지한 감정을 꺼낼 때 무겁게 만들기 싫어서 애교와 농담으로 포장하는 타입 / 서랍을 닫지 않은 것이 다음 행동을 아직 결정하지 않았다는 신호 / 좋아하는 사람 앞에서 빠르게 말하다 눈을 정면으로 못 마주치는 패턴
    - 남자친구 유무: 없음
  - 임소율: 카운터 바깥쪽에서 팔꿈치를 올린 채 서 있는 상태
    - 누적 성인씬 횟수: 6회
    - 외형 참고: 볼륨감 있으면서도 생기 있고 활동적인 인상을 주어 과하게 느껴지지 않는 체형. 균형 잡힌 어깨와 존재감 있는 볼륨. 에코백을 소파에 두고 온 채 카운터에 팔꿈치를 올린 상태.
    - 성격 참고: 거절을 잘 못하고 속마음이 얼굴에 바로 드러나는 타입 / 카운터에 팔꿈치를 올린 것이 가까워지고 싶다는 행동 / 용식이 자신을 진지하게 바라볼 때 말문이 막히는 패턴
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 야근 후 근무복, 카운터 앞에 선 상태
  - 박소연: 프론트데스크 유니폼, 데스크 안쪽에 선 상태
  - 임소율: 야근 후 근무복, 카운터에 팔꿈치를 올린 상태
- 이미지 포인트: 카운터를 사이에 두고 소연이 안쪽 서랍을 열어둔 채, 소율이 팔꿈치를 올린 채, 용식이 앞에서 출구로 가지 않고 셋이 마주한 순간
- 표정 포인트:
  - 김용식: 소연이 서랍을 닫지 않은 것을 보다가 소율이 팔꿈치를 올린 쪽으로 시선을 옮기는 표정
  - 박소연: 서랍 손잡이를 쥔 채 용식이 카운터 앞에 멈춰 있는 것을 확인하는 표정
  - 임소율: 카운터에 팔꿈치를 올린 채 소연과 용식 사이 거리를 보다가 시선이 멈추는 표정
- 손 / 시선 포인트:
  - 김용식: 카운터 앞 / 소연 쪽과 소율 쪽 사이
  - 박소연: 열린 서랍 손잡이 / 용식 방향
  - 임소율: 카운터 위 팔꿈치 / 용식과 소연 방향
- 복장 상태: 소연 프론트데스크 유니폼 목선, 소율 재킷 느슨해진 상태
- 배경 소품 강조: 열린 채로인 서랍 / 카운터 위 팔꿈치 / 꺼진 로비 조명
- 소품 / 환경: 1층 프론트데스크 카운터 안쪽, 조명이 줄어든 야근 후 로비
- 분위기 키워드: 카운터 안과 밖 / 닫히지 않은 서랍 / 팔꿈치를 올린 거리
- 직전 맥락: 마지막 스위치가 꺼졌다. 소연이 데스크 안쪽으로 들어갔다. 소율이 카운터에 팔꿈치를 올렸다. 용식이 카운터 앞에서 멈췄다. 소연이 서랍을 열고 닫지 않았다. 셋이 카운터를 사이에 두고 있었다.
