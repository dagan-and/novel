# ep.088 — 주말 버스, 내릴 정류장을 지나쳤다

히로인: 최윤서
키워드: 주말 한산한 버스 / 이어폰 없음 / 지나친 정류장 / 귀갓길 골목

---

주말 오후 버스였다. 사람이 적었다. 윤서가 창가 자리에 먼저 앉아 있었다. 이어폰을 끼고 있지 않았다. 용식이 탔고 옆자리에 앉았다. 버스가 흔들릴 때마다 어깨가 닿았다. 윤서는 창밖을 보지 않고 정면을 봤다. 용식의 정류장이 스쳤다. 버스가 멈추지 않았고 용식도 일어나지 않았다. 다음 정류장에서 두 사람이 동시에 내렸다. 귀갓길이 같은 방향이었다. 가로등이 켜진 골목이 보였다. 윤서가 먼저 골목 안으로 걸음을 옮겼다. 용식이 바로 뒤를 따라갔다.

## [성인씬 #11 - ep.088]

- 장소: 귀갓길 골목 안쪽 / 골목이 꺾이는 지점 모텔 앞
- 등장인물:
  - 김용식: 내릴 정류장을 지나친 채 옆자리에 앉아 있었다 / 골목 안에서 윤서 뒤에 서 있다
    - 누적 성인씬 횟수: 70회 (이 씬 이전 기준)
  - 최윤서: 이어폰 없이 창가에 앉아 있었다 / 골목 안으로 먼저 걸어 들어간 뒤 멈춘 상태
    - 누적 성인씬 횟수: 10회 (이 씬 이전 기준)
    - 외형 참고: 늘씬하고 마른 편으로 어깨선이 좁고 목선이 길며 허리가 자연스럽게 잘록하다. 흑갈색 긴 웨이브 컬이 허리 부근까지 흘러내리며, 골목 불빛 아래에서 빛을 받으면 짙은 갈색이 은은하게 드러난다.
    - 성격 참고: 빠진 장면과 늦은 대답을 그냥 넘기지 못하는 집요함 / 현재 감정보다 기억을 먼저 축적하는 타입 / 용식이 이어폰을 꺼내지 않은 것을 확인했다
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 주말 외출 차림. 얇은 가을 점퍼에 흰 티.
  - 최윤서: 긴 코트 아래 니트 원피스. 버스카드를 주머니에 넣은 상태.
- 이미지 포인트: 골목이 꺾이는 지점에서 윤서가 멈추고, 뒤따라온 용식과 어깨 한 뼘 간격으로 마주 보는 순간
- 표정 포인트:
  - 김용식: 윤서가 멈추는 걸 보고 걸음을 늦췄다 / 한 발 앞에서 눈을 맞추는 표정이 담담하다
  - 최윤서: 등을 보이다가 돌아섰을 때 입꼬리가 미세하게 올라가 있다 / 눈이 용식 쪽에서 내려가지 않는다
- 손 / 시선 포인트:
  - 김용식: 한 손이 코트 주머니에서 나와 윤서 쪽으로 향한다 / 윤서 눈 위
  - 최윤서: 버스카드를 쥐고 있던 손이 주머니에서 나온 채 옆에 있다 / 용식 턱 아래
- 복장 상태: 윤서 코트 깃이 바람에 벌어진 채다. 니트 원피스 목선이 드러나 있다.
- 배경 소품 강조: 버스카드 / 골목 가로등 불빛 / 모텔 간판 불빛이 꺾이는 지점에서 비침
- 소품 / 환경: 주말 낮이 지나 저녁으로 넘어가는 골목, 사람이 드물다
- 분위기 키워드: 내리지 않은 선택 / 먼저 걷기 시작한 것의 무게 / 기억보다 먼저 온 몸
- 관계 단계: 같은 출근버스 반복 탑승 이웃 / 이어폰 없이 나란히 앉은 것이 쌓인 이후
- 현재 구도: 최윤서 ↔ 용식
- 합의 상태: 이어폰 없이 나란히 앉은 두 사람 / 정류장을 지나쳐도 내리지 않은 용식 / 골목 안으로 먼저 걸은 윤서 / 멈춘 뒤 돌아선 윤서
- 씬 이후 감정 방향: 윤서는 버스카드를 코트 안 주머니에 넣을 것이다 / 용식은 골목에서 나올 때 윤서보다 먼저 걸음을 뗄 것이다
