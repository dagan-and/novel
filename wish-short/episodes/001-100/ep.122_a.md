# ep.122 — 분리수거, 계단, 현관문

히로인: 이채영
키워드: 분리수거 날 / 봉투 끈 / 3층 계단 / 현관문 열림

---

분리수거 날이었다. 채영이 봉투 하나를 들고 계단으로 나왔다. 끈이 다시 엉켜 있었다. 계단 아래에서 용식이 올라오고 있었다. 채영 층에서 멈췄다. 봉투 끈을 풀었다. 손잡이가 채영 손으로 넘어왔다. 현관 쪽으로 함께 걸어갔다. 문을 열었다. 봉투를 문 안에 내려뒀다. 용식이 내려가지 않았다.

---

## [성인씬 #1 - ep.122]

- 장소: 아파트 3층 현관 / 계단에서 현관 안쪽
- 등장인물:
  - 김용식: 계단에서 올라오다 채영 층에서 멈춘 상태 / 봉투 끈을 풀어 주고 현관문이 열린 채 내려가지 않음
    - 누적 성인씬 횟수: 142회
  - 이채영: 봉투를 들고 분리수거 계단에서 내려오다 끈이 엉킨 채 용식을 만난 상태 / 봉투를 문 안에 내려두고 현관문 앞에 서 있음
    - 누적 성인씬 횟수: 8회
    - 외형 참고: 매우 마른 슬림 체형. 어깨가 좁고 부드럽게 떨어지는 직선형 실루엣, 목이 길고 가늘어 목선이 깔끔함. 작고 갸름한 계란형 얼굴, 세로 폭이 적당한 긴 눈, 눈꼬리 살짝 올라감, 짙은 눈동자. 흑발에 가까운 긴 생머리 스트레이트, 풀뱅 앞머리.
    - 성격 참고: 반복 접촉에 누구보다 오래 꼼꼼하게 의미를 붙이는 타입 / 현관에서 기회가 왔을 때 실제보다 훨씬 큰 일처럼 느껴져 망설임 / 봉투 끈이 다시 엉킨 것 자체가 다음 분리수거 날을 기다렸다는 신호
    - 남자친구 유무: 있음
- 의상:
  - 김용식: 퇴근 후 사복
  - 이채영: 집 안 편한 차림, 분리수거 봉투를 손에 들고 있음
- 이미지 포인트: 아파트 3층 현관문이 열린 채 봉투가 문 안에 놓이고 용식이 내려가지 않은 순간
- 표정 포인트:
  - 김용식: 현관문이 열린 채 내려가지 않고 채영 방향을 보는 순간
  - 이채영: 봉투를 내려두고 현관문 앞에 선 채 용식이 내려가지 않은 것을 보는 표정
- 손 / 시선 포인트:
  - 김용식: 현관문 옆 벽에 손 / 채영 방향
  - 이채영: 봉투를 내려둔 뒤 현관문 손잡이 위에 손 / 용식 방향
- 복장 상태: 채영 집 안 편한 차림, 목선이 넓은 티셔츠 상태
- 배경 소품 강조: 분리수거 봉투 / 열린 현관문 / 계단 쪽 복도 조명
- 소품 / 환경: 아파트 3층 복도, 현관문이 안쪽으로 열린 상태
- 분위기 키워드: 분리수거 봉투 끈 / 열린 현관문 / 내려가지 않은 용식
