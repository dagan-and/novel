# ep.086 — 분리수거 날, 봉투 하나

히로인: 이채영
키워드: 분리수거 / 봉투 하나 / 계단 / 자취방 현관

---

분리수거 요일이었다. 이채영은 봉투를 하나만 묶었다. 평소엔 둘이었다. 계단 문을 열었을 때 용식이 반 층 위에서 내려오고 있었다. 이채영은 손에 든 봉투를 내리지 않았다. 용식이 봉투를 내려다보다가 먼저 아래로 내려갔다. 분리수거 함 앞에서 이채영이 봉투를 내려놓으려다 끈이 엉켜 멈췄다. 용식이 끈을 잡아당겨 풀었다. 둘이 동시에 계단을 올라갔다. 이채영 층에서 이채영이 먼저 멈췄다. 용식은 그 위층인데 한 발도 계단을 더 오르지 않았다. 이채영이 현관 앞에 서 있었고 용식이 바로 뒤에 있었다.

- 장소: 이채영 자취방 현관 앞 → 자취방 안
- 등장인물:
  - 김용식: 계단에서 봉투 끈을 풀어 줬다 / 이채영 층에서 멈춘 채 뒤에 서 있다
    - 누적 성인씬 횟수: 68회 (이 씬 이전 기준)
  - 이채영: 분리수거 봉투를 하나만 들고 내려왔다 / 현관 앞에서 뒤를 돌아보지 않은 채 서 있다
    - 누적 성인씬 횟수: 6회 (이 씬 이전 기준)
    - 외형 참고: 매우 마른 슬림 체형으로 어깨가 좁고 직선형 실루엣이며 목이 길고 쇄골이 선명하다. 풀뱅 앞머리 아래로 긴 생머리가 흘러 청순하고 절제된 인상이다.
    - 성격 참고: 반복되는 작은 접촉에 오래 꼼꼼하게 의미를 붙이는 타입 / 행동보다 기회를 기다리는 쪽 / 용식 앞에서 반응이 0.5박자 늦어지고 눈을 먼저 내린다
    - 남자친구 유무: 있음 — 배신·죄책감·욕망 충돌을 긴장 맥락으로 활용한다
- 의상:
  - 김용식: 귀가 후 편한 차림. 얇은 긴팔 티셔츠.
  - 이채영: 집에서 입는 얇은 긴소매. 목선이 넓게 파인 편이다.
- 이미지 포인트: 현관문 앞에서 이채영이 뒤를 돌아보는 순간, 용식이 한 발도 물러서지 않은 채 그 자리에 있다
- 표정 포인트:
  - 김용식: 표정이 없다가 이채영이 뒤돌았을 때 눈이 잠깐 내려간다
  - 이채영: 돌아서면서 얼굴이 굳었다가 용식이 그 자리에 있다는 걸 확인하고 풀린다
- 손 / 시선 포인트:
  - 김용식: 한 손이 이채영 뒤에서 문틀 쪽으로 향한다 / 이채영의 목선 쪽
  - 이채영: 현관 손잡이를 잡고 있다 / 용식 어깨 아래
- 복장 상태: 이채영 목선이 한쪽으로 흘러내려 쇄골 위가 드러난다
- 배경 소품 강조: 계단 복도 형광등 / 분리수거 봉투 없이 빈 손 / 현관 도어록 번호판
- 소품 / 환경: 층간 소등이 반 켜진 복도, 윗집 소리 없음
- 분위기 키워드: 기다린 것이 맞았다는 확인 / 말 없는 승인 / 반층의 거리
- 관계 단계: 같은 아파트 위아래 층 이웃 / 이름을 아는 사이 / 반복 마주침이 쌓인 뒤 첫 정지
- 현재 구도: 이채영 ↔ 용식
- 합의 상태: 봉투를 하나만 들고 내려온 이채영 / 이채영 층에서 멈춘 용식 / 문을 열지 않은 채 뒤를 돌아본 이채영 / 물러서지 않은 용식
- 씬 이후 감정 방향: 이채영은 문을 다시 잠그지 않을 것이다 / 용식은 위층으로 올라가는 시간이 늦어질 것이다
