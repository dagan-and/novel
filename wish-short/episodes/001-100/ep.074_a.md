# ep.074 — 귀국 직후, 골목 입구, 캐리어 손잡이

히로인: 채수빈
키워드: 귀국 직후 피곤한 상태 / 동네 골목 입구 우연 마주침 / 캐리어 손잡이 / 방어가 낮은 저녁

---

저녁 여덟 시가 지나 있었다. 수빈이 캐리어를 끌고 골목 입구에서 꺾었다. 공항에서 두 시간이 걸렸고 어깨가 무거웠다. 반묶음 머리가 흘러내려 있었다. 골목 안쪽에서 용식이 걸어오고 있었다. 두 사람이 같은 방향으로 멈췄다. 오랜만이었다. 수빈이 먼저 알아봤다. 캐리어 손잡이를 더 당겼다. 용식이 천천히 왔다. 수빈 옆으로 걸음을 맞췄다. 귀국이냐고 묻지 않았다. 캐리어가 있는 쪽으로 자리를 바꿨다. 골목이 좁아지는 구간이 있었다. 두 사람의 간격이 좁아졌다. 수빈이 입꼬리가 올라가는 것을 의식했다. 비행 중 자세가 아니었다. 자취방 입구까지 세 블록이 남았다.

---

## [성인씬 #1 - ep.074]

- 장소: 동네 골목 / 수빈 자취방 입구
- 등장인물:
  - 김용식: 귀갓길 저녁 골목에서 수빈 옆 자리를 바꿔 걷는 상태
    - 누적 성인씬 횟수: 77회
  - 채수빈: 귀국 직후 피곤한 상태로 캐리어를 끌고 걸어가다 용식과 걸음을 맞추는 중
    - 누적 성인씬 횟수: 6회
    - 외형 참고: 슬림하고 여린 체형, 목이 길고 가늘어 상체가 답답해 보이지 않음. 반묶음(하프업) 중단발, 끝이 C컬로 안쪽으로 말린 다크브라운. 무표정에서도 입꼬리가 자연스럽게 올라가 온화한 인상.
    - 성격 참고: 퇴근 후·귀국 직후엔 직업적 긴장이 풀려 방어가 낮음 / 좋아하는 사람 앞에서 자세를 신경 쓰다 표정 관리에서 빈틈이 생기는 타입
    - 남자친구 유무: **있음** — 배신·죄책감·욕망 충돌
- 의상:
  - 김용식: 퇴근 후 와이셔츠, 재킷 한 손에 든 상태
  - 채수빈: 귀국 후 사복 / 반묶음 흘러내린 상태
- 이미지 포인트: 좁아지는 골목 구간에서 두 사람의 간격이 좁아지고 수빈이 입꼬리가 올라가는 것을 의식하는 순간
- 표정 포인트:
  - 김용식: 캐리어 쪽 자리를 바꿔 걸으며 수빈 쪽을 가끔 보는 표정
  - 채수빈: 입꼬리 올라가는 것을 누르다가 실패하는 표정 — 비행 중 자세가 아님
- 손 / 시선 포인트:
  - 김용식: 재킷을 한 손에 든 손 / 수빈 캐리어 쪽 방향
  - 채수빈: 캐리어 손잡이를 당기는 손 / 골목 앞을 보다가 용식 쪽으로 내려가는 시선
- 복장 상태: 수빈 반묶음 머리 흘러내린 상태 / 용식 셔츠 소매 걷어 올려진 상태
- 배경 소품 강조: 캐리어 / 좁아지는 골목 구간 / 저녁 가로등 / 흘러내린 반묶음
- 소품 / 환경: 저녁 동네 골목, 두 사람 같은 방향 귀갓길, 수빈 자취방 세 블록 전
- 분위기 키워드: 귀국 직후 방어가 낮은 상태 / 캐리어 쪽 자리 바꿔 걷는 용식 / 눌러도 올라가는 입꼬리
- 직전 맥락: ep.058 현관 앞 이후 오랜 공백 / 귀국 직후 피곤한 저녁 골목 / 골목 입구에서 우연히 마주쳐 걸음을 맞춤
- 관계 단계: 같은 동네 자취생 / ep.058 이후 첫 재회 / 자취방 입구 세 블록 앞 좁아진 골목
