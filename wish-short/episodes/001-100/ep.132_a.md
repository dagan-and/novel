# ep.132 — 새벽 귀국, 편의점, 캐리어 손잡이

히로인: 채수빈
키워드: 새벽 귀국 / 편의점 봉투 / 캐리어 손잡이 / 건물 입구

---

새벽 두 시가 지나 있었다. 채수빈이 캐리어를 끌고 편의점 자동문 안으로 들어왔다. 귀국 후 샤워 전이었다. 카운터 쪽으로 걸어가다 계산대 앞에 먼저 서 있는 사람이 있었다. 용식이었다. 봉투가 이미 들려 있었다. 수빈이 음료 쪽으로 방향을 틀었다. 하나를 집어 계산대 줄에 섰다. 용식이 봉투를 들고 먼저 나갔다. 수빈이 계산을 마치고 따라 나왔다. 골목이 같은 방향이었다. 캐리어 바퀴가 보도블록 틈에 걸렸다. 손잡이 위로 손이 하나 더 올라왔다. 수빈이 손을 놓지 않았다. 두 손이 같은 손잡이를 잡은 채 건물 입구 계단이 보이는 데까지 걸었다.

## [성인씬 #1 - ep.132]

- 장소: 채수빈 자취방 건물 입구 계단 앞
- 등장인물:
  - 김용식: 새벽 편의점에서 먼저 있다가 수빈과 골목 동선이 겹친 상태 / 캐리어 손잡이를 같이 잡은 채 계단 앞에 멈춰 있다
    - 누적 성인씬 횟수: 131회
  - 채수빈: 귀국 직후 피로가 풀리지 않은 상태 / 캐리어 손잡이를 놓지 않은 채 계단 앞에서 멈춰 있다
    - 누적 성인씬 횟수: 8회
    - 외형 참고: 슬림한 체형. 어깨 폭이 넓지 않고 완만한 직선형이며 목이 길고 가늘어 상체가 답답해 보이지 않는다. 작은 골격에 가녀린 실루엣으로 얼굴이 상대적으로 작아 전체적으로 비율이 좋아 보이는 타입이다. 귀국 직후 피로로 머리카락이 느슨하게 내려와 있고, 입꼬리가 자연스럽게 올라가 있어 피곤한 얼굴에서도 온화한 인상이 먼저 보인다.
    - 성격 참고: 비행 후 직업적 긴장이 풀린 상태에서 방어가 낮아짐 / 좋아하는 사람 앞에서 웃음이 일찍 나오고 시선이 자주 감 / 먼저 다가가지 못하고 우연한 마주침에 지나치게 의미를 두는 성향
    - 남자친구 유무: 있음
- 의상:
  - 김용식: 편의점 봉투 든 사복
  - 채수빈: 비행 사복 (편한 트레이닝 상의, 슬랙스), 어깨에 캐리어 끈 가방
- 이미지 포인트: 건물 입구등 아래, 두 손이 같은 캐리어 손잡이를 잡은 채 계단 앞에서 멈춘 순간
- 표정 포인트:
  - 김용식: 손잡이를 잡은 채 수빈 쪽을 내려다본다
  - 채수빈: 피로한 얼굴로 위를 보지 못하다가 계단 앞에서 멈추는 순간 눈이 마주침
- 손/시선 포인트:
  - 김용식: 캐리어 손잡이 위 / 수빈 얼굴 쪽
  - 채수빈: 손잡이를 두 손으로 쥔 채 / 아래에서 용식 손으로
- 복장 상태: 채수빈 — 비행 후 사복으로 갈아입어 허리 밴드가 느슨하게 내려앉아 있음. 어깨끈 가방이 한쪽으로 흘러 있다
- 배경 소품 강조: 캐리어 손잡이 / 편의점 봉투 / 건물 입구등
- 소품/환경: 새벽 골목. 건물 입구 계단 두 개. 자동문이 닫혀 있다
- 분위기 키워드: 새벽 귀국 피로 / 잡힌 손잡이 / 계단 앞
- 직전 맥락: 새벽 편의점에서 마주쳤고 골목 방향이 같았다. 바퀴가 걸렸고 용식이 손잡이를 잡았다. 수빈이 손을 놓지 않은 채 계단 앞까지 걸었다
- 관계 단계: 같은 동네 자취 주민 / 귀국 후 편의점과 골목에서 반복 마주치는 사이
- 현재 구도: 채수빈 ↔ 용식
- 합의 상태: 수빈이 손잡이를 놓지 않았다 / 용식이 먼저 내려두지 않았다 / 계단 앞에서 둘 다 멈췄다
- 씬 이후 감정 방향: 수빈이 먼저 계단을 오를 것이다 / 용식이 캐리어를 계단 위까지 들어올릴 것이다
