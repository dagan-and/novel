# ep.124 — 야근 탕비실, 노트와 에너지바

히로인: 정다은 × 이주희
키워드: 야근 후 / 탕비실 선반 / 노트 / 에너지바 / 비상계단

---

야근이 끝났다. 다은이 탕비실로 들어왔다. 선반 위를 봤다. 노트가 거기 있었다. 주희가 에너지바 두 개를 들고 이미 탕비실 안에 있었다. 에너지바 하나를 선반에 올려뒀다. 노트 옆에 놓였다. 다은이 노트를 집지 않았다. 주희가 에너지바를 열지 않았다. 용식이 탕비실 문을 열고 들어왔다. 탕비실 문이 뒤로 닫혔다. 선반 위에 노트와 에너지바가 나란히 있었다. 셋이었다.

## [성인씬 #1 - ep.124]

- 장소: 야근 후 탕비실 / 선반 앞
- 등장인물:
  - 김용식: 탕비실로 들어온 상태 / 탕비실 문이 닫힌 채 선반 위 노트와 에너지바를 보고 있음
    - 누적 성인씬 횟수: 144회
  - 정다은: 선반 위 노트를 가지러 탕비실에 들어왔지만 집지 않은 상태 / 선반 앞에 서 있음
    - 누적 성인씬 횟수: 10회
    - 외형 참고: 키가 큰 편에 길고 반듯한 실루엣. 어깨선이 얇게 곧고 허리선이 깔끔하게 잡힘. 갸름한 얼굴형에 선이 또렷한 이목구비, 길고 선명한 눈매. 어두운 흑갈색 머리를 낮게 묶거나 틀어 올린 상태. 야근 후 귀 옆으로 짧은 머리카락이 조금 흘러내린 상태.
    - 성격 참고: 업무 명분 뒤에 사적인 감정을 숨기는 타입 / 노트를 선반에 두고 나온 것 자체가 돌아오겠다는 신호 / 선반 위 노트를 집지 않은 것이 아직 나가지 않겠다는 뜻
    - 남자친구 유무: 있음
  - 이주희: 에너지바 두 개를 들고 탕비실 안에 있다가 하나를 선반에 올려둔 상태 / 에너지바를 열지 않고 선반 방향을 보고 있음
    - 누적 성인씬 횟수: 11회
    - 외형 참고: 골반에 비해 허리가 가늘고 잘록한 체형. 살집 없이 마른 편이지만 허벅지와 종아리로 이어지는 다리 라인이 길고 탄탄함. 정돈된 둥근 이마에 크고 순한 쌍꺼풀 눈, 앳된 얼굴. 쇄골까지 오는 레이어드 컷에 가벼운 앞머리.
    - 성격 참고: 몸으로 먼저 움직이는 현장형 / 에너지바를 선반에 올려둔 것이 이미 자리를 잡았다는 신호 / 에너지바를 열지 않은 것이 탕비실에서 나가지 않겠다는 뜻
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 야근 후 근무복 셔츠, 재킷 없음
  - 정다은: 야근 후 근무복, 머리가 약간 흐트러진 상태
  - 이주희: 야근 후 근무복, 에너지바를 손에 들고 있음
- 이미지 포인트: 야근 후 탕비실 선반 위에 노트와 에너지바가 나란히 놓이고 셋이 탕비실 안에 남은 순간
- 표정 포인트:
  - 김용식: 선반 위 노트와 에너지바를 보다가 다은과 주희 쪽으로 시선을 옮기는 순간
  - 정다은: 선반 위 노트를 집지 않고 용식 방향을 보는 표정, 검은 펜을 손에 쥔 채
  - 이주희: 에너지바를 열지 않고 선반 옆에서 다은과 용식 사이를 보는 표정
- 손 / 시선 포인트:
  - 김용식: 탕비실 문 손잡이 위에 손 / 선반과 두 사람 사이
  - 정다은: 검은 펜을 손에 쥔 채 / 선반과 용식 사이
  - 이주희: 에너지바를 손에 쥔 채 / 선반 방향
- 복장 상태:
  - 다은: 야근 후 블라우스 소매가 접혀 있고 귀 옆으로 머리카락이 흘러내린 상태
  - 주희: 야근 후 근무복 상단 단추 한 개가 풀린 상태
- 배경 소품 강조: 선반 위 노트 / 에너지바 / 닫힌 탕비실 문
- 소품 / 환경: 야근 후 조명 절반 꺼진 사무실 탕비실, 선반 위 조명만 켜진 공간
- 분위기 키워드: 야근 후 탕비실 / 노트와 에너지바 나란히 / 셋이 남은 공간
- 직전 맥락: 야근이 끝났다. 다은이 선반에 두고 온 노트를 가지러 탕비실에 들어왔다. 주희가 에너지바 두 개를 들고 이미 탕비실 안에 있었고 하나를 선반에 올려뒀다. 용식이 탕비실로 들어왔다. 탕비실 문이 닫혔다.
- 관계 단계: 같은 회사 직장 동료 셋 — 야근 후 탕비실에서 선반 위 노트와 에너지바를 앞에 두고 남은 거리
- 현재 구도: 정다은 ↔ 용식 ↔ 이주희
- 합의 상태: 다은이 노트를 선반에 두고 나갔다가 가지러 돌아온 것 / 주희가 에너지바를 선반에 올려두고 탕비실 안에 있던 것 / 용식이 탕비실로 들어와 문이 닫힌 것
- 씬 이후 감정 방향: 다은은 선반 위 노트를 집어 나가지 않을 것이다 / 주희는 에너지바를 열지 않을 것이다
