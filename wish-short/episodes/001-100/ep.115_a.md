# ep.115 — 야근, 텅 빈 로비, 마지막 스위치

히로인: 박소연
키워드: 야근 마감 / 텅 빈 로비 / 마지막 스위치 / 번호 순서

---

마감이 늦은 날이었다. 소연이 1층 로비에 혼자 남아 있었다. 프론트데스크 서랍을 닫고 스위치 번호를 확인했다. 번호 순서대로 꺼 나갔다. 마지막 하나가 남아 있었다. 엘리베이터 알림이 울렸다. 용식이 내려왔다. 가방을 들고 로비를 가로질러 출구 쪽으로 걸었다. 소연이 마지막 스위치 앞에 서 있었다. 용식이 그 앞에서 멈췄다. 로비에 두 사람이었다. 스위치에는 손이 닿지 않은 채였다. 조명 하나가 두 사람 위를 비추고 있었다.

## [성인씬 #1 - ep.115]

- 장소: 야근 후 1층 로비 / 프론트데스크 안쪽
- 등장인물:
  - 김용식: 야근 후 내려온 상태 / 로비를 가로지르다 마지막 스위치 앞에 선 소연 앞에서 멈춘 자세
    - 누적 성인씬 횟수: 135회
  - 박소연: 마지막 스위치 하나를 남겨두고 서 있는 상태 / 손이 스위치에 닿지 않은 채
    - 누적 성인씬 횟수: 2회
    - 외형 참고: 골격 자체가 아담하고 어깨가 좁아 상체가 한 품에 안길 듯 가냘픈데, 군살 하나 없이 매끄러운 복부에서 잘록한 허리로 이어지는 굴곡이 선명하며, 슬림한 힙 아래로 허벅지부터 발목까지 군더더기 없이 곧고 길게 뻗은 다리 라인이 탄탄하고 날씬한 태를 고스란히 드러내는 몸매. 붉은 기가 도는 브라운 단발 보브컷, 프론트데스크 근무 복장.
    - 성격 참고: 밝고 상냥하지만 감정이 무거워지면 웃음으로 덮으려는 편 / 스위치 번호 순서를 외우고 있었다는 것이 오래 이 자리에 있었다는 신호 / 마지막 스위치를 끄지 않고 멈춘 것
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 야근 후 셔츠, 가방
  - 박소연: 프론트데스크 근무 블라우스
- 이미지 포인트: 조명 하나만 남은 로비에서 소연이 마지막 스위치 앞에 서 있고 용식이 그 앞에 멈춘 순간
- 표정 포인트:
  - 김용식: 소연이 스위치를 누르지 않는 것을 보고 있는 표정
  - 박소연: 스위치 쪽을 보다가 용식을 올려다보는 순간, 평소보다 말이 없는 표정
- 손 / 시선 포인트:
  - 김용식: 가방 끈에 손 / 소연 얼굴
  - 박소연: 스위치 패널 옆에 손 / 용식 방향
- 복장 상태: 소연 블라우스 목선 단추가 마감 끝 무렵 위쪽 하나 풀린 상태, 용식 셔츠 소매 걷어 올림
- 배경 소품 강조: 스위치 패널 / 프론트데스크 / 꺼진 로비 조명
- 소품 / 환경: 야근 후 텅 빈 1층 로비, 조명 하나만 켜진 공간
- 분위기 키워드: 마감 후 정적 / 마지막 스위치 / 둘만 남은 로비
- 직전 맥락: 소연이 로비 스위치를 번호 순서대로 껐다. 마지막 하나가 남았다. 용식이 내려와 로비를 건너다 소연 앞에서 멈췄다.
- 관계 단계: 같은 회사 프론트데스크 직원과 사원 — 텅 빈 로비에 둘만 남은 거리
- 현재 구도: 박소연 ↔ 용식
- 합의 상태: 소연이 스위치 번호를 순서대로 외우고 있었다는 것 / 마지막 스위치를 끄지 않고 멈춘 것 / 용식이 출구 대신 소연 앞에 선 것
- 씬 이후 감정 방향: 소연은 마지막 스위치를 끄고 나갈 것이다 / 용식은 건물을 먼저 나가지 않을 것이다
