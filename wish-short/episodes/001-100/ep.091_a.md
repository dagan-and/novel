# ep.091 — 야근 중 탕비실, 에너지바 두 개

히로인: 이주희
키워드: 야근 탕비실 / 에너지바 / 비상계단 / 먼저 움직이는 쪽

---

야근이 길어졌다. 팀원 대부분이 나간 뒤에도 용식은 자리에 남아 있었다. 탕비실에서 이주희가 나왔다. 손에 에너지바 두 개가 들려 있었다. 하나를 용식 책상 끄트머리에 내려놓고 그냥 돌아가지 않았다. 용식이 포장을 뜯지 않은 채 봤다. 주희가 탕비실 쪽으로 고개를 했다. 두 사람이 탕비실 안으로 들어갔다. 주희가 전등을 올리지 않았다. 복도 불빛만 들어왔다. 주희가 자신의 에너지바 포장을 벗기다가 멈췄다. 용식이 먼저 비상계단 방향으로 걸었다. 주희가 포장을 책상 위에 놓고 뒤를 따랐다.

- 장소: 야근 후 비상계단 / 계단참 중간층

  - 김용식: 야근 중 자리에 남아 있었다 / 비상계단으로 먼저 걸어 들어간 상태

    - 누적 성인씬 횟수: 8회 (이 씬 이전 기준)
    - 외형 참고: 허리가 잘록하게 파이고 다리 라인이 길고 슬림한 체형이다. 쇄골 아래까지 오는 레이어드 컷 다크브라운 헤어에 둥근 눈과 밝은 미소가 발랄하고 청순한 인상을 만든다.
    - 성격 참고: 몸이 먼저 움직이는 현장형 / 불안하면 움직여서 상황을 바꾸는 타입 / 사적인 고백보다 챙기는 행동이 먼저 나오는 패턴
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 야근 중 셔츠 소매를 걷은 상태. 재킷이 자리에 있다.
  - 이주희: 활동적인 야근 차림. 캔버스백이 탕비실에 걸려 있다.
- 이미지 포인트: 비상계단 계단참 중간층에서 주희가 먼저 한 계단 내려와 눈높이가 같아진 순간
- 표정 포인트:
  - 김용식: 계단에 기댄 채 주희가 내려오는 것을 아래서 올려다보다가 시선을 내리지 않는다
  - 이주희: 포장을 두고 온 손을 옆에 내리고 용식 눈높이로 내려온 뒤 잠깐 멈춘다
- 손 / 시선 포인트:
  - 김용식: 계단 손잡이에 한 손을 걸친 채 / 주희 목선 아래
  - 이주희: 양손이 자기 옆에 있다가 한 손이 계단 벽면 쪽으로 간다 / 용식 어깨
- 복장 상태: 주희 상의 소매가 아까부터 한쪽이 약간 올려져 있다. 에너지바 포장 없이 빈 손이다.
- 배경 소품 강조: 복도에서 새어 들어오는 비상계단 불빛 / 뜯기지 않은 에너지바 (탕비실에 놓고 왔다) / 야근 중 비어가는 사무실 소리
- 소품 / 환경: 비상계단 내부, 스틸 손잡이와 콘크리트 벽, 계단등 하나
- 분위기 키워드: 먼저 움직인 것의 무게 / 에너지바를 내려놓은 손 / 눈높이가 같아진 계단 한 칸
- 관계 단계: 같은 회사 직장 동료 / 야근 반복 동선이 쌓인 뒤 탕비실에서 단둘 / 비상계단에 같이 들어온 첫 밤
- 현재 구도: 이주희 ↔ 용식
- 합의 상태: 전등을 올리지 않은 탕비실 / 용식이 먼저 비상계단으로 걸은 것 / 포장을 두고 따라 들어온 주희 / 한 계단 내려와 눈높이를 맞춘 것
- 씬 이후 감정 방향: 주희는 탕비실로 돌아가 에너지바를 챙길 것이다 / 용식은 재킷을 들고 계단을 내려갈 것이다
