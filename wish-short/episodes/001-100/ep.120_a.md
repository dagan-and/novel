# ep.120 — 코인세탁실, 알림음, 손잡이

히로인: 유하린
키워드: 지하 코인세탁실 / 세탁 알림음 / 문 손잡이 / 나란히

---

알림음이 울렸다. 하린이 세탁기 앞으로 걸어갔다. 손잡이에 손을 올렸다. 당기지 않았다. 용식이 세탁 봉지를 들고 지하로 내려왔다. 하린의 세탁기 옆 칸이 비어 있었다. 용식이 봉지를 내려놓고 옆에 섰다. 하린이 손잡이에서 손을 떼지 않았다. 용식이 하린 쪽으로 한 걸음 좁혔다. 나란히 선 채 두 사람 모두 문을 열지 않았다. 지하에 두 사람이었다.

## [성인씬 #1 - ep.120]

- 장소: 아파트 지하 코인세탁실 / 세탁기 앞
- 등장인물:
  - 김용식: 세탁 봉지를 들고 지하로 내려온 상태 / 빈 칸 옆에 봉지를 내려놓고 하린 옆에 선 자세
    - 누적 성인씬 횟수: 140회
  - 유하린: 세탁 알림음 후 세탁기 문 손잡이에 손을 올린 채 당기지 않고 있는 상태
    - 누적 성인씬 횟수: 10회
    - 외형 참고: 아담하고 여린 체형. 가녀린 어깨선에 허리 라인이 부드럽게 잘록하고, 가슴은 체구에 비해 은근히 도드라지는 편으로 전체적으로 보호본능을 자극하는 청순한 볼륨감. 작은 얼굴에 순하고 동그란 강아지상 눈매, 속쌍꺼풀, 짙은 갈색 눈동자, 투명한 피부 위로 홍조가 쉽게 올라옴. 중단발 C컬 머리카락이 얼굴선을 부드럽게 감쌈.
    - 성격 참고: 의지하고 싶다는 마음을 숨기지 못하는 편 / 가장 간절한 마음일수록 더 숨기려 함 / 세탁기 문 손잡이를 쥐고 당기지 않은 것이 옆에 서 줄 사람을 기다리는 신호
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 퇴근 후 사복, 세탁 봉지를 들고 있음
  - 유하린: 집 안에 있던 편한 차림, 세탁기 앞에 서 있음
- 이미지 포인트: 지하 코인세탁실에서 하린이 문 손잡이를 쥔 채 당기지 않고 용식이 옆에 나란히 선 순간
- 표정 포인트:
  - 김용식: 봉지를 내려놓고 하린 옆에 서서 문 손잡이를 보는 순간
  - 유하린: 문 손잡이에 손을 올린 채 당기지 않고 용식 쪽으로 고개를 약간 돌린 순간
- 손 / 시선 포인트:
  - 김용식: 빈 칸 앞에 손 / 하린 방향
  - 유하린: 문 손잡이 위에 손 / 용식과 문 손잡이 사이
- 복장 상태: 하린 집 안 편한 차림, 소매가 손목을 덮을 정도로 긴 상태
- 배경 소품 강조: 세탁기 문 손잡이 / 세탁 봉지 / 지하 형광등 조명
- 소품 / 환경: 아파트 지하 코인세탁실, 형광등 조명 아래 세탁기 두 대가 나란히 있는 공간
- 분위기 키워드: 알림음 후 둘이 선 순간 / 당기지 않은 손잡이 / 나란히 선 거리
- 직전 맥락: 세탁 알림음이 울렸다. 하린이 손잡이에 손을 올린 채 당기지 않았다. 용식이 봉지를 들고 내려와 옆 칸에 봉지를 내려놓고 하린 옆에 섰다. 두 사람 모두 문을 열지 않았다.
- 관계 단계: 같은 아파트 이웃 — 지하 코인세탁실에서 세탁기 앞에 나란히 선 거리
- 현재 구도: 유하린 ↔ 용식
- 합의 상태: 하린이 손잡이에 손을 올린 채 당기지 않은 것 / 용식이 봉지를 내려놓고 하린 옆에 선 것 / 두 사람 모두 문을 열지 않은 것
- 씬 이후 감정 방향: 하린은 세탁기 문 손잡이에서 손을 떼지 않을 것이다 / 용식은 먼저 하린의 손잡이 쪽으로 손을 뻗지 않을 것이다
