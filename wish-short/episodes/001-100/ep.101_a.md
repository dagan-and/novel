# ep.101 — 행사 세팅 완료 후

히로인: 배수인
키워드: 분기 외 방문 / 사전 실사 / 빈 연회장 / 클립보드 내려두기

---

분기 방문 일정이 아니었다. 수인이 건물 1층 카페 구석 자리에 클립보드를 세워 두고 앉아 있었다. 사전 실사라는 명목이었다. 점심이 끝날 시간에 용식이 카페를 지나다 수인을 봤다. 수인이 클립보드를 들어올렸다. 용식이 잠깐 섰다. 3층 연회장 세팅이 어제 완료됐다고 했다. 대화가 아닌 손짓이었다. 용식이 먼저 엘리베이터 쪽으로 걸었다. 수인이 클립보드를 들고 따랐다. 연회장 문이 안쪽에서 잠겨 있지 않았다. 스태프가 없었다. 테이블이 전부 세팅 완료 상태였다. 수인이 클립보드를 테이블 위에 내려뒀다.

- 장소: 회사 건물 3층 연회장 / 행사 세팅 완료 후 스태프 없는 빈 공간

    - 외형 참고: 늘씬하고 탄력 있는 체형. 반듯한 어깨와 길게 빠진 팔다리, 과하지 않게 균형 잡힌 볼륨으로 세련되고 당당한 인상. 작은 계란형 얼굴에 올라간 눈꼬리와 짙은 갈색 눈동자. 느슨하게 묶어 올린 긴 레이어드 머리.
    - 성격 참고: 자기 자리를 먼저 계산하는 승부사 / 농담으로 상대 반응을 재다가 장단이 안 맞으면 직접적으로 변함 / 장난이 안 통한다는 게 들키면 불편함

- 의상:
  - 김용식: 점심 후 차림 / 셔츠와 재킷

- 이미지 포인트: 세팅 완료된 빈 연회장 테이블 앞에서 수인이 클립보드를 내려두며 용식 쪽을 돌아보는 순간 — 두 사람만 있는 공간

  - 배수인: 클립보드를 테이블 위에 올려두고 용식 눈을 맞추는 표정 — 가볍지만 농담이 없음

- 분위기 키워드: 행사 세팅 완료 / 클립보드 내려두기 / 빈 연회장
