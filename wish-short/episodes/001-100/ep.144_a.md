# ep.144 — 밤 골목 모퉁이, 코르크 스크루, 덮힌 스케치북

히로인: 이하은 × 한서진 (다인씬)
키워드: 밤 골목 모퉁이 / 코르크 스크루 / 덮힌 스케치북 / 가로등 하나

---

밤 열한 시였다. 이하은이 카페 문을 닫았다. 스케치북을 먼저 덮고 가방에 넣었다. 골목으로 나왔다. 와인바 쪽 골목 안에서 발소리가 났다. 한서진이 코르크 스크루를 손에 쥔 채 걸어나왔다. 두 사람이 골목 모퉁이에서 마주쳤다. 서진이 먼저 멈췄다. 하은이 가방 끈을 고쳐 잡았다. 반대편 골목 어둠 속에서 발소리가 들렸다. 용식이 골목으로 들어왔다. 세 사람이 골목 모퉁이에 있었다. 서진이 코르크 스크루를 손에서 놓지 않았다. 골목 가로등 하나만 켜진 상태였다.

  - 이하은: 카페 마감 후 스케치북을 먼저 덮고 나와 골목 모퉁이에서 멈춰 있다

    - 성격 참고: 겉으로는 냉정하고 독립적이지만 예상 밖의 말 앞에서 무너지는 타입 / 좋아하는 사람 앞에서 자기도 모르게 대화를 먼저 이어 간다
    - 남자친구 유무: 있음 — 성인씬 작성 시 배신·죄책감·욕망 충돌을 긴장 맥락으로 활용한다
  - 한서진: 와인바 마감 후 코르크 스크루를 손에 쥔 채 나와 골목 모퉁이에서 멈춰 있다
    - 누적 성인씬 횟수: 5회
    - 외형 참고: 세련된 단발 스타일. 작은 계란형 얼굴에 여우상 눈매. 균형미가 돋보이는 볼륨과 반듯한 어깨. 웃고 있어도 빈틈을 보이지 않는 인상.
    - 성격 참고: 자신감 있고 현실적이지만 사랑에는 서툰 타입 / 예상 밖의 말 앞에서 잠시 굳는 순간 감추고 있던 서투름이 드러난다
    - 남자친구 유무: 있음 — 성인씬 작성 시 배신·죄책감·욕망 충돌을 긴장 맥락으로 활용한다
- 두 히로인 관계: 같은 동네 생활권의 카페·와인바 종사자. 골목에서 마주치는 사이. 서로 이름을 알고 있다.
