# ep.111 — 야근, 탕비실, 내려놓은 머그컵

히로인: 임세라
키워드: 야근 / 탕비실 / 머그컵 / 종이컵 두 개

---

야근이 두 시간째였다. 용식은 화면 하단의 저장 버튼을 눌렀다가 손을 뗐다. 보고서 초안 수정은 내일 아침으로 밀었다. 탕비실로 물을 받으러 갔다. 탕비실 문이 반쯤 열려 있었다. 세라가 먼저 서 있었다. 손에 머그컵이 있었다. 선반 위에는 종이컵 두 개가 나란히 놓여 있었다. 용식이 들어갔다. 세라가 머그컵을 선반 모서리에 내려놓았다. 두 손이 비었다. 수도꼭지를 틀었다. 세라가 선반 모서리에 손을 올린 채 서 있었다. 두 사람 사이에 종이컵 두 개가 있었다. 탕비실 문이 뒤로 밀려 닫혔다.

## [성인씬 #10 - ep.111]

- 장소: 야근 후 탕비실 / 선반 앞
- 등장인물:
  - 김용식: 보고서 수정을 내일로 밀고 물을 받으러 탕비실에 온 상태 / 종이컵 옆에 서서 세라 쪽을 보는 자세
    - 누적 성인씬 횟수: 131회
  - 임세라: 머그컵을 들고 탕비실에 먼저 나타난 상태 / 종이컵 두 개를 선반에 미리 올려두고 머그컵을 내려놓은 채 빈 손으로 서 있음
    - 누적 성인씬 횟수: 10회
    - 외형 참고: 키 166~169cm 정도의 늘씬한 체형. 전체적으로 마른 편이지만 지나치게 왜소하지는 않다. 어깨선은 좁고 부드러우며 목선이 길어 상체가 가녀려 보인다. 밝은 초콜릿 브라운 긴 머리, C컬 끝처리. 야근 끝 무렵 머리카락 몇 올이 목선 옆으로 흘러내린 상태.
    - 성격 참고: 여러 사람에게 여지를 주는 방식이 몸에 배어 있지만 그것이 용식에게는 잘 통하지 않는다는 것을 알고 있다 / 머그컵을 들고 탕비실에 먼저 나타난 것이 명분 / 종이컵을 미리 올려두고 머그컵을 내려놓은 것이 실제 신호 / 빈 손으로 선반 모서리에 서 있는 것이 남겠다는 뜻
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 야근 중 셔츠, 소매 약간 걷어 올림
  - 임세라: 블라우스, 슬랙스. 머그컵을 선반에 내려둔 후 빈 손 상태.
- 이미지 포인트: 선반 모서리에 내려놓인 머그컵 하나, 나란히 놓인 종이컵 두 개, 선반에 손을 올린 세라, 탕비실 안 두 사람
- 표정 포인트:
  - 김용식: 종이컵을 집으려다 멈춘 표정, 세라의 빈 손 쪽을 보고 있음
  - 임세라: 선반 쪽에서 시선을 내리다 용식을 정면으로 보는 순간, 입꼬리가 평소보다 낮아진 채
- 손 / 시선 포인트:
  - 김용식: 컵 위에 손 / 세라의 빈 손 쪽으로 시선
  - 임세라: 선반 모서리에 손 / 용식 얼굴을 정면으로
- 복장 상태: 세라의 블라우스 목선 단추 위쪽이 야근 끝 무렵 약간 풀린 상태, 용식 소매 걷어 올림
- 배경 소품 강조: 선반 위 머그컵 / 종이컵 두 개 / 탕비실 선반 모서리
- 소품 / 환경: 탕비실 형광등이 반만 켜진 상태, 수도꼭지에서 물 소리가 멈춘 공간
- 분위기 키워드: 야근 끝 정적 / 먼저 와서 기다린 것 / 내려놓은 머그컵
- 직전 맥락: 세라가 머그컵을 들고 탕비실에 먼저 나타났다. 종이컵 두 개를 선반에 미리 올려뒀다. 용식이 들어왔다. 머그컵을 선반에 내려놓고 빈 손으로 서 있었다.
- 관계 단계: 다른 팀 직장 동료 — 업무 명분이 이미 사라진 거리
- 현재 구도: 임세라 ↔ 용식
- 합의 상태: 세라가 머그컵을 들고 탕비실에 먼저 나타난 것 / 종이컵을 선반에 미리 올려두고 머그컵을 내려놓은 것 / 용식이 탕비실 문을 닫은 것
- 씬 이후 감정 방향: 세라는 머그컵을 탕비실 선반에 두고 나갈 것이다 / 용식은 물컵을 집지 않을 것이다
