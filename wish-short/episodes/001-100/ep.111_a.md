# ep.111 — 야근, 탕비실, 닫힌 노트

히로인: 정다은
키워드: 야근 / 탕비실 / 닫힌 노트 / 검은 펜 뚜껑

---

야근이 두 시간째였다. 용식은 화면 하단의 저장 버튼을 눌렀다가 손을 뗐다. 보고서 초안 수정은 내일 아침으로 밀었다. 탕비실로 물을 받으러 갔다. 탕비실 문이 반쯤 열려 있었다. 다은이 먼저 서 있었다. 손에 노트와 검은 펜이 있었다. 선반 위에는 종이컵 두 개가 놓여 있었다. 용식이 들어갔다. 다은이 노트를 선반 모서리에 내려놓았다. 닫힌 채였다. 검은 펜 뚜껑이 열려 있었다. 수도꼭지를 틀었다. 다은이 선반 모서리에 손을 올린 채 서 있었다. 두 사람 사이에 종이컵 두 개가 있었다.

## [성인씬 #1 - ep.111]

- 장소: 야근 후 탕비실 / 선반 앞
- 등장인물:
  - 김용식: 보고서 수정을 내일로 밀고 물을 받으러 탕비실에 온 상태 / 종이컵 옆에 서서 다은 쪽을 보는 자세
    - 누적 성인씬 횟수: 131회
  - 정다은: 노트와 검은 펜을 들고 먼저 탕비실에 와 있던 상태 / 노트를 선반에 내려놓고 펜을 쥔 채 서 있음
    - 누적 성인씬 횟수: 9회
    - 외형 참고: 키는 큰 편이고 전체적으로 길고 반듯한 실루엣이다. 어깨선이 얇게 곧고 허리선이 깔끔하게 잡혀 있어, 단정한 셔츠와 슬랙스 차림에서 더 눈에 띈다. 야근 끝 무렵 귀 옆으로 짧은 머리카락이 조금 흘러내린 상태, 흑갈색 머리를 낮게 묶은 채.
    - 성격 참고: 침착하고 정확하며 애매한 관계를 싫어함 / 좋아하는 사람 앞에서 기록하거나 정리하려던 손을 멈추는 패턴 / 명분 없이 노트를 들고 탕비실에 나타난 것 자체가 감정의 노출
    - 남자친구 유무: 있음
- 의상:
  - 김용식: 야근 중 셔츠, 소매 약간 걷어 올림
  - 정다은: 흰 셔츠, 슬랙스, 검은 펜
- 이미지 포인트: 선반 모서리에 닫힌 노트 하나, 뚜껑 열린 검은 펜, 종이컵 두 개가 나란히 놓인 순간 — 탕비실에 두 사람만 있다
- 표정 포인트:
  - 김용식: 종이컵을 집으려다 멈춘 표정, 다은의 손 쪽을 보고 있음
  - 정다은: 노트에서 시선을 내리다 용식을 정면으로 보는 순간, 입꼬리가 풀리지 않은 채
- 손 / 시선 포인트:
  - 김용식: 컵 위에 손 / 다은의 펜 쪽으로 시선
  - 정다은: 선반 모서리에 손 / 용식 얼굴을 정면으로
- 복장 상태: 다은의 셔츠 목선 단추 위쪽이 야근 끝 무렵 약간 풀린 상태, 용식 소매 걷어 올림
- 배경 소품 강조: 닫힌 노트 / 뚜껑 열린 검은 펜 / 종이컵 두 개
- 소품 / 환경: 탕비실 형광등이 반만 켜진 상태, 수도꼭지에서 물 소리가 멈춘 공간
- 분위기 키워드: 야근 끝 정적 / 닫힌 명분 / 두고 온 것들
- 직전 맥락: 다은이 노트를 들고 탕비실에 먼저 나타났다. 쓸 것이 없는데 노트를 들고 왔다. 검은 펜 뚜껑은 열려 있었다.
- 관계 단계: 같은 회사 직장 동료 — 업무 명분이 이미 사라진 거리
- 현재 구도: 정다은 ↔ 용식
- 합의 상태: 다은이 명분 없이 탕비실에 먼저 나타난 것 / 노트를 선반에 내려놓고 집지 않은 것 / 용식이 탕비실 문을 등으로 밀어 닫은 것
- 씬 이후 감정 방향: 다은은 노트를 탕비실 선반에 두고 나갈 것이다 / 용식은 물컵을 집지 않을 것이다
