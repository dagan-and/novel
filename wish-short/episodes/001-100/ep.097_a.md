# ep.097 — 새벽 두 시 창고

히로인: 서나윤
키워드: 야간 교대 끝 / 폐기 도시락 / 재고 창고 / 새벽 두 시

---

교대 인수인계까지 한 시간이 남아 있었다. 나윤이 폐기 목록 마지막 항목을 체크하다 손을 멈췄다. 유리문 쪽에서 재킷 소매가 왔다. 용식이었다. 밤 두 시에 들어오는 손님은 거의 없었다. 카운터 안쪽 냉장고에 데워 둔 도시락이 있었다. 나윤은 스캐너를 들지 않았다. 폐기 처리할 도시락 봉지를 카운터 위에 올렸다. 한 개였다. 용식이 카운터 모서리에 팔을 올리고 섰다. 나윤은 계산 버튼을 누르지 않았다. 뒤쪽 재고 창고로 향하는 커튼이 반쯤 열려 있었다. 나윤이 먼저 도시락 봉지를 들고 커튼 안으로 걸었다.

---

## [성인씬 #1 - ep.097]

- 장소: 편의점 야간 재고 창고 / 커튼 안쪽
- 등장인물:
  - 김용식: 야간 편의점 카운터에서 봉지 옆에 팔을 올린 / 나윤이 창고 쪽으로 먼저 걸어가자 커튼 안으로 따라 들어온 상태
    - 누적 성인씬 횟수: 96회
  - 서나윤: 폐기 도시락 봉지를 들고 창고로 먼저 걸어 들어간 / 스캐너를 잡지 않았고 계산 버튼을 누르지 않은 채
    - 누적 성인씬 횟수: 8회
    - 외형 참고: 균형 잡힌 키에 운동으로 다져진 탄탄한 슬림 체형. 시원한 어깨선과 자연스럽게 조여드는 허리, 길게 뻗은 다리선. 얇은 옷차림에서도 탄력과 긴장감이 느껴지는 몸. 고양이상 눈매에 짙은 갈색 눈동자, 높게 묶은 하이 포니테일 아래로 애시톤 머리카락이 길게 흘러내린다.
    - 성격 참고: 승부욕 강함 / 감정이 확실해지면 먼저 움직이고 먼저 자리를 만드는 타입 / 지고 지나가는 걸 못 견딤
    - 남자친구 유무: 있음
- 의상:
  - 김용식: 야간 외출용 재킷 / 셔츠
  - 서나윤: 편의점 유니폼 흰 셔츠 위 조끼 형태 근무복
- 이미지 포인트: 창고 커튼 안에서 나윤이 도시락 봉지를 선반에 올리다 돌아보는 순간 용식이 바로 뒤에 서 있는 거리
- 표정 포인트:
  - 김용식: 봉지를 올리는 나윤 등을 보다가 돌아보자 눈을 맞추는 표정 — 피하지 않음
  - 서나윤: 몸을 돌리다 용식이 바로 뒤에 있다는 걸 확인하는 순간 — 눈이 굳지 않고 직선으로 맞춤
- 손 / 시선 포인트:
  - 김용식: 선반 옆 벽에 얹은 손 / 나윤 얼굴
  - 서나윤: 선반에서 손을 뗀 채 / 용식 얼굴 정면
- 복장 상태: 나윤 유니폼 조끼 앞 단추 위 두 개 느슨한 상태 / 용식 재킷이 창고 선반 모서리에 걸린 상태
- 배경 소품 강조: 재고 창고 선반 / 폐기 도시락 봉지 / 반쯤 열린 커튼
- 소품 / 환경: 창고 내부 형광등 / 커튼 너머 카운터 빛 / 새벽 두 시의 빈 편의점
- 분위기 키워드: 새벽 창고 / 계산 없는 이동 / 먼저 들어간 쪽
- 직전 맥락: 나윤이 스캐너를 잡지 않고 폐기 봉지를 카운터에 올렸다 / 계산 버튼 없이 창고로 먼저 걸었다
- 관계 단계: 편의점 야간 아르바이트생과 단골 손님 / 새벽 두 시 카운터 안팎
- 현재 구도: 서나윤 ↔ 용식
- 합의 상태: 스캐너를 잡지 않은 나윤 / 창고로 먼저 걸어간 나윤 / 커튼 안으로 따라 들어온 용식 / 도시락 봉지를 내려놓고 몸을 돌린 나윤
- 씬 이후 감정 방향: 나윤은 폐기 목록 마지막 항목을 체크하지 않을 것이다 / 용식은 창고 커튼을 닫고 나갈 때 나윤 쪽을 한 번 더 볼 것이다
