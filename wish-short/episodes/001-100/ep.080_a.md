# ep.080 — 외근 복귀, 에너지바 두 개, 건물 옆 골목

히로인: 이주희
키워드: 외근 복귀 / 에너지바 두 개 / 메신저 알림 무시 / 비상계단 입구

---

외근 후 걸어서 돌아오는 길이었다. 편의점 앞에서 주희가 먼저 들어갔다. 용식이 뒤따라 들어가려다 주희가 에너지바 두 개를 들고 나왔다. 포장을 뜯지 않은 것 하나를 용식 쪽으로 내밀었다. 받았다. 메신저 알림이 울렸다. 용식이 확인하지 않았다. 편의점 봉투를 주희가 들었다. 회사 건물 앞 정면 출입문 방향이었다가 주희가 걸음을 옆 골목 쪽으로 바꿨다. 건물 옆에 비상계단 입구가 있었다. 용식이 봉투를 넘겨받으려다 주희가 그냥 들고 골목 안으로 들어갔다. 에너지바 포장이 손에 있었다. 알림이 한 번 더 울렸다. 용식이 따라 꺾었다.

---

## [성인씬 #8 - ep.080]

- 장소: 회사 건물 옆 골목 비상계단 입구 → 비상계단 계단참
- 등장인물:
  - 김용식: 외근 복귀 후 편의점 들러 에너지바 받음 / 메신저 알림 무시하고 골목으로 따라 꺾는다
    - 누적 성인씬 횟수: 96회
  - 이주희: 에너지바 두 개를 사서 하나 건넨 뒤 / 정면 출입문 대신 건물 옆 골목으로 먼저 꺾는다
    - 누적 성인씬 횟수: 7회
    - 외형 참고: 골반에 비해 허리가 가늘고 잘록하게 파여 굴곡이 확실히 도드라지며, 살집 없이 마른 편인데도 엉덩이나 허벅지, 종아리로 이어지는 다리 라인이 길고 미끈하게 뻗어 있어 전체적으로 슬림하면서도 탄탄한 탄력이 고스란히 드러나는 몸매. 앞머리를 가볍게 내린 채 쇄골까지 오는 레이어드 컷, 외근 후반 머리카락이 약간 흐트러진 상태.
    - 성격 참고: 가만히 기다리면 불안해서 몸이 먼저 움직인다 / 설명 없이 골목을 먼저 꺾는 것이 사적인 결정임을 스스로도 나중에 인정한다 / 에너지바 두 개는 용식 몫까지 미리 계산한 것
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 외근 복귀 — 자켓, 서류 가방 / 에너지바 포장을 손에 든 채
  - 이주희: 외근 복귀 — 큼직한 캔버스백 / 편의점 봉투 들고 / 레이어드 컷이 귀 옆으로 약간 흐트러짐
- 이미지 포인트: 골목 입구에서 주희가 먼저 비상계단 쪽으로 방향을 바꾸는 순간 — 봉투를 건네지 않고 들고 들어가는 것
- 표정 포인트:
  - 김용식: 메신저 알림을 무시하고 골목으로 꺾는 순간의 눈빛 — 설명을 요구하지 않는다
  - 이주희: 봉투를 들고 골목 안으로 들어가면서 한 번도 뒤돌아보지 않는 표정
- 손 / 시선 포인트:
  - 김용식: 에너지바 포장을 쥔 손 / 골목 방향으로 꺾는 주희 뒤통수를 향한 시선
  - 이주희: 편의점 봉투를 든 손 / 비상계단 입구 방향을 보는 시선
- 복장 상태: 자켓 앞을 연 채 / 캔버스백 한 어깨에 걸친 상태 / 레이어드 컷 흐트러짐
- 배경 소품 강조: 에너지바 두 개 / 편의점 봉투 / 건물 옆 비상계단 입구 철문
- 소품 / 환경: 가을 오후 회사 건물 옆 골목 / 메신저 알림 울리는 중
- 분위기 키워드: 에너지바 두 개 / 먼저 꺾은 발걸음 / 설명 없는 방향 전환
- 직전 맥락: ep.070에서 예약 알림이 드러난 뒤 먼저 골목으로 걸었다 / 이번엔 에너지바가 먼저 나왔다
- 관계 단계: 같은 회사 직장 동료 / 외근 동선이 퇴근 방향으로 이어지는 거리
