# ep.113 — 새벽, 편의점 창고, 폐기 목록

히로인: 서나윤
키워드: 새벽 / 폐기 목록 / 창고 / 체크 안 된 항목

---

새벽 한 시 반이었다. 용식이 편의점 문을 밀었다. 나윤이 카운터 안쪽에서 폐기 목록을 확인하고 있었다. 스캐너를 잡지 않고 목록 마지막 줄을 봤다. 체크가 안 된 항목이 하나 있었다. 용식이 들어와 음료 쪽으로 걸었다. 나윤이 카운터 밖으로 나왔다. 창고 방향으로 걸으면서 목록을 들고 있었다. 용식이 음료를 집지 않고 나윤 쪽을 봤다. 나윤이 창고 커튼 앞에서 멈추지 않고 들어갔다. 목록을 선반 위에 올려놓았다. 용식이 창고 입구에 섰다. 커튼이 아직 열려 있었다.

- 장소: 편의점 재고 창고 / 선반 앞
- 등장인물:
  - 김용식: 새벽에 편의점 들러 음료 쪽으로 가다가 창고 앞에 선 상태 / 커튼 끝에 손을 얹은 자세

  - 서나윤: 폐기 목록 마지막 항목 체크 핑계로 창고에 들어간 상태 / 선반에 목록을 올려두고 돌아선 자세
    - 누적 성인씬 횟수: 9회
    - 외형 참고: 균형 잡힌 키에 운동으로 다져진 탄탄한 슬림 체형이라, 시원한 어깨선과 자연스럽게 조여드는 허리, 길게 뻗은 다리선이 먼저 눈에 들어온다. 높게 묶어 올린 하이 포니테일, 야간 근무복과 앞치마 차림.
    - 성격 참고: 좋아하는 사람 앞에서 먼저 움직이는 직진형 / 감정이 흔들리면 몸이 먼저 반응 / 목록에 실제로 체크할 것이 없다는 걸 알면서 창고로 들어간 것
    - 남자친구 유무: 있음
- 의상:
  - 김용식: 사복, 가방 없이 편의점 들어온 차림
  - 서나윤: 편의점 근무복, 앞치마
- 이미지 포인트: 창고 선반 앞에 나윤이 서 있고 목록이 선반 위에 놓인 채 창고 커튼이 열려 있는 순간
- 표정 포인트:
  - 김용식: 창고 커튼 앞에서 멈춘 채 나윤 쪽을 보고 있음
  - 서나윤: 선반에서 돌아서며 용식과 눈이 마주친 순간, 목록을 집지 않음
- 손 / 시선 포인트:
  - 김용식: 커튼 끝에 손 / 나윤 얼굴
  - 서나윤: 선반 옆에 손 / 용식 쪽으로 정면
- 복장 상태: 나윤 앞치마 끈 한쪽이 흘러내린 상태
- 배경 소품 강조: 폐기 목록 / 창고 선반 / 편의점 근무복 앞치마
- 소품 / 환경: 새벽 한 시 반 편의점 창고, 형광등 하나만 켜진 좁은 공간
- 분위기 키워드: 새벽 창고 / 미완성 목록 / 먼저 들어간 사람
- 직전 맥락: 나윤이 창고로 들어가면서 목록을 들고 갔다. 실제로 체크할 것이 없었다. 용식이 창고 입구에 섰고 커튼이 열려 있었다.

- 현재 구도: 서나윤 ↔ 용식
- 합의 상태: 나윤이 창고로 먼저 들어간 것 / 목록을 선반에 올리고 집지 않은 것 / 용식이 창고 커튼 앞에 서서 들어온 것
