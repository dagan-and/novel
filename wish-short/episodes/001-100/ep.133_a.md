# ep.133 — 비 오는 오후, 카페, 슬리브 메모

히로인: 박미현
키워드: 비 오는 오후 / 빈 카페 / 슬리브 메모 / 카운터 문

---

오후 두 시 반이었다. 빗소리가 유리창을 때렸다. 카페 안은 비어 있었다. 박미현이 카운터 안쪽 냉장고 유리를 닦고 있었다. 스태프는 식사를 나간 뒤였다. 카운터 위가 깔끔하게 비워진 상태였다. 문이 열렸다. 용식이 빗속을 뚫고 들어왔다. 한 손에 컵이 들려 있었다. 슬리브가 씌워진 채였다. 미현이 행주를 내려놓았다. 용식이 카운터 앞에 컵을 올렸다. 슬리브 안쪽에 무언가가 적혀 있었다. 미현이 컵을 카운터 안으로 끌었다. 카운터 문에 손이 갔다.

## [성인씬 #1 - ep.133]

- 장소: 카페 / 카운터 안쪽
- 등장인물:
  - 김용식: 비 오는 날 슬리브에 뭔가가 적힌 컵을 들고 들어온 상태 / 카운터 앞에서 서 있다
    - 누적 성인씬 횟수: 132회
  - 박미현: 슬리브를 읽고 카운터 문에 손을 뻗은 상태 / 행주가 카운터 안쪽에 내려져 있다
    - 누적 성인씬 횟수: 8회
    - 외형 참고: 슬림하고 여린 체형. 가는 어깨선과 잘록한 허리선이 먼저 눈에 들어오고, 가슴은 적당한 볼륨이라 전체적으로 청순하면서도 은근히 시선을 끄는 인상이다. 긴 생머리가 어깨 아래로 흘러내려 있고, 순한 눈빛이 슬리브를 훑는 순간 집중된 눈빛으로 바뀐다.
    - 성격 참고: 한 번 마음이 꽂히면 상대를 자기 안으로 끌어당기는 집착 / 기억받는 것보다 자신이 먼저 기억하는 쪽에 만족감을 느낌 / 용식과 관련된 감정에서 순한 표정 아래 독점욕이 본능처럼 드러남
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 빗속에서 젖은 캐주얼 셔츠, 겉옷
  - 박미현: 카페 에이프런, 흰 반팔 상의
- 이미지 포인트: 카운터 안에서 슬리브 메모를 읽고 카운터 문으로 손을 뻗은 미현과, 카운터 밖에서 그것을 바라보는 용식이 유리 카운터를 사이에 둔 순간
- 표정 포인트:
  - 김용식: 카운터 안의 미현 얼굴을 바라보며 대기하는 눈빛
  - 박미현: 슬리브를 읽다가 카운터 문으로 손이 가는 순간 시선이 올라감
- 손/시선 포인트:
  - 김용식: 카운터 위에 올린 손 / 미현 쪽
  - 박미현: 카운터 문 손잡이 / 용식 쪽으로 올라가는 시선
- 복장 상태: 미현 — 에이프런 끈이 허리에 느슨하게 묶여 있고, 카운터 문을 열면 끈이 당겨질 위치
- 배경 소품 강조: 슬리브 메모가 적힌 컵 / 빗소리 / 카운터 위에 내려진 행주
- 소품/환경: 비 오는 오후 빈 카페. 유리창에 빗소리. 카운터 위에 컵 하나
- 분위기 키워드: 비 오는 오후 / 슬리브 글씨 / 카운터 문
- 직전 맥락: 스태프가 나가고 비 오는 카페에 두 사람뿐이다. 용식이 슬리브가 씌워진 컵을 카운터에 올렸다. 미현이 읽고 문으로 손을 뻗었다
- 관계 단계: 카페 단골 손님과 아르바이트생 / 비 오는 날 반복 마주침 / 슬리브 메모가 핑계가 된 사이
- 현재 구도: 박미현 ↔ 용식
- 합의 상태: 용식이 슬리브에 뭔가를 써서 가져왔다 / 미현이 카운터 안으로 끌었다 / 카운터 문에 손이 갔다
- 씬 이후 감정 방향: 미현이 카운터 밖으로 나올 것이다 / 용식이 물러서지 않을 것이다
