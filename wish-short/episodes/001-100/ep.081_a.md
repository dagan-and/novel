# ep.081 — 분기 방문, 빈칸 하나, 마지막 엘리베이터

히로인: 배수인
키워드: 분기 방문 / 체크리스트 빈칸 / 마지막 엘리베이터 / 클립보드 돌리기

---

분기 방문 마지막 날 오후였다. 미팅룸이 끝난 뒤 수인이 클립보드를 겨드랑이에 끼고 복도로 나왔다. 엘리베이터 앞에 용식이 혼자 서 있었다. 수인이 버튼을 눌렀다. 불이 이미 켜져 있었다. 클립보드를 앞으로 돌렸다. 체크리스트 마지막 항목 하나가 빈칸이었다. 용식이 수인 쪽을 봤다. 수인이 클립보드를 다시 뒤로 돌렸다. 엘리베이터 문이 열렸다. 아무도 타고 있지 않았다. 수인이 먼저 들어갔다. 용식이 뒤따라 들어왔다. 문이 닫혔다. 수인이 로비 버튼을 눌렀다. 용식이 같은 층 버튼이 이미 눌린 것을 봤다. 내려가는 동안 두 사람 말고 아무것도 없었다.

## [성인씬 #2 - ep.081]

- 장소: 엘리베이터 → 건물 1층 로비 카페 안 / 마감 직전
- 등장인물:
  - 김용식: 미팅룸 종료 후 복도에서 수인을 마주침 / 같은 층 버튼이 눌린 엘리베이터에 함께 탄다
    - 누적 성인씬 횟수: 97회
  - 배수인: 체크리스트 빈칸 하나를 가린 채 엘리베이터에 먼저 들어감 / 클립보드를 뒤로 돌린 이유를 말하지 않는다
    - 누적 성인씬 횟수: 1회
    - 외형 참고: 늘씬하고 탄탄한 체형으로 반듯한 어깨와 길게 빠진 팔다리가 가만히 서 있어도 시선을 머물게 한다. 과하지 않은 균형 잡힌 볼륨. 작은 계란형 얼굴에 올라간 눈꼬리, 속쌍꺼풀, 짙은 갈색 눈동자. 긴 레이어드 머리를 느슨하게 묶어 올린 상태, 복도에서 빠른 걸음으로 나온 탓에 앞머리카락이 약간 흐트러져 있다.
    - 성격 참고: 장난처럼 툭 던지다가 감정이 걸리면 직선적으로 밀어붙이는 방식 / 장난이 안 통하는 순간 준비한 가벼움이 무너진다 / 클립보드 뒤로 돌리는 것이 먼저 흔들린 신호
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 오후 업무복 — 셔츠, 슬랙스
  - 배수인: 방문 업무복 — 재킷 + 슬랙스 / 클립보드를 겨드랑이에 낀 채 / 명함 지갑이 재킷 안주머니에 있음
- 이미지 포인트: 엘리베이터 안에서 내려가는 동안 클립보드를 뒤로 돌린 채 로비 버튼만 눌린 것을 확인하는 두 사람
- 표정 포인트:
  - 김용식: 같은 층 버튼이 이미 눌려 있다는 것을 알아챈 순간의 눈빛
  - 배수인: 클립보드를 뒤로 돌리고 정면 문을 보는 표정 — 빈칸 이야기를 꺼내지 않는다
- 손 / 시선 포인트:
  - 김용식: 버튼 위에서 멈춘 손 / 수인의 클립보드 방향을 향한 시선
  - 배수인: 클립보드를 겨드랑이 사이에서 뒤로 돌린 손 / 문이 닫히는 것을 보는 시선
- 복장 상태: 재킷 앞단 여밈 유지 / 흐트러진 앞머리카락
- 배경 소품 강조: 체크리스트 클립보드 / 엘리베이터 층수 표시 / 건물 1층 로비 카페
- 소품 / 환경: 엘리베이터 안 단둘 / 내려가는 층수
- 분위기 키워드: 빈칸 하나 / 클립보드 돌리기 / 내려가는 동안의 침묵
- 직전 맥락: ep.061에서 수인이 임소율과 용식 사이의 공기를 읽었다 — 이번엔 임소율 없이 단둘
- 관계 단계: 거래처 프리랜서 / 분기마다 방문하는 거리

- 씬 이후 감정 방향: 체크리스트 빈칸이 채워지는지 / 다음 분기 방문 날짜가 당겨지는지
