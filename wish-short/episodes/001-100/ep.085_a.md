# ep.085 — 새벽 편의점, 폐기 봉지, 스캐너 없이

히로인: 서나윤
키워드: 새벽 한 시 / 폐기 봉지 / 스캐너 잡지 않기 / 봉지 위에 얹은 손

---

새벽 한 시가 넘어 있었다. 편의점 안에 손님이 없었다. 나윤이 폐기 봉지를 카운터 위에 올려놓고 라벨을 확인하는 중이었다. 문이 열렸다. 용식이었다. 나윤이 봉지에서 손을 빼지 않았다. 용식이 카운터 쪽으로 왔다. 나윤이 봉지를 들어올리다 카운터 위에 그냥 내려뒀다. 스캐너를 잡지 않았다. 봉지 한쪽에 가격 스티커가 붙어 있었다. 계산이 시작된 것인지 아닌지 불분명했다. 용식이 봉지 옆에 손을 올렸다. 나윤이 스캐너 손잡이를 한 번 봤다가 카운터 위 봉지 쪽으로 시선을 옮겼다. 편의점 안 조명만 밝았다.

- 장소: 편의점 야간 카운터 → 카운터 밖 야간 테이블 / 폐기 봉지 정리 직전
- 등장인물:
  - 김용식: 새벽 한 시 넘어 편의점에 들어옴 / 봉지 옆에 손을 올리고 스캐너를 잡지 않는 나윤을 그냥 둔다
    - 누적 성인씬 횟수: 101회
  - 서나윤: 폐기 봉지 확인 중 스캐너를 잡지 않음 / 계산이 시작된 것인지 아닌지 분명히 하지 않는다
    - 누적 성인씬 횟수: 7회
    - 외형 참고: 균형 잡힌 키에 운동으로 다져진 탄탄한 슬림 체형으로 시원한 어깨선과 길게 뻗은 다리선이 눈에 들어온다. 고양이상 눈매에 짙은 갈색 눈동자가 날카롭고 또렷하다. 높게 묶은 하이 포니테일, 새벽 야간 교대 막바지라 포니테일 끝이 조금 흘러내린 상태.
    - 성격 참고: 감정이 확실해지면 먼저 선을 넘고 먼저 자리를 만들려 든다 / 스캐너를 잡지 않는 것이 먼저 움직인 것 / 봉지 위에 얹은 손을 확인하는 눈빛이 장난이 아님
    - 남자친구 유무: 있음
- 의상:
  - 김용식: 새벽 외출복 — 후드티, 가벼운 재킷
  - 서나윤: 편의점 알바 조끼 + 티셔츠 / 하이 포니테일이 끝부분 흘러내린 상태
- 이미지 포인트: 카운터 위 폐기 봉지 옆에 용식의 손이 올라간 순간 — 나윤이 스캐너를 잡지 않은 채 그것을 보는 눈빛
- 표정 포인트:
  - 김용식: 봉지 위에 손을 올리고 나윤의 시선이 어디로 가는지 확인하는 눈빛 — 장난이 아닌 것을 알면서 기다리는 얼굴
  - 서나윤: 스캐너를 한 번 보고 봉지로 시선을 옮기는 표정 — 먼저 정리하지 않기로 결정한 얼굴
- 손 / 시선 포인트:
  - 김용식: 봉지 옆 카운터 위에 얹은 손 / 나윤의 스캐너 방향 시선을 향한 눈빛
  - 서나윤: 봉지에서 뺀 뒤 카운터 위에 올린 손 / 용식의 손 위치를 향한 시선
- 복장 상태: 알바 조끼 앞섶 / 끝이 흘러내린 하이 포니테일
- 배경 소품 강조: 폐기 봉지 + 가격 스티커 / 카운터 위 스캐너 / 편의점 새벽 조명
- 소품 / 환경: 손님 없는 새벽 편의점 / 조명만 밝은 카운터

- 직전 맥락: ep.072에서 스캐너를 잡지 않고 데운 봉지 들고 카운터 밖으로 나왔다 — 이번엔 카운터 위에 봉지를 그냥 둔다
