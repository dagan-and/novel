# ep.163 — 가을 벤치, 낙엽, 교재

히로인: 이채영
키워드: 아파트 단지 벤치 / 전화가 끊김 / 낙엽 / 봉투 없는 손

10월 오후였다. 채영은 단지 내 벤치에 전공 교재를 펼쳐 놓고 앉아 있었다. 전화가 한 번 왔다가 끊겼다. 화면이 꺼졌다. 다시 보지 않았다. 교재 위로 낙엽이 한 장 내려왔다. 손으로 쓸어냈다. 손이 가볍게 움직이고 멈췄다. 용식이 귀갓길에 단지 안쪽 길을 지나다 채영을 봤다. 멈추지 않으려다 발이 먼저 멈춰버렸다. 채영이 고개를 들었다. 봉투가 없었다. 교재 위에 손이 올려진 채였다. 용식이 벤치 반대편 끝에 앉았다. 이름을 먼저 부르지 않았다. 낙엽이 또 한 장 내려왔다. 단지 안에 두 사람 외에는 아무도 없었다.

## [성인씬 #1 - ep.163]

- 장소: 아파트 단지 내 벤치 → 이채영 자취방 3층
- 등장인물:
  - 김용식: 귀갓길에 채영을 발견 후 멈춰 벤치 끝에 앉은 상태 / 이름을 먼저 부르지 않고 나란히 앉은 채
    - 누적 성인씬 횟수: 193회
  - 이채영: 전화가 끊긴 뒤 교재를 덮지 않은 채 벤치에 앉아 있다 용식과 마주친 상태 / 봉투 없이 나온 날
    - 누적 성인씬 횟수: 11회
    - 외형 참고: 매우 마른 슬림 체형. 어깨가 좁고 부드럽게 떨어지는 직선형 실루엣으로, 목이 길고 가늘어 상체가 더욱 늘씬해 보인다. 쇄골이 선명하게 드러날 정도로 지방이 적고, 팔과 손목 모두 매우 가늘다. 골격보다는 부드럽고 여성스러운 라인이 먼저 눈에 들어오는 체형이다. 가을 야외에 앉아 뺨이 약간 붉고, 흑발 긴 생머리가 바람에 살짝 흐트러진 상태.
    - 성격 참고: 감정 표현이 절제됨 / 반응이 0.5박자 늦음 / 마음이 있어도 먼저 행동하지 못함 / 봉투 없이 나온 것이 오늘의 첫 다른 선택
    - 남자친구 유무: 있음 — 벤치에 앉기 직전 전화가 끊겼다. 배신감과 욕망의 충돌을 긴장 맥락으로 활용.
- 의상:
  - 김용식: 회사 귀갓길 복장, 셔츠에 재킷을 걸친 상태
  - 이채영: 긴 카디건에 이너 티셔츠, 전공 교재를 들고 나온 복장 / 흑발 생머리를 내려뜨린 상태
- 이미지 포인트: 낙엽이 내려앉은 교재를 덮지 않은 채 채영이 봉투 없는 손을 무릎 위에 올리고 용식 쪽을 바라보는 순간
- 표정 포인트:
  - 김용식: 낙엽 한 장을 보다가 채영 쪽으로 시선이 이동해 멈춘 표정
  - 이채영: 전화가 끊긴 뒤 교재를 보다 용식과 눈이 마주쳤을 때 반응이 0.5박자 늦음 / 시선을 내리지 않고 마주친 채
- 손 / 시선 포인트:
  - 김용식: 손은 무릎 위 / 시선은 채영 쪽에서 내리지 않음
  - 이채영: 손은 교재 위에 올린 채 / 시선은 용식과 마주쳤다가 내리지 않음
- 복장 상태: 카디건이 어깨에서 약간 흘러내린 상태 / 교재가 무릎 위에 놓인 채 덮이지 않음
- 배경 소품 강조: 전공 교재, 낙엽, 아파트 단지 벤치
- 소품 / 환경: 가을 오후 단지 내 벤치, 낙엽이 하나씩 내려오는 조용한 단지 안
- 분위기 키워드: 정지된 오후 / 방금 끊긴 전화 / 봉투 없는 손
- 직전 맥락: 남자친구 전화가 끊기고 교재를 보다가 용식이 지나다 멈춤. 벤치 반대편 끝에 앉음.
- 관계 단계: 같은 아파트 위아래 층 이웃 / 이름과 얼굴을 서로 아는 단계
- 현재 구도: 이채영 ↔ 용식
- 합의 상태: 채영이 봉투 없이 나온 것이 오늘의 첫 다른 선택 / 용식이 멈추지 않으려다 멈춘 것 / 벤치 끝에 앉은 뒤 이름을 먼저 부르지 않은 것 / 교재를 덮지 않고 손을 무릎에 올린 채 용식 쪽을 본 것
- 씬 이후 감정 방향: 채영은 교재를 집어 들지 않을 것이다 / 용식은 먼저 일어서지 않을 것이다
