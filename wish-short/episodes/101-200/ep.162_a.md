# ep.162 — 야근, 빈 엘리베이터, 에코백

히로인: 임소율
키워드: 야근 / 빈 엘리베이터 / 편의점 봉투 두 개 / 층 버튼 아무것도 눌리지 않음

가을이 깊어진 건물은 9시가 넘으면 반쯤 비어 있었다. 소율은 기획팀 사무실에서 마지막으로 불을 껐다. 에코백을 어깨에 올렸다. 가방 안에는 편의점 봉투 두 개가 나란히 들어 있었다. 하나는 점심 전에 산 것이고, 하나는 퇴근 전에 사면서 손이 두 번 간 것이었다. 엘리베이터 앞에서 버튼을 누르고 기다렸다. 문이 열렸을 때 용식이 안쪽 벽에 기대 있었다. 서류 봉투를 옆구리에 낀 채였다. 소율이 들어갔다. 문이 닫혔다. 닫힌 뒤에야 층 버튼이 아무것도 눌리지 않았다는 걸 알아챘다. 용식이 먼저 움직이지 않았다. 소율도 버튼 쪽으로 손을 뻗지 않았다. 에코백 끈이 어깨에서 천천히 내려왔다.

  - 김용식: 야근 후 서류 봉투를 옆구리에 낀 채 벽에 기댄 상태 / 층 버튼을 누르지 않고 소율이 들어온 뒤 그대로 있음
    - 누적 성인씬 횟수: 192회
  - 임소율: 기획팀 야근 마감 직후 에코백을 어깨에서 내린 상태 / 버튼 쪽으로 손을 뻗지 않은 채 섬
    - 누적 성인씬 횟수: 8회
    - 외형 참고: 볼륨감 있으면서도 생기 있고 활동적인 인상을 주어 과하게 느껴지지 않는 체형. 균형 잡힌 어깨와 존재감 있는 볼륨. 야근 후 불 꺼진 층을 나온 직후라 S컬 웨이브 머리가 반쯤 흐트러지고 표정이 약간 풀려 있다.
    - 성격 참고: 겉으로 명랑하지만 속마음이 바로 드러남 / 용식 앞에서 말이 많아지다 갑자기 멈추는 패턴 / 밝게 굴다 어색하게 굳음
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 야근 후 셔츠 소매를 팔꿈치까지 접어 올린 상태, 서류 봉투를 옆구리에 낀 채
  - 임소율: 야근 후 블라우스, 에코백을 한쪽 어깨에서 내린 상태
- 이미지 포인트: 엘리베이터 문이 닫힌 뒤 층 버튼 하나도 눌리지 않은 상태에서 에코백 끈이 바닥 가까이 내려온 순간
- 표정 포인트:
  - 김용식: 버튼 패널 쪽을 보지 않고 소율 쪽으로 시선이 향한 채
  - 임소율: 버튼 쪽을 확인하다 용식과 눈이 마주쳤을 때 입이 반쯤 열림
- 손 / 시선 포인트:
  - 김용식: 손은 서류 봉투를 느슨하게 쥔 채 / 시선은 소율 방향에서 내리지 않음
  - 임소율: 손은 에코백 끈을 느슨하게 잡은 채 / 시선은 버튼 패널과 용식 사이를 오가다 멈춤
- 복장 상태: 블라우스 깃이 야근 후 약간 흐트러짐 / 에코백 끈이 어깨에서 벗어나 손에만 걸린 상태
- 배경 소품 강조: 에코백, 편의점 봉투 두 개, 눌리지 않은 엘리베이터 층 버튼 패널
- 소품 / 환경: 야근 후 반쯤 꺼진 건물 엘리베이터 내부, 멈춰 있는 층 표시
- 분위기 키워드: 정지 / 들킬 것 같은 무게 / 밀폐된 공기
- 직전 맥락: 기획팀 야근 마감 직후, 엘리베이터에 탔을 때 용식이 먼저 안에 있었다. 문이 닫힌 뒤 아무도 버튼을 누르지 않음.
- 관계 단계: 같은 건물 다른 층 직장인 / 지하 식당과 엘리베이터에서 자주 마주쳐온 관계
- 현재 구도: 임소율 ↔ 용식
- 합의 상태: 소율이 버튼 쪽으로 손을 뻗지 않음 / 용식도 버튼을 누르지 않고 그대로 있음 / 에코백이 어깨에서 내려온 것이 소율의 결정 / 두 사람 모두 엘리베이터가 움직이지 않는다는 걸 알면서 멈춰 있음
- 씬 이후 감정 방향: 소율은 편의점 봉투 두 개를 꺼내지 못할 것이다 / 용식은 서류 봉투를 바닥에 내려놓을 것이다
