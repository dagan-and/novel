# ep.151 — 분기 방문일, 뒤집힌 클립보드, 팔꿈치

히로인: 배수인
키워드: 분기 방문일 / 뒤집힌 클립보드 / 팔꿈치 / 미팅룸

---

분기 방문일이었다. 배수인이 미팅룸에 먼저 들어와 있었다. 클립보드를 뒤집어 테이블 위에 내려뒀다. 팔꿈치를 테이블에 올린 채였다. 창문 쪽 의자에 가방을 두지 않았다. 미팅룸 문이 닫혀 있었다. 팔꿈치가 테이블에서 내려가지 않았다. 복도에서 발소리가 났다. 미팅룸 문이 열렸다. 용식이 들어왔다. 수인이 팔꿈치를 내리지 않은 채 방향을 봤다. 뒤집힌 클립보드가 테이블 위에 있었다.

---

## [성인씬 #1 - ep.151]

- 장소: 회사 건물 미팅룸
- 등장인물:
  - 김용식: 분기 방문일에 미팅룸에 들어왔다 / 맞은편에 섰다
    - 누적 성인씬 횟수: 150회
  - 배수인: 분기 방문일에 클립보드를 뒤집어 테이블에 내려두고 팔꿈치를 올린 채 먼저 기다렸다
    - 누적 성인씬 횟수: 5회
    - 외형 참고: 늘씬한 체형. 긴 레이어드 스타일 머리를 느슨하게 묶거나 내린 상태. 업무 복장.
    - 성격 참고: 가볍게 농담으로 흐름을 잡지만 용식이 휩쓸리지 않으면 준비한 가벼움이 무너진다
    - 남자친구 유무: 없음
- 의상:
  - 김용식: 업무 복장
  - 배수인: 업무 복장. 클립보드를 테이블에 뒤집어 둔 채 팔꿈치를 올리고 있다
- 이미지 포인트: 미팅룸에 뒤집힌 클립보드를 둔 채 팔꿈치를 올리고 먼저 기다리던 수인이 용식이 들어오자 팔꿈치를 내리지 않은 채 방향을 보는 순간
- 표정 포인트:
  - 김용식: 문을 열고 들어와 수인 방향을 본다 / 클립보드를 봤다가 수인을 본다
  - 배수인: 팔꿈치를 내리지 않고 용식 방향을 본다
- 손/시선 포인트:
  - 김용식: 문 손잡이에서 손을 뗀 채 / 수인, 클립보드 순서로 시선
  - 배수인: 테이블 위에 팔꿈치 / 용식 방향 시선
- 배경 소품 강조: 뒤집힌 클립보드 / 내려두지 않은 가방 / 닫혀 있다가 열린 미팅룸 문
- 소품/환경: 분기 방문일 회사 건물 미팅룸. 창문 쪽 의자에 아무것도 없다. 뒤집힌 클립보드가 테이블 중앙에 있다
- 분위기 키워드: 뒤집힌 클립보드 / 내려가지 않는 팔꿈치 / 먼저 기다린 미팅룸
- 직전 맥락: 수인이 클립보드를 뒤집어 테이블에 두고 팔꿈치를 올린 채 먼저 기다렸다. 복도에서 발소리가 났고 용식이 들어왔다. 팔꿈치를 내리지 않았다
- 관계 단계: 거래처 프리랜서 / 분기마다 반복된 미팅룸 방문 / 팔꿈치를 내리지 않고 기다린 첫 순간
- 현재 구도: 배수인 ↔ 용식
- 합의 상태: 클립보드가 뒤집혀 있다 / 팔꿈치를 내리지 않았다 / 용식이 들어와 멈췄다
- 씬 이후 감정 방향: 수인이 팔꿈치를 내릴지 / 용식이 맞은편 의자를 당겨 앉을지
