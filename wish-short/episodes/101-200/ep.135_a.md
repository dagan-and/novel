# ep.135 — 새벽 창고, 폐기 봉지, 커튼

히로인: 서나윤
키워드: 새벽 두 시 / 편의점 창고 / 폐기 봉지 / 커튼

---

새벽 두 시 이십 분이었다. 서나윤이 폐기 봉지를 들고 편의점 창고 커튼을 젖혔다. 봉지를 선반에 올렸다. 폐기 목록 맨 아래 칸에 체크했다. 야간 교대는 네 시에 끝났다. 봉지를 올리고 돌아섰을 때 창고 커튼 안에 용식이 서 있었다. 나윤이 먼저 움직이지 않았다. 봉지 손잡이가 선반 모서리에 걸려 있었다. 목록이 손에서 내려졌다. 나윤이 선반 가장자리를 잡았다. 용식이 커튼 안으로 반 발 들어와 있었다. 두 사람 사이에 봉지가 하나 있었다. 나윤이 선반에서 손을 떼지 않았다.

- 장소: 편의점 재고 창고 / 선반 앞
- 등장인물:
  - 김용식: 창고 커튼 안으로 반 발 들어와 선 상태 / 나윤이 돌아서는 것을 기다리고 있었다
    - 누적 성인씬 횟수: 134회
  - 서나윤: 폐기 봉지를 선반에 올리고 돌아선 채 선반 가장자리를 잡고 있다 / 먼저 움직이지 않은 상태
    - 누적 성인씬 횟수: 10회
    - 외형 참고: 균형 잡힌 키에 운동으로 다져진 탄탄한 슬림 체형이라, 시원한 어깨선과 자연스럽게 조여드는 허리, 길게 뻗은 다리선이 먼저 눈에 들어온다. 과한 굴곡보다 가볍고 단단한 근육선이 살아 있어, 얇은 옷차림에서도 몸을 쓰던 사람 특유의 탄력과 긴장감이 바로 느껴진다. 하이 포니테일이 돌아서는 순간 흔들리며 목선을 드러낸다.
    - 성격 참고: 감정이 확실해지는 순간 먼저 선을 넘고 먼저 자리를 만드는 승부욕 / 질투가 올라오면 차분하게 숨기기보다 몸이 먼저 움직이는 타입 / 결정적인 순간에 숨김없이 눈을 맞추며 직진
    - 남자친구 유무: 있음
- 의상:
  - 김용식: 야간 편의점 사복 (티셔츠, 바지)
  - 서나윤: 편의점 유니폼 조끼, 검은 긴바지, 하이 포니테일
- 이미지 포인트: 나윤이 선반 가장자리를 잡고 돌아선 채, 창고 커튼 안에 서 있는 용식과 폐기 봉지 하나를 사이에 두고 마주선 순간
- 표정 포인트:
  - 김용식: 나윤이 돌아선 것을 보고 한 발도 물러서지 않는다
  - 서나윤: 선반 가장자리를 잡은 채 용식 얼굴을 정면으로 올려다본다
- 손/시선 포인트:
  - 김용식: 커튼 가장자리를 한 손으로 잡음 / 나윤 얼굴 쪽
  - 서나윤: 선반 가장자리를 잡은 손 / 용식 얼굴 정면
- 복장 상태: 나윤 — 야간 유니폼 조끼가 앞쪽으로 약간 당겨진 상태. 포니테일이 돌아서는 순간 목선을 드러내며 흔들렸다
- 배경 소품 강조: 폐기 봉지 / 폐기 목록 / 창고 커튼
- 소품/환경: 새벽 두 시 편의점 재고 창고. 선반 위 형광등 하나만 켜져 있다. 커튼 너머 편의점 내부는 조용하다
- 분위기 키워드: 새벽 창고 / 커튼 안 / 봉지 하나
- 직전 맥락: 폐기 봉지를 선반에 올리고 목록을 체크했다. 돌아섰을 때 용식이 커튼 안에 서 있었다. 나윤이 선반에서 손을 떼지 않았다
- 관계 단계: 야간 편의점 아르바이트생과 단골 손님 / 새벽 반복 마주침 / 창고 안 단둘
