# AGENTS.md - 리부트 설정 이식 단편 세션 가이드

## 단편 구성 포맷 (최우선)

- **도입부와 성인씬 본문 모두 대화를 쓰지 않는다.** `[이름] "대사"` 형식, 문자 메시지, 단어 단위 발화 포함 일절 금지.
- 도입부는 상황 묘사와 직접 감정/감각 표현으로, 성인씬 본문은 행위·감각 묘사만으로 구성한다.
- 직접 감정 표현은 허용하되, 대사나 내적 독백 형식(`생각했다`, `느꼈다` 등의 추상적 표현)이 아닌 구체적 신체 반응과 행동으로 드러낸다.
- 세부 규칙은 `setting/단편구성포맷.md`를 최우선으로 따른다.

## 사용 원칙

- 각 단편은 한 편씩 끊어서 완결한다. 이전 단편의 사건, 관계 진도, 성인씬 횟수를 다음 단편의 확정 과거로 자동 연결하지 않는다.
- 단편 작업은 이 폴더 내부 문서만을 기준으로 진행한다.
- 시나리오 작성 요청이 있기 전까지는 `episodes/` 원고를 생성하지 않는다.
- 세부 작업 순서는 `setting/워크플로우.md`를 따른다.
- 단편 완성 후 반드시 `setting/워크플로우.md`의 **STEP 7**을 실행한다. 해당 히로인 캐릭터 파일의 `최근 변화`, `다음 압력`, `성인씬 기록`을 갱신한다.
- 단편 방향은 `planning/단편개요.md`를 최우선 참조한다.
- 성인씬이 필요한 경우 직접 본문 묘사를 쓰지 않고 `setting/성인씬작성규칙.md`의 성인씬 컨텍스트 구역을 사용한다.
- 캐릭터 개별 고정/가변 정보는 `characters/` 파일을 따른다.
- `characters/` 폴더 안의 모든 `.md` 파일(캐릭터양식.md, 김용식.md 제외)은 히로인으로 자동 인식한다. 새 히로인 추가 시 해당 파일만 생성하면 되며, 다른 파일을 수동으로 수정하지 않아도 된다.

## 단편 핵심 방향

- 중심 감정: 30살 평범한 직장인
- 시작 시점: 2020년 3월
- 주인공 상태: 큰 불만은 없지만 삶에서 중요한 결정을 자꾸 미루는 타입
- 기본 생활권: 카페, 편의점, 직장, 아파트, 출근버스, 자취방 동선
- 중심 관계: 단편마다 김용식과 중심 히로인 1명
- 기본 감정: 모든 히로인은 자기 생활권에서 김용식을 짝사랑하고 있다.
- 진행 원칙: 한 편 안의 장면 목표, 충돌, 감정 잔상을 우선
- 저장 원칙: 링크와 목록 관리를 위해 `episodes/001-100/ep.001_a.md` 같은 번호 기반 파일명으로 저장한다. 단, 번호는 정렬용 ID일 뿐 이어지는 서사를 뜻하지 않는다.

## 에피소드 폴더 접근 규칙 (필독)

> **신규 작업 세션에서 `episodes/` 폴더의 원고 파일을 읽지 않는다.**

### 이유

- 에피소드 수가 늘어날수록 읽기 비용이 선형으로 증가한다.
- 각 단편은 독립 완결이므로 이전 원고를 읽어도 확정 과거로 연결할 수 없다.
- 필요한 정보는 이미 아래 두 곳에 구조화되어 있다.

### 대신 참조할 것

| 필요한 정보 | 참조 위치 |
|---|---|
| 포맷·구조·문체 | `setting/에피소드샘플.md` |
| 전체 에피소드 현황·인물별 요약·성인씬 횟수 | `히스토리.md` |
| 히로인 개별 히스토리 (최근 변화·다음 압력·누적 성인씬) | `characters/[히로인이름].md` → `[가변]` 섹션 |
| 김용식 누적 성인씬 횟수 | `characters/김용식.md` |

### 신규 세션 시작 시 읽기 순서

1. `AGENTS.md` (현재 파일) — 운영 원칙·금지 사항
2. `setting/에피소드샘플.md` — 포맷·구조·문체 기준
3. `히스토리.md` — 전체 현황·인물별 요약·성인씬 횟수
4. `setting/단편구성포맷.md` — 도입부·성인씬 본문 규칙
5. `setting/성인씬작성규칙.md` — 컨텍스트 구역 포맷
6. `setting/워크플로우.md` — 작업 순서
7. `setting/확장공간카탈로그.md` — 기원 생활권 밖 공간·상황·동행 목록 (단편 개요 잡기 전 확인)
8. `planning/핵심컨셉.md` — 단편 엔진·히로인별 기본 축
9. `planning/단편개요.md` — 형식·핵심 전제·다인 씬 규칙
10. `planning/주인공설계.md` — 용식 장점·약점·장면 운용
11. `planning/주제와정서.md` — 정서 키워드·피해야 할 정서
12. `characters/김용식.md` — 용식 누적 횟수·고정 설정
13. `characters/[이번 히로인].md` — 개별 히스토리 (최근 변화·다음 압력·성인씬 기록)

### 예외 (사용자가 명시한 경우만)

- 사용자가 특정 에피소드 번호를 직접 지정하며 참조를 요청할 때
- 연속 단편 의뢰 등 사용자가 이전 원고 내용을 이어받도록 명시할 때

## 금지 사항

- **`episodes/` 폴더의 파일을 신규 작업 시작 시 자동으로 읽지 않는다.** 포맷 확인은 `setting/에피소드샘플.md`로 대체한다.
- 사용자가 명시하지 않은 `reunion-reboot/episodes/` 사건을 단편의 확정 과거로 가져오지 않는다.
- 이전에 작성한 독립 단편의 사건을 다음 단편의 확정 과거로 자동 연결하지 않는다.
- 장편의 장기 구조를 단편 안에서 설명으로 늘어놓지 않는다.
- 초반부터 관계를 완성된 상태로 시작하지 않는다.
- 상담, 회의, 감정 정리만으로 이야기를 끝내지 않는다.
- 새 인물을 단순 인원 보충용으로 투입하지 않는다.
- 용식이 모든 장면에서 정답만 주는 해결사로 고정되지 않게 한다.
- 성인씬은 AI가 직접 노골적 본문으로 작성하지 않고 컨텍스트 구역으로만 남긴다.
