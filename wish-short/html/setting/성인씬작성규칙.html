성인씬 작성 규칙

적용 범위

  • 이 문서는 성인 캐릭터 간 합의된 관계 진전이 필요할 때만 적용한다.
  • AI는 성인씬의 직접 본문 묘사를 작성하지 않고, 성인씬 컨텍스트와 구성 정보만 작성한다.
  • 작가가 직접 작성하는 성인씬 본문은 별도 원고 영역으로 둘 수 있다.
  • 작가 직접 작성 영역에서는 캐릭터 설정의 체형, 얼굴, 헤어, 분위기를 더 직접적으로 반영해도 된다.
  • AI가 작성하는 경우에는 본문 대신 성인씬 컨텍스트 구역만 삽입하고, 실제 묘사는 작가가 직접 작성한다.

기본 원칙

1. 모든 참여자는 성인으로만 설정한다.

외형 참고 반영 규칙

  • 성인씬 컨텍스트의 외형 참고는 반드시 해당 캐릭터 파일의 ### 외형 항목을 먼저 확인하고 작성한다.
  • 여성 캐릭터의 외형 참고는 캐릭터 파일의 체형 항목만 원문 그대로 가져온다.
  • 얼굴, 헤어, 분위기는 필요한 만큼 함께 반영하되, 매번 모든 항목을 길게 반복하지 않고 그 장면에서 가장 잘 보이는 특징을 1~2문장으로 압축한다.
  • 장면 상황에 맞춘 추가 설명이 필요하면, 체형 원문 뒤에 별도 문장으로 1~2줄만 덧붙인다.
  • 외형 참고는 캐릭터 설정의 체형을 바꾸거나 새로 만들지 않는다. 이미 정해진 체형과 분위기를 장면 상황에 맞게 다시 표현한다.
  • AI가 작성하는 컨텍스트에서는 수치, 노골적인 신체 부위 중심 묘사, 직접적인 성적 묘사는 쓰지 않는다. 실루엣, 옷차림, 자세, 손끝, 시선, 분위기 중심으로 쓴다.
  • 작가가 직접 작성하는 본문에서는 캐릭터 설정의 체형 정보를 더 직접적으로 사용할 수 있다. 단, 설정과 다른 체형으로 바꾸지 말고 기존 체형의 특징을 강화하는 방향으로만 쓴다.
  • 다인 씬에서는 참여 여성 각각의 체형 항목을 원문 그대로 가져오고, 얼굴/헤어/분위기는 서로 구분되는 특징만 짧게 압축한다. 예를 들어 미현은 부드럽고 여린 선, 나윤은 탄탄하고 날렵한 선, 다은은 길고 반듯한 실루엣처럼 캐릭터별 인상이 겹치지 않게 한다.

구역 포맷

씬 트리거 조건에 도달하면 묘사 없이 아래 형식만 삽입한다.

```text

[성인씬 #번호 - ep.번호]

  • 장소:
  • 등장인물:

- 김용식: (현재 감정/상태)

- 누적 성인씬 횟수: (이 씬 이전 기준 N회)

- [이름]: (현재 감정/상태)

- 누적 성인씬 횟수: (이 씬 이전 기준 N회)

- 외형 참고: 캐릭터 파일의 ### 외형 아래 체형 설정 원문을 그대로 가져온다. 얼굴/헤어/분위기는 장면에서 필요한 특징만 1~2문장으로 압축한다.

- 성격 참고: 성격 키워드 / 감정 표현 방식 / 김용식 앞에서의 반응 패턴

- 남자친구 유무 : 케릭터 파일에 남자친구 참고

- [이름2]: (현재 감정/상태) ← 다인 씬일 경우 추가

- 누적 성인씬 횟수: (이 씬 이전 기준 N회)

- 외형 참고: 캐릭터 파일의 ### 외형 아래 체형 설정 원문을 그대로 가져온다. 얼굴/헤어/분위기는 [이름]과 구분되는 특징만 1~2문장으로 압축한다.

- 성격 참고: 성격 키워드 / 감정 표현 방식 / 김용식 앞에서의 반응 패턴

- 남자친구 유무 : 케릭터 파일에 남자친구 참고

  • 의상:

- 김용식: (씬 진입 시점 착용 의상)

- [이름]: (씬 진입 시점 착용 의상)

- [이름2]: (다인 씬일 경우 추가)

  • 이미지 포인트: (서로 가까워진 채 감정을 확인하는 핵심 순간 1개)
  • 표정 포인트:

- 김용식:

- [이름]:

- [이름2]: (다인 씬일 경우 추가)

  • 손 / 시선 포인트:

- 김용식:

- [이름]:

- [이름2]: (다인 씬일 경우 추가)

  • 복장 상태: (과한 노출 묘사 없이 소매, 목선, 셔츠 단추, 앞치마 등 흐름만 간단히)
  • 배경 소품 강조: (이 장면이 누구의 생활권인지 드러나는 소품 1~3개)
  • 소품 / 환경:
  • 분위기 키워드:
  • 직전 맥락:
  • 관계 단계:
  • 현재 구도: ([이름] ↔ 용식 / [이름2] ↔ 용식 / [이름] ↔ [이름2])
  • 합의 상태: (누가 먼저 열었는지 / 누가 망설이는지 / 어디까지 합의됐는지)
  • 씬 이후 감정 방향:
  • [sex]

```

운영 규칙

  • AI가 작성하는 성인씬 컨텍스트 구역 내부에는 직접적인 성적 묘사를 쓰지 않는다.
  • 작가 직접 작성 본문이 필요한 경우, 컨텍스트 구역과 분리된 별도 원고 영역에 작성한다.
  • 태그는 성인씬 구역 말미에만 쓴다.
  • 성인씬 컨텍스트가 포함된 에피소드는 _a 파일로 저장한다.
  • 같은 번호의 일반 파일과 _a 파일을 동시에 만들지 않는다.
  • 구역 뒤 본문에서 "씬 이후", "장면이 끝나고" 같은 메타 표현을 쓰지 않는다.
  • 다음 문장은 인물의 행동, 호흡, 물건, 공간의 변화로 바로 이어 간다.
