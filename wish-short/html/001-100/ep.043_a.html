ep.043 — 열쇠, 엘리베이터, 봉투

히로인: 이채영

키워드: 귀가 시간 겹침 / 엘리베이터 단둘 / 현관 앞 열쇠 / 봉투

* * *

저녁 여덟 시. 엘리베이터 앞에 이채영이 먼저 와 있었다. 편의점 봉투를 왼손에 들고 버튼을 누른 상태. 층수를 올려다보고 있었다. 형광등이 뒤통수와 어깨선에 떨어졌다. 긴 흑발이 등 중간까지 내려와 있었다. 봉투에서 규칙적으로 비닐 소리가 났다. 손목을 돌리고 있었다.

용식이 계단에서 올라와 복도에 들어섰다. 이채영이 고개를 돌리는 데 반 박자가 걸렸다. 시선이 닿자 봉투 흔들기가 멈췄다. 표정을 정리하는 시간이 있었다. 용식은 엘리베이터 옆에 섰다. 거리는 팔 하나.

문이 열렸다.

안은 좁았다. 둘이 벽을 등지면 공간이 없을 정도. 이채영이 안쪽으로 들어가 모서리 근처에 섰다. 봉투를 두 손으로 쥐었다. 버튼을 누르고 손을 내렸다. 봉투 위에 얹혔다.

문이 닫혔다.

공간이 바뀌었다. 온도가 아니라 밀도처럼. 이채영은 거울을 보지 않았다. 봉투 글자를 내려다봤다. 흑발이 풀뱅과 만났다. 가늘고 긴 목이 기울었다. 손가락이 떨렸다.

4층에서 멈췄다.

문이 열리자 이채영이 움직였다. 5호실 방향으로 걸었다. 봉투가 다시 흔들렸다. 용식도 같은 방향. 복도에서 다섯 걸음 정도였다. 이채영의 현관이 먼저 나왔다. 멈추고 가방을 뒤졌다.

봉투를 바닥에 내려놨다. 가방을 열고 지갑 칸 아래를 훑었다. 열쇠가 나왔다. 들었다. 자물쇠 앞에서 손이 멈췄다.

용식이 옆을 지나치지 않았다.

이채영은 고개를 들지 않은 채 열쇠를 자물쇠에 가져갔다. 넣지 않았다. 손목이 돌아가지 않았다. 봉투가 바닥에서 반짝였다. 호흡만 들렸다.

몇 초가 지났다.

이채영이 고개만 돌렸다. 풀뱅 아래로 아몬드형 눈이 정면을 향했다. 시선이 용식에게 닿는 데 반 박자. 닿은 후 바로 거두지 않았다. 손에 떨림이 있었다.

문은 아직 잠겨 있었다.

* * *

- 장소: 4층 복도 / 이채영 현관 앞

- 등장인물:

- 김용식: 귀갓길 귀로, 지나치려다 멈춘 상태 / 이채영의 손이 멈추는 것을 보고 있었음

- 누적 성인씬 횟수: 37회

- 이채영: 열쇠를 손에 든 채 문을 열지 못하고 옆을 돌아본 상태 / 시선을 거두지 않음

- 누적 성인씬 횟수: 3회

- 외형 참고: 매우 마른 슬림 체형, 어깨 좁고 목 길고 가늘며 쇄골 선명, 팔과 손목 매우 가늘다. 작고 갸름한 계란형 얼굴, 풀뱅 앞머리에 가슴 아래까지 닿는 긴 생머리 흑발. 아몬드형 눈이 좁은 어깨 위로 옆을 향해 있다.

- 성격 참고: 반복 접촉에 꼼꼼하게 의미를 붙이는 타입 / 반응이 0.5박자 느리게 오는 편 / 감정을 먼저 말하지 않고 몸이 먼저 멈추는 방식으로 드러냄

- 의상:

- 김용식: 회사 귀가 복장 — 차콜 슬랙스, 흰 옥스퍼드 셔츠 위에 걸친 얇은 가을 재킷

- 이채영: 연한 크림색 니트 원피스, 무릎 아래 기장, 얇은 소재 / 편의점 봉투가 바닥에 놓여 있음

- 이미지 포인트: 열쇠가 자물쇠 앞에서 멈춘 채 이채영이 옆으로 고개를 돌리는 순간, 복도 등이 두 사람 사이에 수직으로 켜져 있다

- 표정 포인트:

- 김용식: 지나치려다 발이 멈춘 뒤의 표정 — 말이 나오기 직전의 조용함

- 이채영: 풀뱅 아래 아몬드형 눈이 용식에게 닿은 채 거두어지지 않음 / 입은 다물고 있음

- 손 / 시선 포인트:

- 김용식: 양손은 측면 — 아직 아무것도 잡지 않음 / 이채영의 손 위치를 보고 있음

- 이채영: 오른손이 열쇠를 쥔 채 자물쇠 앞 허공에 있음 / 시선은 용식의 얼굴에 고정

- 복장 상태: 니트 원피스 어깨선이 좁고 내려앉아 있음 / 가방 끈이 한쪽 어깨에서 내려져 있음

- 배경 소품 강조: 현관문 자물쇠 / 바닥에 놓인 편의점 봉투 / 복도 등

- 소품 / 환경: 4층 복도, 야간 형광등 하나, 엘리베이터 닫히는 소리가 막 끝난 직후

- 분위기 키워드: 멈춤 / 잠기지 않은 것 / 0.5박자

- 직전 맥락: 봉투를 바닥에 내려놓고 열쇠를 꺼낸 뒤 자물쇠 앞에서 손이 멈췄다 / 용식이 지나치지 않았다

- 관계 단계: 같은 아파트 위아래 층, 엘리베이터에서 귀가 시간이 겹치는 반복 접촉 / 아직 관계를 규정한 적 없음

- 현재 구도: 이채영 ↔ 용식

- 합의 상태: 열쇠를 자물쇠에 꽂지 않은 이채영 / 지나치지 않은 용식 / 시선이 거두어지지 않음 / 봉투가 바닥에 있고 현관은 아직 닫혀 있음

- 씬 이후 감정 방향: 이채영은 봉투를 다시 집어 들 것이다 / 용식은 재킷 안주머니에 손을 넣지 않을 것이다
